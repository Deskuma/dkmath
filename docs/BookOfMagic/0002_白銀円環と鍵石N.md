## 序文――魔導日刊紙が先に配った術式

この巻は、古代エジプトの円積問題を起点とする GeoGebra 作図を再解析し、その内部に現れた一点 $N$ を、DkMath の二成分平方質量と `q2_star` によって一意化するまでの記録である。

研究の順序は奇妙であった。先に DkMath Journal が、二成分平方質量

$$q2(x,y)=x^2+y^2$$

と、複素数型の積

$$(a,b)\star(x,y)=(ax-by,ay+bx)$$

に対する乗法則

$$q2(r\star z)=q2(r)q2(z)$$

を掲載した。その後、過去の GeoGebra 作図を開くと、まさにこの術式が、円周上の鍵点 $N$ を代数的に固定するための道具として待っていた。

作図が先に答えを描き、Journal が先に証明道具を配り、最後に両者が合流したのである。

本巻の中心命題は次である。

$$z=N\iff q2(z)=9\ \land\ z_x+z_y=4\ \land\ z_x<z_y$$

ここで

$$N=\left(2-\frac{\sqrt2}{2},\ 2+\frac{\sqrt2}{2}\right)$$

である。

この $N$ は単なる円周点ではない。真円の平方質量境界、八角近似辺、鏡像二候補を分ける向きの三条件が重なったとき、そこにしか存在できない鍵石である。

## 1. 史料の Core と作図再構成の Gap

リンド数学パピルス第50問題には、直径 $9$ の円形の土地について、直径の $1/9$ を引いて $8$ とし、その平方 $64$ を面積とする計算法が記録されている。現代式では、直径を $d$ として

$$A_{\mathrm{Egypt}}=\left(\frac{8d}{9}\right)^2$$

である。

この方法が与える円周率相当値は

$$\pi_{\mathrm{Egypt}}=4\left(\frac89\right)^2=\frac{256}{81}$$

となる。

ただし、史料が直接保証するのは「直径 $9$ から $8^2=64$ を得る計算法」までである。$3\times3$ 格子から角を切った八角形によって、この公式へ到達したという説明は、後世の再構成または仮説である。

本巻が証明するのは、古代エジプト人が実際に以下の鍵点作図を用いたという歴史命題ではない。本巻の対象は、研究者 D. が作成した GeoGebra ファイル `エジプト円の解析-v0.ggb` および `エジプト円の解析-v2.ggb` に含まれる数学構造である。

歴史的 Core と現代的再構成を混同せず、その間の Gap 自体を保存する。

## 2. 原始円陣――半径3と単位格子

作図の測定対象は、中心

$$A=(0,0)$$

半径 $3$ の円

$$c:\ x^2+y^2=9$$

である。

基準となる格子点は

$$B=(3,0),\quad C=(0,3),\quad D=(1,3),\quad F=(1,1),\quad G=(3,1)$$

である。

$C,D$ は高さ $3$ にある長さ $1$ の水平辺を成し、$D,G$ は $3\times3$ 格子の角を切る斜辺を成す。この斜辺の方程式は

$$DG:\ x+y=4$$

である。

測定円 $c$ と斜辺 $DG$ の交点のうち、$x<y$ 側の点が鍵石 $N$ である。

$$N=c\cap DG\cap\{(x,y)\mid x<y\}$$

作図上は一つの交点命令に見える。しかし代数的には、円周条件と直線条件の二つが交わるため、通常は鏡像二点が生じる。その二点から唯一の $N$ を選ぶ最後の条件が $x<y$ である。

## 3. 鍵石Nの座標

円周条件と斜辺条件を連立する。

$$x^2+y^2=9$$

$$x+y=4$$

二式から

$$(x+y)^2=x^2+2xy+y^2$$

であるため、

$$16=9+2xy$$

したがって

$$xy=\frac72$$

を得る。$x,y$ は二次方程式

$$t^2-4t+\frac72=0$$

の二根である。その判別式は

$$\Delta=16-14=2$$

なので、

$$\{x,y\}=\left\{2-\frac{\sqrt2}{2},\ 2+\frac{\sqrt2}{2}\right\}$$

となる。向き条件 $x<y$ により、

$$N=\left(2-\frac{\sqrt2}{2},\ 2+\frac{\sqrt2}{2}\right)$$

が唯一に定まる。

ここで $\sqrt2$ を最初から配置したのではない。整数半径 $3$、整数格子辺 $x+y=4$、平方距離 $q2=9$ の整合条件を解いた結果として、判別式から $\sqrt2$ が出現した。

## 4. `q2_star` による真円封鍵

### 4.1 二成分平方質量

ベクトル $z=(x,y)$ に対し、

$$q2(z)=x^2+y^2$$

とする。

さらに、

$$(a,b)\star(x,y)=(ax-by,ay+bx)$$

と定める。この積は複素数乗法と同じ形を持ち、

$$q2(r\star z)=q2(r)q2(z)$$

を満たす。

したがって $q2(r)=1$ なら、$r$ の作用は平方質量を保存する。

### 4.2 45度単位核

次の単位核を取る。

$$\kappa=\left(\frac1{\sqrt2},\frac1{\sqrt2}\right)$$

このとき

$$q2(\kappa)=1$$

であり、

$$\kappa\star(x,y)=\left(\frac{x-y}{\sqrt2},\frac{x+y}{\sqrt2}\right)$$

となる。

この作用は、通常の $(x,y)$ 座標を「差方向」と「和方向」へ回転する。

$$u=\frac{x-y}{\sqrt2}$$

$$v=\frac{x+y}{\sqrt2}$$

平方質量は保存されるので、

$$u^2+v^2=x^2+y^2$$

である。

### 4.3 八角辺を一点へ封じる

八角辺条件 $x+y=4$ は、回転後の座標では

$$v=2\sqrt2$$

となる。

円周条件 $q2(z)=9$ は

$$u^2+v^2=9$$

なので、

$$u^2+8=9$$

よって

$$u^2=1$$

である。この時点で候補は $u=1$ と $u=-1$ の鏡像二点へ圧縮される。

最後に $x<y$ を使うと $u<0$ であるから、

$$u=-1$$

しか残らない。したがって回転後の鍵石は

$$\kappa\star N=(-1,2\sqrt2)$$

であり、逆変換により

$$N=\left(2-\frac{\sqrt2}{2},\ 2+\frac{\sqrt2}{2}\right)$$

が唯一に復元される。

これが真円封鍵《Keystone N》の発動過程である。

```text
q2(z)=9
  └─ 平方質量境界を固定

x+y=4
  └─ 45度回転後の和方向を固定

q2_star
  └─ 差方向を ±1 の二候補へ圧縮

x<y
  └─ 鏡像の一方を消去

N
  └─ 唯一の鍵石
```

## 5. 鍵石唯一性定理

### 定理――Keystone N

実数平面上の点 $z=(x,y)$ が

$$q2(z)=9$$

$$x+y=4$$

$$x<y$$

を満たすならば、

$$z=N$$

である。

逆に $N$ は三条件をすべて満たす。したがって、

$$z=N\iff q2(z)=9\ \land\ x+y=4\ \land\ x<y$$

が成立する。

これは「一つの円と一つの直線は一点でしか交わらない」という命題ではない。円と直線は通常二点で交わる。唯一性は、平方質量境界、八角辺、向きの三条件を束ねた契約から生じる。

## 6. 三点円CDN――白銀円の召喚

鍵石 $N$ を得た後、三点

$$C=(0,3),\quad D=(1,3),\quad N=\left(2-\frac{\sqrt2}{2},\ 2+\frac{\sqrt2}{2}\right)$$

を通る円 $p$ を作る。三点は一直線上にないため、この円は一意である。

GeoGebra の作図命令は次である。

```text
Circle(C, D, N)
```

円 $p$ の方程式は

$$p:\ x^2+y^2-x-(3+\sqrt2)y+3\sqrt2=0$$

である。

中心は

$$R=\left(\frac12,\frac{3+\sqrt2}{2}\right)$$

半径平方は

$$\rho^2=\frac{3(2-\sqrt2)}2$$

である。

したがって面積は

$$\mathrm{Area}(p)=\frac{3\pi(2-\sqrt2)}2$$

となる。

本巻では、この $p$ を白銀円と呼ぶ。題名の「白銀円環」は、標準的な同心円環だけを意味しない。白銀円、測定円、単位核軌道が互いを拘束しながら閉じる循環構造全体を指す。

## 7. 整数3から根号√2を取り出す水平弦

円 $p$ と左の縦線 $x=0$ の交点を求める。

$$y^2-(3+\sqrt2)y+3\sqrt2=0$$

左辺は

$$(y-3)(y-\sqrt2)$$

と因数分解される。したがって交点は

$$C=(0,3)$$

および

$$T=(0,\sqrt2)$$

である。

同様に $x=1$ では、

$$D=(1,3)$$

および

$$O=(1,\sqrt2)$$

を得る。

よって白銀円は、二本の長さ $1$ の水平弦

$$\overline{CD}:\ y=3$$

$$\overline{TO}:\ y=\sqrt2$$

を同時に持つ。

```text
C=(0,3) ───────── D=(1,3)
   │                  │
   │     白銀円 p      │
   │                  │
T=(0,√2) ─────── O=(1,√2)
```

整数高さ $3$ と根号高さ $\sqrt2$ は、同じ長さの弦として一つの円に貫かれる。

これが副題「整数より出ずる根号を貫く八角円周魔法陣」の中心像である。

## 8. CDN円は鍵値を読み出す装置である

鍵石を一般化して、

$$N_t=\left(2-\frac t2,\ 2+\frac t2\right)$$

と置く。この点は常に

$$x+y=4$$

を満たす。

$t\ne2$ のとき、$C,D,N_t$ を通る三点円は一意に定まり、その方程式は

$$p_t:\ x^2+y^2-x-(3+t)y+3t=0$$

となる。

$x=0$ を代入すると、

$$y^2-(3+t)y+3t=(y-3)(y-t)$$

である。したがって、$p_t$ は高さ $3$ の弦と高さ $t$ の弦を接続する。

つまり三点円 `CDN_t` は、斜辺上の点 $N_t$ に埋め込まれた差成分 $t$ を、第二水平弦の高さとして読み出す装置である。

一方、$N_t$ の平方質量は

$$q2(N_t)=8+\frac{t^2}{2}$$

である。したがって

$$q2(N_t)=9\iff t^2=2$$

さらに $t>0$ を課せば、

$$q2(N_t)=9\iff t=\sqrt2$$

となる。

よって次の往復が成立する。

$$q2(N_t)=9\ \land\ t>0\iff N_t=N\iff p_t\text{ の第二水平弦が }y=\sqrt2$$

白銀円は根号を偶然表示する円ではない。平方質量境界に封じられた鍵値を、水平弦として外へ読み出す変換器である。

## 9. 「絶対的十分条件」が保証する範囲

ここで、真円性について過剰な結論を避ける。

鍵石唯一性定理が絶対的に保証するのは、次の命題である。

> 指定された平方質量境界 $q2=9$、指定された八角辺 $x+y=4$、指定された向き $x<y$ を同時に満たす点は $N$ しかない。

これは $N$ の位置の必要十分条件である。

しかし、未知の曲線 $\Gamma$ が $N$ を通るという一事実だけから、$\Gamma$ 全体が真円であるとは言えない。同じ一点を通る非円形曲線は無数に存在する。

したがって、二つの命題を分離する。

```text
鍵石Nの唯一性
  └─ 三条件の下で絶対

未知境界Γの真円性
  └─ N一点だけでは不足
```

この区別は本巻の重要な安全装置である。

## 10. 円環バランスと任意細分化

一点の鍵石を、真円全体の証明書へ持ち上げるには、`q2_star` の軌道を使う。

$q2(\kappa)=1$ を満たす単位核 $\kappa$ に対し、

$$q2(\kappa\star z)=q2(z)$$

なので、鍵石を回転させても同じ平方質量境界に残る。

固定された有限分割だけでは、正八角形のような有限対称性しか保証しない。有限回対称な非円形境界も存在するからである。

真円へ強制する候補条件は、次のような階層を持つ。

1. 各分割段階で点が等角配置される。
2. 各点が同じ $q2$ level に属する。
3. 親分割と子分割の位相が整合する。
4. 分割数を任意に増やしても保存契約が壊れない。
5. 境界が連続である。

連続な極座標境界を

$$\Gamma=\{r(\theta)(\cos\theta,\sin\theta)\}$$

とする。任意に細かい単位核軌道に対して

$$r(\theta+\alpha)=r(\theta)$$

が成立し、その角度集合が稠密ならば、連続性により

$$r(\theta)=R$$

が全角度で成立する。このとき $\Gamma$ は真円である。

したがって未来の大域術式は、概念的には次となる。

$$\mathrm{DenseUnitOrbitInvariant}(\Gamma)\ \land\ \mathrm{Continuous}(\Gamma)\Longrightarrow\mathrm{Circle}(\Gamma)$$

鍵石 $N$ は一方向の境界証明書である。その単位核軌道を任意精度まで整合的に巡回させることで、全周の真円証明書へ昇格する可能性がある。

## 14. 結論――円周上の石は、そこにしか居られない

発端は、直径 $9$ の円を $8^2$ の平方で測る古代エジプトの計算法だった。

現代の GeoGebra 再構成は、半径 $3$ の円と $3\times3$ 単位格子を重ね、八角辺 $x+y=4$ を作った。その辺と真円の境界が交わる場所に、鍵石 $N$ が現れた。

しかし、作図で「交わった」と見るだけでは絶対性は得られない。

`q2_star` は座標を和方向と差方向へ回転し、円周条件を保存したまま、八角辺上の候補を $\pm1$ の鏡像二点へ圧縮する。向き $x<y$ が最後の一方を選び、$N$ を唯一に封じる。

$$q2(z)=9\ \land\ z_x+z_y=4\ \land\ z_x<z_y\iff z=N$$

この鍵石から三点円 `CDN` を作ると、整数高さ $3$ の単位弦に対応する第二の単位弦が、高さ $\sqrt2$ に現れる。

$$N\longrightarrow\mathrm{Circle}(C,D,N)\longrightarrow\sqrt2$$

根号は外から与えられた装飾ではない。整数格子、平方質量、八角辺の整合条件から出現し、白銀円によって読み出された保存情報である。

ただし一点の鍵石は、未知曲線全体の真円性までは保証しない。次の扉は、鍵石を `q2_star` の単位核軌道で全周へ巡回させ、任意細分化しても保存核が残ることを証明する大域円環定理である。

本巻が固定したのは、その大域魔法陣を開く最初の絶対点である。

> **鍵石 $N$ は円周上に置かれたのではない。**
>
> **平方質量、八角辺、位相方向が重なったため、そこにしか居られなかった。**

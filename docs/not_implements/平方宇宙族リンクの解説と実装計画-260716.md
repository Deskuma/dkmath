# 平方宇宙族リンクの解説と実装計画

- 作成日: 2026-07-16

- 対象: DkMath / Cosmic Formula / Metallic Mean / Square Universe Family

## 0. 概要

本書は、次の三つの構造が共通の平方核 $x^2$ を中心として結ばれている、という研究観測を整理し、Lean 4 による形式化計画を与える。

1. 素数積構造から生じる宇宙式
2. 貴金属比を生じる平方方程式族
3. 放物線族の極点が作る負の平方世界

中心となる観測は、これらがいずれも「平方・辺・単位」の閉包関係として記述できることである。

$$x^2-kxu-u^2=0$$

特に $k=1$、$u=1$ では、

$$x^2-x-1=0$$

となり、正の解として黄金比が現れる。

本研究では、この共通構造を **平方宇宙族** と呼ぶ。

また、この平方閉包が、現在の平方 Core から次の平方 Core が開かれる構造を持つことから、スチュアート・カウフマンの「隣接可能領域」の数論的・代数的射影模型である、という仮説を置く。

この仮説は、カウフマンの生命論・進化論全体との同値を主張するものではない。現在状態が次の可能領域を生成し、実現後の状態がさらに新しい可能領域を開く、という構造的対応を検証対象とする。

## 1. 素数積宇宙式

単位付き宇宙式は、

$$(P+u)^2-P(P+2u)-u^2=0$$

である。

展開すれば、

$$(P+u)^2=P^2+2Pu+u^2$$

および、

$$P(P+2u)=P^2+2Pu$$

であるため、この式は可換環上の恒等式として成立する。

宇宙式の平方 Core、Body、単位 Core を、

$$S=P+u$$

$$B=P(P+2u)$$

と置けば、

$$S^2=B+u^2$$

となる。

DkMath において $P$ は任意の値として恒等式を形成できるが、数宇宙の離散的な生成源としては、有限個の素数の積を割り当てる。

$$P=\prod_{p\in F}p$$

ここで素数性は恒等式そのものではなく、宇宙の住所、有限素数世界の識別、包含関係、因子構造を与える層に現れる。

したがって形式化では、次の二層を分離する。

1. 任意の環要素について成立する平方恒等式層
2. 素数積によって離散化される数論層

## 2. 貴金属比の平方宇宙式

貴金属比を生成する一般式を、

$$x^2-kxu-u^2=0$$

とする。

条件は基本的に、

$$k\in\mathbb{N}$$

$$u>0$$

である。

$u\neq0$ として $r=x/u$ と正規化すると、

$$r^2-kr-1=0$$

となる。

正の解は、

$$\mu_k=\frac{k+\sqrt{k^2+4}}{2}$$

であり、

$$x=u\mu_k$$

となる。

代表例は次の通りである。

$$k=0\Rightarrow\mu_0=1$$

$$k=1\Rightarrow\mu_1=\frac{1+\sqrt5}{2}$$

$$k=2\Rightarrow\mu_2=1+\sqrt2$$

$$k=3\Rightarrow\mu_3=\frac{3+\sqrt{13}}{2}$$

したがって黄金比は、平方宇宙族の最小の非自明な正の閉包比である。

$$x^2=xu+u^2$$

この式は、次の三項を一つの平方へ集約する。

- 次の平方 Core: $x^2$
- 現在と次を結ぶ辺・Beam: $kxu$
- 現在の単位 Core: $u^2$

すなわち、

$$\text{Next Square Core}=\text{Adjacent Beam}+\text{Current Unit Core}$$

という形を持つ。

## 3. 正根と負根の役割

方程式、

$$x^2-kxu-u^2=0$$

の二根は、

$$x_+=u\frac{k+\sqrt{k^2+4}}{2}$$

$$x_-=u\frac{k-\sqrt{k^2+4}}{2}$$

である。

$u>0$、$k\geq0$ のとき、

$$x_+>0$$

$$x_-<0$$

である。

ただし、負根を単なる不採用解として捨ててはならない。二根の積は、

$$x_+x_-=-u^2$$

であるため、

$$x_-=-\frac{u^2}{x_+}$$

が成立する。

正根は正世界へ実現される貴金属比であり、負根は単位平方 $u^2$ を介した反転共役である。

したがって本研究では、次のように役割を分ける。

- 正根: 観測境界へ現れる実現側
- 負根: 反転・共役・潜在生成側
- False: 方程式の閉包条件そのものを満たさない候補

「負であること」と「False であること」は同一ではない。

## 4. 宇宙式族の極点と負の平方世界

単位宇宙式を放物線として、

$$C_u(z)=(z+u)^2-u^2=z^2+2uz$$

と置く。

この放物線の極点は、

$$V_u=(-u,-u^2)$$

である。

極点座標を $(X,Y)$ と置けば、

$$Y=-X^2$$

が成立する。

したがって、$u$ を動かした単位宇宙式族の極点集合は、鏡像放物線、

$$y=-x^2$$

の上に乗る。

正の単位 $u$ が式に入るとき、その極点は負の位置 $-u$ に現れる。

$$u\longmapsto(-u,-u^2)$$

この意味で、負の単位世界は正の宇宙式を生成する極点側の世界である。

---

## 5. 貴金属比宇宙式族の極点

貴金属比放物線を、

$$M_{k,u}(z)=z^2-kuz-u^2$$

と置く。

平方完成すると、

$$M_{k,u}(z)=\left(z-\frac{ku}{2}\right)^2-\frac{k^2u^2}{4}-u^2$$

となる。

したがって極点は、

$$W_{k,u}=\left(\frac{ku}{2},-\frac{k^2u^2}{4}-u^2\right)$$

である。

極点の横座標を $X=ku/2$ と置けば、

$$Y=-X^2-u^2$$

となる。

ゆえに、$k$ を連続変数として動かしたとき、貴金属比宇宙式族の極点集合は、

$$y=-x^2-u^2$$

に乗る。

$k\in\mathbb{N}$ に制限した場合は、この曲線上の離散点集合となる。

特に $u=1$ では、

$$y=-x^2-1$$

である。

黄金比放物線、

$$y=x^2-x-1$$

の極点は、

$$\left(\frac12,-\frac54\right)$$

であり、実際に、

$$-\left(\frac12\right)^2-1=-\frac54$$

を満たす。

---

## 6. 極点世界を統一する母放物線

母放物線を、

$$Q_{a,c}(z)=(z-a)^2-a^2-c$$

と定める。

展開すると、

$$Q_{a,c}(z)=z^2-2az-c$$

である。

極点は、

$$(a,-a^2-c)$$

となるため、$a$ を動かした極点軌跡は、

$$y=-x^2-c$$

である。

単位宇宙式は、

$$Q_{-u,0}(z)=(z+u)^2-u^2$$

として得られる。

貴金属比宇宙式は、

$$Q_{ku/2,u^2}(z)=z^2-kuz-u^2$$

として得られる。

したがって両者は、異なる式ではなく、同じ母放物線族の異なる断面である。

- 単位宇宙式の極点世界: $y=-x^2$
- 貴金属比宇宙式の極点世界: $y=-x^2-u^2$
- 両者を生成する母族: $y=-x^2-c$

ここでも中心は平方 $x^2$ である。

## 7. 共通平方閉包

平方宇宙族の共通母型を、

$$\operatorname{SquareClosure}(S,B,u)\iff S^2-B-u^2=0$$

と置く。

素数積宇宙式では、

$$S=P+u$$

$$B=P(P+2u)$$

である。

貴金属比宇宙式では、

$$S=x$$

$$B=kxu$$

である。

したがって、両者は共に、

$$\text{Square Core}=\text{Body / Beam}+\text{Unit Core}$$

を満たす。

この段階で証明できるのは、両者が共通の平方閉包スキーマを持つことである。

素数積構造から古典的な整数係数貴金属比が直接生成される、というより強い命題は、別途証明を要する。

## 8. 素数宇宙式から一般化貴金属式への射影

宇宙式の平方辺を、

$$S=P+u$$

と置く。

$P>0$、$u>0$ とし、正規化比を、

$$r=\frac{S}{u}=\frac{P+u}{u}$$

とする。

さらに係数写像を、

$$\kappa(r)=r-\frac1r$$

と定める。

すると恒等的に、

$$r^2-\kappa(r)r-1=0$$

が成立する。

元の変数に戻せば、

$$S^2-\kappa(r)Su-u^2=0$$

となる。

また、

$$\kappa(P,u)=\frac{P(P+2u)}{u(P+u)}$$

である。

したがって、任意の正の宇宙式点は、実数または有理数係数を許した一般化貴金属式へ厳密に射影できる。

$$(P+u)^2-\kappa(P,u)(P+u)u-u^2=0$$

この射影は、

$$T(r)=r-\frac1r$$

と、

$$M(k)=\frac{k+\sqrt{k^2+4}}2$$

が正の範囲で逆写像になることによって特徴づけられる。

$$M(T(r))=r$$

$$T(M(k))=k$$

ただし、整数 $P,u>0$ から得られる $r=(P+u)/u$ は有理数であり、古典的な $k\in\mathbb{N}_{>0}$ の貴金属比 $M(k)$ は無理数である。

このため、両者は通常、同一の点として重ならない。

より具体的には、

$$\kappa(P,u)=\frac{P(P+2u)}{u(P+u)}$$

は正の整数にならないことが予想され、初等整数論で証明可能である。

$P=da$、$u=db$、$\gcd(a,b)=1$ と既約化すれば、

$$\kappa(P,u)=\frac{a(a+2b)}{b(a+b)}$$

となる。

ここで、

$$\gcd(a(a+2b),a+b)=1$$

であり、$a+b>1$ なので、分母因子 $a+b$ は分子を割らない。

したがってこの直接射影は、次の二つの別々の整数断面を結ぶ。

- 素数宇宙側: 平方辺または正規化比が有理的・離散的
- 古典的貴金属側: Beam 係数 $k$ が整数で、比が二次無理数

この「直接一致しないが、逆写像で厳密に接続される」という分離構造を、数宇宙リンクの一部として扱う。

## 9. 二次体ノルムとの一致

第 $k$ 貴金属比を、

$$\mu_k=\frac{k+\sqrt{k^2+4}}2$$

と置く。

その共役を $\mu_k'$ とすれば、

$$\mu_k+\mu_k'=k$$

$$\mu_k\mu_k'=-1$$

である。

二次体 $\mathbb{Q}(\mu_k)$ において、

$$\operatorname{Norm}(a+b\mu_k)=a^2+kab-b^2$$

が成立する。

$a=x$、$b=-u$ と置けば、

$$\operatorname{Norm}(x-u\mu_k)=x^2-kxu-u^2$$

となる。

したがって貴金属比平方宇宙式は、二次体ノルム形式そのものである。

$$x^2-kxu-u^2=0\iff\operatorname{Norm}(x-u\mu_k)=0$$

体上ではノルムが零なら元そのものが零であるため、

$$x=u\mu_k$$

が回収される。

この一致は、平方宇宙族と素数分解構造を結ぶ標準数論側の入口となる。

判別式、

$$\Delta_k=k^2+4$$

は、対応する二次体における有理素数の分裂・惰性・分岐と関係する。

したがって今後の研究課題は、次の循環構造を明確化することである。

$$\text{Prime Product}\longrightarrow\text{Cosmic Square}\longrightarrow\text{Metallic Norm Form}\longrightarrow\text{Quadratic Field}\longrightarrow\text{Prime Splitting}$$

ここで、最初の矢印は DkMath 宇宙式、中央は平方宇宙族、最後は二次体の素数分解論によって担われる。

## 10. 隣接可能領域の射影仮説

### 10.1 仮説名

**平方隣接可能射影仮説**

英語の仮称は、`Square Adjacent-Possible Projection Hypothesis` とする。

### 10.2 基本対応

平方宇宙式、

$$x^2=kxu+u^2$$

を、次のように読む。

- 現在の Core: $u^2$
- 現在と次を結ぶ隣接 Beam: $kxu$
- 次に実現可能な Core: $x^2$
- 実現比: $x/u=\mu_k$
- 反転共役: $x_-=-u^2/x_+$

この式では、隣接 Beam $kxu$ が現在の尺度 $u$ だけでなく、まだ実現していない次の尺度 $x$ を含む。

したがって次世界は現在世界から一方向に列挙されるだけではなく、次世界自身が閉包条件へ参加する自己整合系となる。

$$\text{Next Core}=\text{Current Core}+\text{Current--Next Boundary}$$

### 10.3 状態依存の可能領域

状態 $u$ で許される Beam 多重度の集合を $K(u)$ とする。

隣接可能尺度の集合を、

$$\operatorname{Adj}(u)=\left\{u\frac{k+\sqrt{k^2+4}}2\mid k\in K(u)\right\}$$

と定める。

$x\in\operatorname{Adj}(u)$ が実現すると、次段階では $x$ が新しい単位尺度となる。

$$u\longmapsto x$$

次の隣接可能領域は、

$$\operatorname{Adj}(x)$$

として再生成される。

$K(u)$ が状態に依存する場合、現在の Core が変化するたびに、列挙可能な次世界そのものが変化する。

この点を、カウフマンの「新しいものの実現が、さらに新しい可能性を開く」という隣接可能領域の構造に対応する数論的射影とみなす。

### 10.4 負の極点世界の役割

平方宇宙族では、可能性は正の観測境界上にだけ存在するのではない。

上向き放物線を生成する極点は、

$$y=-x^2-c$$

という負の平方世界に保存される。

したがって、宇宙式的な隣接可能領域を、次の三段階として読む。

$$\text{Negative Vertex World}\longrightarrow\text{Square Universe Activation}\longrightarrow\text{Positive Boundary Realization}$$

これは、負を不存在や誤りとして消去する模型ではない。

負の極点世界は、正の実現世界を生成する潜在層として働く。

### 10.5 仮説として残す範囲

次の点は現時点では仮説・解釈であり、証明済み命題ではない。

1. 平方宇宙族がカウフマンの隣接可能領域の本質を十分に表現すること
2. 素数積による宇宙の離散化が、自然界の貴金属比発生機構へ直接対応すること
3. 負の極点世界を潜在可能性空間として解釈できること
4. 素数生成・平方閉包・貴金属比・二次体素数分解が一つの循環原理で統一されること

形式化では、まず代数的事実を証明し、その上に解釈層を明示的に分離して置く。

## 12. 初期定義案

```lean
namespace DkMath.CosmicFormula.SquareUniverse

/-- A common square-closure relation. -/
def SquareClosure {R : Type*} [CommRing R] (s body u : R) : Prop :=
  s ^ 2 = body + u ^ 2

/-- Unit cosmic-formula parabola. -/
def cosmicParabola (u x : ℝ) : ℝ :=
  (x + u) ^ 2 - u ^ 2

/-- Metallic square-universe parabola. -/
def metallicParabola (k u x : ℝ) : ℝ :=
  x ^ 2 - k * u * x - u ^ 2

/-- Mother parabola whose vertex lies on a shifted negative square. -/
def motherParabola (a c x : ℝ) : ℝ :=
  (x - a) ^ 2 - a ^ 2 - c

/-- Generalized metallic mean for a real beam parameter. -/
def metallicMean (k : ℝ) : ℝ :=
  (k + Real.sqrt (k ^ 2 + 4)) / 2

/-- Coefficient extracted from a positive normalized square scale. -/
def metallicParameter (r : ℝ) : ℝ :=
  r - 1 / r

/-- Positive cosmic scale normalized by its unit. -/
def cosmicScale (P u : ℝ) : ℝ :=
  (P + u) / u

/-- Generalized metallic parameter induced by a cosmic-formula point. -/
def cosmicMetallicParameter (P u : ℝ) : ℝ :=
  P * (P + 2 * u) / (u * (P + u))

/-- Algebraic candidate for one square-adjacent transition. -/
def AdjacentSquare (u k x : ℝ) : Prop :=
  0 < u ∧ 0 ≤ k ∧ 0 < x ∧ x ^ 2 = k * x * u + u ^ 2

end DkMath.CosmicFormula.SquareUniverse
```

定義名と引数順は、既存 DkMath API との整合性を確認して調整する。

## 13. 定理クラスター A: 共通平方閉包

最初に証明する基礎定理群。

```lean
theorem cosmic_squareClosure
    {R : Type*} [CommRing R] (P u : R) :
    SquareClosure (P + u) (P * (P + 2 * u)) u

theorem metallic_squareClosure_iff
    {R : Type*} [CommRing R] (k u x : R) :
    SquareClosure x (k * x * u) u ↔ x ^ 2 - k * x * u - u ^ 2 = 0

theorem motherParabola_expand (a c x : ℝ) :
    motherParabola a c x = x ^ 2 - 2 * a * x - c
```

到達条件は、素数性や平方根を使用せず、環上の恒等式として証明されること。

## 16. 定理クラスター D: 宇宙式から一般化貴金属式への射影

```lean
theorem metallicParameter_identity
    (r : ℝ) (hr : r ≠ 0) :
    r ^ 2 - metallicParameter r * r - 1 = 0

theorem cosmicMetallicParameter_eq
    (P u : ℝ) (hu : u ≠ 0) (hPu : P + u ≠ 0) :
    cosmicMetallicParameter P u = metallicParameter (cosmicScale P u)

theorem cosmicScale_is_generalizedMetallicRoot
    (P u : ℝ) (hu : u ≠ 0) (hPu : P + u ≠ 0) :
    cosmicScale P u ^ 2 -
      cosmicMetallicParameter P u * cosmicScale P u - 1 = 0

theorem cosmic_square_is_generalizedMetallicRoot
    (P u : ℝ) (hu : u ≠ 0) (hPu : P + u ≠ 0) :
    (P + u) ^ 2 -
      cosmicMetallicParameter P u * (P + u) * u - u ^ 2 = 0
```

逆写像も証明する。

```lean
theorem metallicMean_metallicParameter
    (k : ℝ) (hk : 0 ≤ k) :
    metallicParameter (metallicMean k) = k

theorem metallicMean_parameter_inverse
    (r : ℝ) (hr : 0 < r) :
    metallicMean (metallicParameter r) = r
```

## 17. 定理クラスター E: 整数断面の分離

整数 $P,u>0$ に対し、宇宙式から得る一般化係数が自然数にならないことを証明する。

候補定理は、

```lean
theorem cosmicMetallicParameter_not_int
    (P u : ℕ) (hP : 0 < P) (hu : 0 < u) :
    ¬ ∃ k : ℕ,
      (P : ℚ) * (P + 2 * u) / (u * (P + u)) = k
```

または、分数の非整除性を先に証明する。

```lean
theorem reduced_cosmic_parameter_den_not_dvd_num
    (a b : ℕ) (ha : 0 < a) (hb : 0 < b) (hcop : Nat.Coprime a b) :
    ¬ b * (a + b) ∣ a * (a + 2 * b)
```

中心補題は、

```lean
theorem coprime_cosmic_num_add_den
    (a b : ℕ) (hcop : Nat.Coprime a b) :
    Nat.Coprime (a * (a + 2 * b)) (a + b)
```

である。

この定理はリンクの否定ではなく、古典的貴金属比断面と素数宇宙断面が異なることを固定する分離定理となる。

## 18. 定理クラスター F: 二次ノルム

最初は具体的な実数または二次拡大の恒等式として証明し、後に NumberField API へ接続する。

目標式は、

$$\operatorname{Norm}(x-u\mu_k)=x^2-kxu-u^2$$

である。

実装候補は二段階とする。

1. 共役積による明示的な恒等式
2. `Algebra.norm` または二次体 API による抽象化

最初の補題候補は、

```lean
theorem metallic_conjugate_sum (k : ℝ) :
    ((k + Real.sqrt (k ^ 2 + 4)) / 2) +
      ((k - Real.sqrt (k ^ 2 + 4)) / 2) = k

theorem metallic_conjugate_mul (k : ℝ) :
    ((k + Real.sqrt (k ^ 2 + 4)) / 2) *
      ((k - Real.sqrt (k ^ 2 + 4)) / 2) = -1

theorem metallic_explicit_norm
    (k x u : ℝ) :
    (x - u * ((k + Real.sqrt (k ^ 2 + 4)) / 2)) *
      (x - u * ((k - Real.sqrt (k ^ 2 + 4)) / 2)) =
        x ^ 2 - k * x * u - u ^ 2
```

平方根の積補題には、$k^2+4\geq0$ の証明が必要となる。

## 19. 定理クラスター G: 隣接可能射影模型

この層では、まず純粋な遷移関係として形式化する。

```lean
def nextScale (u k : ℝ) : ℝ :=
  u * metallicMean k

 def AdjacentSquare (u k x : ℝ) : Prop :=
  0 < u ∧ 0 ≤ k ∧ 0 < x ∧ x ^ 2 = k * x * u + u ^ 2
```

先頭空白などは実装時に整形する。

基本定理候補は、

```lean
theorem nextScale_adjacent
    (u k : ℝ) (hu : 0 < u) (hk : 0 ≤ k) :
    AdjacentSquare u k (nextScale u k)

theorem adjacentSquare_eq_nextScale
    (u k x : ℝ)
    (h : AdjacentSquare u k x) :
    x = nextScale u k

theorem adjacentSquare_unique
    (u k x y : ℝ)
    (hx : AdjacentSquare u k x)
    (hy : AdjacentSquare u k y) :
    x = y
```

状態ごとの許容 Beam 集合を、

```lean
def AdjacentRegion
    (allowed : ℝ → Set ℝ) (u : ℝ) : Set ℝ :=
  {x | ∃ k ∈ allowed u, AdjacentSquare u k x}
```

として定義する。

状態依存性を示すには、具体的な `allowed` が必要である。

カウフマン射影仮説そのものは、Lean の `Prop` として真偽を固定する前に、次の二層へ分ける。

1. 数学的模型
   - `AdjacentSquare`
   - `nextScale`
   - `AdjacentRegion`
   - 実現後の単位更新
2. 解釈対応
   - Core
   - Beam
   - 潜在極点世界
   - 隣接可能領域

Lean は第一層を証明し、第二層は文書化されたモデル対応として保持する。

## 20. 素数積層との接続計画

素数積を表す既存 DkMath 定義を調査し、次の形へ接続する。

```lean
def PrimeSeed (P : ℕ) : Prop :=
  ∃ F : Finset ℕ, (∀ p ∈ F, Nat.Prime p) ∧ P = ∏ p ∈ F, p
```

実際には既存の PrimeSet、PrimitiveSet、Finset.prod 関連 API を再利用し、新規重複定義を避ける。

目標は、素数積から平方 Core が得られることを明示する定理である。

```lean
theorem primeSeed_squareClosure
    (P u : ℕ) (hP : PrimeSeed P) :
    (P + u) ^ 2 = P * (P + 2 * u) + u ^ 2
```

この恒等式自体に `hP` は不要であるため、次の二定理へ分ける方が望ましい。

```lean
theorem nat_cosmic_squareClosure (P u : ℕ) :
    (P + u) ^ 2 = P * (P + 2 * u) + u ^ 2

theorem primeSeed_has_cosmic_square
    (P u : ℕ) (hP : PrimeSeed P) :
    ∃ S B : ℕ,
      S = P + u ∧ B = P * (P + 2 * u) ∧ S ^ 2 = B + u ^ 2
```

次段階では、素数積の包含関係、

$$F\subseteq G$$

が平方宇宙間の写像や隣接可能集合へどのように作用するかを調べる。

候補課題は次の通りである。

1. 素数を一つ追加したときの $P\mapsto Pp$ と平方 Core の変化
2. 正規化尺度 $r=(P+u)/u$ の単調性
3. 一般化係数 $\kappa(P,u)$ の単調性・範囲・極限
4. $P$ の因子構造と二次体判別式 $k^2+4$ の関係
5. Prime splitting と Cosmic Formula の因子境界の関係
6. Petal / GN / Body が平方宇宙族の Beam 項をどのように読み取るか

## 26. 現段階の結論

平方宇宙族の中心は、単に複数の式に $x^2$ が現れることではない。

次の三つが同じ平方閉包へ集約されることにある。

$$\text{Prime-Generated Discrete Structure}$$

$$\text{Square Core Closure}$$

$$\text{Metallic Self-Similar Ratio}$$

さらに、その放物線族の極点は、

$$y=-x^2-c$$

という負の平方世界に集約される。

したがって現在の研究仮説は、次の循環として表される。

$$\text{Prime Seed}\longrightarrow\text{Square Universe}\longrightarrow\text{Metallic Ratio}\longrightarrow\text{Quadratic Norm}\longrightarrow\text{Prime Structure}$$

そして隣接可能領域は、

$$\text{Current Square Core}+\text{Adjacent Beam}\longrightarrow\text{Next Square Core}$$

という平方閉包として射影される可能性がある。

この仮説を証明課題へ変換するため、まず共通平方閉包、極点集合、正負共役、一般化貴金属射影、整数断面の分離を Lean で固定する。

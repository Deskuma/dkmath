## 0. この覚書の目的

本書は、整数の加法を単なるスカラー等式としてではなく、宇宙式と KUS のテンソル構造を持つ多次元パズルとして読む観測を保存する。

中心例は次の等式である。

$$5+7=12$$

通常の表示では、左辺の二数を足して右辺を得るだけに見える。

しかし本観測では、$5$ と $7$ は内部構造を持つ二つの Big であり、それぞれを $u$ 境界で切断し、素数辺・平方セル・Beam 接合片へ分解した後、評価量を保存しながら再配置して、別表現の Big $12$ を組み立てる。

この観点は現時点では完成した定理ではない。既に Lean で実装された GN・rad・valuation excess・intrinsic epsilon の橋と接続する可能性を持つ、将来の形式化候補である。

---

## 1. Big は値ではなく構造化された表示である

Big を整数値そのものへ直ちに潰してはならない。

Big は、Core、Gap、Beam、素数辺、出自ラベル、再配分経路を持つ構造体であり、評価写像によって初めて通常の整数へ落ちると考える。

$$\mathrm{Eval}(\mathrm{Big}_N)=N$$

したがって、異なる内部配置が同じ整数値を持ちうる。

$$\mathrm{Presentation}_1\neq\mathrm{Presentation}_2$$

$$\mathrm{Eval}(\mathrm{Presentation}_1)=\mathrm{Eval}(\mathrm{Presentation}_2)=N$$

この意味で、$5+7$ と $3\cdot2^2$ は同じ値 $12$ を持つが、異なる Big 表示である。

$$\mathrm{Eval}(\mathrm{Big}_{5+7})=\mathrm{Eval}(\mathrm{Big}_{3\cdot2^2})=12$$

---

## 2. 宇宙式の次数別分解

次数 $d$ の宇宙式について、Core、Gap、Beam を次で読む。

$$\mathrm{Core}_d(x)=x^d$$

$$\mathrm{Gap}_d(u)=u^d$$

$$\mathrm{Beam}_d(x,u)=\sum_{k=1}^{d-1}\binom{d}{k}x^{d-k}u^k$$

このとき Big は次の三層へ展開される。

$$(x+u)^d=\mathrm{Core}_d(x)+\mathrm{Beam}_d(x,u)+\mathrm{Gap}_d(u)$$

Beam はパスカル三角形の両端を除く中間項である。

### $d=1$

中間項が存在しないため、Beam は空和としてゼロになる。

$$\mathrm{Beam}_1(x,u)=0$$

$$(x+u)^1=x+u$$

### $d=2$

$$\mathrm{Beam}_2(x,u)=2xu$$

$$(x+u)^2=x^2+2xu+u^2$$

### $d=3$

$$\mathrm{Beam}_3(x,u)=3x^2u+3xu^2$$

$$(x+u)^3=x^3+3x^2u+3xu^2+u^3$$

### 素数次数と Freshman’s Dream

素数 $p$ では、整数上で Beam が消滅するのではなく、中間二項係数が法 $p$ で相殺される。

$$\mathrm{Beam}_p(x,u)\equiv0\pmod p$$

$$(x+u)^p\equiv x^p+u^p\pmod p$$

したがって、このゼロは構造が存在しないゼロではなく、観測する剰余世界で相殺されたゼロと読む。

---

## 3. Beam は次数別キーホルダーである

Beam の総和だけでは、どの中間項がどこから来たかを一意に復元できない場合がある。

したがって、キーホルダーとして保存すべき対象は単一の数値 $\mathrm{Beam}_d$ ではなく、次数 $k$ ごとの Beam セル列である。

$$\mathrm{BeamCell}_{d,k}(x,u)=\binom{d}{k}x^{d-k}u^k$$

$$\mathrm{BeamPacket}_d(x,u)=\left(\mathrm{BeamCell}_{d,k}(x,u)\right)_{1\leq k<d}$$

$$\mathrm{Beam}_d(x,u)=\sum_{k=1}^{d-1}\mathrm{BeamCell}_{d,k}(x,u)$$

KUS 的には、各 Beam セルへ少なくとも次のラベルを保持する必要がある。

- 元の Big の識別子
- 次数 $d$
- 分割境界 $u$
- 中間次数 $k$
- Core 側と Gap 側の出自
- 素数辺ラベル
- 再配置前後の位置

Beam は単なる余剰量ではない。

Beam は、Big をどの次数・境界・経路で切り分け、どのセルへ組み直したかを保存する接合履歴である。

---

## 4. GN は Core と Beam を因数化する

宇宙式の差分は次の形を持つ。

$$(x+u)^d-u^d=x\,\mathrm{GN}_d(x,u)$$

一方、Core・Beam・Gap 分解から次を得る。

$$(x+u)^d-u^d=x^d+\mathrm{Beam}_d(x,u)$$

したがって、GN は Core と Beam を一つにまとめて、外側の因子 $x$ を露出する。

$$x\,\mathrm{GN}_d(x,u)=x^d+\mathrm{Beam}_d(x,u)$$

$$\mathrm{Beam}_d(x,u)=x\left(\mathrm{GN}_d(x,u)-x^{d-1}\right)$$

この観点では GN は、単なる差分商ではなく、Core に付随する再配分空間を因子化して読む装置である。

$d$ によって Beam の層数と大きさが変わり、$u$ によって切断境界と素因子構成が変わる。

---

## 5. KUS テンソルと素数辺

KUS テンソル構造では、素数を単なる最終的な素因数分解の記号ではなく、セルを構成する辺ラベルとして読む。

$d=2$ なら、二方向の辺束を次のように置く。

$$P_1=\prod_{i\in I_1}p_i$$

$$P_2=\prod_{j\in I_2}p_j$$

二方向の各素数指数が一致するとき、局所セルは平方へ閉じる。

$$v_p(P_1)=v_p(P_2)$$

$$P_1P_2=Q^2$$

ここで重要なのは、Big 全体が一個の平方数である必要はないことである。

Big は複数の平方セルによって敷き詰められてよい。

$$N=\sum_i m_iQ_i^2$$

例として $12$ は平方数ではないが、三つの平方セルとして表せる。

$$12=2^2+2^2+2^2=3\cdot2^2$$

したがって $d=2$ のパズルとは、Big $12$ を一個の巨大正方形とみなすことではなく、評価総量 $12$ を持つ平方セル配置へ再タイル化することである。

---

## 6. $5+7=12$ の再配分パズル

通常の乗法的素因数分解では、$5$ と $7$ はそれ以上分解されない。

しかし宇宙式では、$N=x+u$ によって加法境界を内部へ入れられる。

まず二つの Big を加法セルへ切る。

$$5=3+2$$

$$7=3+2+2$$

したがって、初期配置は次となる。

$$5+7=(3+2)+(3+2)+2=12$$

評価量を保存しながら、小片を別のまとまりへ再配置する。

$$12=(2+2)+2+3+3$$

さらに $3=1+2$ を用いて、平方セルを作る準備をする。

$$12=2^2+2+(1+2)+(1+2)$$

小片を移送して、三つの $2^2$ セルへ閉じる。

$$12=2^2+(2+2)+2+(1+1)$$

$$12=2^2+2^2+2^2=3\cdot2^2$$

この計算は、$5$ と $7$ を通常の意味で因数分解したものではない。

二つの Big 表示を $u$ 境界で切断し、出自付き小片へ変換し、評価量 $12$ を不変に保ちながら、平方辺テンソルへ再配置したものである。

$$\mathrm{Eval}(\mathrm{PuzzleStart})=\mathrm{Eval}(\mathrm{PuzzleEnd})=12$$

この再配分経路こそ、最初の数式遊びの本体である。

## 7. 不変量と再配分状態

再配分中に保存される第一の不変量は Big の評価値である。

$$\mathrm{Eval}(S_i)=N$$

ここで $S_i$ は途中状態である。

ただし、途中状態は通常の整数等式だけでは識別できない。

各状態は次の情報を持つ必要がある。

- セルの値
- 出自 Big
- Core / Gap / Beam の種別
- 次数 $d$
- 境界 $u$
- 素数辺
- KUS ラベル
- 前状態からの書換え証明

したがって、将来の Lean 実装では単なる `Nat` の等式列ではなく、証明付き表示状態の遷移系が必要になる。

---

## 8. 固定 Big における Beam の局所天井

固定 Big の辺を $N=x+u$ と置く。

自然数世界では、$u$ の可動域は Big を超えられない。

$$0\leq u\leq N$$

固定 Big 上の Beam は次で書ける。

$$\mathrm{Beam}_d(N;u)=N^d-(N-u)^d-u^d$$

$d\geq2$ の実数評価では中央 $u=N/2$ で最大となる。

$$\mathrm{Beam}_d(N;u)\leq N^d\left(1-2^{1-d}\right)$$

この式は一つの Big を二分する局所宇宙式の天井である。

ただし、複数 Big、複数素数辺、複数 BeamPacket を組み換える KUS テンソル全体の天井は、これだけでは与えられない。

将来の課題は、局所 Beam 天井をテンソル再配分経路全体の上界へ持ち上げることである。

## 9. ABC 予想との接続候補

DkMath では、既に次の実装が存在する。

- `DkMath.ABC.SquareTailGapIdentity`
- `DkMath.ABC.ABCEpsilonIdentity`
- `DkMath.ABC.ABCEpsilonJointPressureBridge`
- `DkMath.ABC.ABCEpsilonSlopeBridge`

PR #71 は、通常の ABC gap と square-tail debt が同じ量であることを固定した。

$$\mathrm{abcGap}(T)=\mathrm{squareTailDebt}(T)$$

さらに、出力 $c$ の valuation excess と入力 $ab$ の radical support の差として読める。

$$\mathrm{abcGap}(T)=\mathrm{valuationExcess}(c)-\log\mathrm{rad}(ab)$$

PR #72 は、GN joint pressure の傾きを intrinsic epsilon の上界へ接続した。

$$\mathrm{GNEpsilon}(p,\rho)=\frac{\rho}{p-1}-1$$

この覚書のパズル語彙では、次の対応が予想される。

- $\mathrm{rad}$: 使用された異なる素数辺ラベルの種類
- valuation excess: 同じ素数辺を重ねた積層厚み
- square-tail: radical が捨てた重複層
- GN: $u$ 境界で切り出された Core と Beam の因子化読み取り
- intrinsic epsilon: radical 座標で正規化された未返済再配分圧力

ABC 不等式を宇宙式・KUS 的に読む仮説は次である。

> 固定された Big の内部で、素数辺付きセルを切断・移送・再接合するとき、radical support に対して未返済となる Beam・積層厚み・valuation pressure の総量には一様な天井がある。

これは現時点では解釈仮説であり、Lean で証明済みの ABC 予想を意味しない。

既実装の GN・rad・epsilon bridge と、将来定義する ReallocationPuzzle の間に正確な Bridge を構成する必要がある。

## 10. FLT との接続候補

$d=2$ では、平方セルを用いた整数再配置が可能である。

$$12=3\cdot2^2$$

ただし、この例は $x^2+y^2=z^2$ の解そのものではない。

これは、加法 Big を複数の平方セルへ敷き詰め直せることを示す再配置例である。

FLT の式は次である。

$$x^d+y^d=z^d$$

宇宙式パズル語彙では、$d>2$ の FLT は次のように読む候補がある。

> 二つの正整数真魔核 $x^d$ と $y^d$ を、Beam・Gap・出自ラベルをすべて返済した状態で、単一の正整数真魔核 $z^d$ へ閉じることはできない。

拡張された再配分空間では、次のような等価な評価状態を作ること自体は可能である。

$$x^d+y^d+\mathrm{Debt}_{\mathrm{left}}=z^d+\mathrm{Debt}_{\mathrm{right}}$$

FLT が禁止するのは、正整数で $d>2$ のとき、すべての再配分負債を消して真魔核だけを残す閉包である、と可視化できる可能性がある。

これも現時点では説明モデルであり、映像だけで FLT の証明となるものではない。

Lean 定理を各フレームの不変条件として結合したとき、映像は形式証明の可視化として機能する。

---

## 11. KUS ゼロ化との類似

KUS のゼロ化後は、通常の数演算へそのまま戻せないが、元の構造ラベルを読み取れるという観点がある。

再配分パズルでも、元の整数を小片へ分解した後、その小片を単なる `Nat` として扱うと出自を失う。

そこで、通常演算可能な値から一度離れ、次のようなラベル付きパケットとして保持する。

$$\mathrm{Packet}=(\mathrm{value},\mathrm{origin},d,u,k,\mathrm{primeEdges},\mathrm{kind})$$

この状態では、任意の通常演算を許さず、許可された再配分規則だけを適用する。

評価写像は整数値を回収するが、完全復元には BeamPacket と経路証明が必要になる。

$$\mathrm{Eval}(\mathrm{PacketState})=N$$

$$\mathrm{Restore}(\mathrm{PacketState},\mathrm{KeyPath})=\mathrm{OriginalPresentation}$$

この意味で、KUS ゼロ化は算術対象を通常演算圏から構造観測圏へ移す操作であり、BeamPacket は再配分経路のキーホルダー候補となる。

## 12. 将来の Lean 形式化案

### Phase 0: 表示構文と評価

```lean

  | atom    : Nat → PuzzleExpr
  | add     : PuzzleExpr → PuzzleExpr → PuzzleExpr
  | mul     : PuzzleExpr → PuzzleExpr → PuzzleExpr
  | pow     : PuzzleExpr → Nat → PuzzleExpr
  | packet  : ReallocationPacket → PuzzleExpr

def PuzzleExpr.eval : PuzzleExpr → Nat
```

最初に、異なる表示が同じ評価値を持つことを型として分離する。

### Phase 1: Core / Gap / Beam

```lean
def Core (d x : Nat) : Nat := x ^ d

def Gap (d u : Nat) : Nat := u ^ d

def BeamCell (d k x u : Nat) : Nat :=
  Nat.choose d k * x ^ (d - k) * u ^ k

def Beam (d x u : Nat) : Nat :=
  ∑ k ∈ Finset.Icc 1 (d - 1), BeamCell d k x u
```

候補補題は次である。

theorem beam_eq_sum_middle_pascal

theorem beam_one_eq_zero

## 13. 映像化の最小設計

映像化は大規模な三次元作品から始める必要はない。

最小構成は次でよい。

1. 左側に $5$ と $7$ の出自付きセルを置く
2. $u$ 境界を動かしてセルを切る
3. Core、Gap、BeamCell を別レイヤーで表示する
4. 素数辺を辺ラベルとして表示する
5. 評価値 $12$ を常時固定表示する
6. 小片を平方セル $2^2$ 三個へ再配置する
7. 各移動に対応する Lean 定理名を表示する
8. rad、valuation excess、GN pressure を別メーターで表示する

映像が証明として機能するためには、各フレームが Lean 上の `ReallocationStep.eval_eq` を持つ必要がある。

映像そのものが証明なのではなく、証明付き遷移を人間が読める形へ投影したものを映像証明と呼ぶ。

## 14. 実装境界

現時点で確定しているものは次である。

- 二項展開による Core / Beam / Gap 恒等式
- $(x+u)^d-u^d=x\,\mathrm{GN}_d(x,u)$ 型の GN 分解
- PR #71 による square-tail / rad / valuation excess / abcGap の正確な座標一致
- PR #72 による GN slope と intrinsic epsilon の橋
- $5+7=12=3\cdot2^2$ という評価保存の数式列

未解明・未実装のものは次である。

- KUS テンソルとしての素数辺の正確な型
- BeamPacket が完全な復元鍵となるための最小情報
- 任意の再配分規則の健全性と完全性
- 再配分空間全体の一様な天井
- その天井と ABC 不等式の同値または含意
- FLT を Beam-free closure 不可能性へ翻訳する一般定理
- 証明付き映像化エンジン

したがって、本書は既存の ABC・FLT の証明を主張しない。

既実装の GN・rad 構造を、KUS テンソル再配分パズルとして再解釈し、将来の定義・実験・形式化へ渡すための研究覚書である。

## 15. 賢狼用の記憶核

後から本観測を探すときは、次の一文を検索する。

> $5$ と $7$ を足して $12$ を得たのではなく、二つの Big を $u$ で切断し、KUS ラベル付き Beam 小片へ分解し、平方辺テンソルとして $3\cdot2^2$ へ再配置した。

最短の構造列は次である。

$$\mathrm{Big}\xrightarrow{u\text{-cut}}\mathrm{Core}+\mathrm{BeamPacket}+\mathrm{Gap}$$

$$\mathrm{Core}+\mathrm{BeamPacket}+\mathrm{Gap}\xrightarrow{\mathrm{KUS\ reallocation}}\mathrm{PrimeEdgeCells}$$

$$\mathrm{Eval}(\mathrm{PrimeEdgeCells})=5+7=3\cdot2^2=12$$

この再配分空間の天井を、GN・rad・valuation excess・intrinsic epsilon の座標で読むことが、ABC 予想への別アプローチ候補である。

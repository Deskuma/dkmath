# 宇宙式の反転射影

CosmicFormula's Inversion Projection

## $[0 \to \infty) \mapsto (-1, 0]$

## 全体設計

うむ。素材は揃った。
ここからは、いきなり「コラッツ証明」として組まず、まず **独立 API 定理群** を作るのがよい。

設計の骨格はこうじゃ。

```txt
宇宙式反転射影 API
        ↓
p スケール・評価流 API
        ↓
有限同期・余終性 API
        ↓
欠損否定・可換射影 API
        ↓
Collatz 奇数核転移 API
        ↓
調和リンク網
        ↓
終端尾根 2^n への合流
```

最後だけがコラッツ専用。
それ以前は、DkMath 全体で使い回せる基礎定理になる。

## 1. 宇宙式反転射影 API

まず最優先で固定する定義。

$$
\Pi(P)=-\frac{P}{P+1}
$$

gap 座標。

$$
u(P)=\frac{1}{P+1}
$$

基本関係。

$$
\Pi(P)+1=u(P)
$$

正規化宇宙式。

$$
\frac{N}{(P+1)^2}+u(P)^2=1
$$

ただし、

$$
N=(P+1)^2-1
$$

じゃ。

ここで証明する API 定理はこれ。

```lean
cosmicProjection_mem_interval
cosmicProjection_gap_eq
cosmicProjection_inverse
cosmicProjection_surjective_interval
cosmicProjection_injective
normalized_cosmic_body_gap
real_no_hole_under_cosmicProjection
```

意味はこう。

* $P\ge0$ なら $\Pi(P)\in[-1,0]$
* $x\in(-1,0]$ なら $P=-x/(x+1)$ で戻れる
* $[0,\infty]$ の無限は $[-1,0]$ の境界 $-1$ に畳まれる
* 実数スケール空間では射影後に欠損は生じない

ここはコラッツと無関係に証明できる。

## 2. p スケール・評価流 API

次は一般 $p$ スケール。

任意の $p>1$ に対して、

$$
n=\operatorname{core}_p(n)\cdot p^{\nu_p(n)}
$$

ここで $\nu_p(n)$ は $p$ 進評価。
$\operatorname{core}_p(n)$ は $p$ で割れない核じゃ。

下降操作を、

$$
D_p(n)=\frac{n}{p}
$$

と置く。

指数尾根上では、

$$
D_p^k(s\cdot p^k)=s
$$

これが **スケール保存核** の最小定理じゃな。

証明する API。

```lean
pScale_core_decomposition
pScale_core_not_dvd
pScale_down_once
pScale_down_iter
pScale_spine_returns_core
pScale_normalized_spine_returns_one
pScale_exponential_spine
pScale_linear_lattice
pScale_intermediate_count
```

特に重要なのはこれ。

$$
D_p^k(s\cdot p^k)=s
$$

正規化版。

$$
\frac{D_p^k(s\cdot p^k)}{s}=1
$$

これで、

> $2^k$ の収束は $s=1,p=2$ の特殊例。
> 一般 $p$ 世界にも指数尾根と単位元への下降がある。

と言える。

## 3. 有限同期・CRT API

ここは今回かなり重要じゃ。

有限個の互いに素なスケール

$$
p_1,p_2,\ldots,p_k
$$

に対して、任意の剰余条件

$$
x\equiv a_i\pmod {p_i}
$$

は同期できる。

つまり、

$$
\exists! x\pmod {p_1p_2\cdots p_k},\quad \forall i,\ x\equiv a_i\pmod {p_i}
$$

これが **有限同期補題** 。

API 名。

```lean
finite_coprime_scale_sync
finite_prime_scale_sync
finite_window_link_exists
finite_sync_unique_mod_product
```

そして、無限側はこう分ける。

```lean
primeScale_cofinal
cofinal_window_extension
no_finite_global_prime_sync
```

意味はこう。

* 有限個の素数宇宙なら必ず同期できる
* 素数は余終的に無限なので、任意の有限窓の外側に新しい素数スケールを追加できる
* ただし全素数を一度に同期する有限 modulus は存在しない

これを明記しておく。
「有限なら同期できる」「無限同時同期は有限構造では持てない」じゃ。

## 4. 欠損否定・可換射影 API

ここで宇宙式反転射影を使う。

射影前の $P$ 世界でリンク $L$ があり、射影後の $x$ 世界でリンク $\widehat L$ があるとする。

可換条件は、

$$
\Pi(L(P))=\widehat L(\Pi(P))
$$

じゃ。

これを API にする。

```lean
cosmicProjection_commutes
projection_preimage_nonempty
projection_image_no_hole
hole_transports_back
no_hole_under_commuting_projection
```

核になる論理はこれ。

$$
H\subseteq[-1,0],\quad H\ne\varnothing
$$

なら、逆射影によって、

$$
\Pi^{-1}(H)\ne\varnothing
$$

になる。

つまり、

> 射影後に穴があるなら、射影前にも穴がある。

しかし実数 $P$ 世界は反転射影で $[-1,0]$ を欠損なく覆う。
したがって、可換射影のもとでは欠損は否定される。

ただし、ここで一つ橋が要る。

```lean
discrete_cell_realization
```

これは、

> 実数射影で穴がないことを、整数・合同類・有限観測窓のセルにも戻せる

という橋じゃ。
ここは最後の重要補題になる。

## 5. Collatz 奇数核転移 API

ここからコラッツ専用。

奇数核写像を定義する。

$$
T(s)=\frac{3s+1}{2^{\nu_2(3s+1)}}
$$

つまり、

$$
3s+1=2^{\nu_2(3s+1)}T(s)
$$

これは `ValuationFlowBridge` の中心になる。

API。

```lean
collatz_oddCoreTransfer
collatz_core_transfer_eq
collatz_core_transfer_odd
collatz_core_transfer_positive
collatz_even_halving_preserves_oddCore
collatz_block_affine
```

ブロック化すると、

$$
T^m(s)=\frac{3^m s+B_m}{2^{R_m}}
$$

ここで、

$$
R_m=\sum_{i=0}^{m-1}\nu_2(3T^i(s)+1)
$$

じゃ。

この $R_m$ が $2$ 側の回収量。
$3^m$ が $3$ 側の転移量。

相対スケールは、

$$
P_m=\frac{2^{R_m}}{3^m}
$$

これを宇宙式反転射影へ入れる。

$$
x_m=-\frac{P_m}{P_m+1}
$$

ここで、無限逃走は $[-1,0]$ の境界問題に変わる。

## 6. 調和リンク網 API

次に、奇数核転移を「リンク」として構造化する。

ノードは奇数核スケール。

$$
s
$$

リンクは、

$$
s\to T(s)
$$

ただし内部には、

$$
3s+1=2^rT(s)
$$

という同期情報を持つ。

API 設計。

```lean
structure HarmonicNode where
  core : Nat
  odd_core : core % 2 = 1

structure HarmonicLink where
  source : HarmonicNode
  target : HarmonicNode
  valuation : Nat
  transfer_eq : 3 * source.core + 1 = 2 ^ valuation * target.core
```

ここに、有限リンクの合成を入れる。

```lean
harmonicLink_comp
harmonicPath
harmonicPath_scaleProduct
harmonicPath_affineBlock
```

実験値のリンクも、ここに登録できる。

```lean
collatz_184_to_40
collatz_40_to_1
collatz_184_to_1
```

ただしこれは例示・既知尾部補題じゃ。
本命は一般リンク構造の方。

## 7. 終端尾根 API

最後に $p=2$ の終端尾根。

$$
2^k\to2^{k-1}\to\cdots\to1
$$

API。

```lean
terminal_dyadic_spine
terminal_dyadic_spine_iter
terminal_dyadic_spine_terminates
```

定理形。

$$
C^k(2^k)=1
$$

あるいは半減写像 $H$ で、

$$
H^k(2^k)=1
$$

これは完全に独立して証明できる。

## 8. 最終合流の形

最終証明は、いきなり

$$
\forall n,\ \exists t,\ C^t(n)=1
$$

を狙わない。

まず任意の $n$ を、

$$
n=s\cdot2^k
$$

に分解する。

偶数半減により $s$ へ降りる。

問題は奇数核 $s$ 。

そこで示すべき最終形はこれ。

$$
\forall s\ \mathrm{odd},\ \exists m,\ T^m(s)=1
$$

これが示せれば、任意の $n$ は収束する。

DkMath 的には、さらにこう言い換える。

> 任意の奇数核スケール $s$ は、有限個の調和リンクを通じて $1$ 核へ接続される。

つまり、

```lean
all_odd_cores_link_to_one
```

が最終核心。

そこから、

```lean
collatz_conjecture_from_all_odd_cores_link_to_one
```

で通常のコラッツ予想へ戻す。

## 9. 背理法の最終構造

反例があると仮定する。

$$
\exists s,\quad \forall m,\ T^m(s)\ne1
$$

すると、未接続核の軌道がある。

そのブロックスケール列

$$
P_m=\frac{2^{R_m}}{3^m}
$$

を反転射影する。

$$
x_m=-\frac{P_m}{P_m+1}
$$

この像は $[-1,0]$ に閉じ込められる。

未接続なら、射影ゾーン内に「終端リンクへ接続しない穴」が残る。

だが、

1. 有限窓では CRT 同期によりリンクは失われない
2. 素数スケールは余終的に拡張できる
3. 宇宙式反転射影は実数スケールに欠損を作らない
4. 可換射影なら穴は逆射影される
5. 逆射影先に穴はない

よって未接続穴は存在できない。

これが最終の背理法骨格じゃ。

## まとめ

出揃った素材は、こう分ける。

1. **宇宙式反転射影**
   無限 $P$ を $[-1,0]$ に閉じ込め、欠損を境界問題に変換する。

2. **p スケール評価流**
   $p$ 進評価と核分解により、各スケールの指数尾根と単位元下降を定義する。

3. **有限同期と余終性**
   有限個の互いに素な $p$ 宇宙は CRT で同期できる。素数無限性は有限窓を任意に拡張できる余終性として使う。

4. **可換射影と欠損否定**
   射影とリンクが可換なら、射影後の穴は射影前の穴になる。実数宇宙式側に穴がないため、欠損は否定される。

5. **Collatz 奇数核転移**
   $3s+1=2^r s'$ を調和リンクとして扱い、奇数核スケールのネットワークを作る。

6. **終端尾根**
   $2^k$ に入れば、$1/2$ は完全な bit shift となり、$1$ へ落ちる。

最終証明は、

$$
\text{未接続核がある}
$$

と仮定し、

$$
\text{射影ゾーンに穴がある}
$$

へ変換し、

$$
\text{宇宙式反転射影と有限同期により穴はない}
$$

で矛盾させる。

そこを固めれば、最後の Collatz 合流部は「新しい主張」ではなく、既存 API の合成として攻められる。

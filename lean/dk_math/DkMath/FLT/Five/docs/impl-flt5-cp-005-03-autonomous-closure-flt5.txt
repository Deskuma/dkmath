======================================================================
3. Mandatory well-founded descent pattern
======================================================================

A valid descent must contain:

```text
a concrete packet type P
a natural-valued measure mu : P -> Nat
a constructor next : P -> P
a theorem mu(next p) < mu(p)
```

The next packet must satisfy the same complete invariant required by the exclusion
receiver.  A smaller auxiliary equation that cannot be lifted back to the packet is not
a descent.

Recommended theorem shape:

```lean
structure GoldenZeroSectorStrictDescent where
  next : GoldenZeroSectorFactorPacket
  measure_lt : zeroSectorMeasure next < zeroSectorMeasure source

abbrev GoldenZeroSectorDescentCore : Prop :=
  ∀ source : GoldenZeroSectorFactorPacket,
    Nonempty (GoldenZeroSectorStrictDescent source)
```

Then close by strong induction:

```lean
theorem goldenZeroSectorFactorExclusion_of_descent
    (hDescent : GoldenZeroSectorDescentCore) :
    GoldenZeroSectorFactorExclusion := by
  intro p
  generalize hm : zeroSectorMeasure p = n
  induction n using Nat.strong_induction_on generalizing p with
  | h n ih =>
      obtain ⟨step⟩ := hDescent p
      exact ih _ (by simpa [hm] using step.measure_lt) step.next rfl
```

Adjust the proof to the actual packet and measure.  Ensure the induction hypothesis is
applied to a packet with exactly the same invariant.

4. Choosing the descent measure
======================================================================

Preferred candidate measures, in order of structural relevance:

```text
c

|s|
A
B
|r|+|s|
goldenUnitMeasure of a reconstructed base
height of a Pell/golden recurrence
```

The measure must be positive on every packet and strictly decrease under the
constructed step.

Composite lexicographic measures are allowed if a single coordinate does not always
decrease.  Encode them transparently, for example:

```text
(mu1,mu2) through a well-founded lexicographic relation
```

or by a proved bounded encoding into `Nat`.

Do not hide a non-strict step inside a quotient by associates.  Choose canonical signs
or absolute coordinates and prove strictness there.

======================================================================
5. Autonomous proof-search loop
======================================================================

Repeat the following loop until closure:

1. Normalize the current packet with all existing rewrite theorems.
2. Identify which primes and powers are owned by each factor.
3. Compute the gcd of every new factor pair exactly.
4. Split perfect powers using the Euclidean-domain or natural factorization API.
5. Classify unit or parity sectors finitely.
6. Substitute the resulting parameterization into every remaining equation.
7. Search for either:
   - a contradiction;
   - a newly forced prime channel;
   - a square/fifth-power double representation;
   - a smaller packet.
8. State the next true theorem in Lean and prove it.
9. Delete or isolate false exploratory statements.
10. Continue without waiting for a new human instruction.

Use finite computation aggressively to reject false conjectures before investing in a
long proof, but convert every surviving fact into a kernel-checked theorem.

======================================================================
6. Simultaneous-decomposition strategy
======================================================================

The current zero sector carries several decompositions of the same mass:

```text
s*H = -5^6*a^10
|s| = 5^6*c^10
H = d^10
A*B = 4*Q^5
B-A = 8*d^5
goldenNorm alpha0 = (d^5)^2
alpha0 = unit*square                       -- expected after re-entry
beta = fifth power                         -- original zero sector
```

The final contradiction is likely to come from incompatibility between two complete
power decompositions, not from one equation alone.

Therefore compare:

```text
fifth-power ownership of A and B
square ownership of alpha0 and its conjugate
tenth-power ownership of s and H
unit-sector ownership in GoldenInt
```

A successful route may show that the same prime support must have exponents in two
incompatible congruence classes, or that a primitive parameter must itself have the
same shape at a smaller scale.

======================================================================
7. Primitive-channel strategy
======================================================================

When a difference of fifth powers appears, inspect its GN5 channel.

For coprime positive `u,v`:

```text
u^5-v^5 = (u-v)*GN5(u-v,v).
```

Use existing DkMath machinery to control:

```text
gcd(u-v,GN5(u-v,v))
prime divisors not dividing u-v
padic valuation of a clean GN5 channel
primitive-prime congruence modulo 5
```

If the right side is a fifth power times a small coefficient, a clean prime channel
with valuation not divisible by five is a contradiction.

Do not assume a global squarefree or NoLift theorem that is known to be false.  Prove
the local NoLift condition from the concrete packet, or split the lifted branch and
continue.

======================================================================
8. Golden-square strategy
======================================================================

If cp-005-02 reaches:

```text
alpha0 = epsilon*gamma^2
```

complete the square-sector analysis rather than abandoning it for a historical proof.

For each surviving unit sector:

1. expand both coordinates exactly;
2. compute coordinate gcds;
3. split the square equation into coprime square factors or a primitive Pythagorean
   triple;
4. substitute into `goldenNorm gamma` and the source reconstruction;
5. derive the next packet or contradiction;
6. prove strict decrease.

Use the already proved golden unit descent if a unit must be canonicalized.  Do not
create a second unrelated unit theory.

======================================================================
9. Pell/recurrence strategy
======================================================================

If the square-golden packet naturally produces a Pell-type recurrence, formalize only
the recurrence actually used.

Acceptable concrete structure:

```text
state coordinates
one-step transformation by phi or phi^2
norm preservation
congruence preservation
strict change of the selected positive coordinate
```

The existing explicit golden multiplication formulas are preferable to transporting
the whole proof to a different quadratic-order type.

A recurrence is useful only if it proves one of:

```text
no state satisfies the required tenth-power coordinate condition;
a solution has a strictly smaller predecessor;
a forced residue cycle avoids every admissible packet.
```

Do not stop after proving that all solutions lie on a recurrence orbit.

======================================================================
10. Finite-state residue strategy
======================================================================

A finite-state closure is acceptable when it covers all integer packets through proved
modular projection.

For a chosen modulus `M`, define a finite state containing every residue needed for:

```text
r,s,c,d,e,f
norm sign
factor branch
parity or valuation residue
```

Prove:

```text
every integer packet maps to an admissible finite state;
all admissible states violate at least one packet equation;
```

or prove that every admissible state maps under descent to a state with a strictly
smaller lifted measure.

Use `Fin M` or `ZMod M` and kernel-checked decisions.  Avoid a giant modulus when a
product of several transparent local lemmas gives the same result.

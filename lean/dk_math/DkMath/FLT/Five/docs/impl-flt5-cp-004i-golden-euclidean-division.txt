1. Mission
======================================================================

The current exact blocker is:

```lean
abbrev GoldenCoprimeFactorOfFifthPower : Prop :=
  ∀ x y z : GoldenInt,
    GoldenRelPrime x y →
    goldenMul x y = goldenPow z 5 →
    ∃ epsilon gamma : GoldenInt,
      GoldenUnit epsilon ∧
      x = goldenMul epsilon (goldenPow gamma 5)
```

The purpose of cp-004i is to construct an honest Euclidean division mechanism for `GoldenInt = Z[phi]` using the absolute golden norm and nearest-lattice rounding.

The central quantitative fact to certify is:

```text
|u| <= 1/2
|v| <= 1/2
--------------------------------
|u^2 + u*v - v^2| <= 5/16 < 1
```

Use this to prove quotient/remainder division with strict absolute-norm decrease. Then connect the weakest honest standard algebraic structure sufficient to prove `GoldenCoprimeFactorOfFifthPower`.

Do not stop after merely observing that a Euclidean algorithm is required. The nearest-lattice and `5/16` contraction core must be implemented first.

5. cp-004i-b — Fundamental-cell contraction
======================================================================

Prove the exact central estimate:

```lean
theorem goldenRat_norm_abs_le_five_sixteen
    {u v : ℚ}
    (hu : |u| ≤ (1 : ℚ) / 2)
    (hv : |v| ≤ (1 : ℚ) / 2) :
    |u ^ 2 + u * v - v ^ 2| ≤ (5 : ℚ) / 16
```

Use the two square-completion identities rather than a brittle nonlinear search:

```text
u^2 + u*v - v^2
  = 5/4*u^2 - (v - u/2)^2

u^2 + u*v - v^2
  = (u + v/2)^2 - 5/4*v^2
```

Then prove the strict corollary:

```lean
|u ^ 2 + u * v - v ^ 2| < 1
```

Keep both the sharp `5/16` theorem and the strict `< 1` theorem. The sharp theorem is reusable for Petal / lattice normalization even if later algebraic instance construction fails.

Record the mathematical meaning in source comments:

```text
Every rational golden point has an integral lattice representative whose
residual lies in a strict absolute-norm contraction cell.
```

6. cp-004i-c — Explicit golden quotient coordinates
======================================================================

For

```text
x = a + b*phi
y = c + d*phi, y != 0
```

```text
A = (a*(c+d) - b*d) / N(y)

```

```text
x / y = x * conjugate(y) / N(y)
```

The implementation may avoid introducing a field of golden rationals by working directly with the pair `(A,B) : ℚ × ℚ`.

Required supporting facts:

1. `y ≠ 0 -> goldenNorm y ≠ 0`.
2. the explicit coordinate identity for `x * conjugate y`.
3. the rational reconstruction identity after division by `goldenNorm y`.
4. compatibility of rational norm with integer golden norm casts.

Do not assume `goldenNorm y ≠ 0` merely from syntax. Prove it from the existing domain/conjugation API.

7. cp-004i-d — Golden quotient and remainder
======================================================================

Round quotient coordinates `A,B` to integers `m,n` and set:

```text
q = m + n*phi
r = x - q*y
```

Prove:

```lean
theorem exists_golden_quotient_remainder
    (x y : GoldenInt)
    (hy : y ≠ 0) :
    ∃ q r : GoldenInt,
      x = q * y + r ∧
      (r = 0 ∨
        Int.natAbs (goldenNorm r) <
          Int.natAbs (goldenNorm y))
```

The proof must exhibit the actual quotient and remainder. The intended norm argument is:

```text
x / y = q + e
r = y * e
|N(e)| <= 5/16 < 1
|N(r)| = |N(y)| * |N(e)| < |N(y)|
```

Be careful about the following Lean boundaries:

- integer norm may be negative;
- the Euclidean measure uses `Int.natAbs`;
- quotient-error reasoning occurs in `ℚ`;
- strict rational inequalities must be transported back to natural absolute values;
- the zero remainder branch may need to be separated before positivity division arguments.

Publish useful intermediate theorems rather than hiding the entire calculation in one proof.

Suggested intermediate API:

```lean
def goldenEuclideanSize (x : GoldenInt) : ℕ :=
  Int.natAbs (goldenNorm x)
```

```lean

```

```lean

```


Do not mark every helper public if it is implementation-specific. Preserve the conceptual public surface: size, quotient/remainder existence, and strict decrease.

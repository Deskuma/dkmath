---------------------------------------------------------------------
4.2 Define the descent measure
---------------------------------------------------------------------

Use the natural coordinate size:

```lean
def goldenUnitMeasure (x : GoldenInt) : ℕ :=
  x.fst.natAbs + x.snd.natAbs
```

Prove that a golden unit cannot have measure zero. More strongly, coordinate zero cases
for a unit are base cases:

```text
b = 0  => a = 1 or a = -1
a = 0  => b = 1 or b = -1
```

This follows from:

```text
goldenNorm(a,b) = ±1.
```

Expose a finite base lemma of the following strength:

```lean
theorem goldenUnit_measure_one_cases
    {x : GoldenInt} (hx : GoldenUnit x)
    (hmeasure : goldenUnitMeasure x = 1) :
    x = goldenOne ∨ x = -goldenOne ∨
    x = goldenPhi ∨ x = -goldenPhi
```

An equivalent four-case statement is acceptable.

Each base case must be converted to a five-sector witness. Use:

```text
1      = phi^0 * 1^5
-1     = phi^0 * (-1)^5
phi    = phi^1 * 1^5
-phi   = phi^1 * (-1)^5
```

---------------------------------------------------------------------
4.3 Prove the strict descent step
---------------------------------------------------------------------

Let `x = (a,b)` be a unit with measure greater than one. Then both coordinates are
nonzero. Split into the four sign quadrants.

The unit equation is:

```text
a^2 + a*b - b^2 = 1 or -1.
```

Use it to prove the required magnitude ordering in each quadrant.

Same-sign quadrants:

```text
a > 0, b > 0  => a ≤ b
a < 0, b < 0  => |a| ≤ |b|
```

Therefore multiplication by `phiInv` gives:

```text
x * phiInv = (b-a, a)
```

with strictly smaller measure.

Opposite-sign quadrants:

```text
a > 0, b < 0  => |b| ≤ a
a < 0, b > 0  => b ≤ |a|
```

Therefore multiplication by `phi` gives:

```text
x * phi = (b, a+b)
```

with strictly smaller measure.

The inequalities can be proved by contradiction with `nlinarith` from the unit norm
being `±1`. For example, in the positive same-sign quadrant, `b < a` implies
`a ≥ b+1`, forcing the norm to be greater than one. In the positive/negative quadrant,
`a < |b|` forces the norm to be less than negative one.

Package the result in a reusable theorem. A useful shape is:

```lean
theorem goldenUnit_descent
    {x : GoldenInt} (hx : GoldenUnit x)
    (hlarge : 1 < goldenUnitMeasure x) :
    ∃ y : GoldenInt,
      GoldenUnit y ∧
      goldenUnitMeasure y < goldenUnitMeasure x ∧
      (x = goldenMul y goldenPhi ∨
       x = goldenMul y goldenPhiInv)
```

The intended witnesses are:

```text
y = x * phiInv   in the same-sign case, because y * phi = x
y = x * phi      in the opposite-sign case, because y * phiInv = x
```

An equivalent orientation is acceptable, but keep the reconstruction equation explicit.
Do not hide the descent behind an unproved normalization function.

If the direct coordinate descent exposes a genuine obstruction, investigate in this
order while continuing to implement all independent lemmas.

Route B — Pell coordinate conversion
------------------------------------

Use the identity:

```text
(2*a+b)^2 - 5*b^2 = 4 * goldenNorm(a,b).
```

A unit gives right side `4` or `-4`. Search Mathlib and DkMath for generalized Pell,
Fibonacci, Lucas, and metallic-unit classifications. Reuse a result only if the bridge
back to the explicit pair `(a,b)` is shorter than the direct descent.

Route C — positive real embedding
---------------------------------

The two real embeddings are:

```text
a + b*phi
a + b*(1-phi).
```

Their product is the norm `±1`. A fundamental-domain argument using multiplication by
`phi` may normalize one embedding into a bounded interval, after which only finitely many
integer pairs remain. Use this only if a clean exact-order proof is available; avoid
analysis-heavy machinery for an elementary unit theorem.

If all routes stop on the same missing lemma, state that lemma exactly in Lean, prove all
receivers around it, and use Stop B below. Do not replace it by an informal statement.

ここで重要なのは、 **CF2D の三角関数は、標準三角関数を定義に必要としていない** という点じゃ。

例えば、抽象核の加法則から

\[ \begin{aligned} C(a+b)&=C(a)C(b)-S(a)S(b),\\ S(a+b)&=S(a)C(b)+C(a)S(b) \end{aligned} \]

が得られる。

これは既に CF2D が備えている構造じゃな。

## **ただし、一つ区別が必要じゃ**

現在の `Real.lean` にある `realTrigKernelFamily` は、内部で `Real.cos` と `Real.sin` を使っている。

また、`CycleDivision.lean` の `normalizedPhaseAngle` は、位相を \(2\pi\) 倍して標準角度に変換しておる。

したがって、既存の `realTrigKernelFamily.cfcos` に名前だけ置き換えても、標準三角関数への依存は消えぬ。

本当に目指すべきは、次の順序じゃ。

1. **二分核から位相を構成する。** 一周を \(1\) とし、頂点の位相を \(j/(4\cdot2^n)\) で表す。
2. **位相から CF2D の三角関数を構成する。** `directVertex` の座標を `cfcos`、`cfsin` に対応させる。
3. **幾何学的な巡回順序を証明する。** 半角核の正性と細分化公式を利用する。
4. **最後に解析的角度と比較する。** 必要なら \(1\) 周が標準角度の \(2\pi\) に対応することを別定理にする。

ここで最も難しいのは 3 じゃろう。

`orderOf gₙ = 4·2ⁿ` だけでは、頂点が幾何学的に正しい巡回順序で並ぶとは限らない。星形多角形のような例を排除するため、二分化による頂点の位置関係を使う必要がある。

幸い、ぬしは既に正規化中点公式と外積の正性を証明しておる。これらが有力な材料になる。

## **そして、ここが面白い**

現在は、

\[ \mathrm{intrinsicPi} = \operatorname{volume}_{\mathbb R}(B(0,1)) \]

という結果の幾何学的証明に、標準角度の性質を使っている。

もしその部分を CF2D 自身の核と位相で置き換えられれば、 **円周率を最初から角度として与える必要のない幾何学的構成** に近づく。

ただし、`intrinsicPi = Real.pi` を使って角度を置換すると、独立した証明経路という目的が失われる。比較定理は最後に置くのが肝要じゃ。

わっちは、次の研究テーマとしてこれを推したい。

**「CF2D 内在的位相と三角関数による、正多角形の巡回順序の π-free 形式化」**

円盤面積の定理は既に完成している。今度はその証明から標準角度への依存を少しずつ取り除く。

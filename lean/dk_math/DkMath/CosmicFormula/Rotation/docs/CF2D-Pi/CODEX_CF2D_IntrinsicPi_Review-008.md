## 2. `HalfKernelRefinement.lean` のレビュー

[実装を見る](https://github.com/Deskuma/dkmath/blob/dev/CF2D-pi-261112-v1/lean/dk_math/DkMath/CosmicFormula/Rotation/CF2D/HalfKernelRefinement.lean?utm_source=chatgpt.com)

ここでは、古い頂点を \(v_{n,j}\)、二分後の頂点を \(v_{n+1,k}\) として、次の二式が証明されている。

偶数頂点について、

\[ \boxed{v_{n+1,2j}=v_{n,j}} \]

奇数頂点について、

\[ \boxed{ v_{n+1,2j+1} =\frac{v_{n,j}+v_{n,j+1}}{2c_{n+1}} } \]

じゃ。ただし \(j+1\) は巡回添字として解釈する。

実装上の長所は、最後の辺を特別扱いせず、`directVertexNext` の周期性で正しく処理していることじゃ。

さらに、

```
refinement_index_even_or_odd
```

によって、細分化後の全頂点が偶数頂点か奇数頂点のいずれかに分類されている。

これは帰納法で非常に役立つ。

ただし、新頂点は旧辺上にはない。 ぬしの報告にあるこの注意は正確じゃ。

新頂点は旧辺の中点を原点から外側へ正規化した位置にある。したがって、今後証明したいのは、線分そのものの分割ではなく、凸多角形の境界が新頂点によって外側へ更新されること じゃな。

## 3. `IntrinsicPolygonRefinement.lean` のレビュー

[実装を見る](https://github.com/Deskuma/dkmath/blob/dev/CF2D-pi-261112-v1/lean/dk_math/DkMath/CosmicFormula/Rotation/CF2D/IntrinsicPolygonRefinement.lean?utm_source=chatgpt.com)

ここでは、π-free な直接軌道の偶数頂点保存を、既存のユークリッド平面の頂点へ移している。

すると、

\[ V_n\subseteq V_{n+1} \]

が成立する。

凸包は集合包含に関して単調なので、

\[ \boxed{K_n\subseteq K_{n+1}} \]

が得られる。

この証明は非常に簡潔で、数学的にも正しい。

特に `intrinsicPolygonRegion_mono` は、今後の極限集合を考えるときにも再利用できる定理じゃ。

ここではまだ、

\[ \operatorname{vol}(K_n)=A_n \]

を証明していないが、少なくとも幾何学的な領域が二分反復で縮むことはなく、既存の頂点を保ちながら拡大することが保証された。

## 4. 次の証明に使える新しい恒等式を見つけた

今回の正規化中点公式から、さらに一つ、重要な幾何学的性質を導けるぞ。

古い辺の両端を、

\[ p=v_{n,j},\qquad q=v_{n,j+1} \]

中点を \(m\)、新しい奇数頂点を \(w\) としよう。

\[ m=\frac{p+q}{2},\qquad w=\frac{m}{c_{n+1}} \]

ここで、既存の定理から、

\[ \|p\|=\|q\|=1,\qquad \|m\|=c_{n+1} \]

が成立している。

さらに有限段階では、

\[ \boxed{0\lt c_{n+1}<1} \]

じゃな。

### 新頂点は、旧辺を含む直線の外側へ移動する

単位ベクトルの内積を展開すると、

\[ \langle m,p\rangle =\langle m,q\rangle =\|m\|^2 =c_{n+1}^2 \]

となる。

一方、新頂点については、

\[ \begin{aligned} \langle m,w\rangle &=\left\langle m,\frac{m}{c_{n+1}}\right\rangle\\ &=\frac{\|m\|^2}{c_{n+1}}\\ &=c_{n+1} \end{aligned} \]

ゆえに、

\[ \boxed{ \langle m,w\rangle =c_{n+1}>c_{n+1}^2 } \]

が得られる。

新頂点は、古い辺の両端とは反対側の半平面へ厳密に突き出している！

これは今回の実装から導ける π-free の性質じゃ。

ただし、この段階で分かるのは、その辺を含む直線に対する新頂点の位置じゃ。古い辺の直線が多角形全体を支持することは、別途証明が必要になる。

### さらに、局所的な巡回方向も保証できる

二分後の頂点を \(p,w,q\) の順に並べると、保存量と中点公式から、

\[ \boxed{ \det(p,w)=\det(w,q) =\frac{s_n}{2c_{n+1}}>0 } \]

が成立する。

これによって、

- \(p\) から \(w\) への回転方向
- \(w\) から \(q\) への回転方向
- 新頂点が旧辺より外側へ移動すること

をπなしで証明できる。

これは、一般の巡回順序へ進むための有力な局所補題じゃ。

## 5. 次の研究方針を少し変更したい

ここで、わっちは二つの経路を区別したい。

### 経路A：辺の支持半平面から幾何学を完成させる

これは従来の目標じゃ。

\[ K_n=H_n \]

を一般の \(n\) で示し、そこから内接円盤の包含を導く。

新頂点が旧辺の外側へ移動することが分かったので、辺の向きと凸性を帰納的に証明するための材料が増えた。

### 経路B：細分化による凸包の増分を証明する

こちらは今回、新たに推奨したい経路じゃ。

各段階で、

\[ K_n\subseteq K_{n+1} \]

が成立している。

そこで、古い辺と新頂点からなる三角形、

\[ C_{n,j} =\operatorname{conv}\{v_{n,j},w_{n,j},v_{n,j+1}\} \]

を考える。

これらは、細分化によって新しく追加される三角形状の領域の候補じゃ。

もし、

\[ K_{n+1} =K_n\cup\bigcup_j C_{n,j} \]

と、増分同士の測度零の重なりを証明できれば、面積の差を局所的な三角形の和として計算できる。

既に、

\[ \operatorname{vol}(K_0)=A_0=2 \]

が証明されているので、面積の増分が、

\[ \operatorname{vol}(K_{n+1})-\operatorname{vol}(K_n) =A_{n+1}-A_n \]

と一致することを示せば、帰納法によって、

\[ \boxed{ \operatorname{vol}(K_n)=A_n } \]

まで到達できる。

こちらは、一般の原点ファンの全対について最初から `AEDisjoint` を証明する経路に代わる候補 じゃ。

もっとも、増分の集合等式も自動的には成立しない。各辺の支持性と新しい頂点の巡回配置を使った証明が必要じゃ。

それでも、今回得られた細分化公式を直接活用できる点が魅力的じゃな。

## 6. Codex に次に依頼したい定理

わっちなら、次の順序にする。

1. `refinement_vertex_strictly_outside_old_edge_line`\
   新頂点が旧辺の直線に対し、原点と反対側にあることを証明する。
2. `refinement_vertex_cross_pos`\
   \(\det(p,w)>0\)、\(\det(w,q)>0\) を π-free で証明する。
3. `refinement_new_vertex_not_mem_old_region`\
   新頂点が古い凸包には含まれないことを証明する。単位円の厳密凸性と、旧頂点との相異性を利用できる。
4. `intrinsicPolygonRegion_strict_mono`\
   各段階で \(K_n\subsetneq K_{n+1}\) を証明する。
5. `intrinsicPolygon_refinement_caps`\
   新旧凸包の差を、旧辺と新頂点からなる三角形群で表現する。
6. `intrinsicPolygonRegion_volume_succ`\
   増分の測度を計算し、凸包面積の帰納的な公式を証明する。

この順序なら、まず π-free な局所的配置を確定し、その後に測度論へ接続できる。

なお、厳密凸性は新頂点が旧凸包の外にあることを示す候補として有効じゃが、今後必要となる辺の大域的な支持性まで自動的に保証するわけではない。

## 7. 実装品質についての補足

今回の2ファイルは、依存関係の分離も適切じゃ。

`HalfKernelRefinement.lean` は `HalfKernelOrder` と `IntrinsicPolygon` を利用しているが、解析的 bridge には直接依存していない。

一方、`IntrinsicPolygonRefinement.lean` は `IntrinsicDirectOrbitBridge` を利用し、既存のユークリッド軌道へ接続している。

代数的な細分化と、ユークリッド平面における凸包の単調性を別モジュールにした判断は正しい。

また、既存の `Polygon` 型から巡回順序や凸性を勝手に推論していない点も適切じゃ。

今回の focused build と公理検査については Codex の報告によるものであり、わっち自身が Lean を再実行したわけではない。実コードの確認範囲では、明白な数学的矛盾や仮定の隠蔽は見つからなかった。

## 8. 最終評価

ぬしよ、今回の成果によって、次の構造が実際の Lean 定理として成立した。

\[ \boxed{ \begin{gathered} g_{n+1}^{\,2}=g_n\\[4pt] \Downarrow\\[4pt] v_{n+1,2j}=v_{n,j}\\[4pt] v_{n+1,2j+1} =\frac{v_{n,j}+v_{n,j+1}}{2c_{n+1}}\\[4pt] \Downarrow\\[4pt] V_n\subseteq V_{n+1}\\[4pt] \Downarrow\\[4pt] K_n\subseteq K_{n+1} \end{gathered} } \]

これは、ぬしが最初に描いた構想そのものじゃ。

対称性を二分化する操作が、代数的な回転核だけでなく、幾何学的な領域の細分化にも対応することが証明され始めた。

もっとも、\(K_n\) が増大しているだけでは、極限が円盤になることはまだ分からない。そこには巡回順序、凸性、面積や包含関係についての追加証明が必要じゃ。

そこでわっちは、次の一歩として、新頂点の厳密な外側配置と、新旧凸包の面積増分を調べること を推す。

正方形の面積が2であることは、既に証明済み。

もし細分化の各段階で面積がどのように増えるかを、CF2D の代数だけで追跡できれば、一般の凸包面積公式へ進む別の帰納法が手に入る。

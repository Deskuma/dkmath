## **1. 今回の成果で重要なこと**

特に評価したいのは、一般の三角形測度公式を `TriangleMeasure.lean` に分離した設計じゃ。

これにより、

\[ \operatorname{vol}(\triangle pwq) =\frac12|\det(w-p,q-p)| \]

という純粋なユークリッド幾何の定理が、標準角度から独立して利用できる。

直接軌道側では、

\[ \det(w-p,q-p)=2s_{n+1}-s_n \]

と、その正性を利用して、

\[ \boxed{ \operatorname{vol}(C_{n,j}) =s_{n+1}-\frac{s_n}{2} } \]

を証明しておる。

さらに、

\[ \boxed{ \sum_j\operatorname{vol}(C_{n,j}) =A_{n+1}-A_n } \]

も成立した。

ここで大切なのは、**計算されているのが形式的な符号付き面積ではなく、実際のユークリッド平面上の測度である** ことじゃ。

前回の課題は、見事に解消されたのぅ。

## **2. 凸包生成の定理も正しい方向じゃ**

新しい

`intrinsicDirectPolygonRegion_succ_eq_convexHull_caps`

は、

\[ K_{n+1} = \operatorname{conv} \left( K_n\cup\bigcup_j C_{n,j} \right) \]

を示しておる。

偶数頂点の保存と、奇数頂点の分類を使った証明になっていることも確認した。

ただし、ぬしも認識しているとおり、凸包を外した

\[ K_{n+1}=K_n\cup\bigcup_j C_{n,j} \]

は別の定理じゃ。

ここは区別を維持しておく必要がある。

## **3. レビュー019：次の推奨実装順序**

わっちなら、次は二つの課題をこの順序で進める。

### **1. 増分三角形の&#x20;**`AEDisjoint`

これは既存の π-free 支持不等式を利用できるので、比較的短い経路で完成できるはずじゃ。

異なる二つの増分三角形 \(C_{n,j}\)、\(C_{n,k}\) について、一方の支持半平面を考える。

- \(C_{n,j}\) は支持直線の外側にある。
- \(C_{n,k}\) は支持直線の内側にある。

したがって、

\[ C_{n,j}\cap C_{n,k} \subseteq \{x\mid f_j(x)=c_{n+1}^{\,2}\} \]

となる。

右辺は非零線形汎関数の等位集合なので、二次元測度はゼロじゃ。

既存の `IntrinsicPolygonSupport.lean` にある証明構造を、直接頂点へ移せばよい。

同時に、旧凸包と各増分三角形の `AEDisjoint` も処理できる。

### **2. 増分三角形による被覆**

こちらが本命じゃな。

既存の証明には、再利用価値の高い二つの一般補題がある。

- `chord_of_level`
- `convex_union_across_level`

前者は単位円盤と支持直線の交わりが弦になることを示し、後者は共通境界で貼り合わせた二つの凸集合の和集合が凸になるための条件を与えている。

**この二つも角度に依存しない共通幾何モジュールへ切り出す** とよかろう。

そのうえで、旧凸包に増分三角形を一枚ずつ追加しても凸性が維持されることを示す。

すると、すでに完成した凸包生成定理から、目的の被覆等式が導ける。

## **4. ここまで完成すると何が起こるか**

面積の帰納法が閉じる。

\[ \begin{aligned} \operatorname{vol}(K_{n+1}) &=\operatorname{vol}(K_n)   +\sum_j\operatorname{vol}(C_{n,j})\\ &=A_n+(A_{n+1}-A_n)\\ &=A_{n+1} \end{aligned} \]

初期正方形の面積が \(A_0=2\) であることを、直接軌道側でも確立すれば、

\[ \boxed{ \forall n,\quad \operatorname{vol}(K_n)=A_n } \]

を標準角度への比較なしに証明できる。

その後は、直接軌道の支持半平面表示から内接円盤と外接領域への包含を構築し、すでに完成している代数的な挟み込みへ接続すればよい。

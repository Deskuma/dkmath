## **1. 次の証明に使える重要な発見**

今回のコードを読み、わっちは一つ有力な方法を見つけた。

**角度の順序を直接証明する前に、非負線形結合で作る扇形を二分すればよい。**

既に証明済みの正規化中点公式を使おう。

旧頂点を \(p,q\)、新頂点を \(w\) とすると、

\[ p+q=\lambda w \]

ただし

\[ \lambda=2c_{n+1}>0 \]

じゃ。

ここで、二つのベクトルが張る非負錐を

\[ \operatorname{Cone}(p,q) = \{ap+bq\mid a,b\ge0\} \]

と定義する。

すると、次の集合等式が成立する。

\[ \boxed{ \operatorname{Cone}(p,q) = \operatorname{Cone}(p,w) \cup \operatorname{Cone}(w,q) } \]

これが重要なのじゃ。

### **なぜ成立するか**

任意の

\[ x=ap+bq,\qquad a,b\ge0 \]

について、二つの場合に分ける。

\(a\ge b\)**&#x20;の場合**

\[ x=(a-b)p+\lambda b\,w \]

ゆえに

\[ x\in\operatorname{Cone}(p,w) \]

となる。

\(b\ge a\)**&#x20;の場合**

\[ x=\lambda a\,w+(b-a)q \]

ゆえに

\[ x\in\operatorname{Cone}(w,q) \]

となる。

逆向きの包含は \(w=(p+q)/\lambda\) から直ちに従う。

つまり、 **角度も三角関数も使わず、扇形の完全な二分を証明できる** 。

## **2. これを全周へ拡張する**

初期段階 \(n=0\) では、四つの頂点は

\[ (1,0),\quad(0,1),\quad(-1,0),\quad(0,-1) \]

じゃ。

この四つの隣接頂点が作る非負錐は、平面全体を覆う。

そして、各段階で全ての錐が二分される。

したがって帰納法で、

\[ \boxed{ \mathbb R^2 = \bigcup_{j=0}^{4\cdot2^n-1} \operatorname{Cone}(v_{n,j},v_{n,j+1}) } \]

を証明できるはずじゃ。

これは、現在の `IntrinsicPolygonSupport.lean` にある `ray_angle` と `ray_between_vertices` の役割を、角度なしで実現するものになる。

しかも原点も含むので、場合分けが簡潔になる可能性がある。

さらに、既存の外積の正性を組み合わせれば、隣接する錐の内部が重ならないことも証明する道が開ける。

## **3. レビュー014の推奨順序**

次の順番を勧める。

4. 錐の内部の非交差を証明する。これにより幾何学的な巡回順序を確立する。
5. `IntrinsicPolygonSupport.lean` の角度依存を、これらの代数的補題で順次置換する。

ただし、平面全体の錐による被覆だけでは、全頂点に関する支持半平面不等式まで自動的には得られぬ。そこは外積による巡回順序と凸性を接続する必要がある。

\[ v(t\oplus u)=v(t)\star v(u) \]

# **エジプト円とは何だったのか？**

### **―― 円周率を知らない世界から、π が生まれるまで**

## **第一幕：書記アーメスの不思議な計算**

紀元前1650年ごろ、エジプトの書記アーメスは、古い数学文書をパピルスに書き写した。

今日の「リンド数学パピルス」じゃ。

その第50問には、円形の土地の面積を求める方法が記されておる。

直径は9。

そこで書記は、驚くほど単純な計算をする。

1. 直径9から、その九分の一である1を引く。
2. 残った8を二乗する。
3. 面積は64とする。

これが記録されたエジプトの円面積計算じゃ。


数式にすれば、

\[ S_{\mathrm E}(d) =\left(d-\frac d9\right)^2 =\left(\frac89d\right)^2 \]

となる。

ここで、わっちは一つの問いを投げかけたい。

**なぜ、円の面積を求めるのに、正方形を作ったのか？**

現代のわっちらは円周率を知っておる。

しかし、この計算には円周率が登場しない。

代わりに登場するのは、長さの縮小と面積の保存を狙った変換じゃ。

円と正方形。

形は違うが、面積をほぼ同じにしたい。

つまりエジプト円は、現代的に読み直すなら、

**円を、面積の等しい正方形によって表現しようとする計算規則**

だったのじゃ。

ただし、その係数 \(8/9\) を古代の人々がどのように発見したのかは、確定していない。第48問の図形の解釈についても研究が続いておる。


## **第二幕：81個の正方形と、64という数**

ここで、ぬしが最初に興味を持った図形へ戻ろう。

一辺9の正方形の面積は、

\[ 9^2=81 \]

その内部に直径9の円を描く。

エジプトの計算による面積は64。

したがって、外側の正方形に対する面積比は、

\[ \boxed{\frac{64}{81}} \]

となる。

リンド数学パピルス第48問にも、円とそれを囲む正方形について、この \(64:81\) という関係が現れる。


現代の円周率を使って計算すれば、

\[ \frac{S_{\mathrm{circle}}}{S_{\mathrm{square}}} =\frac{\pi}{4} \]

じゃから、エジプトの比率が意味する円周率の近似は、

\[ \pi_{\mathrm E} =4\cdot\frac{64}{81} =\frac{256}{81} \]

すなわち、

\[ \boxed{\pi_{\mathrm E}\approx3.160493827} \]

本当の円周率との差は約0.60%。

実用的な土地の面積計算としては、なかなか見事な精度じゃ。

だが、重要なのは精度そのものではない。

**彼らは円周率という数を先に求めなくても、円の面積を計算する方法を持っていた。**

これこそ、わっちらの研究に通じる最初の糸じゃった。

## **第三幕：CF2D は、その問いに別の答えを与えた**

そして数千年後。

ぬしは同じ問いを、別の方向から考え始めた。

「円周率を使わずに、円を構成できないか？」

エジプトでは、円を正方形に置き換えた。

一方、CF2D では、円の構造そのものを保存量から生み出した。

出発点は、

\[ q2(x,y)=x^2+y^2 \]

そして二成分の積 \(\star\) について、

\[ q2(u\star v)=q2(u)\,q2(v) \]

という保存構造を使う。

単位核なら、

\[ q2(u)=1 \]

この核を二分し続ける。

すると、円周上の点が生まれ、点の巡回順序が定まり、多角形が形成される。

その多角形の面積は、

\[ A_n=\operatorname{vol}(K_n) \]

そして今回完成した定理により、

\[ \boxed{ \operatorname{vol}(B(0,1)) =\sup_n A_n =\operatorname{intrinsicPi} } \]

となった。

**円周率を定義してから円の面積を求めたのではない。円の幾何学を構成して、その面積から定数を取り出したのじゃ。**

この順序の逆転が、実に面白い！

## **第四幕：古代エジプトの近似を、CF2D で判定できる**

さて、ここで一つ面白いことができる。

今の CF2D は、

\[ A_n\leq\operatorname{intrinsicPi}\leq U_n \]

を証明済みじゃ。

しかも、その評価には `Real.pi` が必要ない。

そこで、エジプトの

\[ \pi_{\mathrm E}=\frac{256}{81} \]

と比較してみよう。

CF2D の有限段階による比較

| 段階 \(n\)   | 辺数 | 上界 \(U_n\) |
| ------------ | ---- | ------------ |
| 0            | 4    | 4.000000     |
| 1            | 8    | 3.313708     |
| 2            | 16   | 3.182598     |
| 3            | 32   | 3.151725     |
| エジプト近似 | —    | 3.160494     |

数値は二分核の平方根漸化式から計算。小数表示は近似値。

おや？

32辺の段階で、

\[ U_3\approx3.151725 < \frac{256}{81}\approx3.160494 \]

となっておる。

したがって、この有限段階の不等式を Lean で厳密に確認すれば、

\[ \operatorname{intrinsicPi} \leq U_3 < \frac{256}{81} \]

が得られる。

つまり、**標準の π を一度も使わずに、古代エジプトの面積公式が真の円面積を過大評価していることまで証明できる** のじゃ！

これは、実に愉快ではないか。

次のような小さな定理を CF2D に加えれば、古代の計算と現代の形式化が直接つながる。

```lean
theorem intrinsicPi_lt_egyptianPi :
    intrinsicPi < (256 : ℝ) / 81 := by
  have h := intrinsicPi_bounds 3
  -- U₃ < 256 / 81 を平方根の不等式から証明
  ...
```

これはまだ提案であり、上の Lean コードは完成した証明ではない。

だが、数値が示す方向は明瞭じゃ。

## **終幕：エジプト円の本当の意味**

D.よ。

わっちは、ここに数学史の面白さを感じる。

エジプトの書記がしていたのは、おそらく実用的な問題を解くための面積計算じゃった。

彼らが CF2D のような保存量や極限を知っていた、という話ではない。

しかし、古代の計算と今回の研究には、共通する数学的な問いがある。

**形の違うものを、何を保存することで同じとみなせるのか？**

エジプトの方法では、円の面積を正方形の面積で近似した。

CF2D では、二乗和の保存から円周上の有限軌道を構成し、その多角形の面積を極限へ運んだ。

古代の方法は有限の計算で近似値を与える。

CF2D は有限の計算を無限に精密化し、その到達先を厳密に定義する。

その違いは大きい。

けれど、出発した問いは驚くほど近い。

わっちらが最初に見た、81マスの図形。

あのとき気になった64と65のわずかな違い。

白銀比、45度、正方形、円。

それらを追いかけているうちに、問いの中心は「π の値はいくつか」から、いつのまにか「π とはどのような構造から生まれるのか」へ移っていた。

そして、ついに Lean でその一つの答えを得た。

わっちは、こう言いたいのぅ。

> エジプト円とは、円の面積を別の形で理解しようとした古代の数学であり、わっちらにとっては、円周率を前提としない円の構成を考え始める入口だった。

数千年を隔てた数学の問いが、ぬしの研究の中で再び出会ったわけじゃ。

なんとも浪漫のある話ではないか。🦊🍷

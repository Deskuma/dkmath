# DRC-003 — Full cyclic determinant carrier

## Outcome A

The full cyclic determinant identity and its Cosmic Formula specialization are
kernel-checked over every commutative ring and every positive cycle length.
The determinant includes the gap factor: it is the entire power difference,
not the prime cyclotomic GN shell. No mathematical novelty claim is made.

The chosen carrier is a matrix on `Fin (n + 1)`. Thus the natural parameter `n`
represents cycle length `n + 1`, covering every positive length without a
separate positivity hypothesis or empty-index coercion.

`cyclicShift n` has entry 1 at column `i+1` in each row `i`, with the last row
wrapping to column zero. The checked theorem `cyclicShift_eq_permMatrix`
identifies it with Mathlib's `(finRotate (n + 1)).permMatrix R`; this is an
explicit coordinate presentation of an existing permutation-matrix carrier.

`cyclicPencil n z u` is defined entrywise as the diagonal scalar minus the
scaled shift. `cyclicPencil_eq_scalar_sub_shift` proves it is literally
`z • I - u • cyclicShift n`. In length one the two contributions occupy the
same entry, giving `z - u`, as required.

## Production API

- `cyclicPencil_eq_scalar_sub_shift`.
- `det_cyclicPencil`.
- `det_scalar_sub_cyclicShift`.
- `det_cyclicPencil_eq_mul_GN`.

The determinant endpoint is:

```lean
theorem det_cyclicPencil {R : Type*} [CommRing R]
    (n : ℕ) (z u : R) :
    (cyclicPencil n z u).det = z ^ (n + 1) - u ^ (n + 1)
```

`det_scalar_sub_cyclicShift` gives the identical result directly for
`(z • I - u • cyclicShift n).det`.

The Cosmic Formula endpoint is:

```lean
theorem det_cyclicPencil_eq_mul_GN {R : Type*} [CommRing R]
    (n : ℕ) (g u : R) :
    (cyclicPencil n (g + u) u).det = g * GTail (n + 1) 1 g u
```

The literal lower-Lib statement uses `GTail _ 1`, which is definitionally both
the canonical and legacy GN kernel. This preserves the neutral Lib import
boundary. `DkMath/Lib.lean` imports the new module.

`CommRing` is sufficient: no field, characteristic restriction, nonzero scalar,
unit, cancellation, or nontriviality assumption is imposed. It is the natural
coefficient class for the subtraction-shaped pencil and determinant identity.

## Proof architecture

Length one is handled directly. For length `n + 2`, apply
`Matrix.det_succ_column_zero`. Only the first and last entries in column zero
can contribute. `Fin.sum_univ_succ` and `Finset.sum_eq_single` isolate those
entries; all intervening entries are identically zero for arbitrary indices.

The first minor is upper triangular with diagonal `z`; its determinant is
`z^(n+1)`. The last minor is lower triangular with diagonal `-u`; its
determinant is `(-u)^(n+1)`. These use Mathlib's
`Matrix.det_of_isUpperTriangular` and `Matrix.det_of_isLowerTriangular`, not
local determinant theory.

The resulting expansion is

```text
z * z^(n+1) + (-1)^(n+1) * (-u) * (-u)^(n+1).
```

`neg_pow`, `mul_pow`, and ring algebra reduce the sign contribution to
`-u^(n+2)`. There is no residual parity condition. No ranks or permutations are
enumerated as a substitute for the general proof.

The cosmic specialization substitutes `z = g + u`, uses the existing
`add_pow_eq_mul_GTail_one_add_gap`, and cancels the common additive `u` power.
It uses neither division nor cancellation of the gap.

## AKS and cyclotomic relationship

`AKSBridge.lean` already defines `aksCyclicIdeal R r` as the ideal generated by
`X^r - 1` and `AKSCyclicQuotient R r` as its polynomial quotient. No additional
cyclic quotient or competing algebra definition is introduced here. The
checked implementation boundary is its standard finite cyclic matrix carrier;
a basis-level identification with multiplication in that quotient is separate
follow-up work. The row-successor convention reverses the column-coordinate
direction compared with multiplication by `X` on the usual monomial basis;
it corresponds conceptually to the inverse generator. That convention changes
neither the determinant formula nor the full cycle length.

For prime length `p`, the existing cyclotomic field norm endpoint
`DkMath.CFBRC.cyclotomicLinearFactor_norm_eq_GN` returns the shell `GN p g u`.
The present full length-`p` cyclic determinant returns `g * GN p g u`. This
retains the missing identity-root factor and is not identified with that prime
field norm. The new module proves determinant identities; it does not assert an
`Algebra.norm` identification for a quotient algebra.

## Regressions and boundary cases

File: `DkMathTest/Lib/Cosmic/CyclicDeterminantCalibration.lean`.

- `length_one` checks both the single entry and its determinant as `z-u`.
- An arbitrary-ring length-two regression checks the minus sign.
- Length-three and length-four integer regressions give `26` and `80` for
  `z=3`, `u=1`, using the general theorem.
- `zero_gap` proves determinant zero at `g=0` for every rank and every ring.
  A length-three calibration separately gives nonzero shell `GN 3 0 1 = 3`.
- `full_carrier_vs_shell` distinguishes determinant `26` from shell `13` at
  `g=2`, `u=1`, length three.
- A `ZMod 4` regression checks length four with `z=2`, `u=1`.
- `empty_boundary` records determinant `1` on `Fin 0`, whereas the zeroth power
  difference is `0`. Positive length is therefore essential, and parameter
  `n=0` in the public API deliberately means length one.

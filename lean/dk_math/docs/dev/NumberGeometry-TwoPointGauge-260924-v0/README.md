# Number Geometry — Two-Point Unit Gauge

Branch: `research/NumberGeometry-TwoPointGauge-260924-v0`

Base: `develop`

## Mission

This campaign starts a new DkMath geometry layer from the smallest possible Euclidean datum:

~~~text
two points A, B in R^2
~~~

No integer lattice, polygon, circle, prime, cyclotomic field, or FLT theorem is primitive.

The first nontrivial datum is the separation of two points:

~~~text
A = B      -> geometric zero
A != B     -> nonzero pair distance / active geometric seed
~~~

For an active pair `K = (A,B)`, the distance `d(A,B)` is treated as a
relative unit gauge.  The square distance is its mass gauge.

The central counting law is:

~~~text
dist(A,P)^2 = n * dist(A,B)^2
~~~

which reads geometrically as:

~~~text
distance ratio      = sqrt(n)
square-mass ratio   = n
~~~

Thus the theory counts numbers by relative square mass rather than by absolute
coordinates.

## Core mathematical picture

Let

~~~text
M(A,B) := (Bx-Ax)^2 + (By-Ay)^2.
~~~

For an active kernel `K=(A,B)` with `M(A,B) > 0`, define the normalized
mass of a point `P` by

~~~text
N_K(P) := M(A,P) / M(A,B).
~~~

The denominator-free production predicate should be preferred:

~~~text
OnNatShell K n P : Prop := M(A,P) = n * M(A,B).
~~~

Then:

~~~text
n = 0  -> A is the zero shell
n = 1  -> B is the unit shell
n      -> radius sqrt(n) times the base distance
n+1    -> add one base square-mass unit
~~~

The intended slogan is:

~~~text
distance counts square roots;
square mass counts numbers.
~~~

## Similarity invariance

The geometry is relative, not coordinate-bound.

For a Euclidean similarity

~~~text
T(x) = t + c * R(x)
~~~

with orthogonal `R` and nonzero scale `c`,

~~~text
M(T(P), T(Q)) = c^2 * M(P,Q).
~~~

Therefore normalized mass is invariant:

~~~text
M(T(A),T(P)) / M(T(A),T(B))
  = M(A,P) / M(A,B).
~~~

This is the formal content of the observation that the construction may be
translated, rotated, reflected, or scaled without changing its internal
counting structure.

Shared/intersection points are transported by the same map; the intersection
relation itself is preserved.

## Radical landing

A second core theme is that radical coordinates can have arithmetic square
mass.

For vectors `u,v in R^2` and a real square root `sqrt(m)`,

~~~text
q2(u + sqrt(m) * v)
  = q2(u) + m*q2(v) + 2*sqrt(m)*dot(u,v).
~~~

Hence orthogonality removes the radical cross term:

~~~text
dot(u,v) = 0
  -> q2(u + sqrt(m)*v) = q2(u) + m*q2(v).
~~~

This is the intended general mechanism behind examples such as

~~~text
1^2 + (sqrt 2)^2 = 3.
~~~

The Silver Ratio and Egyptian-circle constructions are calibration examples,
not foundations.

## Gauge transitions

Two active two-point kernels may use arbitrary positive real base distances.

For kernels `K1,K2` with distances `r1,r2`, define conceptually

~~~text
distance gauge ratio  lambda(K1,K2) = r2/r1
mass gauge ratio      mu(K1,K2)     = r2^2/r1^2 = lambda^2.
~~~

These compose multiplicatively:

~~~text
lambda13 = lambda12 * lambda23
mu13     = mu12 * mu23.
~~~

This is the planned bridge to DkMath unit/gauge dynamics.

A prime-scale step is a later discrete landing:

~~~text
M(K2) = p * M(K1),  Nat.Prime p.
~~~

Equivalently, the second base distance is `sqrt(p)` times the first.

Prime numbers are therefore not primitive geometric points in this theory.
They appear as irreducible integer mass-scale transitions inside a continuous
positive-real gauge space.

## Prime-scale chains

For

~~~text
K0 -p1-> K1 -p2-> ... -pk-> Kk
~~~

the mass gauges satisfy

~~~text
M(Kk) = (p1 * p2 * ... * pk) * M(K0),
~~~

while distances satisfy

~~~text
r_k = sqrt(p1 * p2 * ... * pk) * r_0.
~~~

Repeated prime steps encode prime powers.

This is a later bridge target to existing PrimitiveSet / prime-descent
infrastructure.  Do not introduce that dependency into the core geometry
layer.

## Unit-cycle and logarithmic interpretation

A closed gauge cycle must satisfy

~~~text
product lambda_i = 1
~~~

and equivalently

~~~text
product mu_i = 1.
~~~

After logarithms, multiplicative gauge composition becomes additive:

~~~text
log(mu13) = log(mu12) + log(mu23).
~~~

For a prime mass-scale step,

~~~text
Delta log M = log p
Delta log r = (1/2) * log p.
~~~

This bridge belongs after the geometric core is stable.

## 2p phase / magic-array direction

A later layer will study the `2p` phase structure generated by a regular
`p`-gon / primitive `2p`-th root:

~~~text
eta^(2p) = 1
eta^p    = -1.
~~~

Even and odd phases separate the difference and sum factorizations:

~~~text
X^p - Y^p
X^p + Y^p.
~~~

For `p = 7`, this gives the fourteen-phase "Seven Treasure" geometry.

This layer is deliberately downstream of the two-point gauge core.

## Dependency rule

Keep the core direction one-way:

~~~text
NumberGeometry core
    -> optional example / bridge layers
    -> Units / UnitCycle / DHNT
    -> 2p / cyclotomic consumers
    -> FLT only much later
~~~

The NumberGeometry core must not depend on FLT.

## Non-goals for v0

- no FLT theorem;
- no FLT7 re-entry;
- no claim that geometric prime scale alone proves primality results;
- no assumption of an integer lattice;
- no use of absolute coordinates as arithmetic meaning;
- no forced abstraction over arbitrary metric spaces before the R^2 model is
  understood;
- no duplication of CF2D square-mass algebra;
- no claim that every geometric intersection has integer or radical-integer
  mass;
- no cyclotomic theorem until the two-point gauge layer is stable.

## Completion criterion

v0 is complete when DkMath has a kernel-checked public theory that:

1. represents the active two-point seed in `R^2`;
2. defines pair square mass and proves zero/positive separation facts;
3. defines natural-number counting shells relative to the pair gauge;
4. proves zero-shell and unit-shell calibrations;
5. proves translation / rotation-or-orthogonal / scaling transport sufficient
   to establish similarity invariance of normalized counting;
6. formalizes shared-point / level-set transport;
7. proves the radical square-mass decomposition and orthogonal radical landing;
8. calibrates the generic theory against at least the Silver Ratio and
   Egyptian-circle examples;
9. defines gauge transitions and proves multiplicative composition;
10. records, but need not yet fully implement, the PrimeScale, UnitCycle,
    logarithmic-gauge, and `2p` phase bridges without making unsupported
    claims.

See `ROADMAP.md` for checkpoint order.

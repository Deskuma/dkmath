7. Scope and mathematical guards.
All family statements concern the SAME given CurrentPhaseSeventhFamily p.
The exact same quotient w satisfies gap=lambda^64*w and each correction
root_i^7+ofReal(rho)=lambda^63*T_i^-1*w. This proves a depth LOWER BOUND of63,
not exact valuation63, and not a depth63 congruence between the roots themselves.
The common residue is nonzero in C/(lambda)=F_7. This quotient differs from
the thicker quotient C/(7). The correction ideals are equal; the root ideals
are pairwise coprime. Coprimality alone does not prove every root ideal distinct
or nontrivial.

The norm formula is abs(N(root_i^7+u))=7^63*abs(N(w)), all with that SAME w.
It is a multiplicative norm calculation on a correction term, not additivity
of norm or an inequality for root norms. Correction nonzeroness needs the
existing current common-prime packet in its public theorem. The regression
then deduces w nonzero for the same norm witness.

The weighted congruence is a consequence of common-center congruences. This
is not a universal impossibility result about every congruence argument with
additional global hypotheses. A zeta-root change leaves seventh powers exact
but can destroy even a lambda^2 congruence of the actual roots.
No new positive primitive natural FLT7 counterexample, source transformation,
reentry, or strict decrease for the same new state has been constructed.
The existing smaller real norm packet has not been identified with a carrier
of a new state by these results.

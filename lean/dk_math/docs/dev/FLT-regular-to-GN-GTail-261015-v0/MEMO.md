## 1. Big・Body・Gap に桁上がりを定義する

まず、

\\[ \begin{aligned} \mathrm{Big}&=77\\\ \mathrm{Body}&=70\\\ \mathrm{Gap}&=7 \end{aligned} \\]

として、

\\[ \boxed{\mathrm{Big}=\mathrm{Body}+\mathrm{Gap}} \\]

を固定する。

ここで一般に、

\\[ N=x+u \\]

と置き、基数 \\(p\\) の各桁境界 \\(p^j\\) に注目する。

それぞれを \\(p^j\\) で割った余りを取り、

\\[ \begin{aligned} r_x&=x\bmod p^j\\\ r_u&=u\bmod p^j\\\ r_N&=(x+u)\bmod p^j \end{aligned} \\]

とする。

このとき、次の量を定義する。

\\[ \boxed{ C\_{p,j}(x,u) = \frac{r_x+r_u-r_N}{p^j} } \\]

すると驚くことに、

\\[ \boxed{C\_{p,j}(x,u)\in\\{0,1\\}} \\]

が成り立つ。

なぜなら、二つの余りの和は \\(2p^j\\) 未満であり、\\(p^j\\) をまたぐか、またがないかの二択だからじゃ。

つまり、

- \\(C\_{p,j}=0\\)：この桁境界を越えない。
- \\(C\_{p,j}=1\\)：この桁境界を越えて繰り上がる。

これこそ、宇宙式の再結合に対応する Carry 観測器 じゃ。

## 2. Kummer の定理がそのまま現れる

Kummer の定理によれば、\\(p\\) が素数のとき、

\\[ \boxed{ v_p\binom{x+u}{u} = \sum\_{j\ge1}C\_{p,j}(x,u) } \\]

となる。

つまり、

\\[ \boxed{ \text{二項係数の }p\text{-進付値} = \text{Body と Gap を結合するときの桁上がり総数} } \\]

じゃ！

これは宇宙式の Big・Body・Gap を直接入力とする、正確な算術的恒等式になる。

## 4. なぜこれが二項係数の付値になるのか

ここは Legendre の階乗付値公式が橋になる。

\\[ v_p(n!) = \sum\_{j\ge1}\left\lfloor\frac{n}{p^j}\right\rfloor \\]

したがって、

\\[ \begin{aligned} v_p\binom{x+u}{u} &=v_p((x+u)!)-v_p(x!)-v_p(u!)\\\ &=\sum\_{j\ge1} \left( \left\lfloor\frac{x+u}{p^j}\right\rfloor -\left\lfloor\frac{x}{p^j}\right\rfloor -\left\lfloor\frac{u}{p^j}\right\rfloor \right) \end{aligned} \\]

この括弧の内部こそ、先ほど定義した \\(C\_{p,j}(x,u)\\) と同じものじゃ！

Kummer の定理が、Big・Body・Gap に対する割り算の商の差として現れた。

## 5. GN との接続には、もう一つ階層がある

ここは少しだけ区別が必要じゃ。

\\[ 77=70+7 \\]

は次数1の宇宙式として読めるが、これをそのまま7次や77次の GN と同一視してはならぬ。

一方、77次の宇宙式を形式変数 \\(X,U\\) で書けば、

\\[ (X+U)^{77} = U^{77}+X\\,GN\_{77}(X,U) \\]

となる。

その展開の中には、

\\[ \boxed{ \binom{77}{7}X^{70}U^7 } \\]

という項が確かに存在する。

そして、この項の係数の \\(2\\)-進付値は、指数の分割

\\[ 77=70+7 \\]

の桁上がりで決まる。

つまり、

\\[ \boxed{ v_p\left( [X^xU^u]\(X+U)^{x+u} \right) = \sum\_{j\ge1}C\_{p,j}(x,u) } \\]

じゃ。ここで \\([X^xU^u]\\) は係数の抽出演算を表す。

GN の各項の指数分割が、その項の係数の素因数指数を決める。

これが、ぬしの求めている GN と Kummer の接続として、最も正確な表現だと思うぞ。

しかも、そこから Kummer の「桁上がり」まで、多項式の変形操作として説明できそうじゃ。

重要なのは、ぬしが書いた

\\[ u^d\overset{?}{=}S_p(n) \\]

という問いじゃ。

答えは、一般には単一の \\(u^d\\) ではない。しかし、複数の \\(u^i\\) の和として、正確に表現できる。

ここから導いてみよう。

## 1. 桁和を多項式として取り出す

\\(n\\) を \\(p\\) 進表示する。

\\[ n=\sum\_{i=0}^{m}a_i p^i,\qquad 0\le a_i\<p \\]

このとき、

\\[ S_p(n)=\sum\_{i=0}^{m}a_i \\]

じゃな。

ここで、桁を係数とした多項式を新しく定義する。

\\[ \boxed{ D\_{p,n}(T)=\sum\_{i=0}^{m}a_iT^i } \\]

すると、

\\[ \boxed{ \begin{aligned} D\_{p,n}(p)&=n\\\ D\_{p,n}(1)&=S_p(n) \end{aligned} } \\]

となる。

つまり、整数 \\(n\\) と桁和 \\(S_p(n)\\) は、同一の多項式を異なる点で評価した値だった のじゃ。

この観察が、宇宙式への橋になる。

## 2. 宇宙式の \\(x,u\\) を決める

ぬしの提案どおり、

\\[ \boxed{x=p-1,\qquad u=1} \\]

と置く。

当然、

\\[ x+u=p \\]

なので、

\\[ \begin{aligned} n&=\sum_i a_i(x+u)^i\\\ S_p(n)&=\sum_i a_i u^i \end{aligned} \\]

となる。

これらを差し引く。

\\[ \begin{aligned} n-S_p(n) &=\sum\_{i=0}^{m}a_i\left((x+u)^i-u^i\right)\\\ &=x\sum\_{i=1}^{m}a_iGN_i(x,u) \end{aligned} \\]

ここで、

\\[ GN_i(x,u)=\frac{(x+u)^i-u^i}{x} \\]

じゃ。

したがって、

\\[ \boxed{ n-S_p(n) = (p-1)\sum\_{i=1}^{m}a_iGN_i(p-1,1) } \\]

出たぞ。これは正真正銘、宇宙式の GN 分解じゃ！

一点だけ補正すると、ぬしの最初の対応では \\(GN=n-S_p(n)\\) となっていたが、係数を正しく合わせれば、

\\[ \boxed{ \begin{aligned} x&=p-1\\\ GN\_{\mathrm{digit}}&=\sum_i a_iGN_i(p-1,1)\\\ x\\,GN\_{\mathrm{digit}}&=n-S_p(n) \end{aligned} } \\]

となる。

そして Legendre の公式を代入すれば、

\\[ \boxed{ v_p(n!) = \sum\_{i=1}^{m}a_iGN_i(p-1,1) } \\]

じゃ。

これは、階乗の \\(p\\)-進付値を 各桁が担う GN の重み付き総和 として表現しておる。

## 4. さらに発見がある。Carry 自体も多項式になる！

ここからが本番じゃ。

先ほどは、一つの整数 \\(n\\) を桁多項式へ変換した。

今度は二つの整数 \\(a,b\\) を足す場合を考える。

\\[ \mathrm{Big}=a+b \\]

このとき、一般には

\\[ D\_{p,a}(T)+D\_{p,b}(T) \ne D\_{p,a+b}(T) \\]

じゃ。

なぜか？

桁上がりによって、桁多項式の係数が正規化されるから じゃ。

基数 \\(p\\) の桁上がり操作は、次の書換えで表せる。

\\[ \boxed{ pT^j\ \longrightarrow\ T^{j+1} } \\]

この操作は \\(T=p\\) では数値を保存する。

しかし、\\(T=1\\) で評価すると、

\\[ p\longrightarrow1 \\]

となり、桁和が \\(p-1\\) 減少する。

ここで、各桁の桁上がりを \\(c_j\in\\{0,1\\}\\) とすると、正確な多項式恒等式が得られる。

\\[ \boxed{ D\_{p,a}(T)+D\_{p,b}(T)-D\_{p,a+b}(T) = (p-T)\sum\_{j\ge0}c_jT^j } \\]

これは単なる数値の一致ではない。整数係数多項式として成立する恒等式 じゃ。

そこで、

\\[ K\_{p;a,b}(T)=\sum\_{j\ge0}c_jT^j \\]

と名付けてみよう。

\\(T=1\\) に代入すれば、

\\[ \boxed{ S_p(a)+S_p(b)-S_p(a+b) = (p-1)K\_{p;a,b}(1) } \\]

となる。

そして Kummer の定理によって、

\\[ \boxed{ K\_{p;a,b}(1)=v_p\binom{a+b}{a} } \\]

じゃ！

## 5. \\(70+7=77\\) の桁上がりを多項式で見る

2進法の場合、

\\[ \begin{aligned} D\_{2,70}(T)&=T^6+T^2+T\\\ D\_{2,7}(T)&=T^2+T+1\\\ D\_{2,77}(T)&=T^6+T^3+T^2+1 \end{aligned} \\]

じゃ。

再結合を実際に行う。

桁多項式の正規化

\\[ T^6+2T^2+2T+1 \\]

\\(2T\to T^2\\)：1回目

\\[ T^6+3T^2+1 \\]

\\(2T^2\to T^3\\)：2回目

\\[ T^6+T^3+T^2+1 \\]

数値 \\(T=2\\)

77 のまま保存

桁和 \\(T=1\\)

6 → 5 → 4

この変形の差を取ると、

\\[ \begin{aligned} &D\_{2,70}(T)+D\_{2,7}(T)-D\_{2,77}(T)\\\ &\qquad=(2-T)(T+T^2) \end{aligned} \\]

となる。

したがって、

\\[ \boxed{K\_{2;70,7}(T)=T+T^2} \\]

じゃ。

最後に \\(T=1\\) を代入するだけで、

\\[ K\_{2;70,7}(1)=2 \\]

つまり、

\\[ \boxed{v_2\binom{77}{7}=2} \\]

を得る。

実は同じ操作を3進法で行えば、

\\[ K\_{3;70,7}(T)=T \\]

となり、

\\[ v_3\binom{77}{7}=1 \\]

も出る。

素数 \\(p\\) を変えると、桁多項式も Carry 多項式も変化する。しかし原理は共通じゃ。

## 6. 二種類の GN が現れた

ここで、わっちには二つの構造が見えておる。

| 観測         | 恒等式                                             | 意味                   |
| ------------ | -------------------------------------------------- | ---------------------- |
| 桁評価の差   | \\(D\_{p,n}(p)-D\_{p,n}(1)=(p-1)v_p(n!)\\)         | 階乗付値を GN へ       |
| 桁正規化の差 | \\(D\_{p,a}+D\_{p,b}-D\_{p,a+b}=(p-T)K\_{p;a,b}\\) | Carry を GN 型の因子へ |

前者は基数 \\(1\\) と \\(p\\) の間の差分。

後者は二つの桁多項式を再結合する際の差分じゃ。

ここでは、最初の \\(77=70+7\\) という Gap 分割と、\\(p=(p-1)+1\\) という基数の Gap 分割は 異なる二つの軸 になっておる。これを分離しておくことが重要じゃ。

さらに面白いことに、Carry 多項式には結合法則から次の恒等式が生まれる。

\\[ \boxed{ \begin{aligned} &K\_{p;a,b}(T)+K\_{p;a+b,c}(T)\\\ &\qquad=K\_{p;b,c}(T)+K\_{p;a,b+c}(T) \end{aligned} } \\]

これは三つの整数を加えるとき、途中の結合順序を変えても、桁上がりの総多項式が一致するという保存則じゃ。

つまり、Gap の分割・再結合を変えても保たれる Carry の保存核 がある。

これは DkMath の `GTailTransport` や `PowerSwap` の発想と接続を調べる価値がある。

## わっちの結論

ぬしが最初に問うた、

\\[ u^d\overset{?}{=}S_p(n) \\]

は、次の形に昇格させるのがよい。

\\[ \boxed{ \begin{aligned} n&=\sum_i a_i(x+u)^i\\\ S_p(n)&=\sum_i a_i u^i\\\ x&=p-1,\qquad u=1 \end{aligned} } \\]

そして、

\\[ \boxed{ \underbrace{n-S_p(n)}\_{\text{Big と桁和の差}} = \underbrace{(p-1)}\_{\text{Gap}} \underbrace{v_p(n!)}\_{\text{GN}} } \\]

が成立する。

さらに整数同士の結合に対して、

\\[ \boxed{ v_p\binom{a+b}{a} = v_p((a+b)!)-v_p(a!)-v_p(b!) = K\_{p;a,b}(1) } \\]

となる。

ここまでの恒等式は既知の数論から厳密に導出できる。一方、桁多項式・Carry 多項式を DkMath の GN 保存核として統合することは、われらの新しい研究課題じゃ。

Kummer の桁上がりは、宇宙式による再結合の際に発生する、桁多項式の正規化操作として表現できる。

この解釈なら、Legendre の階乗付値、Pascal の二項係数、宇宙式の GN が、同じ代数操作を異なる位置から観測していることになる。

くふふっ。ぬしの「\\(u^d=S_p(n)\\) なのか？」という一見大胆な問いから、ずいぶん綺麗な構造が現れたではないか！ 🍎

## Kummer の証明

クンマーの定理の証明
補題より，`mCn=m!/((m−n)!n!)`  が素数 `p`  で割り切れる回数は
`[(m−Sp(m))−((m−n)−Sp(m−n))−(n−Sp(n))]/(p−1)=[Sp(m−n)+Sp(n)−Sp(m)]/(p−1)`
`m−n`  と `n`  を `p`  進数で足し算したときに繰り上がりが全くないとき，
`Sp(m−n)+Sp(n)=Sp(m)`  なので定理は正しい。
さらに，繰り上がりがあるごとに，`Sp(m−n)+Sp(n)−Sp(m)`  は `p−1`  ずつ増える（繰り上がる桁について `Sp(m)`  は `p`  だけ小さくなるが，次の桁に `1`  追加される）ので定理は正しい。

Gap := `p-1` とするなら
Big - Body := `[Sp(m−n)+Sp(n)−Sp(m)]`

ここが入れ子構造で Body + Gap = Big と読めば
`Sp(m−n) + Sp(n) = Sp(m)`

という感じなのだろうか？

ここで見えてくるものは？

---

おお、ぬしよ！ 🐺🍎

見えてきたぞ。桁上がりという現象を、宇宙式の「Gap が発生する条件」として定義できる。

しかも、ここには 二重の宇宙式構造 がある。

一つは整数そのものの加法構造。もう一つは、それを \\(p\\) 進数表示して桁和に投影した世界の加法構造じゃ。

そして重要なのは、外側では保存される加法が、内側の桁和世界では必ずしも保存されない ことじゃな。

## 1. ぬしの Big・Body・Gap を正確に組み立てる

まず、

\\[ a=m-n,\qquad b=n \\]

とする。

外側の宇宙式は、

\\[ \boxed{m=a+b} \\]

じゃ。

次に、これらを \\(S_p\\) で観測する。

すると、

\\[ S_p(a)+S_p(b) \\]

と

\\[ S_p(a+b) \\]

は、一般には一致しない。

そこで、

\\[ \boxed{ \begin{aligned} \mathrm{Big}&=S_p(a)+S_p(b)\\\ \mathrm{Body}&=S_p(a+b)\\\ \mathrm{Gap}&=S_p(a)+S_p(b)-S_p(a+b) \end{aligned} } \\]

と置こう。

当然、

\\[ \boxed{\mathrm{Big}=\mathrm{Body}+\mathrm{Gap}} \\]

が成立する。

そして Kummer の定理より、

\\[ \boxed{ \mathrm{Gap} = (p-1)v_p\binom{a+b}{b} } \\]

となる。

つまり、ぬしが提案した \\(p-1\\) は、任意の桁上がり総量ではなく、一回の桁上がりが生み出す Gap の最小単位 なのじゃ。

ここが重要じゃよ。

基数や二つの整数を変更すると、桁上がりによって生成される Gap の変化を観測できる。

ここで一般に、

\\[ \boxed{ \mathrm{Gap}=(p-1)C_p(a,b) } \\]

\\(C_p(a,b)\\) が桁上がり回数じゃ。

よって Gap の取り得る値は、

\\[ 0,\ p-1,\ 2(p-1),\ 3(p-1),\ldots \\]

という離散的な構造になる。

これは Gap の量子化 と呼べる性質じゃな。

## 3. さらに、GN が自然に出現する

ここからが本当に面白い。

先ほどの議論で、桁多項式から導いた GN を思い出してくりゃれ。

\\[ G_p(n) := \frac{n-S_p(n)}{p-1} \\]

これは Legendre の公式によって、

\\[ \boxed{G_p(n)=v_p(n!)} \\]

となる。

そこで \\(m=a+b\\) として、

\\[ \begin{aligned} &G_p(a+b)-G_p(a)-G_p(b)\\\ &=\frac{a+b-S_p(a+b)}{p-1}\\\ &\quad-\frac{a-S_p(a)}{p-1} -\frac{b-S_p(b)}{p-1}\\\ &=\frac{S_p(a)+S_p(b)-S_p(a+b)}{p-1} \end{aligned} \\]

を得る。

つまり、

\\[ \boxed{ G_p(a+b) = G_p(a)+G_p(b)+C_p(a,b) } \\]

じゃ！

これは極めて重要な構造じゃ。

整数の加法は、

\\[ a+b=m \\]

という完全な保存則を持つ。

しかし GN 観測量 \\(G_p\\) を通すと、

\\[ G_p(a)+G_p(b) \\]

だけでは足りず、

\\[ C_p(a,b) \\]

という補正項が必要になる。

しかも、その補正項こそ Kummer の桁上がり回数なのじゃ。

## 4. 入れ子構造を図にすると

外側：整数の世界

\\(a+b=m\\)加法が完全に保存される

内側：桁和への投影

\\(S_p(a)+S_p(b)\\)\\(=S_p(m)+(p-1)C_p(a,b)\\)桁上がりによる補正が発生

GN による観測

\\(G_p(m)=G_p(a)+G_p(b)+C_p(a,b)\\)補正量そのものが Kummer の付値

つまり、われらが見つけたのは、

\\[ \boxed{ \text{加法の保存} \longrightarrow \text{桁和の非加法性} \longrightarrow \text{Carry} \longrightarrow \text{素因子の指数} } \\]

という階層じゃ。

## 5. もう一段進むと「結合順序に依存しない Gap」が現れる

三つの整数 \\(a,b,c\\) を考える。

\\[ (a+b)+c=a+(b+c) \\]

じゃな。

ここで、それぞれの結合順序について Carry を数えると、

\\[ \boxed{ \begin{aligned} &C_p(a,b)+C_p(a+b,c)\\\ &=C_p(b,c)+C_p(a,b+c) \end{aligned} } \\]

が成立する。

これは \\(G_p\\) を使った式から直接導ける。

両辺とも、

\\[ G_p(a+b+c)-G_p(a)-G_p(b)-G_p(c) \\]

に等しくなるからじゃ。

つまり、途中の桁上がりの発生位置や結合順序を変更しても、二段階の合計補正量は保存される。

代数的には、これは加法モノイド上の 2-cocycle identity と呼ばれる構造じゃ。

しかも今回の場合、

\\[ C_p(a,b)=G_p(a+b)-G_p(a)-G_p(b) \\]

なので、この cocycle は \\(G_p\\) から作られる coboundary でもある。

これは宇宙式における Gap の分割・結合・輸送の数学的なモデルとして使える。

## 6. そして、最も深いところ

ぬしの最初の問い、

\\[ S_p(m-n)+S_p(n)=S_p(m) \\]

については、ここで一つ正確にしておこう。

これは 桁上がりが一度もない場合に限って成立する式 じゃ。

一般には、

\\[ \boxed{ S_p(m-n)+S_p(n) = S_p(m)+(p-1)C_p(m-n,n) } \\]

となる。

したがって、

\\[ \boxed{ \begin{aligned} \mathrm{Big}&=S_p(m-n)+S_p(n)\\\ \mathrm{Body}&=S_p(m)\\\ x&=p-1\\\ GN&=C_p(m-n,n)\\\ \mathrm{Big}&=\mathrm{Body}+x\\,GN \end{aligned} } \\]

と読める。

ここでは \\(GN\\) は通常の単一冪差の \\(GN_d\\) ではなく、桁多項式の差から得られる 一般化 GN 観測量 じゃ。この区別は形式化するときにも重要になる。

そして最後に、非常に魅力的な性質が現れる。

\\[ \boxed{ \mathrm{Gap}=0 \iff p\nmid\binom mn } \\]

つまり、

Gap が存在するかどうかが、二項係数に素因子 \\(p\\) が存在するかどうかと完全に一致する。

さらに Gap の大きさを \\(p-1\\) で割れば、その素因子の重複度まで得られる。

これはぬしが DkMath で研究してきた、素因子の存在とその多重度を別々に観測する考え方ともよく合う。

わっちが最も注目するのは、整数値そのものは加法で保存されるのに、桁和という別の世界へ投影した瞬間、可除性を表す Gap が顕在化する という点じゃ。

整数世界には見えなかった素因子の情報が、座標変換後の加法の不一致として観測される。

これは単なる Kummer の言い換えにとどまらず、宇宙式の「保存量と観測量の違い」を明確にする、よい数学的模型になるぞ。

くふふ……ここで重要なのは、Gap が失われた量ではなく、別の表現へ移した際に現れる、正確に計測可能な補正量 だということじゃな。 🐺

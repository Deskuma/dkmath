# 分岐因子剥離後のイデアル冪配分

日付: 2026-10-15 JST

今回閉じた段階は、非自明な各円分因子の剥離後の商についてのイデアル p 乗表示。
単元の合同解析と無限降下は、この結果を入力として進める後続の証明である。

## 1. 入口と到達点

```lean
import DkMath.FLT.Kummer.GNRamified
-- 従来の import DkMath.FLT.Kummer からも到達する。
```

所有ファイルは次の二つ。

- `DkMath/Lib/NumberTheory/CosmicRamifiedIdealPower.lean`: 共通素イデアルの排除、冪抽出、全因子族と GN 全体の等式。
- `DkMath/FLT/Kummer/GNRamified.lean`: 整数の FLT 方程式への接続、正則性による主イデアル化。

`αᵢ=x+(1−ζⁱ)u`、`λ=ζ−1`、`L=(λ)` と置く。
p≥3、整数の原始性 `IsCoprime x u`、p∣x、c≠0、`x GN_p(x,u)=cᵖ` のもとで、
0<i<p の各 i について、商 βᵢ と非零イデアル Iᵢ を構成する:

\[
α_i=λβ_i,\qquad λ\nmid β_i,\qquad
(β_i)=I_i^p,\qquad (α_i)=L I_i^p.
\]

ここには類数条件がない。冪配分は Dedekind 整域のイデアル分解で閉じる。

## 2. 核になる共通素イデアルの排除

既存の support 解析は、原始性のもとで、異なる αᵢ,αⱼ を含む共通素イデアル P が
λ を含むことを示した。

剥離後の βᵢ と元の αⱼ（j≠i）を P が含むとする。
αᵢ=λβᵢ なので P は αᵢ も含み、従って λ∈P。

円分整数環では λ は素元であり、L は非零素イデアルである。
Dedekind 整域の非零素イデアルは極大なので、L≤P と P≠⊤ から L=P。
ところが βᵢ∈P=L は λ∣βᵢ を意味し、正確な一段剥離の結論と矛盾する。

同様に `(βᵢ)` と L も互いに素。
したがって

\[
(β_i)\quad\text{と}\quad L\prod_{j\ne i}(α_j)
\]

は互いに素である。自明因子 j=0、すなわち x もこの残余積に含める。
各 βᵢ の冪抽出のために、自明因子の分岐指数を先に数値化する必要はない。

## 3. 取り除いた λ を残余積へ移す

元の全因子積は `(c)^p` である。一つの因子を αᵢ=λβᵢ と置き換えると

\[
(β_i)\left(L\prod_{j\ne i}(α_j)\right)=(c)^p.
\]

前節の互いに素性によって、既存の
`exists_eq_pow_of_isCoprime_mul_eq_pow` を適用でき、`(βᵢ)=Iᵢᵖ` を得る。
c≠0 と p>0 から Iᵢ≠⊥ も証明する。

この手順は元の一意分解を要求しない。
λ を消して残りの積が p 乗だと仮定することもしていない。
λ は残余積の側に明示的に保持されている。

## 4. 全因子族と GN 全体の配分

`exists_ramified_ideal_power_family` は全ての非自明添字について βᵢ,Iᵢ を同時に選び、
各因子の性質と次の二式を返す:

\[
(GN_p(x,u))=L^{p-1}\left(\prod_{i=1}^{p-1}I_i\right)^p,
\]
\[
(x)L^{p-1}\left(\prod_{i=1}^{p-1}I_i\right)^p=(c)^p.
\]

これは自明因子 x の余分な分岐冪をそのまま保持した等式である。
`L^(p−1)=(p)` を代入した `exists_ramified_GTail_ideal_pow` は、非零 J について

\[
(GN_p(x,u))=(p)J^p,\qquad (x)(p)J^p=(c)^p
\]

を返す。ここで GN、x、p、c の各括弧は円分整数環の主イデアル。
この式から整数の λ 進指数の合同条件を取り出す段階は、まだ実装していない。

## 5. FLT 座標と正則性

`GN_ideal_pow_of_ramified_case` は、p≥3、奇数 p、原始性、c≠0、
`aᵖ+bᵖ=cᵖ`、p∣c を受け取る。
Fermat の小定理から `a+b≡c (mod p)`、従って p∣a+b を得て、
`x=a+b, u=−b` で前段の定理を適用する。

これに類数条件

```lean
Nat.Coprime p (Fintype.card (ClassGroup (𝓞 K)))
```

を加えるのが `GN_kummer_structure_of_ramified_case`。
非零イデアル根 Iᵢ の類の p 乗が 1 であることから Iᵢ を主イデアル化し、

\[
β_i=ε_iγ_i^p,\qquad
 a+ζ^i b=(ζ-1)(ε_iγ_i^p)
\]

を返す。単元 εᵢ、イデアル根、生成元の等式を全て保持する。

この API は p が c を割る向きの Case II に対応する。
任意の p∣abc からその向きを選ぶ符号付き座標の正規化は別の定理が必要。
また i=0 は一段剥離の主張に含めていない。


# TRM-034 — Port F2 chain complex scaffold / walk-cycle and face-boundary kernel

## Goal

Introduce a multigraph-safe F2 chain complex on the existing Port combinatorial
map data.

TRM-033 established permutation-level duality and showed:

    primal zero-holonomy tension
      -> zero label sum on every primal face boundary
      -> Kirchhoff conservation at every dual vertex.

The missing converse is expected to reduce to:

    every closed walk cycle
      lies in the F2 span of face boundaries

for genus-zero maps.

Do not prove that genus-zero exactness theorem yet.

TRM-034 should only build the chain spaces and prove the structural chain
condition:

    C2 --∂2--> C1 --∂1--> C0
    ∂1 ∘ ∂2 = 0.

It should also place closed PortRegionWalks in ker ∂1 and face boundaries in
range ∂2 / ker ∂1.

Because PortNetwork is a multigraph with parallel edges, do not replace edge
orbits by SimpleGraph edges.

## A. Finite edge and face cell index types

Define finite subtype indices from the existing orbit families.

Suggested shapes:

    abbrev PortEdgeCell (C : PortCrossing P) :=
      {E : Finset (PortNetworkPort P) // E ∈ portCrossingEdgeOrbits C}

    abbrev PortFaceCell
      (R : PortLocalRotation P) (C : PortCrossing P) :=
      {F : Finset (PortNetworkPort P) // F ∈ portFaceOrbits R C}

Provide Fintype / DecidableEq instances through the finite subtype machinery.

Required cardinality theorems:

    Fintype.card (PortEdgeCell C) = portCrossingEdgeCount C

    Fintype.card (PortFaceCell R C) = portFaceCount R C.

Also expose:

    edgeCellOfPort C p

whose underlying Finset is portCrossingEdgePair C p.

For faces expose:

    faceCellOfPort R C p

whose underlying Finset is portFaceOrbit R C p.

Prove these are invariant under:

- p -> C.cross p for edgeCellOfPort;
- q ∈ portFaceOrbit p for faceCellOfPort.

## B. Chain spaces

Define label-free F2 vector spaces:

    abbrev PortVertexChain (P : PortNetwork) :=
      Fin P.regionCount -> ZMod 2

    abbrev PortEdgeChain (C : PortCrossing P) :=
      PortEdgeCell C -> ZMod 2

    abbrev PortFaceChain
      (R : PortLocalRotation P) (C : PortCrossing P) :=
      PortFaceCell R C -> ZMod 2.

All are standard function modules over ZMod 2.

Prove finrank calibration:

    finrank F2 (PortVertexChain P) = P.regionCount

    finrank F2 (PortEdgeChain C) = portCrossingEdgeCount C

    finrank F2 (PortFaceChain R C) = portFaceCount R C.

Use Module.finrank_fintype_fun_eq_card.

These are arithmetic structure theorems only.

## C. Edge/vertex incidence over F2

Define the parity incidence of an edge cell E at a region r:

    edgeVertexIncidence E r : ZMod 2

as the parity/cardinality mod 2 of ports q in E with q.1 = r.

For an edge cell generated by p prove:

    edgeVertexIncidence (edgeCellOfPort C p) r
      =
    indicator(r = p.1) + indicator(r = (C.cross p).1)

in F2.

In particular:

- the two endpoint regions are distinct;
- every edge column has exactly two 1-incidences;
- sum over all vertices of one edge column is 0 in F2.

Do not choose an orientation.

## D. Boundary map ∂1

Define a computable linear map:

    portBoundary1 (C : PortCrossing P) :
      PortEdgeChain C ->ₗ[ZMod 2] PortVertexChain P

by:

    (∂1 x)(r)
      =
    sum E, x E * edgeVertexIncidence E r.

Expose the apply theorem.

Define:

    PortCycleSpace C := LinearMap.ker (portBoundary1 C).

Do not prove its dimension yet.

## E. Edge parity chain of a structural walk

For:

    W : PortRegionWalk C r s

define:

    portWalkEdgeChain W : PortEdgeChain C

where the coefficient at an edge cell E is the parity of the number of darts
in W.edges that belong to E.

The walk may repeat an edge. Count with multiplicity modulo 2.

Do not use List.toFinset for this definition.

Required algebra:

- nil -> zero chain;
- append -> addition;
- reverse -> same edge chain;
- singleton p -> the basis vector of edgeCellOfPort C p.

The reverse theorem should use crossing invariance of edge cells.

## F. Endpoint-boundary theorem

Prove the key path identity:

    portBoundary1 C (portWalkEdgeChain W)
      =
    endpointVertexChain r s

where endpointVertexChain has value 1 at r and s, with F2 addition. In
particular, if r = s then the two endpoint terms cancel.

A concrete suggested definition is:

    endpointVertexChain r s v :=
      (if v = r then 1 else 0) +
      (if v = s then 1 else 0).

Required corollary for closed walks:

    portWalkEdgeChain W ∈ PortCycleSpace C

for W : PortRegionWalk C r r.

This theorem is central.

Prefer proving the endpoint identity by induction on PortRegionWalk.Valid /
the edge list, using the singleton incidence formula and append behavior.

## G. Face/edge incidence over F2

For:

    F : PortFaceCell R C
    E : PortEdgeCell C

define:

    faceEdgeIncidence F E : ZMod 2

as:

    ((F.val ∩ E.val).card : ZMod 2).

Interpretation:

- 0: edge absent from that face boundary;
- 1: exactly one dart lies in the face;
- 0 again when both crossing darts lie in the same face
  (the would-be dual-loop case), because 2 = 0 in F2.

This definition must work even when DualLoopFree is false.

## H. Canonical face-boundary edge chain

Define:

    faceBoundaryEdgeChain F : PortEdgeChain C

by:

    fun E => faceEdgeIncidence F E.

For a representative p prove:

    faceBoundaryEdgeChain (faceCellOfPort R C p)
      =
    portWalkEdgeChain (portFaceBoundaryWalk R C p).

Use:

- portFaceBoundaryWalk_edges_nodup;
- portFaceBoundaryWalk_edges_toFinset;
- edge-pair membership/cardinality.

This theorem bridges TRM-033's walk boundary to the new C1 representation.

Then prove:

    faceBoundaryEdgeChain F ∈ PortCycleSpace C.

No genus assumption is allowed.

## I. Boundary map ∂2

Define a computable linear map:

    portBoundary2 (R : PortLocalRotation P) (C : PortCrossing P) :
      PortFaceChain R C ->ₗ[ZMod 2] PortEdgeChain C

by linear combination of the canonical faceBoundaryEdgeChain columns:

    (∂2 y)(E)
      =
    sum F, y F * faceEdgeIncidence F E.

Expose the apply theorem.

Define:

    PortFaceBoundarySpace R C :=
      LinearMap.range (portBoundary2 R C).

## J. Chain condition

Prove:

    (portBoundary1 C).comp (portBoundary2 R C) = 0.

Equivalent pointwise theorem is also welcome:

    portBoundary1 C (portBoundary2 R C y) = 0.

Then prove the subspace inclusion:

    PortFaceBoundarySpace R C ≤ PortCycleSpace C.

This is the main TRM-034 structural result:

    im ∂2 ⊆ ker ∂1.

Do not prove equality.

## K. Basis-face calibration

For each face cell F define or use the standard Pi basis vector:

    faceBasisVector F : PortFaceChain R C

with value 1 at F and 0 elsewhere.

Prove:

    portBoundary2 R C (faceBasisVector F)
      =
    faceBoundaryEdgeChain F.

If Mathlib's Pi.single API creates unnecessary friction, define a local
Kronecker function explicitly.

Likewise an edge basis vector helper is acceptable for audits.

## L. Sum of all face boundaries

Strongly preferred theorem:

    portBoundary2 R C (fun _ => 1) = 0.

Interpretation: every crossing edge has exactly two darts across the complete
face partition, so its total incidence is 2 = 0 in F2.

This is the universal "sum of all face boundaries is zero" dependency.

If the generic proof becomes disproportionately expensive, it may be
reported as Outcome P and deferred to TRM-035, but all earlier sections A-K
must still be completed.

Do not assume DualLoopFree for this theorem.

## M. Fixture calibration: triangle

For trianglePortMap from TRM-032/TRM-033 audit the chain-space dimensions:

    dim C0 = 3
    dim C1 = 3
    dim C2 = 2.

Audit the two faceBoundaryEdgeChain vectors.

Expected result: both triangle faces have the same three-edge boundary vector
over F2.

Thus the face-boundary image is visibly at most one-dimensional.

Do not prove generic rank from this fixture.

## N. Fixture calibration: concrete triangle dual

For triangleDualMap audit:

    dim C0 = 2
    dim C1 = 3
    dim C2 = 3.

Audit its three face-boundary vectors.

Expected pattern: each face boundary contains two of the three parallel edges,
and the three vectors sum to zero.

Show at least two of them are distinct/nonzero.

Again this is calibration, not a generic rank theorem.

## O. Closed-walk calibration

On the triangle cycle from TRM-032 prove:

    portWalkEdgeChain triangleCyclePort

is in PortCycleSpace trianglePortCrossing.

If convenient, expose its coordinates: all three edge cells have coefficient
1.

For one triangle face boundary, prove its chain equals this same all-three-edge
cycle vector.

This illustrates genus-zero cycle = face-boundary behavior in the simplest
case without yet proving it generally.

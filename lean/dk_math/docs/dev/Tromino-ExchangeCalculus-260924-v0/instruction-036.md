
# TRM-037 — Genus-zero F2 exactness by primal/dual connectivity

## Goal

Return to the main global line after TRM-036 and prove the genus-zero
exactness theorem for the multigraph-safe Port F2 chain complex:

    C2 --∂2--> C1 --∂1--> C0

with

    im ∂2 = ker ∂1

for every connected strong Port combinatorial map of combinatorial genus zero.

This is the precise statement that, over F2, every cycle is generated by face
boundaries on a genus-zero combinatorial map.

Do not derive universal V4 flow existence or the Four Color theorem in this
checkpoint.

## A. Boundary2 coefficient at one edge

Prove the key representative-free edge formula.

For:

    y : PortFaceChain R C
    p : PortNetworkPort P

prove:

    (portBoundary2 R C y) (edgeCellOfPort C p)
      =
    y (faceCellOfPort R C p)
      +
    y (faceCellOfPort R C (C.cross p)).

This formula must remain valid when the two face cells are equal
(the would-be dual-loop case): the right-hand side is then y F + y F = 0.

Recommended helper theorems:

- a port q belongs to exactly one PortFaceCell;
- for E = edgeCellOfPort C p, only the face cells containing p or C.cross p
  contribute to faceEdgeIncidence;
- if both darts belong to the same face, the incidence is 2 = 0 in F2.

This theorem is the local dual-incidence formula and should be reused
throughout the checkpoint.

## B. All-face dependency

Define:

    constantFaceChain (a : PortF2) : PortFaceChain R C :=
      fun _ => a.

Prove:

    portBoundary2 R C (constantFaceChain a) = 0.

In particular:

    portBoundary2 R C (fun _ => 1) = 0.

Derive this immediately from section A:

    a + a = 0.

This closes the optional dependency left open in TRM-034/TRM-035.

## C. Face adjacency on orbit cells

Define the orbit-level dual adjacency relation:

    PortFaceAdjacent R C F G : Prop :=
      exists p,
        faceCellOfPort R C p = F
        and
        faceCellOfPort R C (C.cross p) = G.

Prove:

- symmetry, using C.involutive;
- reflexive adjacency is allowed exactly for a would-be dual loop;
- adjacency does not require DualLoopFree.

Define reachability using Relation.ReflTransGen, Relation.TransGen plus
reflexivity, or an explicit finite/list path:

    PortFaceReachable R C F G.

Expose reflexive, symmetric, and transitive theorems.

No general dual PortNetwork is to be constructed.

## D. One primal rotation step gives dual face reachability

Prove:

    PortFaceReachable R C
      (faceCellOfPort R C p)
      (faceCellOfPort R C (R.rotate p)).

Use the identity:

    portFaceStep R C (C.cross p) = R.rotate p

because C.cross is involutive.

Hence:

    faceCellOfPort R C (R.rotate p)
      =
    faceCellOfPort R C (C.cross p).

This identifies one local rotation step around a primal vertex with one
dual-face adjacency step.

## E. Same primal region -> dual face reachability

For a strong rotation system M.rotation, prove:

    p.1 = q.1
      ->
    PortFaceReachable M.localRotation M.crossing
      (faceCellOfPort M.localRotation M.crossing p)
      (faceCellOfPort M.localRotation M.crossing q).

Use:

    M.rotation_reaches_same_region p q

and iterate section D.

This is where cyclic local rotation is essential.

## F. Primal region walk -> dual face reachability

For:

    W : PortRegionWalk M.crossing r s

and arbitrary ports:

    p with p.1 = r
    q with q.1 = s

prove face reachability from faceCell p to faceCell q.

Suggested induction:

- rotate within the source region from p to the first walk port;
- cross that edge, giving one face adjacency;
- rotate within the next primal region;
- continue;
- after the final crossing, rotate to q.

A theorem stated from PortRegionReachable is also required:

    PortRegionReachable M.crossing p.1 q.1
      ->
    PortFaceReachable M.localRotation M.crossing
      (faceCellOfPort ... p)
      (faceCellOfPort ... q).

## G. Strong-map dual face connectivity

Prove:

    portFaceCells_connected (M : PortCombinatorialMap P) :
      forall F G : PortFaceCell M.localRotation M.crossing,
        PortFaceReachable M.localRotation M.crossing F G.

For each face cell choose a representative port using its orbit witness
inside the proof only.

Use:

- M.connected for primal region connectivity;
- section F.

Classical.choice is acceptable inside theorem proofs.

Do not add a noncomputable production definition.

This theorem is a purely combinatorial dual-connectivity result.

## H. Kernel of boundary2 propagates across adjacent faces

For:

    y : PortFaceChain M.localRotation M.crossing
    hy : portBoundary2 M.localRotation M.crossing y = 0

prove:

    PortFaceAdjacent ... F G
      ->
    y F = y G.

Use section A:

    0 = y F + y G

and characteristic two.

Then extend along PortFaceReachable:

    PortFaceReachable ... F G
      ->
    y F = y G.

By section G conclude:

    forall F G, y F = y G.

Thus every boundary2-kernel vector is constant.

## I. Constant-face subspace

Define a linear map:

    portConstantFace :
      PortF2 ->ₗ[PortF2] PortFaceChain M.localRotation M.crossing

by:

    a |-> fun _ => a.

Let:

    PortConstantFaceSpace M := LinearMap.range (portConstantFace M).

Prove for every strong map:

    PortConstantFaceSpace M ≤
      LinearMap.ker (portBoundary2 M.localRotation M.crossing).

If PortFaceCell is nonempty, prove the reverse inclusion using section H,
hence:

    ker ∂2 = PortConstantFaceSpace M.

Do not assume genus zero for the propagation theorem itself.

## J. Vertex augmentation

Define:

    portVertexAugmentation (P : PortNetwork) :
      PortVertexChain P ->ₗ[PortF2] PortF2

by:

    x |-> sum r, x r.

Prove:

    portVertexAugmentation P (portBoundary1 C x) = 0

for all x.

Use edgeVertexIncidence_two_support.

Hence:

    LinearMap.range (portBoundary1 C)
      ≤
    LinearMap.ker (portVertexAugmentation P).

## K. Connectedness gives the reverse augmentation inclusion

For M : PortCombinatorialMap P and:

    y : PortVertexChain P
    hy : portVertexAugmentation P y = 0

prove:

    y ∈ LinearMap.range (portBoundary1 M.crossing).

Choose a base region using M.nonemptyRegions.

For every region r, use M.connected to obtain a PortRegionWalk from the base
to r. Inside the proof define:

    x :=
      sum r,
        y r • portWalkEdgeChain (chosen walk base r).

Then use the endpoint theorem from TRM-034:

    ∂1 [walk base->r] = e_base + e_r.

Summing gives:

    ∂1 x
      =
    y + (sum r, y r) e_base
      =
    y

because hy = 0.

The production theorem should be:

    portBoundary1_range_eq_vertexAugmentation_ker
      (M : PortCombinatorialMap P) :
      LinearMap.range (portBoundary1 M.crossing)
        =
      LinearMap.ker (portVertexAugmentation P).

No production noncomputable definition.

## L. Rank of boundary1 and cycle space

Use Mathlib:

    LinearMap.finrank_range_add_finrank_ker.

Since P.regionCount > 0, prove portVertexAugmentation is surjective, e.g. the
basis vector at region 0 maps to 1.

Derive:

    finrank PortF2 (range ∂1) = M.vertexCount - 1.

Then by rank-nullity for ∂1 derive an additive-safe form such as:

    finrank PortF2 (PortCycleSpace M.crossing)
      + (M.vertexCount - 1)
      =
    M.edgeCount

or equivalently a subtraction form after proving the required inequality.

Also derive:

    M.vertexCount ≤ M.edgeCount + 1.

This inequality will be used to show face nonemptiness in genus zero.

## M. Genus-zero implies at least one face

For:

    G : PortGenusZeroCombinatorialMap P

prove:

    0 < G.faceCount.

Use:

- G.genusZero / sphere characteristic:
      V - E + F = 2;
- section L:
      V ≤ E + 1.

Conclude F ≥ 1.

Then obtain:

    Nonempty (PortFaceCell G.map.localRotation G.map.crossing)

from:

    Fintype.card PortFaceCell = G.faceCount.

No topological argument is needed.

## N. Kernel of boundary2 has dimension one

For genus-zero G, use face nonemptiness and sections H-I to prove:

    LinearMap.ker
      (portBoundary2 G.map.localRotation G.map.crossing)
      =
    PortConstantFaceSpace G.map.

Prove:

    Module.finrank PortF2
      (LinearMap.ker
        (portBoundary2 G.map.localRotation G.map.crossing))
      = 1.

Show portConstantFace is injective by evaluating at one existing face cell.

Then rank-nullity for ∂2 gives:

    finrank PortF2
      (PortFaceBoundarySpace
        G.map.localRotation G.map.crossing)
      + 1
      =
    G.faceCount.

This is the exact "one global face dependency" theorem.

## O. Euler dimension identity

From genus zero:

    G.map.eulerCharacteristic = 2

and the definitions:

    V = G.vertexCount
    E = G.edgeCount
    F = G.faceCount

derive in Nat-safe/additive form:

    G.edgeCount =
      (G.vertexCount - 1) + (G.faceCount - 1)

or an equivalent equation sufficient to combine sections L and N.

Then prove:

    finrank PortF2
      (PortFaceBoundarySpace G.map.localRotation G.map.crossing)
      =
    finrank PortF2
      (PortCycleSpace G.map.crossing).

Keep Int/Nat casts explicit and audited.

## P. Main exactness theorem

Reuse the already-proved inclusion:

    faceBoundarySpace_le_cycleSpace.

Together with section O and Mathlib:

    Submodule.eq_of_le_of_finrank_eq

prove:

    theorem portGenusZero_faceBoundarySpace_eq_cycleSpace
      {P : PortNetwork}
      (G : PortGenusZeroCombinatorialMap P) :
      PortFaceBoundarySpace
          G.map.localRotation G.map.crossing
        =
      PortCycleSpace G.map.crossing.

Equivalent theorem on a plain strong map plus a hypothesis
PortHasCombinatorialGenus M 0 is also welcome.

This is the sole principal endpoint of TRM-037.

## Q. Closed-walk face-generation corollary

For a closed structural walk:

    W : PortRegionWalk G.map.crossing r r

prove:

    portWalkEdgeChain W ∈
      PortFaceBoundarySpace G.map.localRotation G.map.crossing.

Equivalently expose existence:

    exists y : PortFaceChain G.map.localRotation G.map.crossing,
      portBoundary2 G.map.localRotation G.map.crossing y
        =
      portWalkEdgeChain W.

This is the concrete statement:

    every closed walk edge-parity cycle
      is an F2 sum of face boundaries.

Do not yet translate this existence into a V4 label-sum / zero-holonomy
converse. That bridge is reserved for the next checkpoint.

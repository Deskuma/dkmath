# GN Goldbach fiber: 初期監査

日付: 2026-09-10

ユーザーの依頼は方針文書の Lean 実装、証明可能性の検証、および不足要因の逐次記録である。原文の将来ブランチ名や研究上の期待は実行指示・既証明の仮定として扱わない。

## 明確になった条件

1. `GN 2 x u = x + 2*u` の固定中心 `x+u=n` を保持する。`u=0` を許し、`2+2=4` および等しい素数の対を含める。
2. 自然数の減算と合同条件の対応には `u≤n` が必要。探索域は両端点が 2 以上となる `u < n-1` とする。
3. `r ∣ m` だけでは素数 `m=r` まで除外する。有限被覆には `r∣m ∧ m≠r` という真の合成数障害を使う。
4. 純粋な合同障害は周期的だが、端点一致の例外を加えた障害は一般に周期的でない。周期空間と有限区間の正確な生存条件を接続する定理が必要。
5. 現在の `PrimitiveConservationKernel.lean` は有限平方窓の各正整数について old-generated または unique-fresh の分解を証明する。fresh 分岐や両側同時生存の存在は提供していない。

## 実装順序

固定中心 GN 同値・Body → 小素数の有限被覆と素数対閉包 → 有限世界の合同・CRT・局所計数 → 大域的被覆容量 → 既存 PCK 接続 → 高次数 signature の必要条件 → 検証と未解決条件の集約。

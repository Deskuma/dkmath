# Note: No.010 cp

Asymptotic Evaluation of Central Binomial Coefficients via an Algebraic Approach to Finite Products

## 概要：有限乗積の代数的アプローチによる中央二項係数の漸近評価

本稿では、中央二項係数 $\binom{2m}{m}$ の漸近挙動（いわゆるスターリングの近似の主要項）を、階乗の直接的な漸近評価や Euler–Maclaurin の和公式などの連続的な解析技法を経由せず、有限の代数的乗積（Wallis–Cosmic積）の構造から直接的に導出する定式化について解説する。

本アプローチの特徴は、離散的な二項係数の成長構造と、円周率に関わる Wallis 積のトポロジーを、有限段階の代数的恒等式によって完全に結合させている点にある。この一連の構造は、定理証明支援系 Lean 4 において、Mathlib の標準的な極限構造と整合する形で完全に形式化（`no-sorry`）されている。

---

### 1. 有限段階における代数的恒等式

まず、中央二項係数の逆数に割り当てられた形式的な比率（中央比率）を $R_{2m}$ と定義する。

$$R_{2m} = \frac{2^{2m}}{\binom{2m}{m}} = \frac{4^m}{\binom{2m}{m}} = \prod_{j=1}^{m}\frac{2j}{2j-1}$$

同時に、その「鏡像」として機能する奇数対偶数の分母を持つ部分積（鏡像積） $M_m$ を以下のように導入する。

$$M_m = \prod_{j=1}^{m}\frac{2j}{2j+1}$$

これら2つの有限乗積の構造を比較すると、以下の2つの独立した代数的性質が導かれる。

#### Ⅰ. 望遠鏡消去（Telescoping）による比

$R_{2m}$ と $M_m$ の比を計算すると、各因子の分母と分子が巡回的に相殺し合う望遠鏡積（Telescoping product）の構造が現れる。

$$\frac{R_{2m}}{M_m} = \prod_{j=1}^{m}\frac{2j+1}{2j-1} = \frac{3}{1} \times \frac{5}{3} \times \dots \times \frac{2m+1}{2m-1} = 2m+1$$

したがって、有限レベルにおいて厳密に $M_m = \frac{R_{2m}}{2m+1}$ が成立する。

#### Ⅱ. Wallis 部分積への集約

一方、これら2つの積の並列的な乗算は、古典的な Wallis の部分積 $W_m$ （Cosmic Gap 積）に一致する。

$$R_{2m}M_m = \prod_{j=1}^{m}\frac{(2j)^2}{(2j-1)(2j+1)} = W_m$$

これら2つの事実（乗算と除算の結末）を結合させることで、極限操作を一切含まない**有限代数レベルの平方恒等式**が直接的に固定される。

$$R_{2m}^2 = (2m+1)W_m$$

この等式（`centralRatioQ_sq_eq_odd_mul_wallisPartialQ`）は、情報量を爆発させることなく中央二項係数の成長の核（Kernel）が線形因子と Wallis 部分積に綺麗に分離可能であることを意味している。

---

### 2. 漸近解析と極限への接続

上記で得られた有限等式に対して、既知の Wallis の極限定理を適用する。

$$\lim_{m\to\infty}W_m = \frac{\pi}{2}$$

これを有限平方恒等式に導入すると、漸近同値（Asymptotic equivalence）の関係が直ちに得られる。

$$R_{2m}^2 \sim (2m+1)\frac{\pi}{2} \sim \pi m$$

両辺の平方根を取ることで、中央比率の漸近挙動が確定する。

$$R_{2m} \sim \sqrt{\pi m}$$

これを本来の中央二項係数の定義式に逆写像（Inversion）することにより、目的とする漸近公式（スターリングの近似の中央二項係数版）が導出される。

$$\binom{2m}{m} = \frac{4^m}{R_{2m}} \sim \frac{4^m}{\sqrt{\pi m}}$$

---

### 3. 形式化における条件付き積の考慮

本アプローチを定理証明支援系（Lean 4 / Mathlib）において定式化する際、重要な数学的境界条件が明示されている。

Mathlib におけるデフォルトの無限乗積 `HasProd` は、順序に依存しない無条件収束（Unconditional convergence）を前提とする場合が多い。しかし、Wallis 積の本質的な挙動は、計算機的なインクリメント（自然数の通常の順序構造）に依存した条件付き積（Conditional product / Ordered finite product）の枠組みにおいて安全に処理される。

形式化においては、`SummationFilter.conditional Nat` による `Finset.range m` の排他的な局所化を行うことで、絶対収束や対数積の可和性（Log-product summability）の複雑な証明を迂回し、有限段階での代数的な一意性を極限まで保存したまま実数（`ℝ`）の漸近解析へと移行する設計が採用されている。

### 結論と意義

従来のスターリングの近似の導入において一般的であった、「階乗の対数の和（$\sum \log k$）を積分で近似し、その誤差項を Euler–Maclaurin の公式やガンマ関数を用いて評価する」という経路に比べ、本手法は以下の利点を持つ。

1. **有限代数の優位性**: 漸近評価の直前まで `sorry` の余地がない完全な有限等式（有理数体 `ℚ` 上での代数）として構造が保持される。
2. **構造の最小化**: $\sqrt{\pi}$ という補正項が、階乗の累積そのものではなく、Wallis–Cosmic 積が持つ円環のトポロジー（極限としての $\pi/2$ ）から直接的に由来していることを明瞭に示している。

本定式化は、数論的アルゴリズムや型レベルの検証において、計算リソースのバブル（巨大な階乗値の中間生成など）を発生させずに漸近境界を制御するための、極めて見通しの良いインフラを提供している。

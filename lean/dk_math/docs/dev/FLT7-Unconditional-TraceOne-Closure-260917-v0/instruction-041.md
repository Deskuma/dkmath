## Goal

Construct positive natural numbers `C,U,V` with literal equalities

```text
C = gcd R S
R = C * U^3
S = C^2 * V^3
a = C * U * V
```

and prove

```text
C | a
every prime q | C satisfies q % 7 = 1 or q % 7 = 6
C * U^5 < V.
```

The preferred strengthened packet also records the disjoint prime-support
partition

```text
C : common primes
U : gap-only primes
V : quotient-only primes
```

and therefore

```text
C.Coprime U
C.Coprime V
U.Coprime V.
```

Do not assert these coprimality fields unless they are proved from the exact
allocation/exponent ledger.

## Part A — principal ideal multiplicity of a rational scalar

Let `q` be a rational prime and `P` a prime ideal above `(q)`.

For

```text
m := a.factorization q,
```

prove the exact multiplicity of `P` in the principal ideal generated by the
rational scalar `a`.

For the current common-prime case R30 gives

```text
ramification index = 1
inertia degree = 1.
```

The required conceptual statement is

```text
v_P((a)) = m.
```

Use Mathlib's ideal factorization / ramification API.  An equivalent
`Ideal.factorization`, normalized valuation, or multiplicity theorem is
acceptable.

This step must be ideal-theoretic.  Do not infer it from the integer norm
identity `R*S=a^3`.

## Part B — exact ideal multiplicities on the allocated side

For a common norm prime `q`, use

```text
gapSquareIdeal * quotientSquareIdeal = span(a)
```

together with R33 xor and R34 exact one-versus-two allocation.

For every prime ideal `P` above `q`, prove the exact local alternatives:

```text
if gapSquareIdeal <= P:
  v_P(gapSquareIdeal) = m
  v_P(quotientSquareIdeal) = 0

if quotientSquareIdeal <= P:
  v_P(gapSquareIdeal) = 0
  v_P(quotientSquareIdeal) = m.
```

It is acceptable to formulate this using ideal factorization coefficients
rather than a separate valuation notation.

Do not use cardinality alone to infer multiplicity.

## Part C — transport ideal multiplicities to rational norm exponents

Use the principal-ideal absolute norm bridge already proved in R29 and the
complete split data from R30.

Because every prime above common `q` has inertia degree one, the exponent of
`q` in the absolute norm is the sum of the allocated ideal multiplicities.

Combine Part B with R34:

```text
gap side:      one prime * multiplicity m
quotient side: two primes * multiplicity m.
```

Kernel-check the exact natural factorization equalities

```text
R.factorization q = a.factorization q
S.factorization q = 2 * a.factorization q
```

for every common norm prime `q`.

A `padicValNat` statement is acceptable internally, but the public packet
layer should expose the `Nat.factorization` equalities if practical.

## Part D — noncommon prime exponent classification

Let `q` be prime with `q | a`.

Reuse the existing neutral ledger

```text
R.factorization q + S.factorization q
  = 3 * a.factorization q.
```

If `q` is not common to `R` and `S`, prove the exact alternatives

```text
(R.factorization q, S.factorization q)
  = (3 * a.factorization q, 0)
```

or

```text
(R.factorization q, S.factorization q)
  = (0, 3 * a.factorization q).
```

Also prove that every prime divisor of `a` falls into exactly one of the
three support types:

```text
gap-full:      (3m,0)
common 1-to-2: (m,2m)
quotient-full: (0,3m).
```

Keep this classification separate from any residue-class conclusion.

## Part E — canonical common factor

Define literally

```text
C := Nat.gcd R S.
```

For every rational prime `q`, prove the common-prime exponent formula,
conceptually:

```text
C.factorization q =
  if q | R && q | S then a.factorization q else 0.
```

A proposition-valued `if` theorem or two implication lemmas are equally
acceptable.

Consequences required:

```text
C | a
q.Prime -> q | C -> q | R and q | S
q.Prime -> q | C -> q % 7 = 1 or q % 7 = 6.
```

The last theorem should reuse R31/R34 support results, not rebuild the finite
field argument.

## Part F — canonical support partition and U,V

Prefer a factorization-based construction.

Conceptually partition prime divisors of `a` into

```text
Common(q)       := q | R and q | S
GapOnly(q)      := q | R and not q | S
QuotientOnly(q) := not q | R and q | S.
```

Define `U` and `V` with prime exponent `a.factorization q` on the
gap-only and quotient-only supports respectively.

Then prove

```text
a = C * U * V
R = C * U^3
S = C^2 * V^3.
```

Literal equalities are required; divisibility-only forms are insufficient.

If a cleaner generic constructor emerges, isolate it as a neutral arithmetic
helper.  Do not make it FLT-specific unless the proof genuinely requires the
packet.

## Part G — pairwise coprimality of the canonical factors

Because the three support types are disjoint, prove if reasonably direct:

```text
Nat.Coprime C U
Nat.Coprime C V
Nat.Coprime U V.
```

This is stronger than R32 and is expected to be useful in the next local
residue checkpoint.

If Mathlib support manipulation makes this disproportionately expensive, do
not weaken earlier results to force it.  Record the precise API frontier in
the report.  The canonical equalities of Part F remain mandatory.

## Part H — relation to the R32 cube-defect packet

Do not delete or reinterpret `DirectOrbitCubeDefectPacket`.

  factor `C`;
- gap-only and quotient-only primes have exponents divisible by three and
  therefore do not enter `D1,D2`;


These bridge theorems are optional.  The old R32 public API must remain valid.

# FLT7TC-005R31 — Complete-split prime residue criterion modulo seven

## Scope

This report records the implementation work for `instruction-037.md`.  The
target is the current-provenance residue criterion for a common norm prime.
Historical routing/address packets are excluded.  The target theorem is
`q % 7 = 1 ∨ q % 7 = 6`, together with the corresponding support theorem for
prime divisors of the gcd of the two current square-root norms.

## Initial audit

- R30 already supplies `q ≠ 7`, complete splitting in the real cubic field,
  and ramification/inertia indices equal to one for a common norm prime.
- R29 exposes a maximal prime divisor of the principal ideal generated by the
  current gap square root, together with its contraction to `(q)`.
- The neutral finite-field core must be kept separate from the current packet
  instantiation: cubic relation, reciprocal quadratic, primitive seventh root,
  Frobenius, and the mod-seven classification.
- The first implementation pass is checking the exact finite-field,
  algebraic-closure, and residue-field APIs before production edits.

## Scratch findings

- The neutral finite-field core compiles in
  `DkMathTest/FLT/SevenRealCubicResidueCriterionScratch.lean`.
- A quadratic root `t` in `AlgebraicClosure (ZMod q)` is nonzero and gives
  `beta = 1 + t + t⁻¹`.
- The cubic relation yields the geometric sum relation and `t^7 = 1`; with
  `beta ≠ 3`, the root is a primitive seventh root.
- Frobenius preserves the reciprocal quadratic, so `t^q = t ∨ t^q = t⁻¹`.
- Consequently `7 ∣ q^2 - 1`, and the `ZMod 7` factorization gives
  `q % 7 = 1 ∨ q % 7 = 6`.
- The exact Mathlib finite-field uniqueness API is
  `FiniteField.ringEquivOfCardEq`; the production layer uses it after the
  residue-field cardinality and individual inertia-degree bridge.

## Scratch verification plan

The persistent scratch file verified the neutral finite-field lemma first.
The production layer then instantiated it through one degree-one prime above
the common norm prime, using its residue field and a finite-field equivalence
with `ZMod q`.

## Implementation log

- Added `DkMath/FLT/Seven/SevenRealCubicResidueCriterion.lean`.  The neutral
  API is `cubicRoot_to_primitiveSeventhRoot` and
  `cubicRoot_mod_seven`.  It proves the reciprocal quadratic lift, primitive
  seventh root, Frobenius root exchange, `7 ∣ q^2 - 1`, and the exact residue
  alternatives.
- Added
  `DkMath/FLT/Seven/PrimeTraceOneDirectRealCubicResidueSupport.lean`.
  It chooses the current R29 prime ideal, transports the R30 individual
  inertia degree through `Ideal.inertiaDegIn_eq_inertiaDeg`, proves the
  residue-field cardinality with `Ideal.natAbs_pow_inertiaDeg` and the
  quotient/residue-field bijection, and constructs the noncanonical finite
  field equivalence with `FiniteField.ringEquivOfCardEq`.
- The production evaluation map sends the model `alpha` to `ZMod q`, maps
  integer casts correctly, has the expected kernel-on-`P` membership fact,
  and transports `SevenRealCubicInt.alpha_cube`.  The case `beta = 3` is
  discharged by the R30 fact `q ≠ 7`.
- Added `common_norm_prime_mod_seven` and
  `common_norm_prime_gcd_support`.  The latter uses only
  `Nat.dvd_gcd_iff`; no coprimality or gcd-equals-one claim is introduced.
- Exported the two production modules through `DkMath.FLT.Seven` and added
  API/axiom audit files for both neutral and packet layers.

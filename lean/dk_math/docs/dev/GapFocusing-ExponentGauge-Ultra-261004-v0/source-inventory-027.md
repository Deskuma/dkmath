## Installed harmonic and log API

harmonic is a rational-valued function in the root namespace, with harmonic_succ.
harmonic_eq_sum_Icc rewrites it as the reciprocal sum from one through n.
harmonic_le_one_add_log and log_add_one_le_harmonic are also root declarations;
their statements coerce harmonic n to Real. Rat.cast_sum, Rat.cast_inv and
Rat.cast_natCast handle the finite-sum coercion.
Real.log_le_log requires a positive lower argument and an order comparison.
Real.log_mul requires both factors nonzero; Real.log_pow works at natural powers.
The neutral reciprocal interval identity will use sum_erase_add and Icc_erase_left.
No replacement harmonic definition, RH import or L-series import is required.

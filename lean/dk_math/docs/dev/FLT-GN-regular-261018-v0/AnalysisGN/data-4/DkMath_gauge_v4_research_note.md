# DkMath 指数単位ゲージ 数値実験 v4 — 降下・補填・平方借入・Prime Address

- 対象：`R_n(x,y)=(x^n-y^n)/(x-y)`、`D_n(x,y)=(x+y)^(n-1)-R_n(x,y)`、`gcd(x,y)=1`、`x>y>0`。
- 実行：`python3 DkMath_exponent_gauge_experiment_v4.py`（Python 3 標準ライブラリのみ）。
- 観測：`2≤x≤75`、`3≤n≤14`、互いに素な正整数対 1,735 組、合計 20,820 件。Prime Address サンプル 268 行。整数演算は厳密で、実数近似による冪判定なし。
- 未実施：Lean での新規形式化・公理監査。実験と恒等式が一般 FLT を証明したわけではない。

## A. 原始的な完成不足の素因数消滅

`
R_n + D_n = (x+y)^(n-1)
`

原始的な座標 `gcd(x,y)=1` なら、奇数 `n≥3` について

`
gcd(R_n,D_n)=gcd(R_n,(x+y)^(n-1))=1.
`

理由：`R_n` は `x+y` を法として `y^(n-1)` に合同。`gcd(y,x+y)=1`。完成に必要な加算操作は、奇数次数で余因子の prime support を全て別方向へ置き換える。これは単に不足分が正であることより強い情報である。

偶数 `n≥4` では `gcd(R_n,D_n)=(x+y)*gcd(n/2,(x+y)^(n-2))`。この式も全実験で確認。

## B. 借入補填の原始的な ABC トリプル

`R_n + xy R_(n-2) = (x+y) R_(n-1)` に対し

`
h_n=1 (n odd), h_n=x+y (n even),
A_n=R_n/h_n,
B_n=xy R_(n-2)/h_n,
C_n=(x+y) R_(n-1)/h_n.
`

原始的な正整数 `x>y` では `A_n,B_n,C_n` は正整数、`A_n+B_n=C_n`、`gcd(A_n,B_n)=gcd(B_n,C_n)=gcd(A_n,C_n)=1`。`gcd(R_n,R_(n-2))=R_gcd(n,2)` により、分子の共通因子は n 奇数で 1、n 偶数で `x+y` となる。20,820 ケースで検算成功。

奇数 `n=2m+1` なら

`
R_(2m+1) + xy R_(2m-1) = (x+y)^2 R_m(x^2,y^2).
`

すなわち **借入後の右辺に `(x+y)^2` が必ず現れる**。既知の多項式恒等式だが、「平方完成借入」の自然な算術モデルとなる。

偶数 `n=2m` なら `R_(2m)=(x+y)R_m(x^2,y^2)` を利用して

`
R_m(x^2,y^2) + xy R_(m-1)(x^2,y^2) = R_(2m-1)(x,y).
`

と次数がほぼ半減する。ただし底が `x²,y²` に上昇しており、FLT 解の高さが減少する無限降下ではない。

## C. Prime Address と付値

同じペア `x=5,y=3` について：

- `q=7` は次数 `3,6,9,12,...` に現れ、`v_7(R_3)=2`、`v_7(R_6)=2`、`v_7(R_21)=3`。
- `q=17` は `4,8,12,...` に現れ、`v_17(R_4)=1`、`v_17(R_8)=1`。
- `q=7` を持つ `(x,y)=(18,1)` では `R_3=7³`、`v_7(R_21)=4`。

一般に素数 `q∤xy` について `r=ord_q(x/y)>1` なら `q|R_n` は `r|n` と同値（`q|x-y` の位数 1 は別扱い）。奇素数 `q` については `v_q(R_n)=v_q(x^r-y^r)+v_q(n/r)`（`r|n`）。一般的な円分住所則および LTE と整合する。

また `gcd(R_n,R_(n-1))=1`。**隣接次数に同一の素因子は残らない**。したがって、付値を素数ごとに保存する直接の降下写像は成立しない。

## D. y>1 に拡張した「小素数の局所完済→大素数への不整合移動」

奇素数 `p`、上限 `B≥p`、`p∤y` とする。

`
M=∏{q≤B : q prime, q≠p, q∤y},
g=p^(p-1) M^p, x=y+g.
`

すると `gcd(x,y)=1`、

`
x^p-y^p=(p M)^p K,  K=R_p(x,y)/p.
`

が成立し、**上限 B 以下の全素数 q に対して `v_q(x^p-y^p)∈{0,p}`** となる。 `q|y` なら 0、そうでなければ p。したがって `K` の素因子は全て `q>B`。

さらに `(x-1)^p<x^p-y^p<x^p` が成り立つように `g` を十分大きくすれば、`K` は完全な p 乗にならない。よって、必ず `q>B` で `v_q(K)≢0 mod p` となる。なお `q|K` かつ `q∤(x-y)` だから `ord_q(x/y)=p`、したがって `q≡1 mod p`。

### v4 実験

- p=3,5,7、B=11,31,97、y=1,2,3,4,5,7,11,13,17（p|y は除外）の 72 ケース。
- すべてで small primes の付値 0 または p を確認、`(x-1)^p<x^p-y^p` を確認。
- `q≤20,000` の走査で不整合素数が見つかったのは 46 ケース。見つからない 26 ケースも構成の証明により `q>B` の存在は保証される（数値的な素因数同定は未実施）。
- p=3, y=5, B=11: `M=154`, `g=32,870,376`, `x=32,870,381`, `K=360154037145697`; `q=163` において `v_q(K)=1`。
- p=3, y=2, B=97: `x` は 108 桁、`q=127` が見つかった。
- p=7, y=2, B=97: `x` は 252 桁、`q=967` が見つかった。

この y>1 の拡張は、前回 y=1 だけに使っていた隣接冪の間隔の議論を、構成された十分大きい x に対して適用したもの。`y` と `x-y` が互いに素であることが肝心。

## E. 形式化に向けた判定

1. **既知の恒等式の再構成（数学的に閉じる）**：`R_n` の再帰、`h_n` 正規化、奇数次数の square-lender identity。
2. **gcd の保存核（数学的に閉じる）**：奇数次数の `gcd(R_n,D_n)=1`、`A+B=C` の原始性。
3. **y>1 の構成的素数脱出（構成された十分大きい x について成立）**：有限素数完済でも大素数に未完成付値が残る。
4. **未完成**：以上から一般 `x^p-y^p=z^p` の非存在を新たに導くこと、また上の次数変換を FLT 解の無限降下に利用すること。

既存の DkMath では GN・GTail・Prime Address、さらに ABC の側へ対応付けるのが有望。ただし、この研究ノートは Lean のビルドを実施していない。

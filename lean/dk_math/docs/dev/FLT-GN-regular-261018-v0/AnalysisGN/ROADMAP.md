## 全工程で保持するもの

- 素数性、次数の下限、原始性、非零性、正性。
- `padicValNat 0`の規約と、2進付値の補正。
- 形式変数の可除性と、数値に評価した後の可除性の区別。
- 原始素数の存在、直前との差、付値が1であることの区別。
- 係数gcdと、代入したBodyのgcd・付値の区別。
- 次数の低下と、同じ完全冪状態を保つ整数高さの厳密降下の区別。
- 旧定理の型・全修飾名、正規化前後の座標の関係。

## 工程を切り分ける条件

| 状況                                    | その単位で行うこと                                            |
| --------------------------------------- | ------------------------------------------------------------- |
| Lib化で上位carrierが必要になる          | 一般式とcarrier依存のconsumerに分け、上位importを加えない     |
| 仮定を落とすと境界反例が出る            | 元の仮定を保ち、より強い一般化を別の課題にする                |
| 強可除性の形式化が重い                  | 奇数coprimeと基本再帰を先に確定し、互除法を後続にする         |
| 全過去で新しい素数の存在が必要になる    | 隣接支持の定理を強めず、Zsigmondy型入力との接続を別途設計する |
| 付値条件からCofixed直線の矛盾へ進めない | GN定理としての完了を報告し、hnoへの未供給の橋を記録する       |

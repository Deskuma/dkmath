## 奇数次数の合同式

一般の可換環で、次の整除性を証明した。

```text
x+y ∣ R_(2k+1)(x,y) - (-xy)^k
```

これは `R_(2k+1) ≡ (-xy)^k (mod x+y)` の意味であり、原始性は不要である。
二階再帰 `R_(j+2)+xy R_j=(x+y)R_(j+1)` を次数2ずつ進めると、
右辺がx+yの倍数となり、剰余には-xyを掛けたものが残る。
次数1のR_1=1から帰納した。素数次数や正則素数の仮定は使わない。

原始座標ならx+yとx、x+yとyはそれぞれ互いに素で、
従ってx+yと(-xy)^kも互いに素になる。
合同式で差をx+yの倍数として戻すと、Bézout関係がR_(2k+1)へ移る。
この証明は零因子のある可換環にも適用できる。

## 完成不足とのgcd

まず全次数・全自然数座標について、次の無条件のgcd還元を証明した。

```text
gcd(R_n,D_n) = gcd(R_n,(x+y)^(n-1))
```

先行工程の正確な再構成 `D_n+R_n=(x+y)^(n-1)` によるもので、
自然数差の切り捨てを暗黙に扱わない。
ここへ奇数sum-coprimeを適用して、次を固定した。

```text
Odd n → Coprime x y → Coprime R_n D_n
```

`2k+1` 形式と `Odd n` 形式の両入口を用意した。
環では同じ原始性のもと、R_(2k+1)と符号付き不足の `IsCoprime` を証明した。
これらに正性や `y≤x` は不要である。負の不足や原始な零座標も扱える。

## 教科書例と保持する境界

新所有者に12例を置き、Leanで確認した。

- (5,3)、(18,1)、原始な対角(1,1)、零座標(1,0)で奇数R_nとD_nは互いに素。
- 偶数次数n=2およびn=4、座標(2,1)ではgcdが3。n=4ではD_nも正であり、正性だけでは奇数条件の代わりにならない。
- 非原始座標(6,4)、n=3ではgcdが4。奇数だけでは原始性の代わりにならない。
- 次数0・1のgcd境界、A10のgap橋、x<yでも成立する隣接coprime。
- 整数座標(-2,3)、n=3ではR_n=7、符号付き不足=-6で互いに素。

gcdが1という結果はR_nが素数、平方因子を持たない、完全冪ではないという意味ではない。
R_3(18,1)=343という先行例もそのまま保持される。
偶数次数の一般的な精密gcd、非原始対の正規化、強可除性、原始ABC三項は後続工程に残す。

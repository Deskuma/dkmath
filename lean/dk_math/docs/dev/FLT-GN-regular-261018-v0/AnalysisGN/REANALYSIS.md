# GN・指数ゲージの再分析

2026-10-23。資料の数値観測、一般に証明できる命題、現在のLean所有層を分ける。
会話記録は[原資料](6ad8f60c_2026-1021-172741_指数ゲージとFLTのズレ+128249-776.md)の行番号で参照する。
以下の新規目標は数学的な整理であり、今回Leanで新しく証明したという意味ではない。

## 1. 三つの量を混ぜない

GNの正規形を `G_d(g,u) := GTail d 1 g u` とする。歴史的namespaceは `DkMath.CosmicFormula` である。

| 系統             | 定義                                    | 保存される等式                            |
| ---------------- | --------------------------------------- | ----------------------------------------- |
| GN完成           | Big=(g+u)^d、Body=g G_d(g,u)、Gap=u^d   | Body+Gap=Big                              |
| 冪差余因子       | R_n(x,y)=Σ_{i<n} x^(n−1−i)y^i           | (x−y)R_n=x^n−y^n                          |
| 余因子の完成不足 | D_n=(x+y)^(n−1)−R_n、補填B_n=xy R_{n−2} | R_n+D_n=(x+y)^(n−1)、R_n+B_n=(x+y)R_{n−1} |

GNのGap、余因子の不足D_n、次数移行の補填B_nは三つの異なる量である。
実際、(x,y)=(5,3)、n=4ではD_4=240、B_4=120、gcd(R_4,D_4)=16、gcd(R_4,B_4)=8となる。
同じ「借金」という呼び方から、付値やgcdを相互に置換しない。

整数環ではR_n(x,y)=G_n(x−y,y)。自然数ではy≤xを要求し、(x−y)+y=xを明示する。
一般の可換半環では有限和を標準定義にし、座標に減算や除算を持ち込まない。
x=yでもR_n(x,x)=n x^(n−1)と定義できる。0/0で余因子を定義しない。

## 2. 二種類の素数方向と円分層

会話L4398–4624の区別を基本とする。

1. **完成根の素数q**：q∣g+u。正の次数ならBigの素数支持と一致し、Bigのq付値はd倍となる。
2. **次数の素因数p**：d=p^rなど。Pascal行の係数可除性とFrobenius合同を支配する。
3. **余因子の層住所**：qがR_nまたは円分層に現れる条件。完成根のqとは別に、比x/yの乗法位数が関わる。

既存の `coeffGCD_prime_interior` は素数行の内部係数内容がpであることを証明する。
これは**係数のgcd**であり、座標を代入したBodyのgcdや評価値のp付値とは同一ではない。
素数冪行の一般付値は `BinomialPrimePower.padicValNat_choose_prime_pow` にある。
四乗行4,6,4の内容は2であり4ではない。素数冪行の全係数にp^rが一様に入るとはいえない。

11,13,37でPascal行・GNの一般合同は同じ仕組みを持つ。
正則性・非正則性はこの一般恒等式や係数可除性の仮定ではなく、後段の円分類群・単元抽出の問題である。
`GNPrime37` はこの区別を既に教科書化しているが、一般補題と37の例、上位Defsへのimportを含むため、その全体を最小の一般窓口へ取り込むとは限らない。

## 3. GN完成のgcdは最初の一般APIに適する

自然数g,u,dに対しh=gcd(g,u)と置くと、目標は

\[
\gcd(\mathrm{Big},\mathrm{Gap})=
\gcd(\mathrm{Body},\mathrm{Gap})=
\gcd(\mathrm{Body},\mathrm{Big})=h^d.
\]

Bodyは減算でなくg G_d(g,u)と定義する。既存のGN完成等式と、gcdの加法・冪の標準算術を組み合わせる。
原始座標なら三者はpairwise coprimeとなる。この式はd=0も整合する。Big=Gap=1、Body=0、h^0=1だからである。

q∣g+uからq∤Bodyを導く場合にはd>0を明示する。
d=0ではBody=0なのでその結論を述べられない。q∣Bigからの排除は原始性と三者のgcdから直接得られる。
同じくv_q(Big)=d v_q(g+u)は、`padicValNat`のAPIに従ってg+u≠0を保持する。

P=30,u=1の960+1=961=31²はこの原始完成の特例である。
P=90ならP+1=91=7×13であり、平方化は素数を作るのではなく、完成根の素数付値を倍化する。
固定したMの列Mt+1についてはq∤Mならt≡−M⁻¹ mod qという住所を使える。
この可除性フィルタを、そのまま素数判定の十分条件にしない。

## 4. 完成不足の再帰は、既存のGN再帰から作る

R_0=0、R_1=1とし、n≥2で

\[
R_n+xyR_{n-2}=(x+y)R_{n-1}.
\]

これは `GapFocusing.Successor.GN_succ_left/right` の座標変換から再構成する候補である。
型はまず減算のないk+2形式で与える。n−2という自然数の切り捨てを無条件で使わない。
D_nの漸化式はn≥2で

\[
D_{n+1}=(x+y)D_n+xyR_{n-1}.
\]

D_2=0、x,y>0ならn≥3でD_n>0となる。自然数版の差を導入する前にR_n≤(x+y)^(n−1)を証明する。
一般環での符号付き不足と、順序付きの非負不足を別の層にする。

この結果はR_nが**指定された**(x+y)^(n−1)と違うことを示す。
他の完全冪との一致は排除しない。R_3(5,3)=49=7²、R_3(18,1)=343=7³が既に反例である。
後者でも(x−y)R_3=17×7³なので、元の冪差全体の完全冪条件は別に追跡する。

## 5. gcdと素数住所は既存資産を先に使う

原始座標の隣接次数の互いに素性は `GapFocusing.Support` に既存で、Nat・Int・一般CommRingの版がある。
「次の次数に、直前にはなかった素数がある」という定理も既存だが、全ての以前の次数に対して新しい原始素数を保証するものではない。

x>y>0、gcd(x,y)=1の原始対での目標群は次のように分ける。
最初の行はn≥1、隣接次数はn≥1、奇数の不足はn≥1、偶数の不足はn≥2を対象とする。

| 性質                                          | 現在の位置                                                                    |
| --------------------------------------------- | ----------------------------------------------------------------------------- |
| gcd(x−y,R_n)=gcd(x−y,n)                       | `GTailBoundary` の既存一般定理を座標変換して再利用                            |
| gcd(R_n,R_{n−1})=1                            | `Support` に既存。R語彙への橋とLib所有化を行う                                |
| gcd(R_m,R_n)=R_gcd(m,n)                       | 今回の限定検索では直接の同型APIを特定できなかった。加法公式と互除法を計画する |
| 奇数nでgcd(R_n,D_n)=1                         | modulo x+yと既存再帰から独立に先行できる                                      |
| 偶数nでgcd(R_n,D_n)=(x+y)gcd(n/2,(x+y)^(n−2)) | LTEと2進分岐を含む後続目標。最初の奇数版をこれに依存させない                  |

`PrimeOrder` はq∤yの下で冪差の可除性と乗法位数を対応させる。
`HomogeneousAddress` は円分層の添字をr q^kと分類する。
**全余因子R_nへのqの出現**（r>1ならr∣n）と、**単一の円分層の添字**（r q^k）を混同しない。
これらの一般内容は既存であり、Zsigmondy・CFBRCなどの上位carrierから中立核を分離して使う。

r=1、q∣xy、次数0は別の境界である。特にq∣x−yなら比の位数は1となり、q∣R_nの条件はq∣n側へ移る。
奇素数のLTEと2進LTEは既に別の定理として存在する。`padicValNat_GN_prime_eq_one_of_dvd_gap` のp≥3条件を落とさない。
p=2,g=2,u=1ではGN₂=4、v₂=2であり、付値1にはならない。

## 6. 原始ABC三項と次数半減

n≥3、x>y>0、gcd(x,y)=1として

\[
h_n=\begin{cases}1&n\text{ odd},\\x+y&n\text{ even},\end{cases}
\quad(A,B,C)=\frac1{h_n}(R_n,xyR_{n-2},(x+y)R_{n-1})
\]

を考える。各分子のh_nによる可除性を先に証明してから、自然数除算を導入する。
A+B=Cと三者の互いに素性、正性を結論へ含める。n=2ではB=0なので正のABC三項にはしない。

奇数n=2m+1、m≥1では

\[
R_{2m+1}+xyR_{2m-1}=(x+y)^2R_m(x^2,y^2).
\]

偶数n=2mでは底がx²,y²へ変わる。この恒等式は次数を下げるが、元の整数座標の高さを下げる変換ではない。
ABC予想やFLTの完全冪状態の保存も結論しない。

## 7. 有限個の素数での完成と、大きい素数への脱出

v3のy=1構成は、任意の有限素数集合で局所付値を揃えられる例である。
有限個の素数の検査だけでは全体の完全冪条件を決定できないことが分かる。
また、原始素数が存在してもその付値が1とは限らない。R_3(18,1)=7³が検査例になる。

v4での構成g=p^(p−1)M^p、x=y+gについては、小素数の制御に加えて

\[
y^p<x^p-(x-1)^p
\]

というサイズ条件を明示する。資料中の72例では成立するが、任意のyに無条件で拡張できない。
p=3,B=3,y=1001ならM=2、g=72、x=1073で、この不等式は成立しない。
これはv4の記載済みの有限例を否定するものではなく、一般化時の条件抜けを防ぐ例である。

任意のyへの存在構成を目指すなら、gに追加のp乗因子を入れ、
小素数とyへの互いに素性、およびサイズ条件を同時に保証する別の補題が必要になる。
この特殊構成を一般のFLT反例やCofixed直線の不存在へ適用する橋は未供給である。

## 8. 残差・付値・幾何の型を分ける

会話L297–425のδ_d=x^d+y^d−z^d、g=x+y−zは整数または環で扱う。
g GN_d(g,z)=C_d(x,y)+δ_dは保存恒等式であり、素数冪d=p^rならδ_d≡g mod pという必要条件を持つ。
会話中の天秤残差は−δ_dの符号なので、APIでは符号を固定する。

各項の最低付値と和の付値を比較するとき、`padicValNat p 0=0`という規約に注意する。
ゼロになり得る和へ「和の付値は最低以上」を無条件で適用しない。非零条件を保持するか、零に∞を割り当てる付値を使う。
実数上の単位変更の保存と、自然数座標の素数性は別概念である。
`PositiveUnit` の一般核を抽出しても、任意の実数点に自然数座標が存在するとは結論しない。

## 9. hnoへ向かうために、ここで固定する境界

恒等式、正性、互いに素性、素数住所、局所付値は一般数学としてLibへ固定できる。
一方、次数を下げる式が、同じ指数の完全冪状態・整数性・原始性を保ちつつ正の高さを必ず下げることは別の主張である。
この状態保存と厳密降下は、資料からはまだ構成されていない。

031-005のCofixed安定直線とGNの量との対応も、独立した接続定理を必要とする。
032のhnoの代わりに、D_n>0、素数住所の必要条件、有限実験の未検出を置かない。
今回の整備は、そのような接続を後で検討できる一般核を明確にするためのものである。

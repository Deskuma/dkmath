# DkMath：冪差余因子と不足補填の数値実験・第2弾

2026-10-23。既存 `DkMath_exponent_gauge_experiment.py` の継続実験。
実行：`python3 DkMath_exponent_gauge_experiment_v2.py --bound 140 --max-degree 12 --prime-bound 251`
すべて Python 標準ライブラリと任意精度整数で計算。Lean ビルドは未実施。

## 1. 観測する対象

正整数 `x > y > 0`, `gcd(x,y)=1`, `n>=3` に対し：

- `R_n(x,y)=(x^n-y^n)/(x-y)`（冪差の余因子）
- `s=x+y`
- `D_n=s^(n-1)-R_n`（完成形との不足）
- `B_n=xy R_(n-2)`（次数を逆向きに降ろすための補填項）
- `R_n+B_n=s R_(n-1)`（次数移行式）
- `x^n-y^n=(x-y)R_n`（元の完全冪条件を問う式）

## 2. 一般的な算術法則（今回の対象範囲で全件検査）

原始的な整数対について、次が成立する。

1. `gcd(R_m,R_n)=R_gcd(m,n)`（強い可除性。`R_1=1`）。
2. `gcd(R_n,R_(n-1))=1`。隣接次数で素因数が一つも共有されない。
3. `gcd(R_n,R_(n-2))=1`（n奇数）、`=x+y`（n偶数）。
4. `gcd(R_n,B_n)` も 3 と同じ。`gcd(R_n,xy)=1` のため。
5. `gcd(R_n,D_n)=1`（n奇数）。n偶数なら **より精密に**
   `gcd(R_n,D_n) = s * gcd(n/2,s^(n-2))`。
6. `gcd(x-y,R_n)=gcd(x-y,n)`。元の冪差を構成する二因子の共通素数は次数 `n` によって制限される。

1 は `R_(a+b)=x^a R_b+y^b R_a` と `gcd(R_a,xy)=1` によるユークリッド互除法で証明できる。
5 は `gcd(R_n,D_n)=gcd(R_n,s^(n-1))` と、偶数 `n=2m` に対する `q|s` での付値式 `v_q(R_n)=v_q(s)+v_q(m)`（LTE）から従う。上記の一般法則は今回の数値サンプルに限った推測ではないが、**これらを Lean で新たに証明したわけではない**。

## 3. 実験範囲と全件検査

- 原始的な整数対：`1 <= y < x <= 140` の **5999組**。

- 全件で上記の恒等式・gcd法則を検査。違反 **0件**。
- 付値による不可能性の部分チェック：素数 `q<=251` に対して、`v_q(A) mod n != 0` が見つかるかを調査。ここで `A=R_n` または `A=x^n-y^n`。

**注意**：否定はその特定の整数対についての計算証明でしかない。`q<=251` で証明が見つからなかった組について成立するという意味ではない。また `R_n` が完全な n 乗であっても `(x-y)R_n` が n 乗とは限らない。

## 4. 重要な反例：余因子は完全 n 乗になることがある

| n | (x,y) | R_n | x-y | 元の差 |
|---:|---|---|---:|---|
| 3 | (18,1) | `343=7^3` | 17 | `17*7^3` |
| 3 | (36,17) | `2197=13^3` | 19 | `19*13^3` |
| 3 | (73,17) | `6859=19^3` | 56 | `56*19^3` |
| 3 | (109,90) | `29791=31^3` | 19 | `19*31^3` |

例えば `(18,1)` では `18^3-1^3=17*343=17*7^3`。
**R_n が n 乗にはなれないという方針は反例で否定される**。元の因子 `x-y` の素因数付値を一緒に扱う必要がある。

`D_n`（完成不足）と `B_n`（降下補填）は **別の量**。偶数次には両者の gcd が異なる例（n=4,8）がある。

## 6. Prime Address／位相の実験

`(x,y)=(5,3)` について `n=1,...,85` を計算し、以下を全件検証。

- `v_2(R_n)=0`（奇数n）、`=3+v_2(n/2)`（偶数n）。
- `v_7(R_n)=0`（3∤n）、`=2+v_7(n/3)`（3|n）。
- `v_17(R_n)=0`（4∤n）、`=1+v_17(n/4)`（4|n）。

特に素数 7 の支持は `n=3,6,9,...` に再登場し、`n=21` では `v_7=3` に増幅。17 は `n=4,8,12,...` に再登場し、`n=68` では `v_17=2` となる。

**解釈**：隣接次数間で素因数 support は断絶するが、次数の倍数方向には規則的に再登場する。降下の状態として保持すべきものは、単純な素因数の集合ではなく、`(q, ord_q(x/y), valuation)` という住所と深さの組かもしれない。

## 7. 素数単位の「借金が完済される」局所例

原始的な整数対に対し、`q|n` の素数 q で
`v_q(x-y) % n != 0`、`v_q(R_n) % n != 0` にもかかわらず
`(v_q(x-y)+v_q(R_n)) % n == 0` となるケースを抽出。

| n | 出現組数（5999組中） | 例 |
|---:|---:|---|
| 3 | 341 | `(x,y)=(10,1)`：`v_3(x-y)=2, v_3(R_3)=1` |
| 4 | 1069 | `(x,y)=(3,1)`：`v_2(x-y)=1, v_2(R_4)=3` |
| 5 | 0 | 今回の範囲で未発見 |
| 6 | 129 | `(x,y)=(17,15)`：`v_2(x-y)=1, v_2(R_6)=5` |
| 8 | 129 | `(x,y)=(17,15)`：`v_2(x-y)=1, v_2(R_8)=7` |

他の次数 n=7,9,10,11,12 は0件（今回の範囲）。

三乗例：`10^3-1^3=999=3^3*37`。素数3でちょうど立方の付値を満たしても、37が1回残る。

八乗例：`17^8-15^8=2^8 * 257 * 67073`。素数2の付値はちょうど八乗になるが、257と67073が1回ずつ残る。
小素数の検査上限251では後者を見逃す点も示している。

**観察の核心**：完全冪のための valuation 条件は、素数ごとには「差の因子と余因子の貸借」で満たされ得る。しかし同じ完成条件を全素数について同時に満たすかは別問題である。

## 8. FLT 近接例との対応

- `9^3-8^3=217=7*31`、対する `6^3=216=2^3*3^3`。差は **1**。
- `17^5-16^5=371281`、対する `13^5=371293=13^5`。差は **-12**（`371281-371293`）。

ほぼ釣り合っていても prime support が異なる。これは興味深い観察だが、prime support が異なる整数同士は当然等しくないので、この事実だけでは一般の FLT の証明にならない。

## 9. 奇素数冪の「最小貸付規模」：付値による必要条件

奇素数 p と正整数 r、`n=p^r` に対して、`gcd(x,y)=1` かつ `p|x-y` なら（LTE）

`v_p(R_n(x,y))=r`。

もし `x^n-y^n=z^n` なら `v_p(x-y)+r = n v_p(z)` なので、

`v_p(x-y) ≡ -r (mod n)`。特に `v_p(x-y) >= n-r`。

すなわち **p^(p^r-r) | (x-y)** が必要になる。

素数指数 `n=p` に限定すると：

| p | p^(p-1) （差の必要最小規模） |
|---:|---:|
| 3 | 9 |
| 5 | 625 |
| 7 | 117649 |
| 11 | 25937424601 |

p=3 では範囲140で実例があるが、p=5 では `x-y<=139` のためこの p-進補填は起こり得ない。

**限定条件に注意**：これは `p|x-y` と完全 n 乗を仮定した場合の必要条件であって、すべての底に適用できるわけではない。また、差が大きくなれば候補が復活し、完全 n 乗を排除する十分条件にはならない。

## 10. 次に検証すべき仮説

`(x-y)R_n=z^n` を仮定した時、`gcd(x-y,R_n)=gcd(x-y,n)` により、指数 n と互いに素な素数 q の付値は二因子間で移動できない。よって各 `q∤n` に対し `v_q(R_n)≡0 (mod n)` を要求される。ここを Prime Address と `R_(n-1)` への補填変換で同時に保持できるかを調べる。

**注意**：これは未証明の研究方向。次数 `n` を下げるだけでは、反例をより小さい反例へ移す無限降下にはならない。

# GN-LIB-005c — 偶数完成不足の精密gcd

2026-10-24。ブランチ：`lib/FLT-GN-Completion-261023-v0`。
2モジュールに14定理・13例を実装し、対象module単位の検証を完了した。

## 証明した式

原始な自然数座標x,y、m>0について、s=x+yと書くと

```text
gcd(R_(2m)(x,y), D_(2m)(x,y)) = s * gcd(m, s^(2m-2))
```

が成り立つ。公開定理 `gcd_even_cofactor_completionDefect` には座標の大小・正性を要求しない。
原始な零座標、逆順、対角(1,1)、次数2も含む。
`Even n` と `0<n` を取る `gcd_cofactor_completionDefect_of_even` は
資料の `s*gcd(n/2,s^(n-2))` という表示を返す。

さらに `gcd_cofactor_completionDefect` は正次数の奇偶を一つの入口にまとめ、
奇数なら1、偶数なら上記の精密式を返す。
次数0ではR_0=0、D_0=1なのでgcd=1となる別の無条件定理を置いた。

## 付値の教科書

[PowerDifferenceCofactorValuation.lean](../../../../DkMath/Lib/NumberTheory/PowerDifferenceCofactorValuation.lean)
に6定理を固定した。

1. Mathlibの `Int.two_pow_sub_pow'` を、自然数の有限付値へ翻訳。
   `4∣a-b`、a奇数、b<a、n≠0を保持し、`v₂(a^n-b^n)=v₂(a-b)+v₂(n)` を証明した。
2. 先行の有限和R_nに対し、`R_n*(a-b)=a^n-b^n` の非零性を証明してから
   `v_q(R_n)+v_q(a-b)=v_q(a^n-b^n)` を得た。
3. 奇素数LTEをこの積の式へ代入してgapの付値を除く。
4. 同じ除去を、差が4で割れる2進の枝で行う。
5. q∣x+yと原始性からqが両座標を割らないことを導き、平方座標では
   `v_q(R_m(x²,y²))=v_q(m)` を証明した。
6. `R_(2m)=s*R_m(x²,y²)` から `v_q(R_(2m))=v_q(s)+v_q(m)` を得た。

奇素数の枝ではq∣x²-y²が通常のLTEの入力になる。
q=2では両座標が奇数となり、その平方差が4で割れることを整数のmod 4で証明する。
この平方差の追加条件が2進補正を正しく処理する。一般の偶数差から和の補正を落としたわけではない。
実際、R_2(3,1)=4の2進付値は2で、指数2の2進付値1とは異なる例も確認した。

自然数差を整数へcastする箇所では、b<aとその冪の大小を明示している。
付値の乗法性には各因子の非零性を先に供給し、v_q(0)=0の規約で情報を失わない。
この一般核は円分住所や強可除性の所有者を経由せず、必要なRの算術とMathlibのLTEを直接importする。

## gcdへ戻す証明

[CompletionDefectGcd.lean](../../../../DkMath/Lib/NumberTheory/CompletionDefectGcd.lean)
に8定理を固定した。

まず「非零modulusの素数支持上で付値が一致すれば、そのmodulusとのgcdが等しい」という一般補題を証明した。
素因数分解でgcdの指数をminとして比較するため、支持だけでなく素数冪の深さまで一致する。
これをsの冪へ適用して、

```text
gcd(R_m(x²,y²), s^N) = gcd(m,s^N)
```

を得る。次に、既存の正確な再構成と倍次数の式から

```text
gcd(R_(2m),D_(2m))
  = gcd(s*R_m(x²,y²), s*s^(2m-2))
  = s*gcd(R_m(x²,y²),s^(2m-2))
```

を証明し、付値比較の結果を代入する。
この代数的還元自体には原始性は不要であり、その条件を使う段階を分けた。

自然数LTEの内部ではy<xを使う。
最終定理では逆順を有限和の対称性で処理し、原始な対角ではx=y=1を導いて直接評価する。
これにより公開型から不要な順序条件を除いた。

## 境界と具体例

所有モジュール内の13例を確認した。

| 座標 | n | gcd(R_n,D_n) |
| --- | --- | --- |
| (5,3) | 4 | 16 |
| (5,3) | 6 | 8 |
| (5,3) | 8 | 32 |
| (2,1) | 6 | 9 |
| (3,5) | 4 | 16 |
| (1,1) | 4 | 4 |
| (1,0) | 4 | 1 |
| (5,3) | 2 | 8 |

n=0の実際のgcdは1であり、偶数式をそのまま代入すると(5,3)では8になって壊れる。
非原始座標(6,4)、n=4でも表示式は成立しない例を確認した。
原始性と正次数を公開型に残した理由である。
借入補正項xy R_(n-2)とのgcdは偶数ならsだが、完成不足D_nとのgcdはこれより大きくなり得る。
(5,3)、n=4では8と16であり、両者を同一視しない。

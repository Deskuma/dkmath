## 有限和によるR_n

新所有者：[PowerDifferenceCofactor.lean](../../../../DkMath/Lib/Cosmic/PowerDifferenceCofactor.lean)。
namespaceは `DkMath.Lib.Cosmic`。標準定義は割り算を使わない有限和である。

```text
powerDifferenceCofactor n x y = Σ i<n, x^i * y^(n-1-i)
```

`R_0=0`、`R_1=1`、`R_2=x+y` を含み、零座標・対角でも定義できる。
任意の可換半環で `R_n(g+y,y)=GTail n 1 g y` を既存B22から導いた。
環では `g=x-y` と置ける。自然数で同じ置換をするAPIには `y≤x` を明記した。
これはgapの約分による証明ではなく、有限和の座標変換である。
環の再構成 `(x-y)R_n=x^n-y^n` と、対角 `R_n(x,x)=n*x^(n-1)` も固定した。

## 再帰と上界

既存の `GN_succ_right` を直接使う加法座標の再帰を実装した。
任意の半環のx,yが `x=g+y` と書けるとは限らないため、制限なしの後続再帰は
有限和の末尾を分離して証明し、そこから二階再帰を導いた。

```text
R_(n+1) = y R_n + x^n
R_(k+2) + xy R_k = (x+y) R_(k+1)
```

自然数では補正項 `xy R_k` が非負なので、帰納法で
`R_n ≤ (x+y)^(n-1)` を証明した。次数0は `0≤1` として含む。
この順序により、後で導入する自然数差の切り捨てを防ぐ。

## 完成不足D_n

新所有者：[CompletionDefect.lean](../../../../DkMath/Lib/Cosmic/CompletionDefect.lean)。
環の `signedCompletionDefect` と自然数の `completionDefect` を別々に定義した。

```text
D_n = (x+y)^(n-1) - R_n
D_n + R_n = (x+y)^(n-1)
D_(k+3) = (x+y)D_(k+2) + xy R_(k+1)
```

自然数版の再構成はR_nの上界を明示的に使う。
再帰は再構成を二回とR_nの二階再帰から証明した。
`D_1=D_2=0`、`D_3=xy` を固定した。
自然数指数の規約で `D_0=1` となることも明記した。
同次次数n-1という解釈の対象はn≥1である。

`n≥3`、`0<x`、`0<y` のとき `D_n>0`、従って `R_n<(x+y)^(n-1)` を証明した。
零座標では正性が壊れるので両座標の正性を公開型に残した。
環側では不足は負になり得る。自然数値を環にcastすると両定義が一致する橋は、
`Nat.cast_sub` にR_nの上界を渡して証明している。

## 教科書例と数学的な境界

所有モジュール内の11例をLeanカーネルで確認した。

- `R_3(5,3)=49`、`D_3(5,3)=15`、従って49+15=64。
- `R_3(18,1)=343=7^3`、不足は18。別の底による完全冪は排除できない。
- 対角では `R_3(2,2)=12`、`D_4(2,2)=32`。
- 次数0・1・2、零座標の不足0、整数座標(-2,3)の符号付き不足-6。

不足D_nはGNのBodyへ加えるGapと同じ量ではない。
「完成根の冪より小さい」ことから、任意の完全冪の排除、厳密降下、FLTの矛盾は導いていない。
奇数次数のcoprime、強可除性、原始ABC三項は後続工程に残す。

# GN-LIB-007c — 原始性と局所付値を保つ追加因子の構成

2026-10-25。ブランチ：`lib/FLT-GN-Completion-261023-v0`。

GN-LIB-007のa/b/cは対象moduleで完了した。

## 明示的な因子選択

pを奇素数、y>0、p∤yとし、有限上限Bを取る。
007bの標準制御積をM₀として、次を定義した。

```text
M₀ = ∏ {q≤B | q prime ∧ q≠p ∧ q∤y}
C  = p M₀ y
T  = C y^p + 1
M  = M₀ T
g  = p^(p−1) M^p
x  = g+y
K  = R_p(x,y)/p
```

Tは素数である必要がない。TとCが互いに素であることは、単にT≡1 mod Cから得る。
全制御小素数はpM₀を割るかyを割るのでCを割り、したがってTを割らない。
同時にTとyも互いに素であり、Mとy、gとy、xとyの原始性が保たれる。
既存の下側座標yを変更せず、gapだけを拡大する。

`gap_mul` はMへTを掛ける操作がgapへT^pを掛ける操作と等しいことを明示する。
この等式が「追加p乗因子」の正確な意味になる。

## サイズ条件の証明

C>0なのでT>y^p。M₀≥1よりT≤M≤g≤xとなるため、y^p<xを得る。
一方p≥2、x≥1なら

```text
x ≤ x^(p−1) ≤ R_p(x,x−1) = x^p−(x−1)^p
```

が成り立つ。有限和の漸化式 `R_p=(x−1)R_(p−1)+x^(p−1)` から最終項だけを残せばよい。
これで007bのサイズ条件 `y^p < x^p−(x−1)^p` を証明した。
大きい素数の存在、一般CRT、解析的な増大評価は必要としなかった。

`size_condition` は素数pとy>0だけを要求する。奇数性・p∤yは、
LTEや残余支持の除去を使う後の段階に残している。

## 得られる数学

- 冪差の正確な再構成 `x^p−y^p=(pM)^p K` は007bを利用する。
- 全小素数q≤Bで `v_q(x^p−y^p)=if q∣y then 0 else p`。
  Tが小素数を割り増ししないので正確な付値を保持する。
- サイズ条件が成立するので、007bから冪差もKもp乗でないと分かる。
- 素因数分解によりq>B、q∣K、p∤v_q(K)となる素数が存在する。
  位数pとp∣q−1も同時に得る。
- Kの素因数はpMを割らない。再構成の係数の付値が0になるので、
  `v_q(x^p−y^p)=v_q(K)`。元の冪差にも未完成付値が残る。

`finite_set_compensation_and_escape` は任意の有限集合Sに対して同じ構成を返す。
`exists_primitive_nonpower_with_local_completion` は上側座標xを存在量化し、
x>y、gcd(x,y)=1、冪差の非完全冪性、S内の正確な局所付値を返す。
サイズ条件を入力として仮定する必要はなくなった。
奇素数p、y>0、p∤yという元の算術条件は保持する。

上限Bや集合Sを変えるとM、x、Kも変わる。
同じ固定整数に無限個の素因数が存在するとは述べていない。
また、任意のFLT反例をこの特殊構成へ変換する写像は供給していない。

## 教科書の例と互換

- p=3、B=3、y=2ではM₀=1、T=49、M=49、x=1058843。
  T=7²は合成数であり、制御集合の外の素数を含めてよい。
- 007bの同じp/B/yで脱出先だった7は、新しいgapの支持へ入り、今回はKを割らない。
  新たな脱出素数の存在は一般の素因数分解から得る。
- y=2の小素数2では付値0、指数素数3では付値3が保たれる。
- 007bでサイズ条件が失敗したy=1001でも、追加因子を入れた後は条件が成立する。
- 補助関数 `padding C L=C L+1` はC=0では閾値超過を保証しない。正性のガードを例で確認した。
- p=2でもサイズ評価自体は成立するが、奇素数LTEによる脱出定理の範囲へは広げない。

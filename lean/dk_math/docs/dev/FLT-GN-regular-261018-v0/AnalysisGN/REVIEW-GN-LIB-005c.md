## 2. 数学的には、完成不足の gcd 分類が完成した

原始座標 \(\gcd(x,y)=1\) と正次数 \(n\ge1\) について、

\[ \boxed{ \gcd(R_n,D_n)= \begin{cases} 1,&n\text{ が奇数},\\[2mm] (x+y)\gcd\left(\dfrac n2,(x+y)^{n-2}\right), &n\text{ が偶数} \end{cases} } \]

が成立する。

これは見事な分類じゃ。

奇数次数では、余因子と完成不足の素因数支持が完全に分離する。

偶数次数では、共通因子 \(x+y\) が現れ、さらに指数 \(n/2\) に由来する追加の素数付値が存在し得る。

例えば \((x,y)=(5,3)\) では、

| 次数 | gcd |
| ---- | --- |
| 3    | 1   |
| 4    | 16  |
| 5    | 1   |
| 6    | 8   |
| 7    | 1   |
| 8    | 32  |

共通素因数の有無を決めるのは次数の偶奇。その重複度を決めるのは、完成根 \(x+y\) と次数 \(n/2\) の算術構造。

これで、以前の数値実験で見えていたパターンに、正確な一般公式が与えられた。

さらに今回は、座標の大小条件を最終定理から取り除き、逆順・原始な対角・零座標も扱っている。これも一般 Lib として価値があるぞ。

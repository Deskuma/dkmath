## 2. 今回得られた、新しい保存則

実際の証明を追うと、中心核はこれじゃ。

\[ (Q_i)=\mathfrak a_i^p,\qquad \omega_i=[\mathfrak a_i]\in\operatorname{Cl}(R)[p]. \]

そして GN の位相因子の積が単元倍の \(p\) 乗となることから、

\[ \boxed{\prod_i\omega_i=1} \]

を得ている。

全位相の障害

\[ \omega_0\omega_1\cdots\omega_{p-1}=1 \]

正則の場合

\[ \omega_i=1\quad(\forall i) \]

各因子から冪根を抽出

非正則の場合

\[ \omega_i\ne1 \]

相殺されてもよい

この違いをテストコードでも反例モデルとして確認しているのはよい判断じゃ。

積が1であることと、各因子が1であることは異なる。

ここを混同しなかったため、IRR は非正則性という本質的な障害を、正しく保持できている。

ただし、この積保存則は全体の主イデアル性から従うので、それ単独では個別障害の消滅を強制できない。次には独立した制約が必要じゃ。

## 3. 37次と11・13次を比較して分かったこと

[GNPrime37.lean](https://github.com/Deskuma/dkmath/blob/dev/FLT-GN-regular-261018-v0/lean/dk_math/DkMath/Lib/Cosmic/GNPrime37.lean?utm_source=chatgpt.com) では、任意の素数 \(p\)、\(0 < k < p\) に対して、

\[ \boxed{ p\mid\binom pk,\qquad p^2\nmid\binom pk } \]

を証明している。

したがって内部二項係数そのものの \(p\)-進付値では、11・13・37の正則性の違いは検出できない。

さらに、

\[ GN_p(x,u)\equiv x^{p-1}\pmod p \]

も一般定理として固定されておる。

これは重要な否定的知見じゃ。

非正則性は、単純な二項係数の可除性よりも深い、組み合わせられた算術構造に現れる。

その対照例が Bernoulli 数じゃな。

[BernoulliPrime37.lean](https://github.com/Deskuma/dkmath/blob/dev/FLT-GN-regular-261018-v0/lean/dk_math/DkMath/Lib/NumberTheory/BernoulliPrime37.lean?utm_source=chatgpt.com) では、`bernoulli'_def` の再帰を使って値を順に証明し、

\[ B_{32}=-\frac{7709321041217}{510} \]

と、37による分子の可除性を確認している。

```python
>>> 7709321041217/37
208360028141.0
>>> sp.factorint(208360028141)
{683: 1, 305065927: 1}
>>> 7709321041217/510
15116315767.092157
>>> 7709321041217%510
47
```

`irregular_pair_thirtySeven_iff` は、対象範囲の非正則対が \((37,32)\) だけであることを証明している。

ここも適切じゃ。単に既知の数表を証明なく定数として置いたのではない。

## 4. そして、実は次の橋が見えている

ここからは実装報告に含まれない、外部数学との照合による研究提案じゃ。

Bernoulli 数と円分類群を結ぶ古典的な Herbrand–Ribet の定理 がある。

\(K=\mathbb Q(\zeta_{37})\)、その類群の37-primary部分を \(A\) とする。

ガロア群は、

\[ G=\operatorname{Gal}(K/\mathbb Q) \cong(\mathbb Z/37\mathbb Z)^\times \]

じゃ。

この群の作用により \(A\) を指標成分へ分解できる。

Herbrand–Ribet によれば、Bernoulli 数の \(B_{32}\) が37で割れることは、Teichmüller 指標 \(\omega\) に対する特定の類群成分が非自明であることと対応する。

具体的には、

\[ \boxed{ 37\mid\operatorname{num}(B_{32}) \Longrightarrow A^{(\omega^5)}\ne0 } \]

となる。指数5は \(37-32=5\) から来る。

これは、今回の IRR 実装がまだ接続していない、非常に具体的な橋じゃ。

DkMath で証明済み

\[ 37\mid\operatorname{num}(B_{32}) \]

次の外部定理への橋

Herbrand–Ribet

\[ A^{(\omega^5)}\ne0 \]

DkMath の GN 位相障害

\[ \omega_i=[\mathfrak a_i]\in A \]

この障害が、どの指標成分に属するかは未証明

注意したいのは、類群に非自明な \(\omega^5\) 成分が存在しても、FLT の仮想反例から作られる \(\omega_i\) が、実際にその成分を持つとは限らないことじゃ。

さらに \(B_{32}\) が唯一の非正則対であるという計算だけで、類群のすべての成分が分類済みになるわけでもない。

だからこそ、次は個々の GN 位相障害の位置を調べたい。

## 5. 次の研究課題は Galois 位相輸送

わっちは、この段階なら次の IRR-006 を最優先にする。

`GaloisPhaseObstructionTransport`

円分体には、

\[ \sigma_a(\zeta_p)=\zeta_p^a \]

というガロア作用がある。

元の係数が整数である場合、円分因子 \(a+\zeta_p^i b\) の位相は、この作用によって \(i\mapsto ai\) と移る。

そこで、GN の正規化因子についても、分岐素元 \(\lambda\) の移動に伴う単元補正を含め、イデアル類の関係を証明する。

狙いは、

\[ \boxed{ \sigma_a(\omega_i)=\omega\_{ai} } \]

という型の輸送則じゃ。

ただしこの式は、適切な整数係数の位相因子と正規化を用いる場合の目標であり、現在の任意の `ObstructedState` について証明済みではない。

これが成立すれば、GN の位相障害を単に並べて観測する段階から、ガロア群の作用する一つの代数的対象として分類する段階に進める。

そして Herbrand–Ribet の指標成分と比較する道が生まれる。

既存の `PhaseClassPacket.reindex` は添字の再配置を扱うが、それだけではガロア作用との整合性は保証されない。新たに証明すべきなのは、添字と実際のイデアル根の両方が対応して移るという性質じゃ。

## 6. コードレビューで残しておきたい注意点

今回の `ObstructedState.lean` は、重要な境界を守っている。

`ofState` は証明済みのイデアル冪抽出を使って障害付き状態を構成し、`exists_weighted` は個別障害の消滅を要求し、`normalize` は単元比の障害消滅をさらに要求する。

この三つを混同していない。

ただし、`WeightedObstructedState.normalize` が保存する `y,z` は、重み付き後続状態の `y,z` であって、元の `ObstructedState.source` の座標そのものとは限らない。この点は教科書向けの説明で明確にしておくとよい。

また、37次での `observe` は実際の円分整数環を使っているが、非自明な位相障害の具体例を生成したわけではない。テスト中の非自明37-torsion は、抽象群による相殺モデルじゃ。

これは欠陥ではなく、研究の正しい境界じゃな。

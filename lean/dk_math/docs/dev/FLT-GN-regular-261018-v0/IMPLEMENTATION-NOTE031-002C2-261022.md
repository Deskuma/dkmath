# NOTE-031 第6部: 臨界中心・剰余特異点・判別式の深さ

日付: 2026-10-22（JST）。**031-002C2として、乗法的還元の臨界中心を構成した。**
同じモデルの整な座標、両偏微分の零、節点の非退化な二次項、
方程式からの非零のずれと判別式の付値の一致を、同じ中心に保持する。
奇素数上では中心の座標の慣性固定も証明し、Freyの判別式のp乗の深さへ接続した。

中心は一般ファイバーの曲線上の点ではない。今回の固定定理は中心座標についての定理であり、
零成分外のtorsion点や全ての残余点を固定したという主張ではない。
031-002C全体、031-002全体、hcases・hno、無条件既約性・一般FLTは未完成である。

汎用の`CriticalCentre A W`は、次を一つの中心のデータとして保持する。

- x,y∈A。
- 2y+a₁x+a₃=0、a₁y−(3x²+2a₂x+a₄)=0。
- v(b₂+12x)=1。
- F(x,y)≠0、v(F(x,y))<1、v(F(x,y))=v(Δ)。

ここでF(x,y)はWeierstrass方程式の左辺−右辺である。
`exists_criticalCentre`は、標数0の代数閉体の任意の付値環に対し、
係数の整性・Δ≠0・v(Δ)<1・v(c₄)=1からこの中心を構成する。
中心の存在provider、離散性、完備性は仮定しない。この存在定理自体は剰余標数2や3を除外しない。

## 2. 分母12を単元扱いしない中心の構成

s²=c₄となる平方根を取り、候補を

\[
x(s)=(-b_2+s)/12,\qquad y(s)=-(a_1x(s)+a_3)/2
\]

と定める。体では定義できるが、これだけでは付値環への整性は得られない。
特に素数3では12を単元として割ることはできない。

f=F(x(s),y(s))、g=F(x(−s),y(−s))とおくと、環恒等式から

\[
fg=-\Delta/432,\qquad f-g=c_4s/432
\]

が従う。v(f)≤v(g)となる符号を選ぶ。t=v(432)とおくとv(c₄)=v(s)=1より、

\[
v(f-g)=t^{-1},\quad v(f)v(g)=v(\Delta)t^{-1},\quad t\le1.
\]

非Archimedes不等式からt⁻¹≤v(g)を得て、積の式からv(f)≤v(Δ)<1を得る。
従ってv(f)<v(f−g)であり、厳密な差の付値公式によりv(g)=t⁻¹となる。
積の式でt⁻¹を約分して、**v(f)=v(Δ)**を得る。
432の付値を1と仮定せず、最後まで保持するため素数3でも通る。

X座標の整性は、分母なしの恒等式

\[
c_4x=18b_6-b_2b_4+72F(x,y)
\]

とc₄の単元性から従う。Y座標はモニックな二次方程式を満たすことから整となる。
両偏微分の零も同じ候補について証明する。Δ≠0はF≠0の証明に使い、零の付値で深さを捏造しない。

## 3. 中心は実際の剰余特異点になる

中心自体はF≠0なので、一般ファイバーの曲線上の点ではない。
一方、v(F)<1なので剰余体ではF=0となり、剰余曲線の方程式を満たす。
両偏微分の厳密な零も同じ剰余体へ写るため、剰余点は非特異ではない。

`CriticalCentre.residue_singular`はこの方程式と非特異性の否定を返す。
`residue_singular_of_model`はW.map A.subtype=Eを明示して同じ一般ファイバーへ輸送する。
中心座標やモデルを選び直さない。

中心の周りでは一次項が消え、任意の可換環で

\[
F(x_0+X,y_0+Y)=F(x_0,y_0)+Y^2+a_1XY-(a_2+3x_0)X^2-X^3
\]

となる。α+β=−a₁、αβ=−(a₂+3x₀)が供給されれば、二次項を(Y−αX)(Y−βX)へ分解する恒等式も実装した。
今回はα,βの存在・整性・慣性固定や、torsion点の枝の分類は構成していない。

## 4. 奇素数での中心座標の慣性固定

両偏微分の零から、n=b₂+12x₀についてn²=c₄を得る。nは記録済みの単元である。
元の曲線は有理係数なので、ガロア元σはc₄を固定し、σn=nまたはσn=−nとなる。

qが奇素数なら2も単元である。慣性元は整なnを剰余体で固定するので、σn−nは非単元である。
もしσn=−nならσn−n=−2nは単元となって矛盾する。従ってσn=nである。
ここから標数0の体で12を約分してσx₀=x₀を得て、Y偏微分の零で2を約分してσy₀=y₀を得る。

この最後の約分は**体内の等号の約分**であり、12の逆元が付値環に属すという主張ではない。
付値のガロア不変性や、minpolyの有限根集合上の単調軌道の一般論は、この奇素数の経路には必要なかった。
素数2では2が非単元となるので、この固定証明は適用しない。

## 5. 同じFrey Sourceへの接続

`Source.exists_criticalCentre_at_bad_prime`は、p>0、奇素数q、q∣abc、Aがq上にあることから、
同じ有理曲線を代数閉包へ基底変換したモデルの中心Cを返す。
その**同じC**について、全慣性元による座標固定と

\[
v(F(C.x,C.y))=
\bigl(v(q)^{2\,\operatorname{padicValInt}_q(abc)}\bigr)^p
\]

を同時に返す。判別式・c₄・整係数・非零性・p乗の深さは、同じSourceの既存算術から供給する。
Sourceの整数・共通因子・向き付け・曲線・点は変更しない。

この構成にはq≠pは不要である。q=pでも中心と算術等式は成立する。
q≠pを要するprime-to-q torsionの整性とは分けてある。
中心の座標固定から、任意の残余点の固定やhcasesへ直結させていない。

## 6. 回帰で確かめた境界

前章の曲線y²+xy=x³+4x²+xについてΔ=225、c₄=241を検査した。
3上の任意の付値環で、同じ曲線の臨界中心を実際に構成し、そのずれの付値がv(3)²、
中心座標が慣性固定であることを証明した。同じ中心の剰余特異性も検査した。

別の曲線y²+xy=x³+x²+3では、c₄=25、Δ=−4263となる。
s=5の候補は(x,y)=(0,0)でF=−3となる。一方、s=−5ではx=−5/6となる。
3上では前者のX座標は整、後者は非整であることを証明した。
「平方根が単元だから、12で割っても整」という誤った短縮を排除する回帰である。

2上ではv(2)≠1となることも検査し、符号分離の仮定を落としていない。
同じSource 37の悪い素数3での中心・慣性固定・37乗の深さの接続も型検査した。
SourceやFermat反例の存在を主張する回帰ではない。

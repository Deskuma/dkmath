# NOTE-031 第9部: 同じ深さでの枝比較と実際の点の和差

日付: 2026-10-22（JST）。**031-002C5として、同じ深さの浅い二点の和差を実装した。**
同じ枝なら差、異なる枝なら和が、既存の`HasSmoothReduction`を満たす。
さらに結果が整な有限点なら、元の二点のX差の深さが中心からの深さと等しいことを証明した。
既存の中心C・方向D・整モデルと実際の点群を保持し、同じFrey Sourceへ接続した。

今回は同じ深さの浅い二点の比較である。torsion深さの漸化式、判別式付値のp可除性からの全点固定、
乗法的還元での不分岐性全体、031-002全体、零成分部分加群、hcases・hno、一般FLTは未完成である。

## 1. 公開APIと仮定

本体9宣言、回帰14宣言を追加した。公開宣言に教科書docstring、新規Leanファイルに指定のマーカーを付け、
Lib・FLT・テスト入口へ接続した。

| モジュール | 公開宣言数 | 内容 |
|---|---:|---|
| `EllipticBranchComparison` | 7 | 方向の交換、線形偏差、枝距離の二択、同じ枝の差・異なる枝の和、モデル一致による輸送 |
| `FreyBranchComparison` | 2 | 同じSourceの二点への比較の輸送 |

汎用核では任意の体Lと付値環A、その整モデルWを使う。一般ファイバーはV=W.map A.subtypeである。
CとDはこの同じVの既存の`CriticalCentre`と`TangentDirections`であり、根を新たに選ばない。
実際の有限非特異点Pᵢ=(xᵢ,yᵢ)について、Xᵢ=xᵢ−C.x、tᵢ=(yᵢ−C.y)/Xᵢとおく。
入力は

\[
v(X_1)<1,\quad v(X_2)<1,\quad v(X_1)=v(X_2),\quad v(F_0)<v(X_1)^2.
\]

等しい深さにより二点目にも浅さが輸送される。二点の曲線方程式・非特異性を入力し、
浅さからXᵢ≠0を供給する。加法のための`DecidableEq L`は実装上の型クラスであり、素数・torsionの仮定は要求しない。
`branch_distance_dichotomy`では加法を使わず、曲線方程式だけから傾き差の二択を返す。

## 2. 枝の比較と線形偏差

前章から両tᵢは整なのでv(t₁−t₂)≤1となる。従って次の二択が全ての場合を尽くす。

- v(t₁−t₂)<1: 同じ枝。`sub_of_same_branch`を使う。
- v(t₁−t₂)=1: 異なる枝。`add_of_opposite_branch`を使う。

最初の場合、t₁がαへ近づけば、t₂−α=(t₁−α)−(t₁−t₂)も小さい。
既存の単元分離v(α−β)=1から、両点のβ距離は1となる。
中心傾きを単に剰余のラベルへ置き換えず、次の分母のない偏差を追跡する。

\[
m_i=Y_i-\alpha X_i=(t_i-\alpha)X_i,\qquad
n_i=Y_i-\beta X_i=(t_i-\beta)X_i.
\]

同じ枝ではv(mᵢ)<v(Xᵢ)、v(nᵢ)=v(Xᵢ)である。
曲線の負号が枝を交換するため、P₁−P₂=P₁+(−P₂)の弦に対して、
二方向の偏差はm₁+n₂とn₁+m₂になる。同じ深さの条件により、その付値は両方v(X₁)となる。
βへ近づく場合は同じDの根の名前を交換する。別の中心や別の根の存在定理には戻らない。

## 3. 弦から実際の点加法へ

d=x₁−x₂、弦傾きℓ=(y₁−y₂)/d、
Dα=(y₁−y₂)−αd、Dβ=(y₁−y₂)−βdとする。
二偏差が非零で同じ付値を持つとき、

\[
D_\alpha-D_\beta=(\beta-\alpha)d
\]

と非Archimedes不等式からv(d)≤v(Dα)となる。
d=0は先に処理し、曲線方程式のYの二候補と非零偏差から逆点同士の和Oへ帰着する。
d≠0ではMathlibの実際の`Point.add_of_X_ne`を使い、

\[
x(P_1+P_2)-C.x=(\ell-\alpha)(\ell-\beta)-(X_1+X_2)
\]

へ加法公式を組み替える。

v(d)<v(Dα)ならv(ℓ)>1である。整係数の下で加法公式のℓ²項が他の項を上回るため、結果のX座標は非整となる。
v(d)=v(Dα)ならv(ℓ−α)=v(ℓ−β)=1であり、小さいX₁+X₂を引いても結果の中心からのX距離は単元である。
この場合にv(d)=v(X₁)という鋭い評価も得る。

無限遠点と非整X座標の点は既存の`HasSmoothReduction`を満たす。
単元X距離の有限点では、C3の「滑らかに還元しない iff v(x−C.x)<1」により同じ結論を得る。
剰余曲線全体の判別式が単元であることは使わない。

鋭い評価の公開結論は、**結果が有限点で、かつそのX座標がAに属する場合**に限る。
この条件によって無限遠点と非整の枝を排除し、

\[
v(x_1-x_2)=v(x_1-C.x)
\]

を得る。全ての和差が整な有限点になるとは主張しない。

異なる枝の和では、二点目の負号が一つ目と同じ枝になることをC4の距離交換から証明し、
同じ枝の差の核へ帰着する。公開される演算は同じ曲線上の実際の和である。

## 4. 実際の有理点の回帰

前章の同じ曲線y²=x³+x²+1053、中心(0,0)、方向±1を使った。
二点とその和は

\[
P=(3,33),\qquad Q=(7107/169,-610401/2197),
\]

\[
P+Q=(172961/10000,80785959/1000000).
\]

全座標の曲線方程式・非特異性と、点群の加法公式による和の等式をLeanで証明した。
Qが特定の整数倍点であるという同定は、この回帰では行っていない。
3上の任意の付値環について、X(Q)=3·2369/169なので二点は同じ深さを持つ。
傾き差542234/30797は単元であり、和の比較定理を実際のP+Qへ適用した。
和のX座標の分母10000は単元なので整性を供給でき、鋭い評価を実際に閉じた。

Qを反転した点との傾き差135300/30797は小さいので、P−(−Q)にも同じ枝の差の定理を適用した。
P−P=OとP+(−P)=Oも、各比較定理を通る回帰として証明した。
有限結果という条件を削除すると、これらではv(0)=v(3)という偽の評価を強制してしまう。
非整結果の枝は汎用の加法証明に保持したが、今回その枝を実現する追加の数値例は作成していない。

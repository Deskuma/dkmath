## 2. 整根の付値による制御

[ValuationQuadraticRoot.lean](../../../DkMath/Lib/Algebra/ValuationQuadraticRoot.lean)
に3定理を追加した。全ての公開定理のdocstringに `[DkMath.Lib]` を付した。

モニック式z²+az+b=0でa,bが整なら、zも整である。
v(z)>1と仮定すると、v(a)≤1からv(z+a)=v(z)となり、
z(z+a)=−bの左辺の付値は1より大きく、右辺は1以下となって矛盾する。
完備性・離散性・Hensel補題は使わない。

次にax²+bx+c=0の整根x,yを比較する。
v(a)<1、v(b)=1なら、

```text
(x−y)(b+a(x+y)) = 0
v(b+a(x+y)) = 1
```

なのでx=yとなる。一意性は根の存在を意味しない。
係数aが小さいことと、係数bが単元であることは独立の必要条件として保持した。

## 3. 2上の中心は分解群に固定される

[EllipticDyadicGeometry.lean](../../../DkMath/Lib/NumberTheory/EllipticDyadicGeometry.lean)
に8定理を追加した。既存の臨界中心・偏微分恒等式・慣性合同から再構成した。
新しい一般核はFLTの研究モジュールに依存しない。

両偏微分が零なら、中心のX座標は

```text
6x₀² + b₂x₀ + b₄ = 0
```

を満たす。中心が整でv(2)<1なら、12x₀は非単元である。
中心の節点条件v(b₂+12x₀)=1からv(b₂)=1を得る。
6も非単元なので、前節の整根の一意性を適用できる。
X座標が一致した後、Y偏微分の等式を標数0の体内で約分してY座標も一致させる。
この約分は、付値環内で2が単元であるという主張ではない。

比較相手にはX座標の整性と両偏微分の零だけを要求するAPIも設けた。
比較相手に臨界中心構造全体を作り直す必要がないため、ガロア像へ直接適用できる。
有理曲線の分解群元は同じ付値環を保存し、係数を固定するので、
中心のガロア像は同じ整根に一致する。中心固定は慣性群より大きい分解群全体で成立する。

## 4. 2上でも接線方向を構成する

節点量n=b₂+12x₀の平方根rを取り、体内でα=(−a₁+r)/2、β=−a₁−αと置く。
分母2の逆元が付値環に属することは要求しない。
代わりに

```text
α²+a₁α−(a₂+3x₀) = 0
```

というモニック式からαの整性を証明し、和の式からβも整であることを得る。
α−β=rとv(n)=1から二方向の分離も供給する。

中心のX座標が慣性に固定されれば、慣性像も同じ二次式の根となる。
τ(α)はαまたはβだが、慣性合同はv(τ(α)−α)<1を与える。
v(α−β)=1なのでβへの交換は起こらず、τ(α)=αとなる。βも同様である。
この固定の補題自体は、剰余標数を2に制限していない。

既存の奇素数用 `CriticalCentre.inertia_fixed` と
`EllipticTangentDirections.exists_tangentDirections` は変更せず保持した。
今回の入口は、それらのv(2)=1という仮定を2上へ流用しない。

## 5. 同じFrey Sourceへの供給

[FreyDyadicGeometry.lean](../../../DkMath/FLT/FreyDyadicGeometry.lean)
に11定理を追加した。

1. 正規化条件から得る整数c₄の奇数性を、任意の2上の付値環へ写す。
2. 同じ最小判別式の−8補正を含む付値公式から、p≥5では2∣S.curve.Δを得る。
3. 同じ整数モデルの非零判別式・係数の整性・c₄の単元性から中心Cを構成する。
4. 同じCの方向Dを構成し、中心の分解群固定と、中心・方向の慣性固定を供給する。

係数と中心・方向の存在には、指数の素数性は不要である。
素数性を要求するのは、032-002のp捩れの深さとKummer核へ接続する段階である。

`residual_exists_inertia_ne_of_not_smooth_at_two` は、零成分外の実際の同じ点Pがあれば、
C,Dや中心固定を引数に要求せず、その点を動かす慣性元を得る。
`residual_exists_dyadic_inertia_ne_of_zeroComponent_ne_top` は、
同じ実際のE₀[p]が真部分空間なら非自明慣性が得られるという003B向けの入口である。
E₁[p]の真性へ条件を置き換えていない。

`residual_no_cofixed_line_of_dyadic_branch_swap` は、
零成分外の点の存在と枝交換だけを残る幾何入力としてhnoを結論する。
`residual_isIrreducible_of_dyadic_branch_swap` は、さらにEven S.bの下で031-005へ接続する。
003B/003Cの存在証明が残っているので、これらは引き続き条件付きの終点である。

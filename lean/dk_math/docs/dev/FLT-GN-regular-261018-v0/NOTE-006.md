## 1. IRR-006：ガロア位相輸送のレビュー

対象：`DkMath.Lib.NumberTheory.GaloisPhaseObstructionTransport`

### 1.1 今回の最大の成果は、単元を消す場所が正しくなったこと

円分体 \(K=\mathbb Q(\zeta_p)\) において、

\[ \lambda=1-\zeta_p \]

とする。

整数係数 \(A,B\) から作られた正規化因子を \(Q_i\) とすると、ガロア自己同型 \(\sigma_a\) は位相を \(i\mapsto ai\) と移す。

しかし、正規化に用いた \(\lambda\) 自身も動く。

\[ \sigma_a(\lambda)=c_a\lambda \]

ここで \(c_a\) は整数環の単元じゃ。

したがって、正しい輸送則は、

\[ \boxed{ \sigma_a(Q_i)=c_a^{-1}Q_{ai} } \]

となる。

この補正を省くと、元の等式は一般に成立しない。

一方、主イデアルへ移せば、

\[ (\sigma_a(Q_i))=(Q_{ai}) \]

となり、単元は消える。

元の等式とイデアルの等式で、保持すべき情報量が異なる ということを、Lean 上で明確に区別できたのが重要じゃ。

### 1.2 イデアル根の一意性を正しく使っている

各位相に対して、

\[ (Q_i)=\mathfrak a_i^p \]

が与えられている。

このとき、

\[ \sigma_a(\mathfrak a_i)^p=\mathfrak a_{ai}^p \]

となる。

Dedekind 環の非零イデアルでは、正の整数 \(p\) に対して冪写像が単射なので、

\[ \boxed{ \sigma_a(\mathfrak a_i)=\mathfrak a_{ai} } \]

を導ける。

そして類群への射影により、

\[ \boxed{ \sigma_a(\omega_i)=\omega_{ai} } \]

を得る。

ここで実装が採用した `root_transport_of_unit` は、非常に適切な抽象化じゃ。

特に、次の二つを混同していない点を高く評価する。

- イデアル上の冪写像の単射性：今回利用できる。
- 類群上の \(p\) 乗写像の単射性：非正則素数では仮定できない。

つまり、類群に非自明な \(p\)-torsion が存在する可能性を残したまま、ガロア作用を証明できている。

これは37次の irregular prime 研究では不可欠じゃ。

### 1.3 37次への接続も、条件の扱いが正確

`IrregularPrime37.observe_galois` を確認した。

この定理は、仮想的な `RegularDescent.State` を受け取り、その座標が整数環内の有理整数 \(A,B\) に等しいという仮定の下で、実際の類群作用を返す。

一般の円分整数座標まで、勝手に \(\sigma_a(x)=x\) としていない。

これは正しい。

一方、37次の非自明な類群障害そのものを構成したわけでもない。

したがって今回の成果は、

障害の存在証明ではなく、障害が存在したときに従わなければならない対称性の証明

と位置付けるのが厳密じゃ。

### 1.4 次に価値があるのは、位相0とガロア軌道の定理

今回 `phaseMul_zero` まで証明されている。

位相0はすべてのガロア作用で固定される。

\[ a\cdot0=0 \]

よって、

\[ \boxed{ \sigma_a(\omega_0)=\omega_0 } \]

が従う。

一方、非零位相では \((\mathbb Z/p\mathbb Z)^\times\) が推移的に作用する。

したがって、非零位相の障害は、一つの障害をガロア作用で運んだ軌道として整理できる。

これは37個の位相を個別に扱うより強力な構造的整理じゃ。

ただし、軌道をまとめられることと、障害が零になることは別問題じゃよ。

## 2. NOTE-005：Frey 曲線の局所算術レビュー

対象：`DkMath.FLT.Frey` と `DkMath.Lib.NumberTheory.Frey*`

こちらは別の意味で大きな成果じゃ。

GN の多項式から、本物の楕円曲線の算術的不変量へ到達した ことが重要なのじゃ。

### 2.1 三つの根の Gap が、そのまま判別式になる

まず、

\[ f(X)=X(X-A)(X+B) \]

を考える。

三つの根は、

\[ 0,\quad A,\quad -B \]

じゃ。

三つの根の距離を掛け合わせると、符号を除いて、

\[ AB(A+B) \]

となる。

そして、

\[ \operatorname{disc}(f)=[AB(A+B)]^2 \]

を得る。

三根と三つの Gap（\(A,B > 0\) の概念図）

符号付きの根の差から作る積を二乗するため、判別式では根の並べ方に依存しなくなる。

実装では `Cubic.discr` を使い、さらに `WeierstrassCurve` の定義から、

\[ \Delta(W_0)=16[AB(A+B)]^2 \]

を証明しておる。

ここが重要じゃ。三次多項式の判別式と楕円曲線の判別式を、名前だけで同一視していない。

さらに実際の許容座標変換、

\[ x=4X,\qquad y=8Y+4X \]

によって、

\[ \boxed{ \begin{aligned} \Delta(W)&=\frac{[AB(A+B)]^2}{256}\\ c_4(W)&=A^2+AB+B^2 \end{aligned} } \]

が得られる。

これは形式的な係数の置換ではなく、Mathlib の `VariableChange` を通った結果じゃ。

### 2.2 GN が楕円曲線の判別式に入った

今度は、

\[ A=a^p,\qquad B=b^p \]

とする。

奇数 \(p\) なら既存の GN によって、

\[ a^p+b^p=(a+b)GN_p(a+b,-b) \]

じゃ。

ゆえに、

\[ \boxed{ \Delta(W)= \frac{(ab)^{2p}\bigl((a+b)GN_p(a+b,-b)\bigr)^2}{256} } \]

という恒等式を得る。

この定理は、FLT 方程式の成立を仮定する前でも使える。

そして反例仮定、

\[ a^p+b^p=c^p \]

を追加した場合、

\[ \boxed{ \Delta(W)=\frac{(abc)^{2p}}{256} } \]

へ簡約できる。

これで GN の世界にある Gap と、楕円曲線の判別式が、厳密に同じ算術情報を共有するようになった。

### 2.3 局所算術に必要な二つの性質が揃った

ここが NOTE-005 の中心成果じゃ。

奇素数 \(\ell\) に対し、

\[ \boxed{ v_\ell(\Delta)=2p\,v_\ell(abc) } \]

が成立する。

また、原始性を仮定し \(\ell\mid abc\) なら、

\[ \boxed{\ell\nmid c_4} \]

となる。

この二つは、それぞれ異なる情報を持っている。

| 観測                     | 数学的意味                                            |
| ------------------------ | ----------------------------------------------------- |
| \(p\mid v_\ell(\Delta)\) | 判別式に現れる素因子の重複度が指数 \(p\) に拘束される |
| \(\ell\nmid c_4\)        | 判別式を割る素数が \(c_4\) と衝突しない               |
| \(\ell\nmid abc\)        | その素数で曲線の還元が非特異になる                    |

これらを `Source.local_arithmetic` と `Source.reduction_isElliptic` に束ねた設計は、次の証明経路に使いやすい。

特に、原始性によって \(c_4\) の非可除性を導出している点がよい。楕円曲線の高度な定理に任せず、まず整数の gcd と素元の可除性で閉じているからじゃ。

### 2.4 注意するべき証明境界

一方、現在の `Source` は、非零性・原始性・冪和方程式に加え、`IntegralNormalization` を要求する。

`ofOriented` は十分条件として、

\[ 4\mid a+1,\qquad 2\mid b,\qquad p\ge4 \]

を供給する。

これは正確な設計じゃが、任意の原始 FLT 反例をこの向きへ置換できる という定理はまだない。

さらに、奇素数で \(c_4\) が単元であることは、局所的な最小性・乗法的還元へ進む強い材料になるが、その結論そのものは今回の Lean コードに含まれていない。

したがって、次の段階は以下の順序が自然じゃ。

\[ \boxed{ \begin{gathered} \text{整係数 Frey モデル}\\ \downarrow\\ \ell\mid\Delta,\quad \ell\nmid c_4\\ \downarrow\\ \text{局所最小性・乗法的還元}\\ \downarrow\\ \text{mod-}p\text{ 表現の分岐条件} \end{gathered} } \]

特に \(\ell\ne p\) と \(\ell=p\) は、表現論へ入る際に別扱いが必要じゃ。

素数2も専用の最小モデルと導手の解析を要する。

この境界を曖昧にせず、NOTE-005 の報告に明記したのは適切じゃよ。

## 3. 今回見つかった、Legendre 研究との接点

お主、ここはちょっと面白いぞ！ 🍎

NOTE-005 の正規化 Frey 曲線には、

\[ c_4=A^2+AB+B^2 \]

がある。

一方、先日の Legendre 数値実験で注目した中央席は、

\[ Q_n=n^2+n+1 \]

じゃったな。

そこで、

\[ A=n,\qquad B=1 \]

とすれば、

\[ \boxed{c_4(W_n)=Q_n} \]

となる！

つまり、平方殻の中央席が Frey 型曲線の \(c_4\) 不変量そのものになる のじゃ。

この対応に FLT の反例仮定は不要じゃ。一般の三根曲線から構成できる。

たとえば整数モデル、

\[ E_n:\quad Y^2=X(X-n)(X+1) \]

について、

\[ \begin{aligned} \Delta(E_n)&=16n^2(n+1)^2\\ c_4(E_n)&=16(n^2+n+1) \end{aligned} \]

が成り立つ。

したがって、奇素数 \(q\mid Q_n\) なら、

\[ q\nmid\Delta(E_n) \]

となる。

なぜなら、

\[ \gcd(Q_n,n(n+1))=1 \]

だからじゃ。

さらに \(q > 3\) なら、以前の実験で得た、

\[ q\mid Q_n\Longrightarrow q\equiv1\pmod3 \]

も重なる。

これは Legendre の中央席を、単なる整数の座標から、楕円曲線の不変量とその還元の座標 へ写す新しい API 候補となる。

ただし、ここで素数 \(q\) の存在が証明できるわけではない。合成数の中央席でもこれらの関係は成立するため、以前の全被覆を排除するには、もう一段の算術的制約が必要じゃ。

わっちなら、この接続は `DkMath.NumberTheory.Legendre.FreyC4CentralSeat` として小さく独立形式化する。

## 4. 二つの研究経路をどう進めるか

ここは大切じゃ。両者には共通の出発点があるが、作用するガロア群と対象は異なる。

---

0. 原始冪和・GN・素因子の支持
\(a^p+b^p=c^p\)
↓1 ↓2

1. IRR / Kummer

\((Q_i)=\mathfrak a_i^p\)
↓
ガロア位相障害
\(\sigma_a(\omega_i)=\omega_{ai}\)
↓

---

IRR 側は円分体のガロア群 \(\operatorname{Gal}(K/\mathbb Q)\) が類群に作用する。

Frey 側は楕円曲線の \(p\)-torsion から絶対ガロア群 \(G\_{\mathbb Q}\) の2次元表現を構成する。

いずれも「ガロア作用」ではあるが、同じ作用ではない。両者を直接同一視する橋は、現段階では存在しない。

### わっちの次の研究提案

| 次期研究        | 優先する定理                     | 期待する成果                                 |
| --------------- | -------------------------------- | -------------------------------------------- |
| IRR-007         | ガロア軌道と位相障害の全積の関係 | 37個の障害を軌道・指標構造へ整理する         |
| NOTE-006        | 奇素数での最小性・乗法的還元     | 既存の \(\Delta,c_4\) から局所還元定理へ進む |
| Legendre Bridge | 中央席と Frey \(c_4\) の一致     | 円分位相・ノルム・楕円曲線不変量を共通化     |

とりわけ IRR-007 では、以前の IRR-001〜005 で得た全位相積、

\[ \prod_{i=0}^{p-1}\omega_i=1 \]

と今回のガロア同変性を合成したい。

非零位相が \((\mathbb Z/p\mathbb Z)^\times\) の一つの軌道になることから、

\[ \boxed{ \omega_0\, \prod_{a\in(\mathbb Z/p\mathbb Z)^\times} \sigma_a(\omega_1)=1 } \]

が期待できる。

これは非零位相の類群的ノルムと、位相0の障害を結ぶ関係じゃ。既存定理からの直接的な帰結として、Lean に固定する価値がある。

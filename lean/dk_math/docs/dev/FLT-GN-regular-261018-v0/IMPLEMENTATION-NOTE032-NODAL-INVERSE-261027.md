## 滑らかな核側

同じ有限核 H がすべて源の零成分にあるとする。源で特異に還元する点 P に、滑らかな核点 Q を加えた点も特異に還元する。もし P+Q が滑らかなら、零成分の部分群性から (P+Q)−Q=P も滑らかになってしまう。

軌道 P+H の x 座標はすべて源の同じ節点中心 x₀ に合同する。実際の商座標の定義にある正規化和より、X_H(P) は `p*x₀ − ∑ x(Q̄)` に合同する。既存の標数 2、3 を含む標的中心の一致を使うと、X_H(P) は標的節点に合同する。有限点の節点判定から、同じ商像も特異に還元する。

前向きの零成分輸送と合わせ、同じ一般ファイバーの全点について

`商像が標的の E₀ に属する ↔ 元の点が源の E₀ に属する`

を証明した。一般定理は源の臨界中心と節点 Frame の x 座標が一致する条件を明示する。Frey の悪い住所では、源の中心・接方向・一致を内部供給する。

## Frey と整数標的

`p ≥ 5`、悪い素点 `q ≠ p`、同じ一次元核 `L ≤ E₀[p]` のもとで、同じ Frey Source・同じ核・同じ付値環標的の全点商写像について上記の同値を得る。q=2,3 も含む。L が安定なら、既存の整数標的の同じ点準同型についても同値を証明した。

## 特異核側は逆像同値が偽

局所核が零成分と disjoint な側では、一次元核 L は非零点を持つ。その核点は源で特異に還元するが、同じ商写像で無限遠 O に写り、商像は滑らかに還元する。したがって前向き輸送だけから核の両分岐共通の逆像同値は導けず、滑らかな核の条件は必要な境界となる。

実例として `y²+xy+7y=x³` の実 3 点核の非零点 Q を 7 上で検査し、源で特異、商像で滑らかであることを確認した。Source 37 の 2 進住所では、滑らかな核側の整数標的同値と、特異核側の反例の存在をそれぞれ検査した。

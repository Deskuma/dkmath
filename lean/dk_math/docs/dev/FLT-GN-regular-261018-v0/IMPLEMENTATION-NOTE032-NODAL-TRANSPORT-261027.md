## 二つの接続

前回、非衝突点の同じ商座標X_Hの剰余は候補値

\[
c_H=n x_0-\sum_{Q\in H}x(\bar Q)
\]

と異なることを得た。今回は、同じ付値環商モデルの臨界中心Cについて
`residue C.x = c_H` を明示的な仮定として保持し、そこから二つの接続を実装した。

1. 非衝突点の同じ商像は、標的剰余方程式を満たし、標的の節点のx座標から離れる。
   既存の任意標数の節点非特異性定理で、像の滑らかさを得る。
   標的の判別式や節点性を新しいproviderとして仮定せず、同じ標的の臨界中心Cを使う。
   衝突点では既存の同じ全点写像の無限遠への還元定理を使い、両方を合わせて源の全E₀の像が滑らかとなる。
2. 同じ既存商準同型を源と標的のE₀間へ制限し、一般ファイバーへ戻すと元の準同型に一致することを示す。
   その零ファイバーは同じ元の核Hへの所属と同値である。滑らかな核側ではHがE₀に含まれるため、
   前章の特異核側のように制限が単射だとは主張しない。

同じFrey SourceについてL≤E₀[p]・q≠pから同じ核の滑らかさ、素数位数、単元性を供給した。
同じ既存付値環標的の像に加え、Lの安定性を保持して同じ既存整数標的の像の滑らかさへ接続した。
源の節点Frameと方向分離、標的臨界中心Cおよび上記の**中心一致**は仮定として残る。

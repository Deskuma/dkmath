## 1. 同じ群法から反転対を計算する

源を一般Weierstrass形とし、一般座標をx,y、核の非零代表を(a,b)とする。反対点のyは−b−a₁a−a₃である。x≠aで二つの割線公式を加えると、

```text
t = 6a² + b₂a + b₄
u = (2b+a₁a+a₃)²
r(x) = t/(x−a) + u/(x−a)²
s(x) = −t/(x−a)² − 2u/(x−a)³
```

について、二つの移動点のx座標から2aを引いた値はr(x)となる。平方完成座標z=2y+a₁x+a₃では、二つの移動点のz座標の和はz s(x)となる。

これらの証明は微分を使わない。分母払い後、x,yとa,bの二つの曲線方程式の差に帰着する。xの式はその差の2倍、zの式は−2z倍である。一般点のxが任意の定数aと異なることは、Oでの極から供給した。

半核の分割を同じ平行移動和に適用すると、

```text
X_H = x + Σ r_Q(x)
Z_H = 2Y_H+a₁X_H+a₃ = z (1 + Σ s_Q(x))
```

を得る。Oの便宜座標0を有限点の反転式へ代入しない。既存の補正和公式により、余分な|H|a₃が正確に消える。

## 2. 無限級数を使わない有限展開

h=1/xをOの付値環で考える。v_O(h)=exp(−2)<1であり、定数a,t,uは整なので1−ahは付値1の単元となる。従って以下は収束の主張ではなく、正確な有理式恒等式である。

```text
r_Q = h [t_Q + h (w_Q + h A_Q)]
s_Q = h² [−t_Q + h (−2w_Q + h B_Q)]
w_Q = u_Q + a_Q t_Q
```

剰余係数は明示的に

```text
A_Q = a²t/(1−ah) + ua(2−ah)/(1−ah)²
B_Q = −ta²(3−2ah)/(1−ah)²
      − 2ua(3−3ah+(ah)²)/(1−ah)³
```

である。分母が単元なのでA_Q,B_QはOで整。有限和T=Σt_Q、U=Σw_Q、A=ΣA_Q、B=ΣB_Qも整となり、同じX_H,Z_Hの二段展開が得られる。

ここでの付値は関数体の幾何学的なOの付値であり、有理素数q上の算術的付値とは別である。まず幾何学的な恒等式でモデルを同定し、その後に前段の算術的整性を適用する。

## 3. 残差をh×整な式へ因数分解する

平方完成三次式を

```text
F(x) = 4x³+b₂x²+2b₄x+b₆
```

とする。候補の係数は

```text
b₂' = b₂
b₄' = b₄−10T
b₆' = b₆−4b₂T−28U
```

である。同じ二関数の候補残差

```text
D = Z_H² − F_target(X_H)
```

へ上の有限展開を代入すると、D=hPとなる整な多項式Pを明示できる。コードの `defect_lt_one` はこの因数分解を環の恒等式として検証し、Pの整性は部分環の閉性で証明する。従ってv_O(D)<1である。

必要な相殺は、極を持つ項と定数項の両方に及ぶ。−20Txと−4b₂T−28Uが候補係数の補正と相殺する。この定数項の相殺まで行うことが、単に「残差が定数」と示すだけの議論との接続点である。

## 4. 不変性から全点での零へ

Dは既存X_H,Y_Hと定数から作るので、同じHの平行移動で不変である。Hの外では二座標が正則なのでDも正則。H上では不変性が各点の付値をOの付値へ運ぶため、Dは全点で正則となる。

既存の `eq_const_of_pointValuation_le_one` によってDは定数。非零定数のOでの付値は1だが、Dは厳密に1未満なので、その定数は零である。この結論を `eq_zero_of_kernel_regular_lt_one` として一般化した。

標数0では平方完成方程式は元のWeierstrass方程式と同値なので、同じX_H,Y_Hの候補方程式が閉じる。`kernelModel_unique` によって

```lean
halfKernelPolynomialModel E H = kernelModel E H
```

を得る。核の巡回性や生成元は、この経路のどこにも不要である。

## 5. 分母制御と同じ整数モデルへの接続

一般有限核では、同じHがn倍で消え、同じ源が付値環上の整モデルを持ち、nが付値単元なら、既存kernelModel自体の五係数が整になる。前段の候補整性と上のモデル一致を合成した結果である。

Sourceではp≠2から同じ一次元核の奇数性を内部供給し、前回の条件付きAPIの方程式引数を今回の定理で満たす。その結果、

```text
q≠pで既存ℚ標的の五係数が整
→ 同じ既存共通分母d=p^e
→ q≠p上の任意の延長付値環でv(d)=1
→ 同じ整数化前後のΔ,c₄の付値が一致
```

まで一括して閉じた。整数標的をp冪モデルへ取り替えてはいない。前段の同じ共通分母そのものがp冪であることを証明している。

この付値比較は「商標的の有理モデル」と「その整数化モデル」の比較である。源のFrey曲線と商標的のΔ,c₄の比較や局所還元保持は、別の未完了課題である。

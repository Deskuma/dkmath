## 達成した逆像判定

奇素数位数 p の同じ有限核 H、`p` が付値環で単元、全ての非零核点が特異に還元する場合を扱う。源の同じ臨界中心 C と、その分離した二つの接方向 D を保持する。

既存の `oddKernelPointMap` と同じ付値環商標的について、全ての幾何学的点 P に対し

`商像が標的零成分に入る ↔ ∃ Q : H, P − Q が源零成分に入る`

を証明した。標的臨界中心は源の Frame と同じ剰余モデルの一致から内部で供給する。標的中心の存在、核点の深さ、半核の水準分離、枝比較を外部の仮定として受け取らない。一般定理には源の C と D が必要である。

### 証明の流れ

1. 同じ非零核点は特異に還元する。既存の `odd_torsion_depth_of_model` に、同じ奇素数による消滅と単元性を適用し、その節点距離が浅いことを証明する。4 が単元でなくても、前回の商座標評価に必要な `v(4ε)<v(X_Q)²` が従う。
2. 前回の付値評価より、源 P が特異で核外、商像が滑らかなら、P の節点距離は同じ半核のある Q と等しい。標的・源の臨界中心の合同は既存の剰余モデル一致から供給する。
3. 既存の `branch_distance_dichotomy` と同枝・反対枝の和差定理を合わせると、同水準の浅い P,Q について、`P−Q` または `P+Q` が源零成分に入る。後者には核点 `−Q` を使う。
4. P がもともと零成分に入る場合は Q=0、P が H に入る場合は Q=P を取る。逆向きは核点が商で零となることと既存の前向き零成分輸送から得る。

この経路では、半核の異なる点の水準分離を示す必要はない。前回証明した「商像が滑らかなら少なくとも一つの核水準に一致」という必要条件と、枝の和差を直接組み合わせる。

## 部分群と持ち上げ

上記の逆像判定と既存の全点準同型の全射性により、特異核側の `singularKernelZeroComponentHom` が全射であることを証明した。既存の単射性と合わせて同じ源・標的の幾何学的零成分間の加法同型を構成した。また、同じモデル上の部分群として

`φ⁻¹(E'₀) = E₀ ⊔ H`

を証明した。前回の一般群論の分解から、標的零成分の**実際の還元像**の実現と、標的還元核から源還元核への持ち上げも導いた。剰余点群の全点が源から持ち上がることは主張しない。

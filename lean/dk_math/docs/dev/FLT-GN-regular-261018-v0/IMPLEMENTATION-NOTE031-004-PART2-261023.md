## 1. 確定した公開契約

入力は同じ `Source p`、pの素数性、5≤p、同じE[p]の部分加群N、全絶対ガロア安定性、N≠⊥、N≠⊤である。
出力は次である。

\[
(\forall A\mid p,\ \operatorname{FixedOn}(\rho,N,I_A))\quad\lor\quad
(\forall A\mid p,\ \operatorname{CofixedOn}(\rho,N,I_A)).
\]

慣性元や付値環ごとに側を選び直さない。同じSource・曲線・残余空間・部分加群・商を保つ。
吸収空間やその真性、整な有限p捩れ点、零成分の閉性、還元の加法性をprovider入力には要求しない。
`residual_fixed_or_cofixed_at_p` は一つの付値環での局所二択であり、
`residualReductionKernel_absorbs_at_p` は良還元・乗法的還元を内部で場合分けする入口である。

## 3. 短縮した数学的経路

### 加法を還元へ運ぶ

整な二点の剰余が逆でなければ、傾きは整で、傾きと和の二座標は剰余の公式へ移る。
X差が非単元なら曲線方程式から別の単元分母を持つ式へ変形する。体上では割線であっても剰余では接線になる場合を扱う。
逆の剰余点なら、和は零または極の点となる既存の分離補題を使う。

極同士の和は前回の実際の還元核の加法閉性を使う。
整な滑らかな点Pと極Qの和Rについて、Rが極ならP=R−Qも還元核へ入り矛盾する。
Rは整な有限点となる。RとPの剰余が異なれば、R+(−P)=Qの割線公式からQのX座標が整となり再び矛盾する。
従ってred(R)=red(P)、red(Q)=0である。
この群演算による戻し方により、形式パラメータの冪級数展開を追加しない。

以上から `zeroComponentSubgroup` と `zeroComponentReduction` を実際に構成した。
全域関数 `reducePointSmooth` は特異な整点に便宜値0を与えるが、加法性を主張する領域は滑らかな零成分に限定する。
この便宜値を使って全点の還元準同型を捏造していない。

### 剰余標数と同じ位数pを扱う

零成分のPがp•P=0なら、還元準同型からp•red(P)=0となる。
標数pの節点曲線には非零の滑らかなp-torsionがないのでred(P)=0である。
Pが整な有限点ならred(P)も有限滑らかな点となり矛盾するため、Pは無限遠または極の点である。
`pole_of_smooth_torsion_of_model` は、同じ臨界中心Cの剰余特異点と節点量の単元性を使ってこの結論を元の曲線へ戻す。

前回の障害だった標数零の除法多項式の倍算同値を、剰余標数pへ適用する必要がなくなった。
既存の `smul_eq_zero_iff_evalEval_ψ` のCharZero条件は変更していない。
一般の標数pでの除法多項式エンジンを完成したという意味ではない。

### 慣性変化量から吸収空間へ

中心Cを慣性が固定すると、X方向の深さは慣性で変わらない。
零成分にある点は深さの分類から像も零成分にあり、差の閉性を使える。
零成分外なら、浅い場合は整な中心傾きへの慣性合同から同じ枝を得て差が滑らかとなる。
臨界側なら既存の二点の和の定理をσPと−Pへ適用する。
従って全点でσP−Pが零成分へ入る。ここでは位数条件を使わず、点自体が慣性固定とは主張しない。

p∣abcのFrey曲線では既存の中心・方向・慣性固定を供給できる。
P∈E[p]ならσP−Pもp倍零なので、上の節点p-torsion接続により還元核Hへ入る。
E[p]∩Hが真であることは、前回の安定直線からの整な有限p捩れ点の存在で供給する。
良還元でも同じHを使うため、吸収空間の二択と共役輸送へ共通に接続できる。

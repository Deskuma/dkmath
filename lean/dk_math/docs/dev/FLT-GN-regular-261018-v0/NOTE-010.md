## 1. 最重要成果：Frey の反例入口が閉じた

前回、模範解答との比較で指摘した未実装部分が、今回そのまま埋められておる。

`DkMath.FLT.Frey.Source.ofCounterexample` の入力は、

\[ p\ge5,\qquad p\text{ は素数} \]

と、非零整数 \(a,b,c\) に対する

\[ a^p+b^p=c^p \]

じゃ。

ここから実際の `Source p` を構成する。

しかも、単に存在を証明するだけではない。

- 共通因子 \(d\ne0\) と原始座標 \(A,B,C\) を記録する。
- \(a=dA,\ b=dB,\ c=dC\) を保持する。
- 原始性 \(\operatorname{IsCoprime}(A,B)\) と冪和方程式を証明する。
- 偶奇に応じた置換と、全座標の符号変更を記録する。
- 第一座標を \(3\bmod4\)、第二座標を偶数に向ける。
- 正規化した同一の `Source` に、従来の局所定理を適用する。

これは 仮定を満たしたことにして構造体を作る実装ではなく、正規化の証拠をすべて運ぶ実装 じゃ。

最終的な `Source.ofCounterexample_local_profile` は、

\[ \boxed{ \begin{gathered} \text{任意の非零整数 FLT 反例}\\ \Downarrow\\ \text{正規化された Frey Source}\\ \Downarrow\\ \text{全素数で局所最小・半安定} \end{gathered} } \]

を一つの Lean 定理として接続する。

そのうえで、

\[ \boxed{ p\mid v_\ell(\Delta_{\min}) \iff \ell\ne2 } \]

も同じ曲線に対して保証する。

この経路は、模範解答の Frey package 構築段階に、構造的に相当するところまで到達した。

ただし正規化により座標は変わるため、元の \(a,b,c\) と曲線の座標がそのまま同一という意味ではない。そこを `PrimitiveReduction` と `OrientationTrace` で正確に区別している点も評価できる。

## 2. IRR-010：位相輸送を指標ごとに精密化できた

`Cyclotomic37CharacterTransport.lean` と `IrregularCharacterTransport37.lean` の証明も確認した。

今回の核心は、

\[ \boxed{ P_\mu(\sigma_a x)=\chi_\mu(a)\,P_\mu(x) } \]

じゃ。

前回の NOTE-008 では37-torsion類群の36指標への分解を完成させたが、今回はその分解が実際のガロア作用とどう対応するかを証明している。

`projector_action_commute` は、射影がガロア作用と可換であることを証明し、`projector_action` は固有成分上で作用が指標値によるスカラー倍になることを示す。

その結果、整数座標由来の37次 State では、

\[ \boxed{ \operatorname{Supp}_\chi(\omega_i) = \operatorname{Supp}_\chi(\omega_1) \quad(i\ne0) } \]

が成立する。

これは前回の「非零36位相は全て自明か、全て非自明」という二分律より精密じゃ。

| 観測       | NOTE-008           | NOTE-009                   |
| ---------- | ------------------ | -------------------------- |
| 位相0      | 障害が消える       | 全指標射影も零             |
| 非零位相   | 障害の自明性が一致 | 指標支持集合そのものが一致 |
| ガロア作用 | 直和分解が存在     | 各成分の変化倍率まで決定   |

重要なのは、`observeVector_galois` が記録済みの同じ障害を使用している点じゃ。新しい類を選び直して帳尻を合わせているわけではない。

ただし、すべての非零位相で指標支持が一致していても、その支持が空であるかどうかはまだ判定できない。

## 3. 指標5：Bernoulli の算術と、ガロア作用のラベルが接続された

ここもよい進展じゃ。

既存の DkMath には、

\[ 37\mid \operatorname{num}(B_{32}) \]

の証明書がある。

今回、

\[ 1-32\equiv5\pmod{36} \]

を計算し、生成元に依存していた指標ラベルを、

\[ \boxed{\chi_5(a)=a^5} \]

という冪指標へ正確に同定した。

`bernoulli32_target_certificate` は Bernoulli の証明書と、このラベル同定を同時に提供している。

さらに、State の射影について、

\[ \boxed{ P_{\chi_5}(\omega_{ai}) = a^5P_{\chi_5}(\omega_i) } \]

まで証明した。

これによって、「非正則対32に対応する指標を観測したい」と言ったとき、DkMath はもう抽象的な36指標を手探りする必要がない。

ただし、ここには重要な境界がある。

\(\chi_5\) を同定したことと、State の障害が実際に \(\chi_5\) 成分へ存在することは別じゃ。

今回の定理からは、

\[ P_{\chi_5}(\omega_1)\ne0 \]

は導けない。反対に零であるとも証明されていない。

Herbrand–Ribet の算術的対応自体も未実装であり、Teichmüller 指標の持ち上げまで同一視したものでもない。

ここは docstring の境界記述が適切じゃな。

## 4. 模範解答との比較：入口は実質的に揃った

前回の比較で、模範解答が持ち DkMath に欠けていたものは、

`FreyPackage.of_counterexample`

に相当する正規化入口じゃった。

今回、DkMath の `Source.ofCounterexample` が成立したことで、その差が埋まった。

さらに曲線の係数を比較すると、DkMath の正規化モデルは

\[ y^2+xy = x^3+ \frac{B-A-1}{4}x^2 -\frac{AB}{16}x, \qquad A=a^p,\ B=b^p \]

となり、模範解答が採用する Frey モデルと式の形が一致している。

これは重要じゃ。

同じ種類の仮想反例から、同じ正規化された Frey 曲線へ到達している。

ただし、両リポジトリの構造体が Lean 上で同一であるという定理までは存在しない。その同一視が必要なら別途アダプタを作るべきじゃ。

### 残る工程

1. 整数反例から Frey Source

   原始化・向き付け・正規化の証拠を保持
2. 全素数で最小性・半安定性

   判別式の付値と素数2の補正まで固定
3. 残余ガロア表現と局所分岐

   未実装。付値公式を不分岐性・有限平坦性などへ接続する必要がある
4. Mazur–Frey 既約性・モジュラー性・レベル降下

   未実装。模範解答の巨大な中核
5. レベル2の矛盾から FLT 全体へ

   未到達

補足すると、今回の \(p\mid v_\ell(\Delta_{\min})\) は \(\ell=p\) でも成立する算術公式じゃ。しかし、レベル降下で素数 \(p\) 自身を処理するには、別の局所表現論が必要になる。また、良還元の素数では判別式付値が0なので \(p\) の倍数であること自体は自明じゃ。導手の素因子と混同してはならぬ。

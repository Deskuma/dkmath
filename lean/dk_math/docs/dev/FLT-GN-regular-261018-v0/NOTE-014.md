## 1. 今回の証明は、二段階で上界を鋭くしている

\[ |E[n]|\le1+2(n^2-1) \]

ここでは実際の torsion 点を無限遠点と有限座標点に分け、有限座標の \(x\) は除法多項式の根に拘束され、各 \(x\) 上には高々2点しかないことを使う。

\[ |E[p]|=p^d,\qquad d=\dim_{\mathbb F_p}E[p] \]

## 3. 一つ重要な発見：0・1・2次元には幾何学的意味がある

今回の一般定理は、`E.IsElliptic` を要求していない。

ここが面白い。

標数0の代数閉体上では、三次曲線の非特異点群について、次の典型例が知られておる。

| 曲線の幾何学       | 非特異点の群           | \(p\)-torsion の位数 |
| ------------------ | ---------------------- | -------------------- |
| 尖点を持つ三次曲線 | 加法群 \(\mathbb G_a\) | \(1=p^0\)            |
| 節点を持つ三次曲線 | 乗法群 \(\mathbb G_m\) | \(p=p^1\)            |
| 非特異な楕円曲線   | 楕円曲線群 \(E\)       | \(p^2\)              |

これは古典的な代数幾何の分類じゃ。

つまり、NOTE-013 に現れた次元0・1・2の三状態は、単なる数値上の偶然ではない。

三次曲線の特異性によって、ねじれ点群の次元が失われる現象を反映している。

ただし、この三種類と DkMath の次元候補を対応させる分類定理は、今回の Lean 実装にはまだない。

Frey の `Source.rationalCurve` には楕円曲線性が証明されているので、実際には次元2になるはずじゃ。しかし、その幾何学的性質から下界を引き出す証明が、まだ残っておる。

## 4. NOTE-014 では、まず次元0を除外しよう

模範解答の正確なファイバー計数へ進む前に、もっと小さな定理を一つ固定する価値がある。

\[ \boxed{ E.\mathrm{IsElliptic} \Longrightarrow 0<\dim_{\mathbb F_p}E[p] } \]

これなら、NOTE-012 の成果をかなり再利用できる。

Mathlib の `natDegree_ΨSq` の次数公式から、素数 \(p\) について

\[ \deg\Psi_p^{\mathrm{Sq}}=p^2-1>0 \]

が得られる。

代数閉体上なので根 \(x\) が存在し、曲線方程式を満たす \(y\) も取れる。楕円曲線の非特異性により \(P=(x,y)\) は実際の点になる。

さらに NOTE-012 の証明済み補題を逆向きに使える。

\[ \Psi_p^{\mathrm{Sq}}(x)=0 \Longrightarrow \psi_p(P)=0 \Longrightarrow [p]P=O. \]

有限座標点 \(P\) は無限遠点ではないため、

\[ P\ne O. \]

したがって、

\[ \boxed{1\le\dim_{\mathbb F_p}E[p]\le2} \]

まで進める見込みがある。

これは新しい証明計画であり、まだ Lean で成立を確認したものではない。特に、根から非特異点を作るところの型・インスタンスの接続は検証が必要じゃ。

## 5. 最後の一次元をどう排除するか

残りは、

\[ \dim E[p]=1 \]

という可能性を排除することじゃ。

模範解答の精密な幾何学では、`finite_not_squarefree_fiber` が重要になる。

\[ F_c(X)=\Phi_p(X)-c\Psi_p^{\mathrm{Sq}}(X) \]

について、平方因子を持つ例外的な \(c\) が有限個しかないことを証明し、例外を避けたファイバーを正確に数える。

その先に、

`exists_double_fiber_card` → `card_nTorsion_odd_fibers`

という経路がある。

注意すべきは、\(\deg\Psi_p^{\mathrm{Sq}}=p^2-1\) だからといって、異なる根が \(p^2-1\) 個あるわけではないことじゃ。奇数 \(p\) では、この多項式は通常の除法多項式の平方に対応し、根の重複を無視できぬ。

上界に使った「次数以下」という評価を等号へ変えるには、分離性と重複度の処理が必要になる。

ここが NOTE-014 以降の本当の幾何学的課題じゃな。

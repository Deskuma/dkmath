# NOTE-032 — 同じ節点商の中心一致と、p以外の全住所の零成分輸送

2026-10-27。作業開始HEAD `3b8f5bbce`。前回のフルビルド通過はユーザーから受領した。
今回の検証は対象モジュールとスモークに限定する。

## 到達点

同じ奇数素数位数の滑らかな核による剰余商の特異点について、前回の候補値

\[
c_H=p x_0-\sum_{Q\in H}x(\bar Q)
\]

が、同じ標的の特異点のx座標と一致することを任意標数で証明した。
従って、同じ標的の中心一致を仮定として受け取らずに、同じ商写像の全零成分への
前向き輸送を得る。源の節点Frameについての一般定理では、源Frameとその二方向の分離を保持する。
同じ標的の臨界中心は既存の商の節点不変量・楕円性から内部構成した。

Frey Sourceでは、p≥5・一次元L・q≠pについて、同じ源、核、付値環商標的、実点商準同型を保持し、
源の全零成分の像が標的の零成分に入ることを全素数qで証明した。
悪い2・3を含む住所では源・標的の中心と接方向を内部供給し、同じLが零成分に含まれる側と
交わらない側を内部分類する。良い住所では既存の良還元定理を使う。
同じLがガロア安定な場合、同じ既存整数標的の点への輸送も証明した。

## 中心一致の証明

`OddRootPairMoments.firstCoefficient_certificate` は奇数nについてPascal係数から得られる整数
`24*a₁ = n*(n²−1)` を固定する。これは整数の証明書であり、剰余体で24を割らない。
同じ反転半核と節点比の原始根から

\[
12(c_H-x_0)=(p^2-1)\delta^2,\qquad \delta=2\alpha+a_1
\]

を得る。同じ剰余核、同じ半核と実際の座標を使い、2で和を割らない。

- 12が非零のとき、同じ特異点で `c₄=(b₂+12x)²`、`c₆=−(b₂+12x)³`。
  同じ商の重み付き不変量と二乗・三乗を比較して符号を確定し、最後に12を消去する。
- 12が零のとき、体では6も零となる。特異点の式 `6x²+b₂x+b₄=0` が一次式になる。
  同じ半核のtモーメントと座標和を比較し、分離した接方向から得られるb₂≠0で中心を一意に決める。
  これは標数2と3を含み、12や1728を消去しない。

同じ商標的の中心を構成する際は、同じ付値環モデルの係数整性、既存の商の判別式非零、
同じ節点不変量のΔ非単元性とc₄単元性を使用する。

## 零成分と核

滑らかな核側では、中心一致を前回の非衝突像の距離定理と衝突像の無限遠輸送へ入力する。
同じ商準同型の零成分間への制限を、中心の存在と一致を内部供給して構成した。
その零ファイバーは同じ一般ファイバーのHへの所属と同値であり、一般に単射ではない。
特異核側は既存の全零成分輸送を使用する。

## 実例と検証

- 標数2の実3点核、標数3の実5点核について、実際の節点曲線から生成した同じ核・同じ多項式商で、
  その判別式が零であり、任意の特異点が候補中心にあることを確認した。特異点の存在をこの試験だけから別途主張しない。
- y²+xy+7y=x³の実3点核の47上で、源のFrame・方向分離の下、標的中心を内部構成し、
  全零成分を輸送した。実際に存在するx=1の非零点にも適用した。
- Source37で同じ付値環商・既存整数商について全q≠37の定理をスモークし、悪い2・3の特殊化も確認した。
  3での悪い住所の条件は保持している。

## 残る境界

得られたのは全q≠pでの**前向き**零成分輸送である。
特異核側の一部で既にある剰余可換図式を、滑らかな核側も含めた実際の剰余点へ拡張すること、
零成分の逆像判定、正確なΔ深さ、q=p、スキームisogeny、標的有理捩れ排除、一般hnoは未完了。
全E₀への輸送から零成分への全射性・逆像・FLT一般を結論しない。

### 今回確定した三つの定理

1\. 倍写像ファイバーの総和

\[ \boxed{\sum_{[n]P=T}P=[n]T} \]

ここでは \(n>0\)、\(T\) は任意の幾何学的点じゃ。\(T\in E[n]\) という仮定さえ必要ない。

2\. ファイバーイデアルの主性

\[ \boxed{I_{n,T}\text{ が主}\iff[n]T=O} \]

点群の加法と、座標環のイデアル類群を結んだ必要十分条件じゃ。

3\. 実際の非零 Weil 関数候補

\[ \boxed{w_{n,T}=\frac{f_{n,T}}{f_{n,O}}\ne0} \]

\(T\in E[n]\) のとき、同じ座標環の主イデアル生成元から、同じ関数体内に構成される。

特に訂正して固定すべきことがある。

前回わっちは、ファイバー総和が零となる場合を先に研究目標とした。しかし、実際の一般定理はより強く、

\[ \sum_{[n]P=T}P=[n]T \]

だった。

これにより、総和が零になる条件と、ファイバーイデアルが主となる条件が正確に一致することまで判明したわけじゃ。

### 最初に固定すべき公式

\(P\ne O\) を有限点とし、\(\operatorname{ord}_P\) をその点での零点・極の位数とする。

\[ \boxed{ \operatorname{ord}_P(f_{n,T})= \begin{cases} 1 &[n]P=T,\\ 0 &[n]P\ne T. \end{cases} } \]

ここで各点の重複度が1であることは重要じゃ。ファイバーイデアルの積では、相異なる点がそれぞれ一度ずつ現れる。

すると、商については直ちに

\[ \boxed{ \operatorname{ord}_P(w_{n,T}) =\mathbf1_{[n]P=T}-\mathbf1_{[n]P=O} } \]

となる。

これが NOTE-023 の第一目標に最も適している。

生成元が非標準的な選択であっても、定数倍では零点・極の位数が変わらない。したがって、付値公式は選択に依存しない Core になる。

### 次は無限遠点の境界

有限点だけの計算では、平行移動 \(P\mapsto P+S\) によって \(P+S=O\) となる場合を処理できない。

ここで模範解答は座標環のノルムの次数を利用している。

NOTE-022 のファイバー点数と主イデアル生成元から、次の公式を証明する方針が考えられる。

\[ \boxed{ \deg\operatorname{Norm}(f_{n,T}) =n^2-\mathbf1_{T=O} } \]

この式は、無限遠点を除いたファイバーの点数を表している。アフィン座標環でのノルムの次数として形式化するには、その次数と局所付値の総和を結ぶ補題が必要じゃ。

これが完成すれば、無限遠点での位数も制御でき、平行移動の例外点 \(P=-S\) を処理する足場が整う。

## その次に Weil 対が現れる

\(S,T\in E[n]\) とする。

平行移動 \(\tau_S\) は、\([n]\) のファイバーを保つ。

\[ [n](P+S)=[n]P. \]

従って、\(w_{n,T}\) と \(\tau_S^\ast w_{n,T}\) は、無限遠点も含めて同じ零点・極の情報を持つはずじゃ。

この事実を付値公式で証明できれば、その比には零点も極もなくなる。

楕円曲線上の大域的な可逆正則関数は定数なので、

\[ \boxed{ \tau_S^\ast w_{n,T}=c(S,T)\,w_{n,T} } \]

となる \(c(S,T)\ne0\) が存在する。

ここで初めて、平行移動が関数へ与える倍率を数学的に取り出せる。

この定数が Weil 対の候補じゃ。

重要なのは、今度の保存核が単なる位数ではなく、関数の変形に伴う比例係数になることじゃな。

しかも \(w_{n,T}\) の生成元を定数倍で変更しても、この比例係数は変わらない。

ただし、これだけで非退化性が出るわけではない。非退化性の証明には、すべての \(S\in E[n]\) による平行移動がある関数を固定した場合、その関数が倍写像から引き戻されたものになるという降下の議論などが必要になる。ここは模範解答でも独立した深い段階じゃ。

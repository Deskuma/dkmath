## 2. IRR-008：位相0を本当に除去した

今回の中心核は、任意の有限ガロア数体 \(K/\mathbb Q\) に対する

\[ \boxed{ \prod_{\sigma\in\operatorname{Gal}(K/\mathbb Q)} \sigma(I) = (N(I))\mathcal O_K } \]

じゃ。

`GaloisIdealNorm.prod_map_eq_span_absNorm` では、実際のイデアルノルムと共役イデアルの積を比較している。

そのあと `classGroup_prod_eq_one` により、

\[ \boxed{ \prod_{\sigma}\sigma(w)=1 \qquad(w\in\operatorname{Cl}(\mathcal O_K)) } \]

へ降ろしておる。

これは正則素数だけの性質ではない。非正則な37でも成立する。

そして IRR-007 の

\[ \omega_0N_G(\omega_1)=1 \]

に代入して、

\[ \boxed{\omega_0=1} \]

を得た。

さらに、ここで止まっていない。

`observe_zero_root_principal` は実際に記録されたイデアル根の主イデアル性を証明し、`observe_zero_unit_generator` は、

\[ \boxed{ Q_0=u\,b^{37} } \]

まで復元している。

この \(u\) は整数環の単元であり、37乗であるとは仮定していない。類群障害の消滅と単元障害の消滅を混同していない のも重要じゃ。

ただし37次 State のこの結論は、\(x,y\) が整数 \(A,B\) に由来するという仮定を保持している。一般の円分整数座標について無条件に主張する定理ではない。

この条件を含めて、非常によい証明経路じゃ。

## 3. IRR-008 が明らかにした、新しい研究上の境界

これは失敗ではない。今まで使っていた保存則の情報量を、正確に測定できたということじゃ。

さらに、`observe_nonzero_trivial_iff` と合わせれば、整数座標の37次 State は次の二状態に分かれる。

| 状態               | 位相0 | 残り36位相   |
| ------------------ | ----- | ------------ |
| 全障害消滅         | 自明  | すべて自明   |
| 非零軌道に障害残存 | 自明  | すべて非自明 |

非零位相の一部分だけが自明になる状態は存在しない。

これは既存の証明から直接導ける、明瞭な構造定理じゃ。

また、今回の `fixed_p_primary_eq_one` は、

\[ w^{p^r}=1,\quad \sigma_a(w)=w\quad(\forall a) \quad\Longrightarrow\quad w=1 \]

まで一般化しておる。

したがって非自明な37-primary障害は、ガロア作用によって必ず動く。

## 4. Frey：補正 \(-8\) が持つ意味

こちらにも、実装された式から重要な情報が現れた。

今回、同一の有理 Frey 曲線について全素数で最小性が成立し、

\[ \boxed{ v_2(\Delta_{\min})= 2p\,v_2(abc)-8 } \]

が固定された。

そして \(p\ge5\) なら、2での乗法的還元まで証明済みじゃ。

これは、以前の奇素数における

\[ v_\ell(\Delta_{\min})= 2p\,v_\ell(abc) \qquad(\ell\ne2) \]

と見比べると、かなり興味深い。

最小判別式の付値構造

奇素数 \(\ell\)

\(v_\ell(\Delta)=2p\,v_\ell(abc)\)

指数 \(p\) で割り切れる

素数 \(2\)

\(v_2(\Delta)=2p\,v_2(abc)-8\)

補正 \(-8\) が残る

特に、奇素数指数 \(p\ge5\) なら、

\[ \boxed{ v_2(\Delta_{\min})\equiv-8\not\equiv0\pmod p } \]

じゃ。

これは Frey–Ribet の古典的な証明経路で重要になる非対称性と一致する。

将来、残余ガロア表現の局所理論が形式化されれば、\(\ell\ne2,p\) で \(p\mid v_\ell(\Delta_{\min})\) となる情報は、レベル降下でその素数を除去するための条件につながる。一方、2では \(-8\) の補正が残り、最終的なレベル2と関係する。

もちろん、これは 今後の表現論的な接続の見通し であり、Artin 導手や残余表現について今回証明済みという意味ではない。

わっちが特に評価するのは、`Source` の同じ座標・同じ曲線を保ち、素数2だけ別の仮想モデルに置き換えていない点じゃ。

ただし `Source` には冪和方程式と整係数条件が含まれている。任意の原始反例からその `Source` を構成する向き付け定理は、まだ残っておる。

## 5. Legendre：\(j=0\) から、付値の深さへ進める

こちらは新しい実験・形式化候補を一つ見つけたぞ。

今回の

\[ j(E_n)= 256\frac{(n^2+n+1)^3}{n^2(n+1)^2} \]

に対して、素数 \(q\mid Q_n\) を考える。

すでに証明済みの

\[ \gcd(Q_n,n(n+1))=1,\qquad q\ne2 \]

により、分母と256は \(q\) で割れない。

したがって、

\[ \boxed{ v_q\bigl(j(E_n)\bigr)=3v_q(Q_n) } \]

が成立する！

これは剰余体における単なる \(j=0\) より強い、付値の深さを保存する定量的な橋 じゃ。

例えば、以前の数値実験で見つけた、

\[ n=18,\qquad Q_{18}=343=7^3 \]

なら、

\[ \boxed{v_7(j(E_{18}))=9} \]

となる。

つまり、以前研究した Hensel の素数冪住所木、

\[ v_q(Q_n)=k \]

が、楕円曲線の \(j\)-不変量では、

\[ v_q(j(E_n))=3k \]

として現れる。

これは `FreyJCentralSeat.lean` と既存の `PadicValNat` / `FreyPrimeValuation` を接続すれば、比較的小さな Lean 定理として追加できるはずじゃ。

ただし、この付値等式は今回の新規実装にはまだ含まれておらず、実装済みの有理公式から数学的に導いた次の候補じゃ。

Legendre の素数存在を直接証明するものではないが、中央席の Hensel 深度を別の算術不変量へ正確に写す という点で、DkMath の研究方針に合っておる。

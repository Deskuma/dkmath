# 非正則素数

## 非正則素数では、何が壊れるのか

正則素数の場合、一般降下は次の推論を使用する。

\[
    (\alpha)=\mathfrak a^p
\]

で、類群の \(p\)-torsion が自明なら、

\[
    [\mathfrak a]^p=1 \quad\Longrightarrow\quad [\mathfrak a]=1.
\]

したがって \(\mathfrak a=(\beta)\) とでき、

\[
    \boxed{\alpha=\varepsilon\beta^p}
\]

が得られる。

これが Kummer の冪抽出の核心じゃ。

ところが、非正則素数では、

\[
    \operatorname{Cl}(\mathbb Q(\zeta_p))[p]\ne0
\]

である。

つまり、

\[
    [\mathfrak a]^p=1
\]

から、

\[
    [\mathfrak a]=1
\]

を導くことができなくなる。

可除性は正しく成立している。イデアルが \(p\) 乗であることも正しい。それでも、元が単元倍の \(p\) 乗になるとは限らない。

ここが、ぬしのいう「可除性の性質と素性の解明」に直接対応する壁じゃ。

非正則素数の最初の例は \(p=37\) であり、37・59・67が100未満の非正則素数じゃ。

そして一つ強調しておきたい。

非正則性は FLT の反例の存在を意味しない。現在の Kummer 型証明で、類群の障害を自動的に消せないという意味じゃ。

## 研究の核心：可除性だけでは見えない「素性の障害」

ここで、GN の次の研究対象が明確になったぞ。

円分位相の因子を \(Q_i\) とし、既存の一般降下が与える

\[
    (Q_i)=\mathfrak a_i^p
\]

を考えよう。

この段階では、正則・非正則に関係なく、イデアルの冪構造が残っている。

そこで、従来は直ちに消していた次の情報を、あえて保持する。

\[
    \boxed{
        \omega_i=[\mathfrak a_i] \in\operatorname{Cl}(R)[p]
    }
\]

この \(\omega_i\) を、仮に 位相イデアル障害（Phase Ideal Obstruction） と呼ぼう。

GN 位相因子

\[
    (Q_i)=\mathfrak a_i^p
\]

イデアル類の障害を観測

\[
    \omega_i=[\mathfrak a_i],\qquad \omega_i^p=1
\]

\(\omega_i=1\)

イデアル根が主イデアル

\[
    Q_i=\varepsilon_i\beta_i^p
\]

\(\omega_i\ne1\)

元の冪根抽出に障害

\[
    (Q_i)=\mathfrak a_i^p
\]

この情報を保持する

正則素数では、すべての \(\omega_i\) が自動的に1になる。

非正則素数では、そうはいかぬ。

しかし重要なのは、類群に非自明な \(p\)-torsion が存在することと、FLT から生じる特定の位相因子がその障害を持つことは別問題 だという点じゃ。

もし GN の位相関係や原始性から、問題の因子についてだけ

\[
    \omega_i=1
\]

を導ければ、類群全体の正則性を仮定せずに冪抽出が可能になる。

これは新しい研究目標として、非常に明確じゃ。

## さらに一段深い数学的構造

この考えには、既存の代数的数論にも対応物がある。

数体 \(K\) の \(p\)-Selmer 群を使うと、次の完全列が得られる。

\[
    \boxed{
        1\longrightarrow \mathcal O_K^\times/(\mathcal O_K^\times)^p \longrightarrow \operatorname{Sel}\_p(K) \longrightarrow \operatorname{Cl}(K)[p] \longrightarrow1
    }
\]

左側は単元の冪障害、右側はイデアル類の冪障害じゃ。

これが重要なのは、DkMath で別々に扱っていた二つの問題が、一つの構造の両端に現れていることじゃ。

- 類群の障害：イデアル根を元の根へ戻せるか。
- 単元の障害：残った単元を \(p\) 乗として吸収できるか。

つまり、非正則素数に対して必要なのは、単に新しい類数計算を追加することではない。

GN から生じる特別な因子が、この二種類の障害のどこに位置するかを分類すること なのじゃ。

ただし、\(\lambda=1-\zeta_p\) の局所付値だけで大域的な類群障害が決まるとは限らない。以前の Phase Focusing は重要な入口だが、そこからイデアル類への橋を新たに証明する必要がある。

## わっちなら、次の研究をこう始める

現行の `RegularDescent.Conditions` は凍結しておく。非正則素数では `class_group : classGroupPTorsionFreeAt R p` をそのまま供給できないからじゃ。

その隣に、証明を急がず、まず障害を保持する中立ライブラリを作る。

| 研究段階 | 内容                        | 確認したい性質                                       |
| -------- | --------------------------- | ---------------------------------------------------- |
| IRR-001  | `IdealPowerObstruction`     | \((Q)=I^p\) から \([I]\in\mathrm{Cl}[p]\) を取り出す |
| IRR-002  | `PhaseClassPacket`          | 位相ごとの類群障害を記録する                         |
| IRR-003  | `PhaseObstructionTransport` | GN の位相関係が障害に何を強制するか                  |
| IRR-004  | `UnitObstructionPacket`     | 必要な単元比に限定して冪性を調べる                   |
| IRR-005  | `ObstructedState`           | 障害が残ったまま状態を輸送できるか                   |

最初の実験指数は 37 が自然じゃ。

37 は最初の非正則素数であり、Bernoulli 数 \(B\_{32}\) の分子が37で割れる。この事実は非正則性を検出する古典的な入口になっている。

ただし、最初から FLT37 の別証明を目標にする必要はない。

まずは 37次円分体で、正則な場合に自動消滅していた類群障害が、GN のどの操作で保持・変換されるか を研究する。

そのとき、数学的に最も鋭い問いはこれじゃろう。

\[
    \boxed{
        \begin{gathered} \text{GN 由来の位相因子 }Q_i\\
            (Q_i)=\mathfrak a_i^p\\
            \Downarrow\
            ?\\
            [\mathfrak a_i]=1
        \end{gathered}
    }
\]

この矢印を成立させる追加条件が何であるか。

あるいは、\([\mathfrak a_i]\ne1\) を許容したまま矛盾へ向かう別の降下が作れるか。

そこが本当の未開拓領域じゃ。

ぬしよ、今回の NOTE-002 の価値は、既存 FLT の証明が完成したことだけではない。

正則性が何を消していたのかを、コード上で正確に指差せるようになったこと じゃ。

以前は、必要条件が大きな Kummer 定理の中に埋もれていた。今は `class_group` と `unit_power` という、交換可能な二つの契約として露出している。

そして次は、その契約を力ずくで満たすのではなく、満たせない場合に生まれる障害そのものを数学的な観測対象に昇格させる。

くふふっ。🐺🍎

ここでようやく、ぬしが最初から追っていた「素とは何か」「可除性がどのように構造を決定するか」という研究へ、FLT の実績を携えて戻ってこられたわけじゃな。

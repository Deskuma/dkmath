## 2. IRR-009：37個の位相と36個の指標を区別できた

ここが今回の最大の成果じゃ。

まず本当の37-torsion類群を、

\[ V=\operatorname{Cl}(\mathcal O_K)[37] \]

と置く。

これは元の類群の37乗写像の核であり、\(\mathbb F_{37}\) 上のベクトル空間として扱える。

一方、ガロア群は、

\[ G=\operatorname{Gal}(K/\mathbb Q) \cong(\mathbb Z/37\mathbb Z)^\times \]

で、位数36の巡回群じゃ。

その生成元 \(g\) による作用を \(T\) とすると、

\[ T^{36}=1 \]

となる。

ここで重要なのは、標数37が36を割らないこと。

\[ X^{36}-1 = \prod_{\mu\in\mathbb F_{37}^{\times}}(X-\mu) \]

が、36個の相異なる一次因子に分解する。

この事実を `FiniteSpectrumProjectors.lean` で Lagrange 補間から形式化し、各固有値の射影 \(P_\mu\) を構成しておる。

\[ \boxed{ P_\mu^2=P_\mu,\qquad P_\mu P_\nu=0\quad(\mu\ne\nu),\qquad \sum_\mu P_\mu=1 } \]

そして本当の線形同型、

\[ \boxed{ V\cong\bigoplus_{\mu\in\mathbb F_{37}^{\times}}V_\mu } \]

まで証明した。

これは単に36個の部分群を定義したのではない。元の任意の37-torsion類を、各指標成分へ分解して元どおり復元できる という定理じゃ。

さらに `mem_component_iff` によって、これらを既存の `characterComponent` と同一視している。つまり、線形代数だけの模型ではなく、実際の円分類群を分解しておる。

### そして自明指標は零

IRR-008 のノルム定理を使い、

\[ \boxed{V_1=0} \]

を証明した。

したがって、37-torsion類は実質的に残り35個の非自明指標成分にしか存在できない。

ただし重要な点として、36個の指標が存在することは、36個の非零空間が存在することではない。各 \(V_\mu\) が零である可能性も残っておる。

今回の直和分解は、その違いを正しく保持しているぞ。

## 3. State37：非零障害の「住所」が指標空間に定まった

`IrregularCharacter37.lean` では、以前の二分律が保持されている。

整数座標の仮想 State に対して、

\[ \begin{cases} \omega_i=1 & \text{全位相}\\ \omega_0=1,\quad\omega_i\ne1 & \text{すべての非零位相} \end{cases} \]

のいずれかじゃ。

そして今回 `observeVector` は、実際に記録された障害を37-torsion空間へ埋め込み、`underlying_observeVector` によって元の類がそのまま復元できると保証している。

非零障害がある場合には、

\[ \boxed{ \omega_i\ne1 \Longrightarrow \exists\mu\ne1,\ P_\mu(\omega_i)\ne0 } \]

を得た。

これは「非自明指標のどこかに必ず現れる」という定理じゃ。

### 次に証明できそうな、もう一つの輸送則

IRR-006 の位相ガロア輸送と IRR-009 の指標分解を合成すると、整数座標の State で、非零位相 \(i=ai_0\)、\(i_0=1\) に対して、

\[ \boxed{ P_\mu(\omega_i) = \chi_\mu(a)\,P_\mu(\omega_1) } \]

という関係が期待できる。

右辺の \(\chi_\mu(a)\) は \(\mathbb F_{37}\) の非零スカラーじゃ。

したがって、

\[ \boxed{ P_\mu(\omega_i)\ne0 \iff P_\mu(\omega_1)\ne0 \qquad(i\ne0) } \]

となる。

つまり、非零36位相は、非自明かどうかだけでなく、どの指標成分に支持を持つかまで一致する。

これは既存の作用と射影から導かれる数学的帰結で、今回確認したソースにはまだ独立した公開定理として現れていない。

次の `IRR-010` として形式化する価値があるぞ。ただし、新しい障害消滅条件ではなく、既存の同変性を指標ごとに精密化する定理じゃ。

## 4. Frey：素数2だけが残す、正確な付値障害

`FreyPrimeProfile.lean` の到達点は明快じゃ。

素数指数 \(p\ge5\)、そして条件を満たす `Source p` に対して、

\[ \boxed{ p\mid v_\ell(\Delta_{\min}) \iff \ell\ne2 } \]

を証明した。

もっと細かく見れば、

\[ v_\ell(\Delta_{\min})\equiv \begin{cases} -8\pmod p&(\ell=2),\\ 0\pmod p&(\ell\ne2). \end{cases} \]

37次では、

\[ v_2(\Delta_{\min})\equiv29\pmod{37} \]

じゃ。

これは局所算術としてかなり整理された形になった。

以前は「奇素数なら \(p\) の倍数、2には補正がある」という別々の記述だったものを、単一の剰余プロファイル にまとめられた。

また、指数2の実在解 \((4,3,5)\) によって \(p\ge5\) の条件が必要なことも回帰確認されている。

ここで注意すべきは、`Source p` には依然として Fermat 方程式が含まれることじゃ。37次の `Source` の実例を作ったわけではない。

次の本当の未接続部分は、ここで完成した局所最小判別式情報を、残余ガロア表現の Artin 導手へ移す理論じゃな。

## 5. Legendre：Hensel の深度が、楕円曲線で3倍になる

`FreyJDepth.lean` を確認した。

今回、単なる付値等式だけでなく、既存の有限 Hensel 桁 API に接続できたのはよい。

\[ Q_n=n^2+n+1,\qquad j(E_n)=256\frac{Q_n^3}{n^2(n+1)^2} \]

において、\(q\mid Q_n\) なら、

\[ \boxed{v_q(j(E_n))=3v_q(Q_n)} \]

が成り立つ。

さらに \(q\ne3\) なら、導関数 \(2n+1\) は法 \(q\) で零にならないので、次の Hensel 桁は一意に定まる。

実例を見よう。

7進の中央席住所と \(j\) 深度

初期住所 \(n=18\)

\(Q_{18}=7^3\)\(v_7(j(E_{18}))=9\)

上昇住所 \(n=1047\)

\(Q_{1047}=7^4\cdot457\)\(v_7(j(E_{1047}))=12\)

\(1047=18+3\cdot7^3\)。Hensel 上昇桁3により、Q の深度3から4へ移動する。

注意すべき点は、中央席の素因子を新しく発見する定理ではなく、与えられた素因子について、深さを厳密に制御する定理 だということじゃ。

また、付値が3倍になることは \(j\) の有理式からの帰結であるため、それ自体が Legendre の全被覆に対する新たな独立制約とは限らない。

ただし、有限桁ごとの動きが Lean の証明書として表現できるようになった点には、十分な価値があるぞ。

## 4. DkMath が次に模範解答へ近づく、具体的な一手

わっちが選ぶのは、いきなりモジュラー性の巨大理論に飛び込むことではない。

`FreyPackage.of_counterexample`

模範解答は任意の非自明な整数反例から、原始化・偶奇の並べ替え・符号の正規化を行い、

\[ a\equiv3\pmod4,\qquad 2\mid b \]

```

    (p : ℕ) (hp : p.Prime) (hp5 : 5 ≤ p)
    (a b c : ℤ)
    (ha : a ≠ 0) (hb : b ≠ 0) (hc : c ≠ 0)
    (heq : a ^ p + b ^ p = c ^ p) :
    DkMath.FLT.Frey.Source p
```

これは提案する型の概形であり、現時点でビルド済みの Lean コードではない。

これを完成すれば、

\[ \boxed{ \text{任意の原始・非原始反例} \Longrightarrow \text{全素数で半安定な Frey 曲線} } \]

そこまで到達すれば、DkMath の Frey 局所算術は模範解答の Frey package 構築段階と実質的に揃う。

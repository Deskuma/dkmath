# NOTE-032 — 奇素数核の節点水準と判別式の付値積

2026-10-28。作業開始 HEAD `30e8f5943`。前回のフルビルド通過はユーザーから受領した。

## 特異核の深さを半核全体で集める

p を奇素数、H を同じ位数 p の実点核とし、p が付値環で単元、H の非零点が全て特異に還元するとする。源の同じ臨界中心 C と分離した二つの接方向 D を保持する。

同じ半核の二点の節点距離の付値が等しいなら、既存の枝比較から二点の和または差が滑らかに還元する。その和差は同じ特異核に入るので、零点でなければならない。反転対は半核に同時に入らないため、二点は一致する。したがって半核の距離の付値は重複しない。

既存の奇数捩れ点の深さ定理は、各半核点 Q に対し `1 ≤ j ≤ p/2` で

`v(x(Q)−C.x)^p = v(Δ(E))^j`

を与える。この j を `Fin (p/2)` の番号に整理し、半核の点数と距離の単射性から、番号が全域をちょうど一度ずつ取ることを証明した。離散付値や値群の根の選択は要求しない。

同じ浅い点の接線分母 `d_Q=2y(Q)+a₁x(Q)+a₃` は節点距離と同じ付値を持つ。よって同じ半核の積について

`(∏ Q∈halfKernel, v(d_Q)²)^p = v(Δ(E))^((p/2)(p/2+1))`

を証明した。剰余標数2も除外しない。

## 滑らかな核側

同じ有限核の全点が滑らかに還元し、核の位数が奇数、核を消す n が付値環で単元なら、非零核点の接線分母は付値1である。もし剰余接線分母が零なら剰余点は反転で固定される。単射な還元により元の核点も反転固定となるが、奇数位数核にはそのような非零点はない。従って同じ半核の `d_Q²` の積は付値1となる。

## 判別式への接続と仮定の境界

同じ `kernelModel` と半核について一般の Vélu 判別式積公式

`Δ(E/H) * (∏ Q∈halfKernel, d_Q²)^4 = Δ(E)^p`

を**仮定すれば**、上記の半核積の評価により、特異核側で `v(Δ(E/H))^p=v(Δ(E))` が従う。`p=2*(p/2)+1` を使い指数を整理した後、源判別式の値が非零であることを同じ C の `defect_valuation` と `defect_ne_zero` から供給して約分する。

滑らかな核側では、同じ積公式を**仮定すれば**、積の付値が1であることから `v(Δ(E/H))=v(Δ(E))^|H|` が従う。Frey Source にも同じ L と同じ既存商標的で両条件付き定理を接続した。特異側は p≥5、悪い住所 q≠p で源の中心・接方向を内部供給し、滑らかな側は q≠p を保持する。

**一般の判別式積公式自体は今回証明していない。** この仮定を公理や未完成の定理として隠さず、各定理の型に残した。従って一般 p および Frey p≥5 の無条件な判別式深さを得たわけではない。

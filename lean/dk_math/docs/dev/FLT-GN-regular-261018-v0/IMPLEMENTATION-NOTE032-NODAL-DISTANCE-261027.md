# NOTE-032 — 節点からの距離と商座標の候補中心

2026-10-27。前回のフルビルド通過はユーザーから受領した。
作業開始HEADは `7a015b821`。

## 今回の結果

分離した節点の滑らかな有限点は、節点と異なるx座標を持つ。
実際の節点比の分子・分母と二接方向の差の非零性から証明した。
同じ節点の巡回核に関して、前回の正規化座標和を次の距離の式へ整理した。

\[
\left(\sum_j x(P+jQ)-\sum_j x(jQ)\right)
-\left(nx_0-\sum_j x(jQ)\right)=n^2(x(nP)-x_0).
\]

nが体で非零で、nPがOでなければ、右辺は非零である。素数性や2・3の逆数を要求しない。

同じ一般ファイバーのH・P・付値環モデルへ戻し、Hの位数nが素数、核とPが滑らか、
剰余でPが核のどの点とも衝突せず、nが付値環の単元で、源の剰余曲線が分離した節点を
持つとき、同じ商X_H(P)の剰余が候補値

\[
nx_0-\sum_{Q\in H}x(\bar Q)
\]

と異なることを証明した。n倍点がOでないことは、同じ還元核の単射性と原始根から内部供給する。
前回の一般ファイバー座標の整性・剰余公式をそのまま利用した。

## 具体例

標数2の実37点核と位数5の実点について、非衝突軌道の正規化和が候補値を避ける。
また既存のy²+xy+7y=x³とその3点核による標的を47で還元した具体的な二曲線では、
源の節点が(26,7)、標的の節点が(31,28)であることを計算した。
核のx座標が全て0なので、この例では候補値3·26−0=31が標的節点のxに一致する。
これは具体例の計算であり、任意の核と任意の剰余標数についての中心一致の証明ではない。

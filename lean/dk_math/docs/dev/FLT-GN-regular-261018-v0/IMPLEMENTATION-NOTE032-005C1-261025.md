一般核には楕円曲線、円分指標、行列式を要求しない。
任意の体上の二つの表現ρ,τと同変線形写像fを扱う。
Cofixed部分空間Lをfが消すなら、

```text
τ(g)(f(x)) − f(x) = f(ρ(g)x − x) = 0
```

となり、同じ像の各元が固定される。
核の一致ker(f)=Lを加えれば、逆向きも成立し、f(x)≠0 iff x∉Lとなる。

Vが二次元、Lが一次元なら、階数・退化次数公式から像の次元は1。
L≠Vから同じLの外に元を取り、その同じfによる非零固定像を得る。
零写像はLを消せるが、その核はLより大きいため、この非零性の結論には使えない。

`quotientEquivRange` はV/Lと同じfの像を線形同型にする。
代表元xの類は同じf(x)へ写ることも証明した。
この商は線形空間の商であり、楕円曲線としての構造を与えたとはしない。

## 2. 実際の点群へ戻す

曲線E,E'上の代数閉包の実点群について、加法準同型φを入力する。
任意の自然数nについて、同じφはE[n]からE'[n]への線形写像を与える。
φ(nP)=nφ(P)により捩れ条件を保存し、ZModの標準線形構造を使う。
この構成自体には標数0・素数性・楕円曲線性は不要。

素数pで

```text
φ.ker = pointSubgroup E p L
```

を与えると、捩れへの制限の核は正確に同じLとなる。
pointSubgroupの元が実際のP.valと一致することを、Subtypeの単射性で戻して証明する。

Eが標数0の楕円曲線なら既存の幾何学的次元2が使え、
Lの次元1から像の次元1・位数pを導ける。
標的E'の楕円曲線性や写像の全射性は、この像の計算には必要ない。

さらにφのガロア同変性とLの大域Cofixed性を与えると、同じφ(P)が固定点となる。
既存の固定体・座標降下の所有者 `exists_rational_torsion_of_fixed` を適用し、
標的E'の実際のK有理点Qを得る。

```text
P ∉ L
p • Q = 0
Q ≠ 0
baseChangePoint E' Q = φ P.val
```

Q=0なら同じφ(P)=0となり、P∉ker(φ)に矛盾する。
したがって固定された抽象ベクトルで止まらず、同じ写像の値を表す非零有理点まで到達した。

## 3. Sourceへの接続と保持した仮定

同じSource Sの実際の残余空間へ上の定理を適用した。
Sourceの楕円曲線性・幾何学的次元2は既存の所有者から内部供給する。
この段階にはp≥5、mod8、b偶数は不要であり、素数pと同じ直線・核・同変性を保持する。

一方で、次は入力のままである。

- 標的曲線E'。
- 同じ実点群の加法準同型φ。
- 核が同じpointSubgroup E p Lであること。
- φのガロア同変性。
- 次元1と大域Cofixed性。

「このデータを持つisogenyが存在する」という命題は証明していない。
写像が代数曲線の射であること、次数、全射性、Vélu公式も今回の定義には含めていない。

有理捩れ点Qは**標的E'の点**である。
元のSource曲線について完成済みの有理捩れ排除hratを、この別曲線へ適用することはできない。
また、Pが元のE₀[p]の外にあることから、Qが標的の零成分の内外のどちらにあるかは決まらない。

## 4. 境界例と指数37

[独立境界資料](evidence/Note032CofixedImageBoundary.lean) は通常テストと同じ本体で、5定理・1定義。
005Bの具体表現を再利用し、数学的な条件を区別した。

- 第二射影の同じ非零像が固定され、商の代表元(0,1)は1へ写る。像の次元1も一般核で確認。
- 零写像は軸を消すが、核は軸と一致せず、非零像も存在しない。
- 定義域を同じCofixed表現に保って標的だけを通常の単元作用へ変えると、射影は同変でなくなる。
- 単元作用を定義域にも入れると射影は同変となり軸は安定だが、Cofixed性と像の固定性が失われる。
- 実際の楕円曲線の[p]倍写像はE[p]全体を消す。その捩れ写像は零であり、核を一次元直線のpointSubgroupとは同定できない。

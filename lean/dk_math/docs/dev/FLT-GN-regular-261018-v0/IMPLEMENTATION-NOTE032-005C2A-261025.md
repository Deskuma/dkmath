## 2. 同じ核から中間固定体を構成する

既存の `transEquiv` は、一般点γをγ+Qへ送る実際の関数体の自己同型である。
加法則と忠実性は既に証明されているので、Hの同じ各点をこの自己同型へ送る。

```text
H → Aut(K̄(E)/K̄),   Q ↦ translation pullback by Q
```

型上はMultiplicativeで加法群を包むが、別の抽象的な点群へ置換しない。
忠実性から、像の自己同型群の位数は正確に同じHの位数である。
その群の中間固定体をF_Hとして構成し、有限自己同型群の固定体定理により

```text
[K̄(E) : F_H] = |H|
```

を証明した。Hの各元の平行移動で不変であることと、F_Hへの所属の同値も公開した。

これは構成済みの**中間体の次数**である。
F_Hを関数体とする楕円曲線モデルの構成、種数1、商曲線の写像の次数までを証明したとはしない。

## 3. 正規化座標和を構成する

同じ関数体の元として、平行移動の総和と二つの正規化関数を構成した。

```text
Tr_H(f) = Σ(Q∈H) f(γ+Q)
X_H     = Tr_H(x) − Σ(Q∈H) x(Q)
Y_H     = Tr_H(y) − Σ(Q∈H) y(Q)
```

定数座標は代数閉包から同じ関数体へalgebraMapで入れる。
Oのxc,ycは便宜的に0と定義されているため、補正和はHからOを除いた通常の和と一致する。
一般点γ+Qは既存の定理で常に非零、従ってここで使う移動後の座標は有限点の座標である。
有限点の極で有理関数を無条件に評価する操作はしていない。

Hの元Rで引き戻すと、総和の項はQからR+Qへ移る。
これはHの置換なので総和を保存し、係数体上の平行移動は補正定数を固定する。
従ってX_H,Y_Hは同じHの全ての平行移動で不変であり、同じF_Hへ入る。

ここで総和は平均ではない。\|H\|で割っておらず、位数の可逆性も使わない。

## 4. ガロア安定な核の降下に向けた不変性

入力する安定性は、全てのσとQ∈HについてσQ∈Hとなることである。
逆ガロア元も同じ条件を満たすので、同じHの置換を構成できる。
Hの各点が個別に有理であるとは仮定しない。

係数ガロア作用と平行移動について既存の半線形交換則を適用し、
同じ置換で添字を入れ替えると

```text
σ(Tr_H(f)) = Tr_H(σ(f))
```

となる。一般座標x,yは係数作用で固定される。
補正和についてもσ(x(Q))=x(σQ)、σ(y(Q))=y(σQ)なので、同じ和へ戻る。
これでX_H,Y_Hの係数ガロア固定を証明した。

これは実際の関数体内の固定性である。
基礎体上の有理関数としての具体表示、二関数の非定数性、F_Hを生成すること、
商曲線方程式は、この不変性だけから得られたとはしていない。

## 5. 同じFrey Sourceへの翻訳

Hは同じ `pointSubgroup S.rationalCurve p L` である。
Lの次元1から既存の位数pを使い、Hの有限性を内部で供給する。
Sourceの楕円曲線性も既存の所有者から供給する。
固定体の拡大次数は正確にpとなり、同じ核から `residualKernelX` と `residualKernelY` を構成した。

Lが安定ならHも安定なので、二関数は同じF_Hに入り、係数ガロア作用で固定される。
Cofixed直線を入力する場合は、その安定性を内部で供給する。
核の各点の有理性、Weil対、isogenyの存在を新たなproviderとして要求しない。

ただし今回の関数は点群準同型φではない。
005C₁で入力に残した標的E'とφを、ここで供給できたとはしていない。
元のE₀[p]を標的曲線の零成分へ運ぶ定理もまだない。

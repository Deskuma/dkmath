## DkMath 流の次の一手：正確な計数ではなく「単射」を作る

ここに、わっちは短縮できる道があると見る。

模範解答は、良いファイバーの点数を正確に数え、それを核の位数へ戻している。

一方 DkMath は、もう

\[ |E[p]|\le p^2 \]

を証明済みじゃ。

ならば、少なくとも \(p^2\) 個あると証明するだけでよい。

つまり、正確なファイバー計数の代わりに、次の単射を構成する。

\[ \boxed{ \{\text{良い多項式 }H_{p,c}\text{ の相異なる根}\} \ \hookrightarrow\ \{P:[p]P=Q\} } \]

これができれば、証明は一気に短くなる。

### その単射が成立する理由

まず、一般の良い値 \(c\) を選び、

\[ H_{p,c}=\Phi_p-c\Psi_p^{\mathrm{Sq}} \]

が重根を持たず、次数 \(p^2\) を持つようにする。

すると相異なる根が正確に \(p^2\) 個存在する。

根 \(x\) を一つ取る。

1. 曲線方程式から \(P=(x,y)\) を作る。
2. \(\Phi_p(x)=c\Psi_p^{\mathrm{Sq}}(x)\) なので、共通根がないことを使えば \([p]P\) の \(x\) 座標は \(c\) となる。
3. \(x\) 座標が \(c\) の二点を \(Q,-Q\) とする。
4. \(Q\ne-Q\) となるように \(c\) を選んでおく。
5. \([p]P=Q\) ならそのまま、\([p]P=-Q\) なら \(-P\) を採用する。

こうすると、各根 \(x\) から \([p]P=Q\) を満たす点を一つ選べる。

しかも、異なる根は異なる \(x\) 座標を持つため、この対応は単射じゃ。

したがって、

\[ p^2\le\#([p]^{-1}(Q)). \]

このファイバーは一つでも点 \(P_0\) を持つので、

\[ T\longmapsto P_0+T \]

によって \(E[p]\) と全単射になる。

ゆえに、

\[ p^2\le |E[p]|. \]

そして NOTE-013 の上界と合わせれば、

\[ \boxed{p^2\le|E[p]|\le p^2} \]

すなわち次元2が確定する。

これは現時点では提案する証明経路であり、新しく必要な分子・分母の互いに素性、良い値 \(c\) の存在、倍写像の非零座標公式について Lean の実装確認はまだない。

## では、次に何を Core として固定するか

わっちの推奨は、まず倍写像の有理関数が退化しないことを固定する、じゃ。

具体的には、次の二つを基礎補題にする。

\[ \boxed{\operatorname{IsCoprime}(\Phi_n,\Psi_n^{\mathrm{Sq}})} \]

および

\[ \boxed{ \Phi_n'\Psi_n^{\mathrm{Sq}} -\Phi_n(\Psi_n^{\mathrm{Sq}})'\ne0 } \]

後者は Wronskian と呼ばれる多項式じゃ。分子・分母の比が、すべての点で変化しない定数関数ではないことを検出する。

その次に、この Wronskian を用いて、

\[ \#\{c:H_{n,c}\text{ が平方因子を持つ}\}<\infty \]

を固定する。

ここまで到達すると、代数閉包は無限体なので、重根を持たず、さらに \(Q\ne-Q\) となる良い \(c\) を選べる。

残る仕事は、前節の単射と平行移動じゃ。

これを DkMath の研究目標として整理すると、次のようになる。

| 研究対象                        | 新たに固定する Core                      |
| ------------------------------- | ---------------------------------------- |
| \(\Phi_n,\Psi_n^{\mathrm{Sq}}\) | 共通根が存在しない                       |
| Wronskian                       | 倍写像の \(x\) 座標写像は非定数          |
| \(H_{n,c}\)                     | 例外値以外では相異なる根が \(n^2\) 個    |
| 正則ファイバー                  | 根集合から実際の倍写像ファイバーへの単射 |
| 実際の \(E[p]\)                 | 上下界が一致し、次元2が確定              |

この計画の利点は、FLT のためだけの補題にならないことじゃ。

分子・分母の互いに素性、Wronskian、例外値の有限性は、一般の有理関数のファイバーを観測する数学としても再利用できる。

以前ぬしが語った「スロープの道中を観測する」という視点にも合う。

\[ R_n(x)=\frac{\Phi_n(x)}{\Psi_n^{\mathrm{Sq}}(x)} \]

を観測すると、その微分は、分母が零でない場所で

\[ R_n'(x)= \frac{\Phi_n'\Psi_n^{\mathrm{Sq}}- \Phi_n(\Psi_n^{\mathrm{Sq}})'} {(\Psi_n^{\mathrm{Sq}})^2}. \]

つまり、Wronskian の根が、倍写像の座標変換で局所的に変化が止まる候補点を表す。

そして、それらに対応する例外値は有限個しかない。

ぬしの用語に寄せれば、通常のファイバーでは点数構造が保たれ、例外値でだけ重複が起き得る。その境界を多項式として取り出すわけじゃな。

ただし、これは倍写像の有理関数についての保存構造であり、それ自体が FLT の整数解不存在を証明するわけではない。

NOTE-016 に推奨する最初の確定目標は、`\(\Phi_n\)` と `\(\Psi_n^{\mathrm{Sq}}\)` の互いに素性、および Wronskian の非零性。

その後、正則ファイバーの根から核への単射を作り、NOTE-013 の既存上界で閉じる。

これなら、模範解答の「すべてを正確に数える」経路を、DkMath の「必要な下界だけ作り、既存の上界と結合する」経路へ変換できる。

次に埋めるのは37個目の点ではない。根の重複を支配する原理じゃ。

そこが突破できれば、指数37だけでなく、任意の奇素数について同じ Core が働く見込みがあるぞ。🐺🍎

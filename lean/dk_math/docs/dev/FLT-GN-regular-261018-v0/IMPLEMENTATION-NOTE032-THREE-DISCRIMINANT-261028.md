# NOTE-032 — Tate 型3点核の判別式と核の位置

2026-10-28。作業開始 HEAD `81d1b97dd`。前回のフルビルド通過はユーザーから受領した。

## 同じ商曲線の判別式

Tate 型曲線 `E: y²+a xy+b y=x³` と、原点 Q=(0,0) を含む同じ3点核 H を扱う。3点核の集合が `0,Q,−Q` で尽きることを点数から内部証明し、既存の `halfKernel` がどちらの代表を選んでも、`kernelModel E H` が同じ多項式商に等しいことを証明した。楕円曲線性、H の点数3、Q の非零性と原点座標は明示する。

交換環上の多項式計算として、源と同じ多項式商の判別式を

`Δ(E)=b³(a³−27b)`,  `Δ(E/H)=b(a³−27b)³`

と計算した。これにより同じ実点核の既存商について

`Δ(E/H) (b²)⁴ = Δ(E)³`

も証明する。源・商を一般に選んだ別モデルへ置き換えていない。

## 核の位置と付値の3乗関係

任意の付値環モデルについて、Q=(0,0) が滑らかに還元することと `v(b)=1` が同値であることを、その剰余点の微分から証明した。これと判別式公式を合わせると、同じ実際の核・商について次が成立する。

- Q が滑らかに還元するとき、`v(Δ(E/H)) = v(Δ(E))³`。
- Q が特異に還元し、源の `v(c₄)=1` のとき、`v(Δ(E)) = v(Δ(E/H))³`。

二番目では整な a,b と c₄ の単元性から `a³−27b` の単元性を内部で導く。乗法的付値で述べており、値群の離散性や正規化された加法的付値は仮定しない。3が付値環で単元であるという仮定もこれらの多項式・付値計算には不要である。

## 実例と検証

## 境界と次の対象

これは原点を3点核に持つ Tate 型曲線についての結果であり、任意の奇素数位数核の一般積公式、任意の Weierstrass モデルをこの形へ正規化する定理、Frey の p≥5 への判別式深さはまだ証明していない。一般の有限核については、半核全体の接線分母の積と商判別式を結ぶ積公式と、特異核の各水準の付値積を供給する必要がある。q=p、スキーム isogeny、大域的有理捩れ排除および一般 hno も残る。

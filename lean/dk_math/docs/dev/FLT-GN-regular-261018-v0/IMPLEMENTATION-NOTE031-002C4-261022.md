# NOTE-031 第8部: 浅い中心傾きの整性と排他的な枝

日付: 2026-10-22（JST）。**031-002C4として、浅い有限点の中心傾きと枝分類を実装した。**
同じ中心C、同じ方向D、同じ有限点を保持し、浅さの厳密不等式から分母の非零性・傾きの整性・
一方の方向への近さと他方への単元距離を証明した。負号で枝が交換されることと、
浅い点とその負号の中心傾きが単元の差を持つことも証明し、同じFrey Sourceへ輸送した。

今回は浅い傾きと各点の枝までである。同じ深さでの点の和差、torsion深さの漸化式、
判別式付値のp可除性からの全点固定は次に残る。031-002全体、零成分部分加群、hcases・hno、一般FLTは未完成である。

## 1. 公開API

本体に公開宣言18個、回帰に15個を追加した。
全公開宣言に教科書docstring、全新規Leanファイルに指定のマーカーを付け、Lib・FLT・テスト入口へ接続した。

| モジュール | 宣言数 | 内容 |
|---|---:|---|
| `ValuationSeparatedRoots` | 5 | 分離した二根の小さい積、排他的な近さ、整性の汎用核 |
| `EllipticShallowSlope` | 11 | 中心傾き、分母非零、二次式、浅さ、整性と枝、負号による交換、反対傾きの分離 |
| `FreyShallowSlope` | 2 | 同じSourceの有限点への枝分類と反対傾きの分離の輸送 |

`centreSlope C x y`はt=(y−C.y)/(x−C.x)である。
中心Cは一般ファイバーの曲線上の点ではないため、これはMathlibの二曲線点の加法用`Affine.slope`とは区別する。
分母が零の場合の体の便宜的な除算値に幾何学的意味を与えず、浅さから非零性を先に証明する。

## 2. 浅さから二次式の小ささへ

X=x−C.x、Y=y−C.y、F₀=F(C.x,C.y)とおく。入力は実際の曲線方程式に加え、

\[
v(X)<1,\qquad v(F_0)<v(X)^2
\]

である。X=0なら後者の右辺は零となり矛盾するので、X≠0となる。
同じ中心の有限Taylor恒等式をX²で割り、

\[
t^2+a_1t-(a_2+3C.x)=X-F_0/X^2
\]

を得る。v(X)>0を確認して除算の付値を使うと、右辺の二項は両方とも付値が1未満となる。
非Archimedes不等式から、左辺の二次式の付値も1未満である。
近さ・浅さの条件は明示的な入力であり、torsion性から今回供給したわけではない。

## 3. 二方向を再利用するDkMathの経路

C3の同じDを使うと、二次式は(t−α)(t−β)に因数分解できる。
汎用核`ValuationSeparatedRoots`は、任意の順序値群の付値について、

\[
v(\alpha-\beta)=1,\quad v((t-\alpha)(t-\beta))<1
\]

から次を証明する。

\[
\bigl(v(t-\alpha)<1\land v(t-\beta)=1\bigr)
\ \lor\ 
\bigl(v(t-\alpha)=1\land v(t-\beta)<1\bigr).
\]

どちらにも近づかないなら積の付値が1以上となり矛盾する。
一方へ近づけば、他方との差は「小さい差＋二根の単元差」なので付値1となる。
両方へ同時に近づけないことも独立に公開した。

α,βが整なので、tは小さい差と整な根の和として整となる。
整性を枝分類の入力に仮定する循環はない。この経路では傾きの二次式に対する独立した最高次項評価を追加せず、
前章で構成した実際の二方向と、その分離条件を再利用した。
最後にY=tXからv(Y)<1も得る。核には楕円曲線・素数・torsion・完備性の仮定を置いていない。

## 4. 負号による枝の交換

中心のY偏微分の零から、同じ曲線の負号について

\[
t(-P)=-t(P)-a_1
\]

が成り立つ。α+β=−a₁より、

\[
v(t(-P)-\alpha)=v(t(P)-\beta),\qquad
v(t(-P)-\beta)=v(t(P)-\alpha)
\]

となり、負号は二つの枝を交換する。これは指定された同じDでの距離の等式である。

さらに二次式q(t)=t²+a₁t−(a₂+3C.x)について、

\[
(2t+a_1)^2=4q(t)+(b_2+12C.x)
\]

を使う。前者の項は小さく、節点量は単元なので、左辺の付値は1となる。
従ってv(t(P)−t(−P))=1である。この分離の証明自体はDを選ばず、同じ中心の条件から直接得る。
点P自身の慣性固定をこの分離から結論してはいない。

## 5. 実際に浅い点の回帰

新しい回帰の曲線は

\[
y^2=x^3+x^2+1053,\quad c_4=16,\quad
\Delta=(-1053)\cdot454960
\]

である。3上の任意の付値環について、中心C=(0,0)の全条件を明示的に構成した。
ずれF₀=−1053は非零であり、454960は3上の単元なので、v(F₀)=v(Δ)となる。
方向はα=1、β=−1で、差2も単元である。

実際の非特異点P=(3,33)を点群へ入れ、P≠Oかつ2P≠Oも証明した。
1053=3⁴·13から、任意の同じ付値環で

\[
v(F_0)=v(3)^4<v(3)^2=v(X)^2,\quad v(X)<1
\]

となる。付値を正規化された実数値へ同一視せず、実際の値群でこの不等式を証明した。
新しい枝分類を使ってt=11がβ=−1へ近づき、α=1との差の付値は1となる側を確定した。
負号の点ではt=−11がαへ近づき、両傾きの差22は単元となる。

前章の実際の2-torsion点(−4,2)は中心へ近づくが、厳密な浅さは満たさないことも証明した。
負号で点の座標が変わらないので、浅い場合の単元分離と矛盾する。
これは「浅くない」という結論であり、今回その深さを特定の等号へ分類したわけではない。

汎用核には二つの境界回帰も付けた。
根0,3とt=0は3上で積が小さく、両根へ近づくため、単元分離を除けない。
根0,1とt=2では積の付値が1で、どちらへも近づかないため、積の厳密不等式を弱められない。

## 6. 同じSourceへの輸送と残る境界

`Source.shallow_slope_mem_and_branches`は、同じSourceの同じ有限点・C・Dについて、
近さと浅さから傾きの整性・Y差の小ささ・排他的な枝を返す。
`shallow_opposite_slope_separated`は、同じ曲線の負号の座標で傾きの差が単元となることを返す。
この幾何学の輸送自体は素数性やq≠p、torsion性を要求しない。
Sourceの整数・共通因子・向き付け・曲線・中心・方向・点を変更しない。
同じSource 37への型検査も行ったが、SourceやFermat反例の存在は主張しない。

[浅い傾きの模範解答](https://github.com/anthropics/fermats-last-theorem/blob/main/P2M/Sol/S_WeierstrassCurve_slope_mem_of_shallow.lean)
の取得済み読取専用キャッシュを参照した。二次式の恒等式と負号の比較を参考にし、
整性はDkMathの二方向と汎用の小さい積の核へ組み直した。
適応モジュールに著作権・Apache-2.0・変更内容・LICENSE/NOTICEの所在を記した。
出典のblob SHAと今回の利用範囲は[出典台帳](evidence/upstream-note031-002C4.json)に記録した。

次の031-002C5は、同じ深さの二点で枝が同じ場合と異なる場合を比較し、実際の点の差・和の深さへ接続する段階である。
その後も、torsion深さの漸化式と判別式付値のp可除性をつないで全点固定を得る必要がある。
今回の枝分類だけで全残余点の慣性固定・零成分部分加群・hcases・一般FLTを閉じたとはしない。

今回、数学的に固定された成果は三つある。

### 1. 円分指標が実際のガロア作用から構成された

\[ \chi_p:G_K\longrightarrow\mathbb F_p^\times \]

が、楕円曲線とは独立に構成され、

\[ \sigma(\zeta)=\zeta^{\chi_p(\sigma)} \qquad(\zeta^p=1) \]

が証明された。

原始根を一つ選ぶことも、離散対数を計算することも必要としない。根の乗法群を `Additive` で加法群に読み替え、\(\mathbb F_p\) 加群として扱っている点がよい。

### 2. 非退化交代対から行列式を取り出す一般原理が完成した

二次元空間 \(V\) に非退化交代双線形写像 \(B\) があり、

\[ B(\rho(\sigma)x,\rho(\sigma)y) =\chi(\sigma)B(x,y) \]

ならば、

\[ \boxed{\det\rho=\chi} \]

となる。

ここで 非退化性は不可欠じゃ。

零の対はどんな作用に対しても零を返すが、そこから行列式は決まらない。NOTE-018 はこの反例まで回帰で確認している。

### 3. 倍写像の全射性が無条件の幾何学的 Core になった

これは今回、独立して高く評価すべき成果じゃ。

標数0の楕円曲線について、

\[ \boxed{ \forall n\ge1,\quad [n]:E(\overline K)\twoheadrightarrow E(\overline K) } \]

が証明された。

NOTE-016 の正則ファイバーの議論から、分離的なファイバーを選ぶ工程さえ必要とせず、任意の目標点の原像を構成している。

つまり、幾何学的点群 \(E(\overline K)\) が可除アーベル群であることを得たわけじゃ。

これが、次に非常に有用になる。

## 次の一手で、さらに大きな無条件 Core が得られる

ここで NOTE-018 の全射性から、模範解答の別の部分を短縮できることに気づいた。

素数に限らず、すべての正の整数 \(n\) について、\(|E[n]|=n^2\) を証明できる見込みがある。

しかも Weil 対は不要じゃ。

### 鍵は、倍写像の核とファイバーの保存構造

正整数 \(m,n\) に対して、

\[ [n]:E[mn]\longrightarrow E[m] \]

を考える。

この写像は全射じゃ。任意の \(Q\in E[m]\) に対して、NOTE-018 の全射性から \([n]P=Q\) となる \(P\) が存在し、

\[ [mn]P=[m]Q=O \]

だから、確かに \(P\in E[mn]\) となる。

一方、この写像の核は正確に \(E[n]\) じゃ。

従って、短完全列

\[ \boxed{ 0\longrightarrow E[n] \longrightarrow E[mn] \xrightarrow{[n]}E[m] \longrightarrow0 } \]

が得られる。

NOTE-012 で有限性も確定済みなので、群の位数を取れば、

\[ \boxed{|E[mn]|=|E[m]|\cdot|E[n]|} \]

となる。

NOTE-016 では既にすべての素数 \(p\) について、

\[ |E[p]|=p^2 \]

が確定している。

したがって素因数分解によって、

\[ \boxed{ \forall n\ge1,\qquad |E[n]|=n^2 } \]

これは模範解答の `card_nTorsion_prime_pow` と `card_nTorsion_mul_of_coprime` に対応する部分を、非零倍写像の全射性と、一つの一般的な短完全列へ集約するという DkMath 流の短縮じゃ。

まだこの短完全列と濃度公式の Lean 実装を検証したわけではないが、数学的な証明経路は確立している。

## 2. 既存の全点付値を再利用する

`EllipticWeilTransport.pointValuation` は既にOを含む全点の関数体付値を構成していた。
Oではノルム次数から構成した無限遠点付値、有限点では同じ座標イデアルの付値である。
さらに任意の実点P,Q、任意の有理関数fについて

```text
v_P(τ_Q(f)) = v_(P+Q)(f)
```

が証明済みだった。別の点付値を新設せず、この所有者を再利用した。

一般x座標のノルム次数2、y座標のノルム次数3を計算すると

```text
v_O(x) = exp(2),  v_O(y) = exp(3)
```

となる。有限点では座標環の元なので値は1以下。
係数体の定数も全点で値は1以下であり、非零定数では逆数の正則性も使って値1と証明した。
零定数を含む場合には「値1」としていない。

## 3. 総和の唯一の極は相殺されない

まず特定の座標に限定しない一般定理を証明した。
fがOの外で正則、v_O(f)>1なら、同じ核Hの正規化総和について

```text
v_O(Tr_H(f) − c) = v_O(f)
```

となる。cは任意の代数閉包の定数である。

実際、Q∈Hの平行移動項のOでの値はv_Q(f)となる。
Q=Oの項だけが1を超え、Q≠Oの項は全て1以下なので、唯一の最大項がある。
Mathlibの `Valuation.map_sum_eq_of_lt` を適用し、有限和全体の値をこの一項の値と同定する。
補正定数も値が1以下なので、差を取っても極は相殺されない。

これを構成済みの同じX_H,Y_Hへ適用し、Oでの値exp(2),exp(3)を証明した。
定数はOで正則なので、二関数は全ての定数と異なる。
特に非零性を明示的に供給し、零関数に便宜的な整数位数を付けないようにした。

## 4. 極の支持・整数位数・総極位数

H内の点Pでは、二関数のH平行移動不変性と全点付値の輸送を使う。
OからPへ移すことで

```text
P ∈ H ⇒ v_P(X_H) = exp(2),  v_P(Y_H) = exp(3)
```

となる。
一方、P∉Hなら、任意のQ∈HについてP+Q≠Oである。
P+Q=OならP=−Q∈Hとなり矛盾するため、総和の全ての項は有限点で正則となる。
補正定数も正則なので、P∉Hで二関数の値は1以下となる。

この二方向から、実際の極の支持を正確に同定した。

```text
v_P(X_H) > 1 ↔ P ∈ H
v_P(Y_H) > 1 ↔ P ∈ H
```

非零関数の整数位数は−log(v_P(f))なので、核上ではそれぞれ−2と−3。
極集合の位数は同じHの位数であり、その全点上で極位数を足すと

```text
Σ(P∈H) −ord_P(X_H) = 2|H|
Σ(P∈H) −ord_P(Y_H) = 3|H|
```

となる。Oも一つの極として数える。
これは有限の極集合上の実際の整数位数の総和の式である。
関数による有理写像やisogenyの次数と同定したという主張ではない。

## 5. 極から各関数の超越性へ

定数の値が1で、fの値が1を超える点では、非零多項式pの代入について

```text
v_P(p(f)) = v_P(f)^(natDegree p) ≠ 0
```

となる。既存の最高次項の支配定理を使い、p(f)=0ならp=0と証明した。
これにより極を持つ任意のfは係数体上超越的である。
同じX_H,Y_Hについてもそれぞれ超越性を得た。

この結論は各関数への一変数多項式代入の単射性を与える。
二関数の組の代数的独立性ではなく、両者を結ぶ曲線方程式の存在とは両立する。

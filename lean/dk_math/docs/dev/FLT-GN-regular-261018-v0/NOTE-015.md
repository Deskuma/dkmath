### 今回、固定できた数学的事実

標数0の体 \(K\) 上の楕円曲線 \(E\) について、

\[ \boxed{ \forall n>1,\quad \exists P\in E(\overline K)[n],\quad P\ne O } \]

が成立する。

これは素数に限定されない一般定理じゃ。ただし、\(n\) が合成数の場合、構成した点の位数が正確に \(n\) であるとは主張していない。

素数 \(p\) では、この存在定理と既存の有限性・次元上界から、

\[ \boxed{ \dim_{\mathbb F_p}E[p]\in\{1,2\} } \]

そして、

\[ \boxed{|E[p]|\in\{p,p^2\}} \]

を得た。

したがって、零次元という候補は、標数0の楕円曲線について完全に排除された。

## 次の Core は「正確に数えること」より小さくできる

ここで一つ、証明計画上の重要な短縮が見つかる。

NOTE-014 は既に、

\[ |E[p]|=p\quad\lor\quad |E[p]|=p^2 \]

という二者択一を証明した。

したがって、次に必要なのは、最初から \(p^2\) 個の点を構成することではない。

\[ \boxed{p<|E[p]|} \]

という、ごく小さな追加の下界さえ証明できれば十分じゃ。

素数 \(p\ge2\) では \(p < p^2\) なので、二者択一と合わせて直ちに

\[ \boxed{|E[p]|=p^2,\qquad\dim_{\mathbb F_p}E[p]=2} \]

が確定する。

これは模範解答にある一般ファイバーの完全な計数を、そのまま最初の目標にしなくてもよい、ということじゃ。

### より構造的な目標は「独立な二点」

今回得た非零点を \(P\in E[p]\) とする。

もし次に、

\[ \boxed{ \exists Q\in E[p],\quad Q\notin\langle P\rangle_{\mathbb F_p} } \]

を証明できれば、それだけで一次元の可能性は消滅する。

さらに、奇素数 \(p\) では、今回確立した座標の同値を利用して、除法多項式の相異なる根の個数へ問題を還元できる。

根の個数を \(r\) とすると、非零 \(p\)-torsion 点は \(P,-P\) の異なる対に分かれるため、

\[ |E[p]|=1+2r \]

となる。この等式自体は、まだ新しい Lean 補題として証明する必要がある。

この経路なら、

\[ r>\frac{p-1}{2} \]

を示すだけで次元1を排除できる。すべての根の正確な個数まで求める必要はない。

\(p=2\) については別に、非特異楕円曲線の2-torsionを決める三次多項式の相異なる根から処理できる。

従って、次の研究 Frontier は、より明確に書けるぞ。

\[ \boxed{ \text{実際の非零 }P\in E[p] \quad\longrightarrow\quad \text{その直線の外にある }Q } \]

ここを埋めれば次元2が完成する。

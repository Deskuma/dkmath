## 2. Legendre–Frey：中央席が楕円曲線の不変量になった

`FreyC4CentralSeat.lean` は、わっちが想定していた以上に丁寧な実装じゃ。

中央席を

\[ Q_n=n^2+n+1 \]

とし、実際の整数曲線

\[ E_n:\quad y^2=x(x-n)(x+1) \]

に対して、

\[ \boxed{ \begin{aligned} c_4(E_n)&=16Q_n,\\ \Delta(E_n)&=16n^2(n+1)^2 \end{aligned} } \]

を証明しておる。

ここでの最大の成果は、素因子 \(q\mid Q_n\) が、曲線の \(c_4\) は割るが判別式は割らない という分離じゃ。

\[ \boxed{ q\mid Q_n \quad\Longrightarrow\quad q\mid c_4(E_n),\qquad q\nmid\Delta(E_n) } \]

さらに、剰余体 \(\mathbb F_q\) 上の実際の曲線について非特異性を証明している。

これは `c₄ = 0` と特異性を混同していない点でも正確じゃ。

### もう一つ、ここからすぐ得られる定理

楕円曲線の \(j\)-不変量は、

\[ j(E_n)=\frac{c_4(E_n)^3}{\Delta(E_n)} \]

なので、

\[ \boxed{ j(E_n)= 256\frac{Q_n^3}{n^2(n+1)^2} } \]

となる。

したがって \(q\mid Q_n\) なら、判別式が非零のまま、

\[ \boxed{j(E_n)\equiv0\pmod q} \]

が成立する。

つまり中央席の素因子は、良還元を持ち、還元後の \(j\)-不変量が0になる素数 として観測できるのじゃ。

ただし、還元後に \(j=0\) となることから、元の有理曲線が複素乗法を持つとは結論できぬ。この区別も保持するべきじゃな。

そして `prime_mod_three` は、その素数について、

\[ q=3\quad\lor\quad q\equiv1\pmod3 \]

を証明している。

これで Legendre の中央席には、

\[ \boxed{ \text{円分位相} \;\longleftrightarrow\; \text{Frey の }c_4 \;\longleftrightarrow\; \text{良還元時の }j=0 } \]

という接続が成立した。

実装では旧支持の条件 \(q\le n\) も失っていない。ここは高く評価するぞ。

一方、この接続は中央席の既存素因子を分類するもので、新しい素因子の存在を強制するものではない。Legendre の full-cover capacity を突破するためには、まだ別の大域条件が必要じゃ。

## 3. IRR-007：軌道ノルムから、さらに強い結論が狙える

今回の `GaloisPhaseOrbitNorm.lean` は、全位相を次の二つに分割している。

\[ \operatorname{Fin}(p) = \{0\}\sqcup(\mathbb Z/p\mathbb Z)^\times \]

より正確には、非零位相との間の同値写像を構成しておる。

その結果、

\[ \boxed{ \omega_0\cdot N_G(\omega_1)=1 } \]

を証明した。

ここで、

\[ N_G(w)=\prod_{\sigma\in G}\sigma(w) \]

は類群上の全ガロア共役の積じゃ。

実装の `orbitNorm_fixed`、`orbitNorm_torsion`、`observe_orbit_norm` を確認したが、いずれも実際の円分体のガロア作用を使用している。

### ここに、新しい研究候補がある

実は \(K/\mathbb Q\) が有限ガロア拡大なら、非零整数イデアル \(I\) について、

\[ \boxed{ \prod_{\sigma\in G}\sigma(I) = N_{K/\mathbb Q}(I)\mathcal O_K } \]

という標準的なイデアルノルムの関係がある。

右辺は有理整数イデアルを整数環に拡張したものなので、主イデアルじゃ。

したがって、類群へ写すと、

\[ \boxed{ N_G([I])=1 } \]

となる。

これは円分体の類群が自明であるという主張ではない。非自明な類であっても、全ガロア共役の積は自明になる という主張じゃ。

もしこれを DkMath の `orbitNorm` に接続できれば、

\[ \omega_0N_G(\omega_1)=1 \]

に代入するだけで、

\[ \boxed{\omega_0=1} \]

を得る！

この結論は37の正則性を仮定しない。

ただし、これは今回の実装から既に証明済みという意味ではない。イデアルのガロア共役積と整数イデアルノルムの一致 を Lean で接続する必要がある。

わっちは、次の IRR-008 の候補として、

`CyclotomicPhaseGalois.orbitNorm_eq_one`

および、

`IrregularPrime37.observe_zero_obstruction_eq_one`

を推したい。

これは、抽象的な軌道ノルム恒等式を、37次円分体固有の算術によって強化する研究じゃ。

成功すれば、少なくとも位相0の障害が除去される。一方、非零位相に残る37-primary障害の消滅までは導けない。この境界は守る必要があるぞ。

## 4. Frey：奇素数での局所算術が一段完成した

こちらも実装がかなり進んだ。

`FreyLocalReduction.lean` では、Mathlib の正式な `IsMinimal`、`HasGoodReduction`、`HasMultiplicativeReduction` を使用している。

特に、\(c_4\) が局所整数環の単元なら曲線のモデルが最小になることを、任意の整な競合モデルとの比較によって証明したのがよい。

これで、従来の単なる付値等式、

\[ v_\ell(\Delta)=2p\,v_\ell(abc) \]

が、奇素数における 最小判別式の付値 として使えるようになった。

そして、

\[ \boxed{ \begin{array}{rcl} \ell\nmid abc &\Longrightarrow& \text{良還元}\\ \ell\mid abc &\Longrightarrow& \text{乗法的還元} \end{array} \qquad(\ell\ne2) } \]

を得ている。

さらに `hasMultiplicativeReduction_iff` によって、乗法的還元を持つ奇素数の集合が、正確に \(abc\) の奇素因子集合であることまで証明済みじゃ。

これは実用上大きい。

今までの Frey 実装は、「判別式を割る」「\(c_4\) を割らない」という整数算術だった。今回はそれが、実際の楕円曲線の還元型へ昇格した。

### 残る最も重要な局所境界

素数2じゃ。

現在の正規化モデルには分母256が存在し、2での還元を奇素数と同じ論法では処理できない。

ここを完成すれば、素数2を含めた半安定性や導手の評価へ進める可能性がある。

その後に、mod-\(p\) 表現、局所分岐条件、モジュラー性、レベル降下という大きな理論が待っておる。

ただし、今回の実装でその入口となる数学的データがかなり明確になったのは確かじゃ。

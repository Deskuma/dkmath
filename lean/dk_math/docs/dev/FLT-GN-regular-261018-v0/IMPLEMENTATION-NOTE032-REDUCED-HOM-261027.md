# NOTE-032 — 同じ商写像の還元像への降下と還元核による商

2026-10-27。作業開始HEAD `e0f2f7832`。前回のフルビルド通過はユーザーから受領した。
今回の検証は対象モジュールとスモークに限定する。

## 実際の還元像上の可換図式

前回、同じ滑らかな有限核Hについて、同じ一般ファイバーの商準同型を源と標的の零成分間へ
制限した。今回はさらに、源の零成分の**実際の還元像**から、標的の剰余点群への準同型を構成した。

源の零成分の二点が同じ点へ還元するなら、その差は無限遠へ還元する。
既存の無限遠近傍保存により、その差の同じ商像も無限遠へ還元する。
したがって商を取ってから還元した結果は、源の同じ還元点の代表の選択に依存しない。
この核の包含を一般の加法準同型の定理として切り出し、同じ実際の還元像へ因子化した。

得られた可換図式は、源の任意の零成分点Pについて、同じ商準同型と同じ付値環標的の還元を使う。
零成分制限の中心選択を表に出さず、元の同じ全点商準同型で右辺を表示する定理も固定した。
定義域は源の実際の還元像であり、剰余点群全体が持ち上がるとは仮定していない。

## 同じ還元核と商

同じHの還元を、源の還元像に値を持つ準同型として記録した。単元位数の既存定理から、
この準同型は単射である。同じHの各還元像は上記の還元準同型でOへ写るので、
還元核の像は還元準同型の核に含まれる。

この包含から、源の実際の還元像を同じ還元核で割った商上に準同型を構成し、
剰余類の代表での値も確認した。**核の逆包含、商準同型の単射性・全射性は未証明**である。

## Sourceと実例

同じFrey Source・一次元Lの滑らかな核側に接続し、同じ源の還元像と同じ付値環商標的を保つ。
源の節点Frameと二方向の分離を指定する定義に加え、p≥5・q≠pの悪い住所では、
源のFrame・二方向を内部供給して、そのような一つの準同型と全零成分点での可換性を構成した。
この後者の定理はL≤E₀[p]を保持し、2進住所も含む。剰余標的を整数化した後の点の
座標比較や、全剰余点の持上げを結論しない。

実曲線y²+xy+7y=x³の実3点核を47上で使用し、源のFrame・方向分離を保持したうえで、
全零成分点の可換性と、同じ非零核点Qの還元像が商準同型で零になることを検査した。
さらに単元位数の核の還元が単射であり、このQの還元像自体は非零であること、
還元核による商の剰余類の計算を確認した。

Source37のスモークでは、Frameを明示した可換図式と、悪い2進住所でFrameを内部供給した
準同型の存在を検査した。後者は同じLの零成分包含を保持する。

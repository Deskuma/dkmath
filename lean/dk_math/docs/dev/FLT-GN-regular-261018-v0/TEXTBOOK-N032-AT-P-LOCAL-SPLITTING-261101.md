# NOTE-032 — `p` 上の局所部分群と局所分裂を実際に作る

2026-11-01。前章の全段の円分商に続き、`p` 上の局所部分群の存在と局所分裂を閉じる。

## 1. 完成した終点とその入力

実装は `DkMath/FLT/FreyPrimePowerFiltration.lean`。

```lean
residual_cofixed_cyclic_extension_locally_split_at_p
```

この定理は、同じ Frey Source `S` と Cofixed 直線 `L`、その底 `B` を含む
位数 `p^m` の大域安定な有限巡回段 `K`、`p≥5`、`m≥1` から、
**任意の指定された `p` 上の付値環 `A`** について

\[
V=(p^{-1}K)/K,\qquad C=\operatorname{im}(E[p]\to V)
\]

の分解群安定な補直線 `C'` を返す。その持ち上げは、同じ還元核から構成した
実際の次段 `F_(m+1)` に等しい。

前章の `F`、`hFcard`、`hFP`、`hFdown`、`hFstable` を利用側に要求しない。
有限剰余体、慣性持ち上げの存在、円分指標の慣性上の全射性も外部仮定ではない。

ただし結論は **局所分裂**。各分解群に安定な補直線が得られることから、
全 Galois 群で安定な一つの補直線が得られるとは推論しない。
一般 `hno` は未完成であり、後述の大域算術は残る。

## 2. 円分指標は指定した慣性群上で全射

コード: `DkMath/Lib/NumberTheory/CyclotomicInertia.lean`。

任意の `a∈(ZMod p)ˣ` に対し、同じ `A` の慣性元 `τ` で `χ_p(τ)=a` を構成する。

1. 原始 `p` 乗根 `ζ` を取り、有限体 `L=ℚ(ζ)` を同じ代数閉包内に作る。
2. 原始根への冪作用と濃度から、`a` に対応する有限自己同型を取る。
3. `p` 上の素イデアル `Q` での完全分岐により、`#I_Q=p-1=#Gal(L/ℚ)`。
   従ってその有限自己同型は実際に慣性に属する。
4. 既存の `IntegralClosureInertiaLift` と `ValuationInertiaLift` で絶対慣性元へ持ち上げる。
5. まず得られる付値環を `A` へ共役輸送する。指標の値域が可換なので、
   `χ_p(gτg⁻¹)=χ_p(τ)`。指定値は変わらない。

完全分岐と慣性群の濃度には Mathlib の実定理を使う。
別の付値・分岐辞書を作らず、既存 DkMath の持ち上げと場所共役を再利用した。
上流から参考にした証明と改変内容はソースヘッダの blob とライセンスに記録している。

`a=-1` を選ぶと、元の Cofixed 直線上の作用は `P↦-P`。
`p≥5` なら非零の `p` 捩れ点はこれで動く。従って元の同じ底 `B` を動かす
慣性元が、全ての指定された `p` 上の付値環で得られる。

## 3. 還元核を全高次捩れの吸収先にする

同じ整数モデルの還元核を `H_A` とする。
その点は無限遠、または有限点で x 座標が極となる点である。
`valuationReductionKernel` はこの既存の実際の加法部分群を公開する。

`prime_power_reductionKernel_absorbs_at_p` は全ての `m≥0` について

\[
p^m y=0,\quad \tau\in I_A
\quad\Longrightarrow\quad \tau y-y\in H_A
\]

を証明する。`p` が付値環の単元であるという誤った仮定は使わない。

良還元の場合、既存の全点についての慣性差の還元核への所属がそのまま使える。
乗法還元の場合、既存の臨界中心・接方向によって慣性差は滑らかに還元する。
さらに、剰余標数 `p` の滑らかな節点点群に非零 `p` 捩れがないことから、
反復により非零の `p^m` 捩れもない。
実際の還元準同型を通じて、高次捩れの慣性差の還元は零となる。

コード: `DkMath/Lib/NumberTheory/EllipticNodalPrimePowerKernel.lean`。
一般ファイバーの標数零の除法多項式を剰余曲線へ流用していない。
有限剰余体も仮定せず、同じ臨界中心が剰余節点と接錐の非退化性を供給する。

分解群による `H_A` の安定性は、極という座標条件の保存から別に証明した。

## 4. 同じ交わりとして各局所段を定義する

\[
F_m=E[p^m]\cap H_A.
\]

`primePowerReductionFiltration A m` はこの実際の部分群である。
存在、濃度、巡回性を構造体のフィールドとして仮定してはいない。

底の濃度は高々 `p`。既存の安定直線から得る整な有限 `p` 捩れ点は還元核の外にあるので、
`H_A∩E[p]` は真部分空間となる。実際の `E[p]` の次元2と有限空間の濃度公式から

\[
\#F_1\le p.
\]

任意の `F_m[p]` は `F_1` に入る。有限 `p` 群の既存の判定により、`F_m` は巡回で
`#F_m` は `p^m` を割る。

## 5. 小さすぎる濃度は慣性作用の自明化を引き起こす

コード: `DkMath/Lib/Algebra/AbsorbingTorsionFiltration.lean`。

仮に `#F_m=p^e` で `e<m` とする。任意の `x∈E[p]` を、実際の倍写像の全射性で

\[
p^{m-1}y=x,\qquad y\in E[p^m]
\]

と持ち上げる。慣性差 `τy-y` は `F_m` に属するので `p^e` 倍で消え、
従って `p^(m-1)` 倍でも消える。作用と倍写像の可換性から

\[
\tau x-x=p^{m-1}(\tau y-y)=0.
\]

これは全慣性が `E[p]` を固定することを意味し、円分指標から得た非自明性に矛盾する。
従って `e=m`、すなわち

\[
\boxed{\#F_m=p^m,\qquad F_m\text{ は巡回}}
\]

となる。これは形式群の濃度公式を仮定する代わりに、倍写像、吸収、非自明な底の作用から
実際の群の濃度を確定する論証である。

## 6. 大域巡回段と局所段を同定する

大域安定な巡回 `K` が底 `B` を含むとする。
底を動かす慣性元 `τ` を一つ固定する。巡回生成元 `g` について `τg=ag` と書ける。
もし `p∣a-1` なら `τ` は `K[p]` を固定してしまうから、底の非自明性に反する。

従って `p^m` と `a-1` は互いに素。
`(a-1)g=τg-g∈F_m` と Bézout の等式から `g∈F_m`、従って `K≤F_m`。
両群は同じ濃度 `p^m` を持つため

\[
K=F_m.
\]

非自明な底の作用はこの証明の必須条件である。
恒等作用なら作用差は零部分群へ吸収されるが、`K` 全体が零部分群に入るわけではない。
この欠落が偽の一般化になることを有限群の回帰例で確認している。

## 7. 次段から実際の局所補直線へ

`F=F_(m+1)` とする。同じ `H_A` との交わりなので、次が証明できる。

- `K=F_m≤F`。
- `pF≤K`。
- `#F=p^(m+1)`。
- `F[p]≤K`。
- `F` は同じ `A` の分解群で安定。

前章の `residual_cyclic_extension_complement_of_local_subgroup` にこれらを渡す。
同じ商への `F` の像が `C` の補直線で、分解群による安定性も持つ。
その持ち上げは `F` に戻る。この接続により `p` 上の局所分裂入力を内部供給した。

さらに、塔の指数と捩れ指数がともに `N` なら、慣性差は `E[p^N]∩H_A=F_N=K` に入る。
`prime_power_pointAction_sub_mem_cyclic_tower_at_p` がこの吸収を証明する。
これを最終矛盾へ接続した

```lean
residual_cofixed_cyclic_tower_inertia_frobenius_impossible
```

では、`p` 上の吸収は追加仮定ではない。残る局所入力 `hbad` は
`q≠p` かつ `q=2` または `q∣abc` の住所だけである。
同じ定理には巡回段の存在・不変量と実際の Frobenius 関係を明示して残している。

## 8. 一般 `hno` に残る算術

今回閉じたのは、前章の未実装項目のうち **`p` 上の局所部分群の構成と局所分裂**。
次の工程は残る。

1. 悪い `q≠p` の住所で、必要な高次捩れ・逆像上の慣性吸収を証明する。
   `p` 上の還元核に入るという今回の定理を、他の素点にそのまま使うことはできない。
2. 円分体の類群・単数の omega 二乗固有成分の算術から、大域 extension 消滅を証明する。
3. 大域安定な補直線を持ち上げて、必要な長さの巡回塔を反復構成する。
4. 実際の Frobenius の関係式と、Eisenstein specialization の幾何学的入力を閉じる。

`hEXT`、局所部分群の存在、一般 `hno` を未証明の定数で補っていない。

数学的には前者から後者も得られる。しかし、Lean の API としては別々に公開するのが適切じゃ。

`EllipticTorsionFiniteLevel.lean` は、

\[ \ker\rho_n = \bigcap_{P\in E[n]}\operatorname{Stab}(P) \]

を実際に証明し、有限性を与えたときだけ有限個の開集合の共通部分として核の開性を導いている。

さらに Krull 位相の近傍基底を使い、有限次元・正規な中間体 \(L/K\) を得て、

\[ \operatorname{Gal}(\overline K/L) \subseteq\ker\rho_n \]

これは有限レベルへの因子化を実際に証明する定理であり、単なる構造体の宣言ではない。

ただし、Frey の \(E[37]\) に適用するには、その有限性を供給する証明が依然として必要じゃ。

## 3. 模範解答をさらに調べて分かったこと

今回、模範解答の [位数公式の証明本体](https://github.com/anthropics/fermats-last-theorem/blob/main/P2M/Sol/S_WeierstrassCurve_card_torsion_of_isAlgClosed.lean?utm_source=chatgpt.com) を、補題単位まで追ってみた。

すると、次の重要な分岐が見つかった。

模範解答には、

`card_nTorsion_prime`

という、素数次数だけを扱う補題 が存在する。

その本質は、

\[ p\text{ が素数},\quad \operatorname{char}K\ne p \quad\Longrightarrow\quad |E[p]|=p^2 \]

じゃ。

この証明は \(p=2\) と奇素数を分け、奇素数の場合には `card_nTorsion_odd_fibers` を使用する。

そこからさらに、倍写像のファイバーの個数、除法多項式の根と重複度に関する補題へ依存する。

つまり、模範解答の1,268行の全体を移植する必要があるとは限らない。

FLT で必要な素数 \(p\ge5\) だけに特化し、素数冪・一般合成数への拡張を一旦除外できる可能性がある。

ただし、幾何学的な主要補題は残るので、証明量が劇的に減るとまではまだ判断できない。

## 4. ここで、もっと小さな突破口がある

わっちが次に優先したいのは、実は位数の正確な計算より前の定理じゃ。

\[ \boxed{\operatorname{Finite}(E[p])} \]

有限性だけを先に、無条件で証明する。

これができれば、NOTE-011 の

`representationKernel_isOpen`

と

`factorsThroughFiniteLevel`

を、Frey 曲線について位数 \(p^2\) の仮定なしで適用できるようになる。

具体的には、除法多項式を用いる。

\(P=(x,y)\ne O\) が \(p\)-torsion 点なら、

\[ [p]P=O \quad\Longrightarrow\quad \Psi_p(x)=0 \]

という関係がある。

模範解答には、この対応に必要な `smul_formula_or_zero` と、除法多項式に関する補題がある。

これを現在の Mathlib API へ翻訳し、

1. \([p]P=O\) なら、その \(x\) 座標は所定の除法多項式の根である。
2. その多項式は零多項式ではない。
3. 非零多項式の根は有限個である。
4. 各 \(x\) 座標に対応する楕円曲線上の \(y\) 座標も高々2個である。

と証明できれば、有限性が得られる。

ここで必要なのは、除法多項式の根を正確に全部数えることではなく、根が有限であることだけじゃ。

これは NOTE-012 の先行課題として有望じゃ。

もちろん、倍写像と除法多項式を結ぶ補題の Mathlib 4.34.1 への移植自体はまだ未検証であり、簡単だと断言はできぬ。

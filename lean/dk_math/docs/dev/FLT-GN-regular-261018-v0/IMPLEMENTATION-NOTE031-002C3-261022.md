# NOTE-031 第7部: 同じ中心の接線方向と特異点への深さ

日付: 2026-10-22（JST）。**031-002C3として、接線方向の構成と節点近傍の座標分類を実装した。**
既存の臨界中心Cを保ったまま、整な二方向α,β、剰余体での分離、各方向の慣性固定を証明した。
有限点が滑らかに還元しないことをv(x−C.x)<1と同値にし、Y方向の近さも導いた。
中心へ近づかない同じ実際のFrey残余点は、C1の滑らかな還元の慣性固定へ接続した。

今回の区切りは接線方向と座標分類までである。
浅い点の傾き、同じ深さでの枝比較、零成分外のtorsion点の深さの漸化式は次に残る。
全残余点の固定、零成分部分加群、031-002全体、hcases・hno、一般FLTの完成ではない。

## 2. 接線方向の存在・整性・慣性固定

前章の節点量n=b₂+12C.xは単元である。その平方根rを取り、

\[
\alpha=(-a_1+r)/2,\qquad \beta=(-a_1-r)/2
\]

とおく。v(r)²=v(n)=1からv(r)=1となる。
2が単元なら、a₁の整性からα,βも整であり、その差rは単元となる。
二次式の和・積の関係を体内の恒等式で証明する。
この存在定理の仮定は係数a₁の整性と2の単元性であり、剰余標数2への一般化は今回含めない。

v(α−β)=1から、体内のα≠βだけでなく、実際の剰余体での二方向の非等号も従う。
中心の周りの方程式は、同じ方向を使って

\[
F(C.x+X,C.y+Y)=F(C.x,C.y)+(Y-\alpha X)(Y-\beta X)-X^3
\]

と書ける。実際の曲線上の有限座標なら、枝座標の積はX³−F₀となる。
F₀は前章で非零と証明したずれであり、曲線自体を二直線の和と同一視しない。

有理曲線の慣性元については、前章からC.xが固定されるのでnも固定される。
(α−β)²=nと単元平方根の符号分離から、α−βが固定される。
和α+β=−a₁も固定されるので、2を体内で約分してα,βをそれぞれ固定する。
付値保存の一般論や、方向の固定providerは仮定しない。

## 3. 剰余節点のX座標による分類

任意標数の体で、節点(x₀,y₀)以外のX座標を持つ曲線上の点は非特異である。
証明では、曲線上の特異点に対して成り立つ恒等式

\[
c_4x+(b_2b_4-18b_6)=0
\]

を使う。節点量の非零性からc₄=(b₂+12x₀)²≠0となり、二つの特異点の式の差でX座標を約分できる。
この証明は12を約分せず、素数3でも成立する。

また、同じX座標を持つ曲線上の点のY座標は二候補だが、特異点では負号による二候補が一致する。
従ってX座標が節点と等しければ、Y座標も節点と等しくなる。

これらを同じ付値環モデルと、前章の同じ中心の剰余特異性へ適用し、

```text
¬ HasSmoothReduction W (some x y h)
    ↔ A.valuation (x - C.x) < 1
```

を証明した。非整座標の点も`HasSmoothReduction`へ含めた定義を維持している。
左辺が成り立つと、非整なX座標の枝が排除される。右辺からも、中心の整性と足してXの整性を得る。
Yの整性は既存のモニック二次式の補題から供給する。

剰余X座標の一致は、その差が非単元であることと同値である。
剰余Y座標も上記の一意性で一致するので、v(y−C.y)<1も従う。
この分類は点のn倍零性・剰余標数の奇数性を要求しない。
一般ファイバーへの輸送ではW.map A.subtype=Vを明示し、同じ点と中心を保つ。

ここで扱うのは零成分に対応する**座標条件**である。
零成分部分加群の加法閉性や、既存の外部`InZeroComponentAt`との形式的な同定は実装していない。

## 4. 同じFrey Sourceへの接続

`exists_criticalCentre_directions_at_bad_prime`は、前章が供給した同じCにDを構成し、
中心・各方向の慣性固定と、同じずれのp乗の付値を同時に返す。
qがabcを割る奇素数であればよく、この幾何・算術の構成にq≠pは不要である。
Sourceの整数・共通因子・向き付け・曲線・点を変更していない。

`not_smooth_reduction_iff_depth`は、同じSourceの任意の有限点の滑らかでない還元を深さへ翻訳する。
`residual_fixed_of_not_close_to_centre`はq≠pを加え、実際の残余点Pについて、
P.val=some x y hと¬v(x−C.x)<1から同じ残余表現のσP=Pを証明する。
座標分類から滑らかな還元を供給し、C1へ渡す。固定や還元単射性を仮定するproviderは残らない。
無限遠点には有限座標を割り当てず、この入口では有限表示との等号を明示する。

v(x−C.x)<1の枝については今回の固定定理を適用しない。
接線方向が固定されることから、その方向に近い全てのtorsion点の固定はまだ導いていない。

## 5. 回帰

前章からの曲線y²+xy=x³+4x²+x、Δ=225、c₄=241を引き続き使う。
3上の任意の付値環で、前章の実在する中心から二方向を構成し、剰余値の分離・方向の慣性固定を検査した。
中心を仮定するだけでなく、中心と相異なる方向の組が実在する回帰も含む。

同じ任意の中心に対し、実際の非零2-torsion点(−4,2)はX,Yの両方向で中心へ近づく。
一方、滑らかに還元する実際の非零2-torsion点(0,0)はX方向で中心へ近づかない。
同じ曲線・同じ付値環・同じ中心で二つの枝を区別した。
(−4,2)は有理点でもあり、今回の分類は慣性がこの点を動かすことを意味しない。

尖点の二次式t²では、和・積が零となる二方向は一致することを`ZMod 3`で検査した。
節点の分離条件を落とさないための境界であり、Freyの節点例と混ぜていない。
同じSource 37の方向・深さの供給と、中心へ近づかない同じ実際の残余点の固定も型検査した。
SourceやFermat反例の存在は主張しない。

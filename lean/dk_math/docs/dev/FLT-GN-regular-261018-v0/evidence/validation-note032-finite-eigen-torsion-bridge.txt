Mathematical boundary:
For a finite abelian group, Fitting decomposition of an actual endomorphism gives a kernel
criterion: if its kernel modulo p is zero, its p-torsion kernel is zero. The finite kernel's
p-multiplication is proved surjective then injective. No natural torsion-to-quotient injection
is assumed. The finite action's weighted sum on a ZMod p module is genuinely chi-eigen.
An integer-coefficient lift on the original group agrees with that sum after the natural
quotient and acts by the group cardinality on original torsion eigenvectors. The defect
endomorphism |Gamma| id - S is invertible modulo p when that cardinality is a unit; applying
the Fitting criterion transfers quotient eigen vanishing to torsion. Finite A, Fintype Gamma,
NeZero p and cardinality invertibility remain explicit. Primality is not needed by the generic
bridge. Exactness on eigenspaces is not asserted.

The actual finite number-field class group is supplied by Mathlib's construction. The
same existing classGroupAction descends to ClassModP = Additive Cl / p Additive Cl. For the
same cyclotomic root field, Gal order p-1 and invertibility modulo p are proved internally.

weight-square eigen vanishing of this actual class quotient.

hval and quotient eigen vanishing hvanish. They derive the same classImage's hzero internally
and pass it to the existing same-constant, same-vector, nontrivial unit-class reduction.

## 2. 証明の核心：四状態帰納から慣性固定まで

今回、最も重要な依存経路は次の通りじゃ。

\[ \boxed{ \begin{aligned} &\text{楕円曲線の実際の点群演算}\\ &\downarrow\\ &\text{滑らか・同枝・反対枝・臨界側の四状態帰納}\\ &\downarrow\\ &v(X(P))^p=v(F_0)^j\\ &\downarrow\\ &\text{Frey 判別式の }p\text{ 乗構造}\\ &\downarrow\\ &\text{有理尺度による深さの正規化}\\ &\downarrow\\ &\text{慣性合同と差点の整性}\\ &\downarrow\\ &\rho_{E,p}(\sigma)P=P \end{aligned} } \]

ここには特に三つの評価点がある。

### A. 四状態帰納が実際に閉じている

`EllipticTorsionDepth.odd_torsion_depth` を確認した。

この定理は、実際の楕円曲線上の点 \(P\) について、

\[ [n]P=O \]

を仮定し、すべての自然数 \(m\ge1\) に対して \(mP\) の状態を帰納している。

状態は報告書通り四種類あり、それぞれに冪の等式が付属する。

ここで、

\[ L=v(x(P)-x_0),\qquad F=v(F_0)\big)^{※} \]

と置く。※**右辺の余分な閉じ括弧**を除けば、正確には \(F=v(F_0)\) じゃ。

帰納法の最終段では、\(nP=O\) から有限点の三状態を排除し、

\[ \boxed{ L^n=F^j,\qquad 1\le j,\qquad 2j < n } \]

を得ている。

また、初期点が臨界側の場合は、奇数倍と偶数倍が交互に異なる状態を取ることから、奇数位数との矛盾を証明している。

特に評価できる点は、ここでは \(n\) の素数性を必要としないことじゃ。

奇数 \(n\ge3\) で、\(n\) が付値環の単元なら成立する、より一般的な楕円曲線の局所定理になっておる。

### B. 判別式の \(p\) 乗構造が正確に使われている

悪い素数 \(q\) において、Frey 曲線の算術から、

\[ F=v(q)^{kp}, \qquad k=2v_q(abc) \]

を得る。

四状態帰納の結論

\[ L^p=F^j \]

と組み合わせると、

\[ L^p=v(q)^{kpj}. \]

付値群の非負元に対する冪の単射性から、

\[ \boxed{L=v(q)^{kj}} \]

が得られる。

この導出を `FreyUnramifiedAway.lean` の実際の証明で確認できた。

ここは重要じゃ。

単に判別式の付値が \(p\) で割れるという合同条件で終わらず、実際の点の深さを、有理数 \(q^{kj}\) の深さと一致させている。

これによってガロア慣性作用へ接続する道が開ける。

### C. 慣性合同から「点の等号」まで到達している

`EllipticDepthInertia.lean` の証明も確認した。

まず、

\[ b=q^{kj}\in\mathbb Q^\times \]

と置く。

有理数なので、任意の絶対ガロア元 \(\sigma\) に対して、

\[ \sigma(b)=b. \]

そこで、

\[ U=\frac{x(P)-x_0}{b} \]

を考える。

\(U\) は付値1の単元になるため、慣性による剰余合同から、

\[ \boxed{ v(\sigma x(P)-x(P)) < v(x(P)-x_0) } \]

が得られる。

ただし、座標差の付値が小さいことだけでは、二点が等しいとは限らない。

今回の証明は、そこを飛ばしていない。

1. 中心傾きの慣性合同から、\(\sigma P\) と \(P\) が同じ枝にあることを示す。
2. 差点 \(\sigma P-P\) も \(p\)-torsion であることを確認する。
3. 差点が有限なら、除法多項式からその \(x\) 座標が整になる。
4. 002C5 の鋭い枝比較によって、座標差の付値が元の深さと等しくなる。
5. 先ほどの厳密不等式と矛盾する。

したがって、

\[ \boxed{\sigma P=P} \]

となる。

これは座標合同から点の等号へ至る証明の鎖が、実際につながっているということじゃ。

## 3. 実装短縮の評価

報告書にある「torsion の整性を使った直接復帰」は、非常に合理的な変更じゃ。

模範解答側では、滑らかに還元する点全体について、零成分部分群を構築して加法閉性などを扱う。

今回の DkMath はその一般論をすべて構築する代わりに、必要な対象を torsion 点へ限定した。

\[ [n]P=O,\quad q\nmid n \]

という条件から、既存の除法多項式によって有限座標の整性を得られる。

すると、全倍点 \(mP\) も \(n\)-torsion なので、帰納法で使う整性を毎回供給できる。

つまり、

\[ \boxed{ \text{一般の零成分部分群の構成} \quad\longrightarrow\quad \text{実際の torsion 点の整性} } \]

という置き換えが成功した。

これは単なるコードの短縮ではない。

証明に必要な数学的対象を絞り込み、依存する理論を減らした という、形式化上の重要な成果じゃ。

一方、この実装から一般の零成分部分群の加法閉性が証明されたわけではない。その境界も実装報告書と一致している。

## 5. 回帰テストの価値

今回の回帰には、特に意味のある例が含まれていた。

\[ E:\quad y^2+xy+5y=x^3 \]

における、

\[ P=(0,0) \]

じゃ。

実際に、

\[ P\ne O,\qquad [3]P=O \]

が Lean で証明されている。

さらに、素数5での特異な還元、臨界中心と二方向の構成、そして

\[ \boxed{ v(X(P))^3=v(F_0) } \]

まで検査している。

これは重要な非空虚性テストじゃな。

抽象的な仮定がそもそも成立しないために定理が証明できてしまった、という状況を避けている。

別の点 \(R=(2,1)\) について、滑らかな還元と実際の和

\[ R+P=\left(-\frac54,-\frac{25}{8}\right) \]

も確認しておる。

ただし、この実例は四状態帰納と直接復帰の実在性を検査するものであり、Frey Source の整数反例が存在することを示すものではない。ここも正しく区別されている。

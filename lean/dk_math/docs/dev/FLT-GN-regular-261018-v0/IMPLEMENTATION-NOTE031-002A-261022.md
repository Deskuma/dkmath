## 2. 正規化しない付値環へ整数の算術を運ぶ

乗法的付値をvとする。Aがq上にある条件はv(q)<1である。
qと互いに素な整数zについて、Bezout等式uq+vz=1をAへ写すと、
qが非単元なのでzは単元となる。従ってv(z)=1である。
この証明はAをDVR・完備体・固定の正規化値群と仮定しない。

次に非零整数zをqの冪とqを割らない因子に分け、

\[
v(z)=v(q)^{\operatorname{padicValInt}(q,z)}
\]

を得る。z≠0を保持するのは、`padicValInt q 0=0`という便宜値を誤用しないためである。
左辺のv(0)=0と、便宜値をそのまま代入した右辺のv(q)⁰=1は異なる。

qの素数性とq∈A.nonunitsから、剰余体κ(A)の標数qも証明した。
整数qを剰余体に写すと零になることと、qが素数であることを使い、標数を外部入力に取らない。
整数のq進付値がnで割れる場合の、値群内でのn乗表示も公開した。

## 3. 一般核: 整な多項式の根に極はない

任意の順序付き値群への付値vについて、

```text
∀ i, v(coeff f i) ≤ 1
v(leadingCoeff f) = 1
1 < v(x)
────────────────────────────────
v(f(x)) = v(x) ^ natDegree(f)
```

を証明した。最高次項の付値はv(x)^degree(f)であり、全ての低次項とその和の付値は厳密に小さい。
非Archimedes的な和の等式から結論する。
従ってf(x)=0ならv(x)≤1である。
次数0の場合も含み、最高係数が単元である条件を省かない。

模範解答ではDVR上の良還元の補題の中にある議論を、
数体・離散性・楕円曲線の仮定を持たない`DkMath.Lib.Algebra`の核へ分けた。

## 4. 実際のtorsion点への適用

標数0の体K、付値環A、整モデルW、同じ一般ファイバーE=W.map A.subtypeを取る。
実際の点P=(x,y)がn倍零で、v(n)=1であるとする。
既存のDkMathの倍写像と除法多項式の比較から、

\[
\Psi\mathrm{Sq}_n(x)=0
\]

となる。整モデルから多項式の全係数の付値は1以下であり、
Mathlibの最高係数公式leadingCoeff(ΨSqₙ)=n²から最高係数の付値は1となる。
第3節を適用してx∈Aを得る。

yは同じ曲線方程式により、A上のモニック二次式

\[
Y^2+(a_1x+a_3)Y-(x^3+a_2x^2+a_4x+a_6)
\]

の根となる。付値環の整閉性からy∈Aを得る。
2で割る平方完成を使わないので、剰余標数2でもnが単元なら使える。
yの補題自体は標数0や等号判定のインスタンスを要求しない。

この整性は良還元を仮定しないので、乗法的還元側にも使える。
無限遠点に仮想的な有限座標を与えず、有限座標点の実際のn倍零条件を入力に取る。

## 5. 同じFrey Sourceから供給した結論

q≠2では既存の整数付値公式を第2節へ供給し、

\[
v(\Delta)=v(q)^{2p\,\operatorname{padicValInt}(q,abc)}
=\left(v(q)^{2\operatorname{padicValInt}(q,abc)}\right)^p
\]

を得る。整数判別式が非零であることも、256Δ=(abc)^(2p)と非零積から明示的に供給した。
ここでΔは同じ整数モデルの判別式である。2における正規化の分母を無視せず、q≠2を残す。
この算術等式はq=pでも成立する。

- q∤abcなら、同じA上のモデルをκ(A)へ写した実際の剰余曲線は楕円曲線となる。
- q∣abcかつq≠2なら、同じ整数モデルのc₄はAで単元付値1となる。
- p,qが異なる素数なら、pはAで単元となり、同じ実際のp-torsion点のx,yはAへ入る。

最後の整性にはq≠2も、p≥5も、bの偶数性も追加要求しない。
これらを暗黙のSource条件へ追加していない。

実際の慣性元σはAの剰余体上で恒等に作用する。
従って、整性を証明した同じ座標について、

\[
\sigma x-x\in A^{\mathrm{nonunits}},\qquad
\sigma y-y\in A^{\mathrm{nonunits}}
\]

を得る。ここは定義を別名で仮定したのではなく、分解群内の慣性の核と、
剰余写像の核=極大イデアルを使って証明した。
**この合同からσP=Pへの接続はまだ行っていない。**

## 6. 回帰で確定した境界

実在する楕円曲線

\[
y^2+xy=x^3+4x^2+x,\qquad \Delta=225
\]

と、同じ実際の点P=(-1/4,1/8)を構成した。
Pは非零で2P=0となる。
3上の任意の付値環では2が単元なので、今回の一般定理から両座標が整になる。
2上の任意の付値環ではx=-1/4は環に入らない。
曲線の楕円曲線性・点の非零性・2倍零・xの極を一つの回帰に束ねた。
整性から不分岐性を示す前段でも、p≠qという単元条件を落とせない。

また、3上で4と1が合同であっても4≠1であることと、整数0の付値の便宜値の境界を検査した。
合同例を慣性による二点の具体的な交換と主張してはいない。

Source 37では、3上の判別式・良い素数と悪い素数の両方の算術、
同じ有限torsion点の座標整性と慣性合同を型検査した。
q=p=37での判別式のp乗表示も検査し、算術とprime-to-qの整性の仮定を区別した。
これらはSource 37や整数反例の存在を主張しない。

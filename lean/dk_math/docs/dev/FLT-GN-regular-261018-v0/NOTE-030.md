とりわけ注目すべきは、模範解答の `S04` が単なる巨大な証明ではなく、次の三つの算術操作で構成されていることじゃ。

### 2.1 付値の下限を有限軌道から証明する

素数 \(p\ge5\) と位数 \(p\) の有理点 \(Q\) を取る。

まず、

\[ v_2(x(kQ))\ge0 \]

を示す。

ここで模範解答は、有限な点群軌道で付値が最小となる点を選ぶ。

もし最小付値が負なら、倍点公式によってさらに小さい付値の点が生じ、最小性に矛盾する。

その後、付値がちょうど0の場合を排除し、

\[ \boxed{1\le v_2(x(kQ))} \]

まで進む。

これは DkMath の言葉では、有限軌道における付値の降下不能性 として独立した定理にできそうじゃ。

### 2.2 有理2-torsion が作る付値の反射

ここが特に面白い。

DkMath の既存モデルは、

\[ E:\quad y^2+xy=x^3+a_2x^2+a_4x \]

という正規化を使っている。

この曲線には、

\[ T=(0,0),\qquad 2T=O \]

という有理2-torsion 点が存在する。

そして、\(x(P)\ne0\) なら、

\[ \boxed{ x(P+T)=\frac{a_4}{x(P)} } \]

が成立する。

ここで、

\[ \gamma=v_2(a_4) \]

と置くと、

\[ \boxed{ v_2(x(P+T)) = \gamma-v_2(x(P)) } \]

となる。

これは正真正銘の 付値の反射操作 じゃ！

さらに \(2T=O\) だから、

\[ 2(P+T)=2P. \]

この等式と倍点公式を組み合わせることで、上側の境界

\[ \boxed{ v_2(x(kQ))\le\gamma-1 } \]

を証明する。

ただし \(P+T\) 自体を位数 \(p\) の点とみなしてはならぬ。この区別は Lean でも必要じゃ。

こうして実際の楕円曲線から、

\[ \boxed{ 1\le v_2(x(kQ))\le\gamma-1 } \]

という、NOTE-029 の整数核が要求していた範囲が得られる。

### 2.3 楕円曲線の加法を整数漸化式へ投影する

次の恒等式が、実際の点群から整数列への橋になる。

\[ \boxed{ x(2P)(x(P)+2y(P))^2 = (x(P)^2-a_4)^2 } \]

さらに、適切な非零条件の下で、

\[ \boxed{ \begin{aligned} &x(P+Q)x(P-Q)\\ &\quad\cdot(x(P)-x(Q))^2\\ &=(x(P)x(Q)-a_4)^2. \end{aligned} } \]

これらの両辺に \(v_2\) を適用すると、NOTE-029 で完成した

`no_prime_shifted_valuation_orbit`

が要求する漸化式を得られる。

ここで重要なのは、単なる `ring` や `linear_combination` による恒等式の証明と、非零性を確保したうえでの付値計算を分けることじゃ。

## 3. DkMath 翻訳では、模範解答をそのままコピーしない

今回、既存 DkMath に一つ有利な資産が見つかった。

`DkMath/Lib/NumberTheory/FreyGapCubic.lean` には既に、

```
def normalized (A B : ℚ) : WeierstrassCurve ℚ :=
  ⟨1, (B - A - 1) / 4, 0, -(A * B) / 16, 0⟩
```

がある。

さらに、

```
S.curve_map
S.normalization.four
S.normalization.sixteen
```

も存在する。

つまり、模範解答が個別に行っている \(a_2\) の2進整性の証明は、既存の整数係数モデルから短く導ける可能性がある。

一方で、

\[ v_2(a_4)=p\,v_2(b)-4 \]

には \(a\) の奇数性、\(b\) の偶数性が必要じゃ。

ここは `Source` が持つ条件と、向き付け済みの反例から得る条件を分けなければならぬ。

このように、既存 DkMath の定理で代用できる場所を探し、模範解答からは本当に不足している数学だけを取り込む。 これが翻訳方針じゃな。

## 6. わっちが研究として注目していること

少し興味深い一致がある。

2-torsion の反射は、

\[ e\longmapsto\gamma-e \]

という操作だった。

一方、NOTE-029 の `FoldedValuationOrbit` では、

\[ \theta_k\equiv k\varepsilon\pmod{2\gamma} \]

の合同軌道を折り返し、

\[ e(k)=|\theta_k| \]

という形の構造を証明している。

両者は同一の写像ではない。しかし、境界で反射する作用と、周期軌道を折り返す作用 という共通の構造を持つ。

この対応は、今後の一般化研究に十分値すると思うぞ。

もっとも、いま優先すべきは抽象化ではない。

まず、実際の Frey 曲線から既存の整数核へ付値データを渡す。すると数学的な接続は、

\[ \boxed{ \begin{gathered} \text{Frey 有理点 }Q\\ \downarrow\\ \text{2進付値の上下界}\\ \downarrow\\ \text{楕円曲線の加法公式}\\ \downarrow\\ \text{整数漸化式}\\ \downarrow\\ \text{NOTE-029 FoldedValuationOrbit}\\ \downarrow\\ \bot \end{gathered} } \]

となる。

この経路が完成すれば、NOTE-029 の `hrat` を実際に供給できる。ただし、局所慣性の `hcases` と cofixed 不存在の `hno` は、依然として別の証明を必要とする。

最初の一手は NOTE-030-001、2進付値の一般演算補題を DkMath.Lib に固定すること。

巨大な模範解答を丸呑みするのではなく、ひとつずつ数学の Core に還元していく。

この賢狼、今回もその方式で進めるのが最善と見ておるぞ。🐺🍎

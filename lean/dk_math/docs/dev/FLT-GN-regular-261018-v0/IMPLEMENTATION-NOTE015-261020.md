# NOTE-015: 正確な根ファイバー計数、直線の外の点、指数2の次元2

日付: 2026-10-20。NOTE-015の計画を三つに分けて実装した。

| 工程 | 今回の結果 | 境界 |
| --- | --- | --- |
| 奇数nの正確な計数 | 実際の点数が1+2r | rはΨSqₙの相異なる根の数。次数ではない |
| 一次元を排除する入力の比較 | 次元2 ⇔ pより多い点 ⇔ 指定した非零点の直線の外に点がある | 一般の奇素数で入力の供給は未実装 |
| 奇素数の根への還元 | 次元2 ⇔ (p−1)/2<r | 37では18<rが残る |
| 指数2 | r=3、実際の点数4、F₂次元2、直線の外の第二の点 | 標数0の楕円曲線で証明。一般の奇素数へは拡張しない |

以下、幾何学の座標体は標数0の体K、根と点はその代数閉包上で考える。
残余空間の係数体Fₚの標数pとは区別する。

## 1. 相異なる根と実際の点の正確な分割

`EllipticTorsionRootCount.lean` の `divisionRoots E n` は

```lean
((E.baseChange (AlgebraicClosure K)).ΨSq (n : ℤ)).roots.toFinset
```

である。多重度を捨てた有限集合であり、`divisionRootCount E n` はその要素数rである。
多重度込みの `roots.card` や次数n²−1とは別の量として定義した。

まずn≠0について、同じ実際のn倍写像の核に対し

\[
|E[n]|=1+\sum_{x\in\mathrm{divisionRoots}(n)}|\mathrm{affineXFiber}(x)|
\]

を証明した。有限座標ファイバーはNOTE-013と同じ `xRep = ![x,1]` である。
無限遠点の第二成分は0なので、どの有限ファイバーにも入らない。
異なるxのファイバーは交わらず、有限和を正確に数えられる。
torsion点から根への方向にはNOTE-012、根の上の実際の非特異点からtorsionへの方向には
NOTE-014の `torsion_some_iff_coordinate_root` を使う。
核とこの有限被覆の部分型を同値にして `Nat.card` を運ぶため、位数公式の外部入力はない。

この和の公式自体には楕円曲線性を要求しない。
根の上に実際の非特異点がない場合は、空ファイバーを0点として数える。
n=0ではΨSqが零多項式になり、同じ有限被覆は使えないので除外する。

## 2. 奇数では根ごとにちょうど二点

楕円曲線性があれば、NOTE-014と同じように根xからyを取り、非特異性を供給して
`exists_torsion_over_root` により非零torsion点Pを得る。
同じxのファイバーは `{P,−P}` に等しい。

奇数n=2k+1でP=−Pなら2P=Oとなり、nP=k(2P)+P=Pである。
nP=OもあるのでP=Oとなり、非零性に反する。従ってこの二点は異なる。
この部分の `torsion_ne_neg_of_odd` は標数0を使わない群論的な補題として公開した。

各根のファイバーが2点であることと正確な分割から、

```lean
card_torsion_eq_one_add_twice_roots (hn : Odd n) :
  Nat.card (Torsion E n) = 1 + 2 * divisionRootCount E n
```

を得る。標数0・楕円曲線性を要求するが、素数性は不要であり、n=1にも適用される。
一般の奇数指数で根の数rを計算したとは主張しない。

## 3. 次元2を決める入力の交換

`EllipticTorsionDimensionCriteria.lean` は、素数pについてNOTE-014の位数pかp²という二者択一を使う。
p<|E[p]|さえあればpの候補が消え、位数p²が確定する。
実際の有限Fₚ空間の濃度公式へ戻すと次元2を得る。
旧来の `finrank_eq_two_of_card_sq` を呼ぶ経路にはしていない。

指定した非零点Pの直線は `Submodule.span (ZMod p) {P}` であり、その次元は1である。
直線の外の点Qがあれば、この直線は全空間の真部分空間なので全体の次元は1より大きい。
NOTE-013の上界2により、次元は2となる。
逆に次元2ならPの一次元直線は全体ではなく、その外にQが存在する。
この同値ではP≠0を保持する。ガロア安定性は要求も結論もしない。

奇素数では前節の正確な計数へ接続し、自然数の除算を使って

\[
\dim E[p]=2
\iff p<|E[p]|
\iff (p-1)/2<r
\iff \exists Q\notin\operatorname{span}_{\mathbb F_p}\{P\}
\]

を得た。これは残る入力を交換する証明済みの同値である。
一般の奇素数について最後の存在や根の下界を供給したものではない。
37では18<rが未供給であり、1369個の実際の点の存在も、この実装からはまだ得られない。

## 4. 指数2では幾何学的入力を供給して閉じる

`EllipticTwoTorsionRank.lean` は、指数2を奇数の二点ファイバー公式へ入れない。
二倍零の点はP=−Pなので、根の上のファイバーはちょうど1点である。

Mathlibの `ΨSq_two` と `Ψ₂Sq_eq` によって、除法多項式を実際の2-torsion三次式へ同定する。

\[
\Psi^{\mathrm{Sq}}_2=4X^3+b_2X^2+2b_4X+b_6.
\]

その三次判別式は `twoTorsionPolynomial_discr` により16Δとなる。
標数0の楕円曲線では非零なので、代数閉包で分解する三次式について
`Cubic.card_roots_of_discr_ne_zero` が**相異なる**根がちょうど3個あることを保証する。
次数が3であることだけでなく、判別式によって重複を除いている。

正確な分割に戻すと |E[2]|=1+3=4となる。
その後、濃度公式から2ᵈ=4を得て、`finrank_torsion_two` によって次元2を証明した。
この位数・次元は今回の幾何学が供給し、追加の仮定として受け取らない。
標準torsionBy表示の次元2も、点を保つ線形同型で運ぶ。

従って任意の非零2-torsion点Pについて、その直線の外に実際の第二の点Qが存在する。
点を人工的なF₂²の元へ置き換えることなく、元の実際の曲線の核の中でこの存在を得た。

## 5. Frey接続・回帰・監査

`FreyResidualDimensionCriteria.lean` は同じ `Source.rationalCurve` の楕円曲線性を供給する。
奇数の正確な点数、素数の次元判定、指数2の位数4・次元2・第二の点を同じSource上へ運ぶ。

すべての新規Leanファイルにimport直後の `#print "file: モジュール名"` を置き、
`DkMath.Lib`、`DkMath.FLT`、`DkMathTest` の公開入口へ接続した。

回帰は名前付き8補題と3例である。実在するSource 2の(4,3,5)の同じ曲線について、
E[2]の相異なる根3個・位数4・次元2を確認し、既存の非零点 `twoPoint` の直線の外にQを得る。
同じ曲線のE[37]では正確な計数と18<rへの還元を確認する。
n=1では根は0個、指数2には奇数の1+2rを適用できないことも検査する。

監査では全31公開宣言と8名前付き回帰補題の公理を検査する。

条件付きの旧位数・次元定理、FLT終点、外部未移植宣言、類群・Kummer providerへの迂回を禁止する。
今回、新しい外部コードの移植は行っていない。既存のNOTE-012〜014とMathlibのAPIを組み合わせた。

一般の奇素数に対する根の下界、正確な位数p²と次元2、GL₂実現、Weil対・行列式、
ガロア不変直線の不存在・既約性、局所慣性・Artin導手、一般FLT・FLT37の終点は残る課題である。
指数2の次元2はこれら一般の結論と区別する。

## 2. 還元が単射になる理由

[EllipticSmoothTorsionReduction.lean](../../../DkMath/Lib/NumberTheory/EllipticSmoothTorsionReduction.lean)
に3定理を実装した。全ての公開定理に `[DkMath.Lib]` の昇格マーカーを付した。

滑らかなn捩れ点Pが無限遠へ還元すると仮定する。
Pが有限点なら、nが単元であることから既存の除法多項式による整性定理で両座標が整となる。
滑らかな還元の定義から剰余点は有限の非特異点なので、無限遠へ還元することはない。
従ってPは零点である。この段階で剰余判別式の非零性を仮定しない。

次に、同じ零成分のn捩れ点P,Qの還元が一致するとする。
既存の `zeroComponentReduction` は実際の加法準同型なので、

```text
red(P−Q) = red(P)−red(Q) = 0
n(P−Q) = 0
```

を得る。差も同じ零成分に属するので、前の零点判定からP−Q=0となる。
これが還元の単射性である。座標空間へ仮の線形還元を置いた証明ではない。

最後に、還元像が剰余n捩れに含まれることと単射性を合わせる。
剰余側の有限性から始域の有限性を得てからncardを比較するため、
無限集合のncard=0という既定値を位数上界と取り違えない。

## 3. 同じ節点の剰余Frameを供給する

[EllipticNodalTorsionBound.lean](../../../DkMath/Lib/NumberTheory/EllipticNodalTorsionBound.lean)
に3定理を実装した。

既存の同じ中心Cと分離方向Dを剰余へ写す。
中心の剰余特異性から二偏微分の零を取り出し、方向のモニック二次式の根条件を写す。
Dの剰余分離と和の関係から、剰余方向αがもう一つの方向−a₁−αと異なることを供給する。
これにより既存の `EllipticNodalTorsion.NodalTorsion.Frame` が、
同じ剰余曲線・同じ中心・同じ方向で成立する。

そのFrame上では節点比が滑らかな点の加法を乗法へ写す。
剰余n捩れは1のn乗根へ単射に写るので、高々n個である。
ここで使う所有定理は `finite_and_ncard_torsion_le` であり、
剰余標数とnが一致する場合だけの捩れ消滅定理とは区別した。

前節の還元の単射性から、一般ファイバーの滑らかなn捩れも有限で高々n個となる。
nの素数性、付値の離散性・完備性、剰余体の代数閉性は必要ない。

consumer向けには、元の曲線Vとモデル一致 `W.map A.subtype=V`、
同じ点を保つ単射 `f:T→V.Point` を入力に持つ位数上界APIを設けた。
fの像の滑らかな還元とn倍零性を保持し、Tの有限性を外部へ要求しない。

## 4. 同じFrey Sourceで零成分外の点を得る

[FreyDyadicZeroComponent.lean](../../../DkMath/FLT/FreyDyadicZeroComponent.lean)
に10定理を追加した。

003Aから同じ2上のモデルのC,Dを得て、pが単元であることを既存算術から供給する。
E₀[p]から一般ファイバーの点への写像は、二重のSubtype.valで同じ実点を取り出す写像である。
この単射と前節の上界から

```text
|E₀[p]| ≤ p
|E[p]| = p²
```

を得る。第二式は同じSourceの `residual_card_prime_sq` を使う。
p≥5なのでp²>pとなり、E₀[p]は真部分空間である。
既存の所属条件との同値から、同じSource・同じモデルで滑らかに還元しない実際のp捩れ点を得る。

この点の存在を003Aの定理へ渡すと、任意の2上の住所で同じ残余表現の慣性作用が非自明となる。
`residual_exists_dyadic_inertia_ne` には中心・方向・中心固定・外側の点のproviderが残っていない。
これは032-002の完了であり、一般FLTや無条件hnoの完了とは区別する。

## 5. 零成分は正確に一次元・位数p

003Aの中心・方向・固定性を使い、全慣性変化量が同じE₀[p]に入る吸収を供給した。
非自明慣性元τと点Pについて、

```text
d = ρ(τ)P−P ≠ 0, d ∈ E₀[p]
```

なのでE₀[p]は非零である。
有限体上の位数公式 `|M|=p^(dim M)` と上界≤pからdim M≤1、
非零性からdim M>0となり、dim E₀[p]=1、|E₀[p]|=pを得る。
この下界は、零成分外の点の存在から非自明慣性を供給した後で証明する。
零成分の一次元性を仮定して外側の点を得る循環にはしていない。

`residual_no_cofixed_line_of_branch_swap_at_two` の残る幾何入力は枝交換だけである。
零成分外の点と非自明慣性は既存の同じSourceの証明から供給する。
さらにEven S.bの下では `residual_isIrreducible_of_branch_swap_at_two` が031-005へ接続する。
枝交換の存在は003Cへ残すので、これらはまだ条件付きの終点である。

## 6. 境界と非Frey曲線の例

[独立境界資料](evidence/Note032NodalTorsionBoundary.lean) は登録した通常テストと同じ本体である。

単元条件の境界には、整数曲線

```text
y²+xy=x³+4x²+x, Δ=225
P=(−1/4,1/8)
```

を使った。Pは実際の非特異点で−P=P、2P=0、P≠0となる。
2上ではx座標が極を持つので滑らかな零成分に属し、無限遠へ還元する。
判別式225は奇数であり、この現象は良還元でも起こる。
従って位数の単元性は還元単射性から取り除けない。

正の例には、前工程と同じ係数の実際の楕円曲線

```text
y²+xy=x³+x²+2x, Δ=−412, c₄=−71
```

を使った。任意の2上の住所で中心・方向を構成し、3の単元性を供給した。
実際の3捩れの位数9と、滑らかな捩れの上界3を比較して、零成分外の点を得た。
この例はFrey Sourceの存在を仮定しない。

[Sourceスモーク](evidence/Note032DyadicZeroComponentSmoke.lean) の5定理では、指数37の同じSourceについて
零成分の位数・次元・真性、外側の点、非自明慣性、枝交換だけを残したhnoと既約性を確認した。
Source37の存在は主張しない。

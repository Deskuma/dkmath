## 2. 短縮できた証明経路

前章では、nが付値環Aの単元なら、同じ整モデルの実際のn-torsion点の有限座標がAへ入ることを証明した。
今回はこの結論をP,Qだけでなく、**差点P−Qにも適用する**。

P,Qが同じ剰余座標を持ち、P≠Qと仮定する。
Pと−Qを結ぶ接線または割線を考える。
二点は剰余曲線上で互いに逆となるため、良い剰余曲線の非特異性から、その傾きλはAを外れる。
和のx座標は、

\[
x(P-Q)=\lambda^2+a_1\lambda-a_2-x(P)-x(Q)
\]

である。λ²の項が支配するので、このx座標もAを外れる。
しかしnP=nQ=0からn(P−Q)=0であり、前章の整性に反する。従ってP=Qとなる。

この経路では、全ての点の還元写像の加法性、形式群のn倍帰納法、有限DVRへの制限を構成する必要がなかった。
その代わり、実際の差点のn倍零性と座標公式を直接検査した。
公開したのは**有限torsion座標の還元の単射性**と慣性固定であり、
全点群から剰余点群への加法準同型を今回構成したという主張ではない。

## 3. 接線と割線の三つの場合

極の補題は、座標の一致や分母の零を省略せずに分岐する。

1. x座標が同じ場合は接線を使う。Y方向の偏微分が非単元なら、良還元の非特異性からX方向は単元となる。
   接線の分母は非単元、分子は単元なので、傾きはAを外れる。
2. x座標が異なり、y座標の差が非単元でない場合、割線の分子は単元、分母は非単元となる。
3. 両座標の差が非単元の場合、二つの曲線方程式の差を因数分解する。
   良還元で消えない偏微分を分子に持つ別の割線表示へ変え、同じ結論を得る。

これらは剰余標数2でも有効であり、平方完成による2の逆元を要求しない。
分母の非零性はP−Q≠0の条件と曲線方程式から証明する。

## 4. 合同から実際の慣性固定へ

有理曲線Eと同じ付値環モデルWについて、W.map A.subtype = E.baseChange ℚ̄を明示する。
実際のE[n]の点Pと、その同じ座標作用によるσPを取る。
座標作用は加法準同型なのでn(σP)=0も得られる。

慣性元はAの剰余体を固定するため、両座標の変化量はAの非単元となる。
第2節の単射性を使ってσP=Pを得る。無限遠点は最初から固定されるものとして別に処理する。
有限座標を持たない点へ便宜的な座標を割り当てていない。

Freyへの適用では、前章の`valuationModel_map`と`valuation_reduction_isElliptic`からモデルと良い剰余曲線を供給する。
p≠qからpの単元性を供給するので、Freyの公開定理にはモデル・良還元・単元性・単射性のproviderは残らない。
全点の固定から、N上の点の固定と、全変化量0のNへの所属が直ちに従う。

## 5. 回帰で検査した実在する曲線と境界

曲線y²=x³−xの判別式は64であり、実際のE[3]の位数は9である。
5上の任意の付値環とその任意の慣性元について、同じ9点の全てが固定されることを証明した。
空の点群や零だけの例による回帰ではない。

一方、前章の曲線y²+xy=x³+4x²+x、判別式225では、

\[
P=(-1/4,1/8),\qquad Q=(-4,2)
\]

は異なる実際の2-torsion点である。3上では、

\[
x(P)-x(Q)=15/4,\qquad y(P)-y(Q)=-15/8
\]

がともに非単元となり、同じ剰余座標へ写る。
2は3上で単元であるにもかかわらず、悪い還元では単射性が破れる。
この例は良還元条件の必要性を示し、幾何学的な合同を点の等号と同一視しない回帰となる。
これらの回帰は、ある慣性元がこの二点を交換するとは主張しない。

同じSource 37の良い素数3での実際の残余点の固定も型検査した。
Source 37やFermat反例の存在を主張するものではない。

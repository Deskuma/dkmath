# NOTE-032 教科書: 円分指標の核上に現れる実際の有限加法指標

日付: 2026-11-02。
前章: [非共鳴住所での慣性吸収](TEXTBOOK-N032-NONRESONANT-INERTIA-261101.md)。
実装: `DkMath/Lib/RepresentationTheory/FixedLineExtension.lean` と
`DkMath/FLT/FreyCyclotomicExtensionCharacter.lean`。

今回は、同じ逆像商の大域分裂を妨げる有限加法指標を構成した。
`p` 上の局所分裂、`p` 外の不分岐性、開核を、この具体的な指標へ接続する。
大域分裂しないなら、その一つは実際に位数 `p` の値域へ全射する。
その大域的な消滅を類群・単数から証明する工程は残る。一般 `hno` は未完成である。

## 1. 同じ巡回段から出発する

`p≥5`、同じ `S : Frey.Source p` の Cofixed 直線 `L`、その点群像 `B` を固定する。
大域安定で巡回な同じ部分群 `K` が

\[
|K|=p^m,\quad m\ge1,\quad B\subseteq K
\]

を満たすとする。この段の存在は入力である。

既存の実装は、同じ点群から

\[
V=(p^{-1}K)/K,\qquad C=\operatorname{image}(E[p]\longrightarrow V)
\]

を構成し、`dim V=2`、`dim C=1`、`|C|=p`、`C` の点ごとの大域固定性を供給する。
同じ表現 `ρ` と実際の円分指標 `χ=χ_p` について

\[
\rho(g)v-\chi(g)v\in C
\]

が全段で成立する。新しい `residual_cyclic_extension_quotient_character` は、
この式を通常の `ZMod p` のスカラーで公開する。

## 2. 安定な補直線を、指標核の作用へ還元する

まず一般の体 `k` と群 `G` に対する線形代数を証明する。
`ρ` が `C` 上で恒等、`V/C` 上で指標 `χ` として作用するとする。
`χ(t)≠1` となる元 `t` を一つ固定し、

\[
f=\rho(t)-\chi(t)\operatorname{id},\qquad D=\ker f
\]

を定義する。`f(V)⊆C` で、`c∈C` なら `f(c)=(1-χ(t))c`。
従って `C∩D=0` であり、任意の `v` は

\[
c=(1-\chi(t))^{-1}f(v),\qquad v=c+(v-c),\quad v-c\in D
\]

と分解できる。これは実際の補部分加群の構成であり、補直線の存在を仮定していない。

もし `ker χ` が `V` 上で自明に作用すれば、指標値が同じ二元は同じ作用を持つ。
`χ(gt)=χ(tg)` より `ρ(g)` と `ρ(t)` は可換になり、上の `D` は全群で安定になる。

逆に、安定な補部分加群 `D` があれば、`χ(g)=1` の元について
`ρ(g)d-d` は `C` と `D` の双方に入り、零になる。`C` 上でも恒等なので全 `V` を固定する。
従って

\[
\boxed{\text{大域安定な補部分加群が存在}\iff\ker\chi\subseteq\ker\rho}.
\]

`FixedLineExtension.stable_complement_iff_kernel_trivial` がこの同値を証明する。
Frey 側では指定した `p` 上の円分慣性の全射性から `χ(t)=-1≠1` を内部供給する。
`p≥5` の条件を落としていない。

## 3. 指標核上の作用差は加法的になる

`Γ=ker χ` とし、`u∈Γ` に対して

\[
A(u)=\rho(u)-\operatorname{id}
\]

を考える。`A(u)` の像は `C` に入り、`C` 自体では零になる。
従って `A(u)A(w)=0` であり、

\[
A(uw)=A(u)+A(w).
\]

`deviationHom` はこれを `Γ →* Multiplicative (Module.End k V)` として実装する。
`Multiplicative` は加法群の和を乗法記法で読むための型であり、値が乗法的な行列になるという意味ではない。

さらに同じベクトル `v∈V` を固定すると

\[
a_v:\Gamma\longrightarrow(C,+),\qquad a_v(u)=\rho(u)v-v
\]

が実際の加法指標になる。これが `deviationAt`、Frey 側では
`residualCyclicExtensionCharacter` である。代表点や曲線を選び直していない。
全ての `a_v` が消えることは `ker χ⊆ker ρ` と同値になる。

## 4. 共役の重みは逆指標である

商でのスカラー公式により
`ρ(g⁻¹)v-χ(g⁻¹)v∈C`。`u∈Γ` はこの差を固定するので

\[
\rho(u)\rho(g^{-1})v-\rho(g^{-1})v
=\chi(g^{-1})(\rho(u)v-v).
\]

両辺に `ρ(g)` を作用させ、右辺が `C` に入ることを使うと

\[
\boxed{a_v(gug^{-1})=\chi(g)^{-1}a_v(u)}
\]

を得る。`deviation_conjugate` と `deviationAt_conjugate` はこの向きを形式化している。
ここでの値域は固定直線 `C` であり、まだ `μ_p` 値の Kummer 指標ではない。
模範解答の omega 二乗固有成分へ進むには、根の空間への同定・捩り・双対化と
実際の数体の拡大を構成する必要がある。逆指標の式だけを、その Kummer 接続の完成と扱わない。

## 5. 開核と局所消滅を内部供給する

元の `E[p^(m+1)]` の表現は開核を持ち、その開核は同じ逆像商表現の核に入る。
さらにその指標核への逆像は各 `a_v` の核に入る。
部分群の開性の単調性から、全ての `a_v` は開核を持つ。
`residual_cyclic_extension_character_kernel_isOpen` は、開核を追加仮定にしない。

`p` 上では前々章の実際の局所補直線を使う。
分解群内の `χ=1` の元は、固定線とその補直線の双方を固定するので

\[
a_v|_{\Gamma\cap D_A}=0\qquad(A\mid p)
\]

を得る。これは `Γ∩I_A` 上の消滅より強い。

`q≠p` では前章の商表現の不分岐性から

\[
a_v|_{\Gamma\cap I_A}=0
\]

を得る。ただし、共鳴する悪い住所
`q≥5`、`q≠p`、`q∣abc`、`q mod p=±1` での逆像上の吸収 `hbad` は依然明示入力である。
非共鳴、2・3、良還元の住所は既存の実際の定理で供給される。
今回証明したのはこれらの絶対 Galois 群内の部分群条件であり、
数体の各素点の慣性群との同定を追加で済ませたという主張ではない。

## 6. 非分裂なら位数 `p` の全射指標が実際に存在する

`|C|=p` より、各指標の像の濃度は `p` 以下である。
さらに Lagrange の定理でその濃度は `p` を割るので、`1` または `p`。
大域補直線が存在しなければ、上の同値によりある `v,u` で `a_v(u)≠0`。
その像の濃度は1ではないため `p` となり、`a_v` は `C` へ全射する。

```lean
residual_cyclic_extension_nonsplit_has_surjective_character
```

はこの有限商を実際に取り出す。従って、類群・単数の次の算術工程で排除すべき対象は
「同じ値域へ全射し、上記の共役則・開核・局所消滅を持つ指標」と特定できる。

## 7. 指標族の消滅から同じ巡回塔の次段へ

```lean
residual_cyclic_extension_splits_iff_character_trivial
residual_cyclic_tower_step_of_character_trivial
```

第一の終点は大域分裂と指標族の消滅の同値であり、消滅を仮定しない。
第二の終点は消滅 `hzero` を明示入力として、上で構成した大域補直線を持ち上げる。
同じ点群内の次段 `K'` に対して、包含、濃度 `p^(m+1)`、巡回性、捩れ指数、
大域安定性、`K'[p]⊆K` を既存の実際の商の計算から供給する。
`hzero` の算術的証明と、必要な長さまでの反復は今回実装していない。

## 8. 回帰例と残件

`F₅²` 上の行列 `[[1,b],[0,a]]` からなる位数20の群をテスト内で構成する。
水平軸は固定直線、商指標は `a` であり非自明。
対角部分群では垂直軸が安定な補直線になるが、剪断元 `[[1,1],[0,1]]` は
指標核に入りながら非自明に作用するため、全群に安定な補直線は存在しない。
構成した指標が水平軸へ全射することも確認する。
`a=2` の対角元での共役は剪断の値を `2⁻¹=3` 倍にする。

これは局所分裂から大域分裂を推論する誤りを避ける有限群例であり、
必要な数論的局所条件を全て満たす Galois 拡大を構成する例ではない。

残る工程は、共鳴する悪い住所・Mazur/Eisenstein specialization の幾何、
この具体的な指標と円分体の類群・単数の固有成分の接続と消滅、
大域塔の反復、最終矛盾に用いる実際の Frobenius 関係と指数の選択である。
一般 `hno`、普遍的な extension 消滅、既存 FLT 終点を仮定として追加していない。

検証記録: `evidence/validation-note032-cyclotomic-extension-character.txt`。

## 9. 次章: 最終矛盾の `hCH` 入力を除去

[Frobenius 固定点の計数](TEXTBOOK-N032-FROBENIUS-FIXED-COUNT-261102.md)で、
同じ良還元素数の実際の点数を塔の指数に固定し、作用差の核・像の個数と
実際の良還元単射を組み合わせる最終矛盾を実装した。
一般の Frobenius 特性方程式そのものは未実装だが、この新経路に `hCH` は不要。
上記の残件のうち、その関係式の構成は新経路の必須入力から外れた。
共鳴する悪い住所、指標消滅、必要な長さの巡回塔とその幾何学的入力は残る。

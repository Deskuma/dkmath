# DkMath Primitive Structure — Existing Asset Map

Date: 2026-08-22

Source of truth for this inventory: `develop` at project start.

The purpose of this document is to avoid creating a second theory beside
existing DkMath code.  It records which current modules already own the main
pieces of the proposed Primitive Structure and which gaps remain.

## 1. Cosmic Formula algebraic source

### Module

```text
DkMath.CosmicFormula.CosmicFormulaBinom
```

Current relevant declarations include:

```lean
G
Big
Gap
Body
mul_G_eq_GZ
Body_eq_GZ
big_is_body_and_gap
cosmic_id
cosmic_formula_binom
```

The current `CommRing` layer already defines

$$
\operatorname{Big}(d,x,u)=(x+u)^d,
$$

$$
\operatorname{Gap}(d,u)=u^d,
$$

and a Body whose normalized form is the canonical `GZ` kernel.  In particular,
`big_is_body_and_gap` proves the generic additive decomposition.

### Primitive-project interpretation

This is the algebraic source layer.  It already supports rings such as `ℝ` and
`ℂ`; prime-specific meanings must therefore be added only by lower arithmetic
specializations.

### Initial action

Do not duplicate these definitions in a Primitive namespace.

Potential future work:

- thin square-degree specialization;
- explicit unit-one specialization;
- map/naturality wrappers if current generic theorems do not already expose
  the needed form;
- unit-transport wrappers.

## 3. Finite-prime escape arithmetic

### Module

```text
DkMath.Hackathon.FinitePrimeEscape
```

Current declarations:

```lean
FreshPrimeFactor
prime_dvd_product_add_coprime_not_mem
exists_fresh_prime_factor
```

The local theorem

```lean
prime_dvd_product_add_coprime_not_mem
```

has an important strength: for **any selected prime divisor** `q` of the
product-plus-offset target, the theorem proves `q ∉ S` under the coprimality
hypothesis.

The existential theorem then selects one such prime divisor and packages it as
`FreshPrimeFactor`.

### Primitive-project interpretation

This is a concrete **Escape provider**.

It should not become the definition of Primitive Structure.  Instead the
Primitive facade should consume it through semantic support/direction APIs.

### Important distinction

The provider supplies a target outside a finite generated world, but it does
not automatically place that target inside an arbitrary local interval such as
a consecutive-square shell.

That localization gap is exactly why finite-prime escape does not by itself
prove Legendre.

## 6. PrimitiveBeam origin layer

### Module

```text
DkMath.NumberTheory.PrimitiveBeam
```

Core declaration:

```lean
PrimitivePrimeFactorOfDiffPow
```

Selected current theorems:

```lean
exists_primitive_prime_factor_as_prop
primitive_prime_not_dvd_boundary
primitive_prime_dvd_GN
primitive_prime_padic_eq_GN
primitive_prime_GN_ne_zero
primitive_prime_padic_bound_diff_of_noLift_GN
primitive_prime_padic_bound_diff_of_squarefree_GN_local
primitive_prime_dvd_GN_body
primitive_prime_in_beam_for_body_one
```

### Primitive-project interpretation

This module supplies the main **Origin** coordinate for difference powers.

The predicate means a prime direction appears at exponent `d` but did not
appear in lower positive exponents.  Existing theorems then show that, for
`d > 1`, the primitive prime does not belong to the boundary and is carried by
the GN / Beam factor.

This is not definitionally the same as finite-set freshness.

The facade should preserve both notions and document their relationship rather
than merge them.

## 12. Gaps discovered by the current inventory

### Gap P1 — support disjointness

Need a reusable semantic notion for:

```text
all old prime directions are absent
```

This is stronger than `FreshPrimeDirection` and is the key Legendre entry API.

### Gap P2 — generic square Body arithmetic closure

Need a NumberTheory theorem expressing:

$$
1<m\le P^2+2P
$$

and `m` composite imply a prime divisor at most `P`.

Equivalent prime-closure wrapper:

$$
\left(\forall q\le P,\ q\text{ prime}\Rightarrow q\nmid m\right)
\Longrightarrow m\text{ prime}
$$

inside the certified Body.

This theorem should not mention Legendre.

### Gap P3 — square-anchored support escape

Need the Legendre application predicate/provider:

$$
\exists r,\ 1\le r\le2n
$$

with all prime directions at most `n` absent from `n^2+r`.

The universal existence theorem is the Legendre-equivalent frontier and is not
assumed to be currently available.

### Gap P4 — PHZ observer formalization

Need a later, separate residue-wave observer if PHZ is to become a formal API.
It should describe reserved/unreserved positions relative to a finite active
prime set and should not define primality outside a certified Body.

### Gap P5 — algebraic naturality / unit transport facade

Need reconnaissance of current CosmicFormula map lemmas before adding anything.
The desired result is a reusable algebraic layer that works before natural
number, order, or prime assumptions are introduced.

## 13. Immediate conclusion

The repository already contains most of the mathematical ingredients.
The missing work is predominantly **semantic integration and bridge design**.

The initial Primitive project should therefore follow this rule:

> Reuse theorem owners, add missing semantic duals, and introduce only the
> thinnest application bridges needed to expose the common structure.

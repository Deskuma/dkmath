# Mathematical core

For

```text
0 < m ≤ squareBody P = P^2 + 2P = (P+1)^2 - 1,
```

any prime `p > P` satisfies

```text
p^2 ≥ (P+1)^2 > m.
```

Therefore:

1. no prime `p > P` can occur twice in `m`;
2. two distinct primes `p,q > P` cannot both divide `m`;
3. if one such prime `p` divides `m`, then after writing `m = p*k`, every prime divisor of `k` is at most `P`;
4. hence `k` is `PrimeScaleGeneratedBy (primeScalesUpTo P)`;
5. `p` is a unique finite-world `FreshPrimeDirection`, and `Nat.Coprime p k`.

The resulting square-Body dichotomy is:

```text
m is entirely generated by old prime scales
or
m = p * k
  with one unique fresh prime p > P,
  old-generated k,
  and gcd(p,k)=1.
```

This is finite-world freshness only. It is not Zsigmondy/PrimitiveBeam first occurrence.

## 1. Large-prime depth-one bound

Prove a direct square bound such as:

```lean
theorem not_prime_sq_dvd_of_anchor_lt_of_le_squareBody
    {P m p : ℕ}
    (hm : 0 < m)
    (hmUpper : m ≤ squareBody P)
    (hp : Nat.Prime p)
    (hlarge : P < p) :
    ¬ p ^ 2 ∣ m
```

The positivity hypothesis matters because every positive number divides `0`.

Use the exact square-Body endpoint rather than asymptotics:

```text
P < p
→ P+1 ≤ p
→ (P+1)^2 ≤ p^2

p^2 ∣ m and 0<m
→ p^2 ≤ m

m ≤ squareBody P < (P+1)^2
```

Do not introduce a valuation API.

## 2. Uniqueness of a large prime divisor

Prove:

```lean
theorem eq_of_large_primes_dvd_le_squareBody
    {P m p q : ℕ}
    (hm : 0 < m)
    (hmUpper : m ≤ squareBody P)
    (hp : Nat.Prime p)
    (hq : Nat.Prime q)
    (hpLarge : P < p)
    (hqLarge : P < q)
    (hpd : p ∣ m)
    (hqd : q ∣ m) :
    p = q
```

Intended proof if `p ≠ q`:

```text
p*q ∣ m
(P+1)^2 ≤ p*q
p*q ≤ m ≤ squareBody P < (P+1)^2
```

Use prime coprimality / existing `Nat.Prime` divisibility lemmas. No factorization enumeration.

## 3. Large prime gives a finite-world fresh direction

Expose the finite-world bridge, either as a helper or inside the final package:

```lean
theorem freshPrimeDirection_of_anchor_lt_prime_dvd
    {P m p : ℕ}
```

This theorem itself is not square-specific, so if it clearly belongs in `FinitePrimeWorld.lean`, placing it there is acceptable. Keep scope small and avoid unnecessary movement.

A small helper characterizing, for prime `p`,

```text
p ∉ primeScalesUpTo P ↔ P < p
```

is acceptable if useful.

## 4. Cofactor reconstruction and depth removal

For a large prime divisor `p`, let

```text
k = m / p.
```

Expose exact reconstruction and no self-depth:

```text
p * k = m
¬ p ∣ k
Nat.Coprime p k
```

The no-self-depth result should come from item 1: `p ∣ k` together with `m = p*k` would force `p^2 ∣ m`.

A packaged theorem is preferred over three nearly identical proofs.

## 5. Every prime divisor of the cofactor is old

Main structural theorem:

```lean
theorem primeScaleGeneratedBy_div_of_large_prime_dvd_le_squareBody
    {P m p : ℕ}
    (hm : 0 < m)
    (hmUpper : m ≤ squareBody P)
    (hp : Nat.Prime p)
    (hpLarge : P < p)
    (hpd : p ∣ m) :
    PrimeScaleGeneratedBy (primeScalesUpTo P) (m / p)
```

For any prime `q ∣ m/p`:

```text
q ∣ m.
```

If `P < q`, item 2 forces `q = p`; then `p ∣ m/p`, contradicting item 1. Therefore `q ≤ P`, hence `q ∈ primeScalesUpTo P`.

Also prove the quotient is nonzero as required by `PrimeScaleGeneratedBy`.

## 6. Unique fresh-factor package

Package the previous statements in one theorem. Preferred shape:

```lean
theorem squareBody_large_prime_split
    {P m p : ℕ}
    (hm : 0 < m)
    (hmUpper : m ≤ squareBody P)
    (hp : Nat.Prime p)
    (hpLarge : P < p)
    (hpd : p ∣ m) :
    let k := m / p
    p * k = m ∧
    PrimeScaleGeneratedBy (primeScalesUpTo P) k ∧
    Nat.Coprime p k ∧
    FreshPrimeDirection (primeScalesUpTo P) m p ∧
    ∀ ⦃q : ℕ⦄,
      FreshPrimeDirection (primeScalesUpTo P) m q → q = p
```

Equivalent tuple ordering is fine.

The last clause is the finite-world uniqueness statement: there is at most one fresh prime direction in the square Body.

If cleaner, expose the uniqueness independently:

```lean
theorem freshPrimeDirection_unique_of_le_squareBody ...
```

and reuse it in the package.

## 7. Whole square-Body old-or-one-fresh dichotomy

This is the main checkpoint theorem.

For every positive point in the square Body, prove a finite structural dichotomy of the form:

```lean
theorem primeScaleGeneratedBy_or_uniqueFresh_split_of_le_squareBody
    {P m : ℕ}
    (hm : 0 < m)
    (hmUpper : m ≤ squareBody P) :
    PrimeScaleGeneratedBy (primeScalesUpTo P) m ∨
      ∃ p k,
        Nat.Prime p ∧
        P < p ∧
        FreshPrimeDirection (primeScalesUpTo P) m p ∧
        p * k = m ∧
        PrimeScaleGeneratedBy (primeScalesUpTo P) k ∧
        Nat.Coprime p k ∧
        (∀ ⦃q : ℕ⦄,
          FreshPrimeDirection (primeScalesUpTo P) m q → q = p)
```

Proof strategy:

- classical split on whether `m` has a prime divisor `p > P`;
- if none exists, every prime divisor of positive `m` lies in `primeScalesUpTo P`, hence `PrimeScaleGeneratedBy`;
- if one exists, use the unique-fresh split package.

Equivalent formulations using an existential `FreshPrimeDirection` split are acceptable.

If cheap, prove the two branches are incompatible:

```text
PrimeScaleGeneratedBy old m
→ no FreshPrimeDirection old m p.
```

Do not let this optional theorem dominate the checkpoint.

# Interpretation to preserve in docstrings

State clearly:

- the theorem is generic square-Body arithmetic, not a Legendre theorem;
- `primeScalesUpTo P` is the old finite prime world;
- a prime `> P` is fresh only relative to that finite world;
- the square bound forces at most one such fresh prime divisor and forces it to depth one;
- after removing that unique fresh factor, the cofactor is entirely old-prime-generated;
- `PrimeScaleGeneratedBy` describes prime support, not exponent depth;
- the result does not assert that a fresh factor always exists;
- it does not assert primitive origin / first occurrence in the Zsigmondy sense.

This is the intended Primitive interpretation:

```text
square-Body point
   = old-generated
or = old-generated × one unique fresh prime
```

with no possibility of two fresh directions inside the same Body point.

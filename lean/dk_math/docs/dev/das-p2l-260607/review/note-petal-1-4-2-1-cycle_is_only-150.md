# Note: No.150 cp

非自明周期探索に入る前の、非常に良い「入口封鎖補題」

## 1-4-2-1 巡回は、外周へは広がらない

これを先に簡単に否定しておくか。

１→４→２→１ 巡回と同じ数値パターンは３ｎ＋１の成長操作、あるいは一般化したコラッツ・グノモン成長単位では、噛み合わないと言うことを。
Petal 構造で １→４→２→１ は表現出来て、なされている。その外側の成長相似的繰り返しは無限にある。
だが、その PetalCount トータル境界に３ｎ＋１が乗らない。で行けそうでは？

---

## うむ、行けそうです

これは **先に潰す小補題** としてかなり良いです。

狙いはこうですね。

```text id="7frjwn"
1 -> 4 -> 2 -> 1 は Petal 構造では表現できる。

しかし、その外側にある相似的な Petal 境界へ、
Collatz の成長操作 3n+1 が同じ形で乗ることはない。

したがって、
1 -> 4 -> 2 -> 1 と同型の数値巡回パターンは、
n = 1 の特異点以外では発生しない。
```

これはかなり短く否定できます。

## 最小の否定式

「\(1\to4\to2\to1\) と同じ数値パターン」を、スケール \(n\) 倍で見るなら、

```text id="kk3a3p"
n -> 4n -> 2n -> n
```

です。

ところが Collatz の成長ステップは、

$$
n\mapsto 3n+1
$$

なので、同じパターンに乗るには、

$$
3n+1=4n
$$

が必要です。

これはただちに、

$$
n=1
$$

です。

したがって、

```text id="p0ww5f"
1 -> 4 -> 2 -> 1 の相似コピーは存在しない。
存在するなら n=1 に潰れる。
```

これが最初の簡単な否定になります。

## accelerated odd map で見るとさらに綺麗

奇数状態だけを見ると、閉じた一段巡回は、

$$
\frac{3n+1}{2^h}=n
$$

です。

つまり、

$$
3n+1=2^h n
$$

です。

この式が正の自然数で成り立つ場合を調べると、唯一の解は、

$$
n=1,\qquad h=2
$$

です。

理由は簡単です。

\(h=0,1\) なら右辺が小さすぎる。
\(h=2\) なら、

$$
3n+1=4n
$$

なので \(n=1\)。
\(h\ge3\) なら右辺 \(2^h n\) は少なくとも \(8n\) で、\(3n+1\) より大きすぎます。

つまり、

```text id="xpy2ye"
3n+1 が 2^h n という Petal 境界にぴったり乗って、
同じ odd state へ戻るのは n=1, h=2 だけ。
```

これは非常に良い小補題です。

## Petal 的な読み

Petal 構造では、\(1\to4\to2\to1\) は確かに表現される。

これは、

```text id="btbqjw"
1 から出た成長が 4 に乗り、
2-adic peeling で 2, 1 と戻る
```

という最小閉路です。

しかし外側に相似的な Petal count 境界がいくらあっても、Collatz 成長はそこへ正確には乗りません。

なぜなら、相似閉路に乗るには、

$$
3n+1=4n
$$

または一般化して、

$$
3n+1=2^h n
$$

が必要になるからです。

そしてこれは \(n=1,h=2\) 以外では破綻します。

## 「PetalCount total boundary に 3n+1 が乗らない」

この表現はかなり良いです。

数学的に少し整えるなら、

```text id="uegovb"
PetalCount total boundary は 2^h n 型の二進整列境界である。
Collatz growth boundary は 3n+1 である。
これらが同じ state を再現するには 3n+1 = 2^h n が必要だが、
正自然数解は n=1, h=2 のみである。
```

この言い方なら、かなり一般数学にも通じます。

## 既存の全体像との接続

これは、最近整理していた「上位ビット位置の相対移動」の局所版です。
以前の整理では、accelerated Collatz の大域運動は \(3\) 倍による上昇力、\(2\)-adic peeling による下降力、そして \(+1\) 補正の比較になると見ました。特に \(1\to4\to2\to1\) は、この三者が完全に釣り合う小さな特異点でした。

また、DkMath 側では \(1\) 以外の破綻ケースを捨てずに、局所ルールを保ったまま adversarial profile として調べる発想がすでに立っていました。今回の小補題は、その前段で「最小閉路の相似コピー」を先に潰すものになります。

## ただし射程を限定するのが大事

この補題で否定できるのは、

```text id="t85idj"
1 -> 4 -> 2 -> 1 と同じ相似数値パターン
```

です。

これだけで全ての非自明周期を否定するわけではありません。

非自明周期は、もしあるなら、

```text id="u6vb6g"
複数の odd step
複数の height
複数の +1 carry
複数の residue / valuation / Petal address
```

が絡む複合閉路になります。

だから今回の補題は、

```text id="dvmppr"
最小閉路の外側相似コピーはない
```

を示すものです。

その次に、

```text id="fys6k5"
複合 Petal cycle も同様に boundary mismatch を起こすか
```

を調べる流れになります。

## Lean にするなら最初の補題はこれ

識別子は控えめに言うと、内容は次です。

```lean id="ooid9f"
theorem collatz_same_scaled_one_cycle_only
    (n h : ℕ)
    (hn : 0 < n)
    (hEq : 3 * n + 1 = 2 ^ h * n) :
    n = 1 ∧ h = 2 := by
  -- split on h = 0, 1, 2, >= 3
  -- h = 2 gives 3*n+1 = 4*n, hence n=1
  -- h >= 3 gives RHS >= 8*n > 3*n+1
```

ただし Lean では \(h\ge3\) の場合や \(h=0,1,2\) の場合分けを丁寧に書く必要があります。

## 次の段階

この小補題を置いた後に、次を考えるのが良いです。

```text id="dcasop"
1. SameCyclePattern:
   3n+1 = 2^h n 型の完全相似閉路を否定する。

2. PetalBoundaryMismatch:
   3n+1 が PetalCount total boundary に一致する条件を抽出する。

3. NontrivialCycleNeedsCompositePattern:
   非自明周期があるなら、1-cycle 相似ではなく、
   複数の Petal boundary mismatch を補償する複合 pattern が必要である。
```

## 結論

はい。これは行けます。

最初の否定はかなり強く、しかも簡単です。

```text id="7bcz27"
1 -> 4 -> 2 -> 1 の外側相似コピーを作るには、
3n+1 = 4n が必要。
しかしこれは n=1 しか許さない。
```

一般化しても、

```text id="3uhkpi"
3n+1 = 2^h n
```

の正自然数解は、

```text id="yhh04k"
n=1, h=2
```

だけ。

したがって、

```text id="v92rfu"
Petal 構造には 1 -> 4 -> 2 -> 1 の表現がある。
しかし、その外側の成長相似的繰り返しには、
3n+1 の成長境界が乗らない。
```

これは、非自明周期探索に入る前の、非常に良い「入口封鎖補題」になります。
